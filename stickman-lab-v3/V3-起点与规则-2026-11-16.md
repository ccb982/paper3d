## 3. v3 规则

物理真实性降级为可选项。目标是游戏里看着稳、能演出、能继续做动作。

允许：

- 关节锁死、轴向锁、硬限位、冻结 DOF。
- 增大腿/足/髋的质量、惯量、摩擦、被动刚度。
- 直接给关节或质心加虚拟回正力/力矩。
- IK/姿态目标优先，不要求和接触力/动力学完全自洽。
- 宁可“凭空发力”，也不让角色软倒。
- 关闭 QP；QP 最多保留 shadow。

禁止：

- QP 接管命令层。
- 同一关节两套基础力互相打架。
- 为了数学自洽牺牲蹲姿稳定。

优先级：视觉稳定 > 姿态可读 > 物理真实。

新增作弊开关统一用 `V3_` 前缀，避免和 v2 的 `SQC_*` 混淆。

## 6.1 当前命令层（不是执行层）

确认：**下一步重做的是命令层**。

- PD/执行层：冻结。
- ConstraintLayer：保持唯一约束层，不拿来当回正器。
- PredictionLayer：保持只读，输出 `CoM/CoP/DCM/CMP`。
- 侧向回正：从“连续 PD + 外部髋/root”迁移到 **IP-DCM 间歇预测 DCM**。
- 目标：侧向冲量后不换号/不过冲，而不是继续加阻尼/增益。

设计入口：

```text
docs/神经命令层架构-2026-11-06.md §24（IP-DCM）
docs/预测层-架构-2026-11-16.md
docs/约束层-架构-2026-11-16.md
```

核心规则：

```text
OFF  近稳定流形：主动力=0，让 LIPM 自己收敛
ON   远离稳定流形：低增益 DCM/PD
BRAKE 预测过中心/过目标：短脉冲反向阻尼
HOLD 刚刹完：只保留 intrinsic damping
STEP 可选：p_ref 超出支撑/TTB 过低
```

严格禁止：

```text
连续延迟 PD 在中心附近继续满力
第二个侧向回正写手
靠继续加 hip/root 增益解决换号
QP/WBC 接管命令层
```

两个极限环一起拆：

```text
命令层：连续 IK/CoP/PD 在中心附近继续发力
辅助回正：独立 delay/ramp/阈值，另一套相位
```

只拆一个会暴露另一个。目标：

```text
一个 LateralPhase
命令层拥有相位
辅助回正只做执行器
OFF/HOLD：两边侧向力都=0
ON：命令层主导，辅助按 scale 执行
BRAKE：只允许短脉冲
```

A/B 必须跑三组：命令层 only、辅助 only、共用相位。只拆一边不算完成。

## 8. 伺服切换前馈规则（2026-11-17 补充）

状态切换只切命令实例，PD 不换。但切换后的命令**不能重新从零求支撑力**：

```text
切换瞬间：
  ff0 = 当前 executor.applied / 实际支撑力
  qRef0 = 当前关节角
切换后：
  ff(t) = (1-u)·ff0 + u·ff_ik
  qRef(t) = (1-u)·qRef0 + u·qRef_ik
  u = smooth(t / T_handoff)
```

`ff_ik` 必须由同一帧 IK 反解位置 + Fz/CoP 预算算得；不能把旧 base 当新命令的支撑力，也不能切换首帧直接输出满 PD/满支撑。

当前 SquatCommand 只有骨架，缺 IK/Fz/力链，因此切换后力求解不成立；详见《神经命令层架构》§25.11。

## 9. 下蹲膝盖横向目标（2026-11-17）

实测下蹲后半程：

```text
kneeZ - footZ: 3.4cm → 13.9cm
```

膝盖持续外漂，不像人类。原因不是 knee0 角不够，而是命令层没有“膝关节世界位置”目标。

人类约束：

```text
脚固定
髋后下
膝盖在脚上方附近
髋内收/内旋
踝背屈
```

正确实现：

```text
K_ref = 脚上方膝位置
→ H*（髋目标）
→ solveShankIKTarget
→ hip0/knee0/foot0 qRef
→ 高 kp/kd
```

禁止：

```text
只改 knee0
只加 knee0 辅助力
只加被动刚度
hip1 扭转锁
q0 固定偏移
```

下蹲过程先放宽 hip/knee/foot 限位；交接后按状态收回。详见《神经命令层架构》§25.12。

## 10. 蹲下大腿内收专用命令（2026-11-17）

大腿内收从 `SquatDownCommand` 中拆出，作为下蹲专用子命令：

```text
SquatDownCommand
  ├─ PoseCommand
  ├─ AdductionCommand
  ├─ SupportCommand
  └─ ContactLayer
```

`AdductionCommand` 只输出髋/膝横向目标，不写支撑/抓地。

膝内收是变量：

```text
kneeAdductionTarget = f(p, fz, com, 站距, 脚外旋)
```

不是固定 `kneeZ=footZ+6mm`。

论文：

- Straub & Powers 2024（IJSPT）
- Escamilla 2001
- DKV review 2020（IJERPH 17:8208）
- Neutral/squeeze/outward squat 2015
- Stance width/toe direction 2021
- Two-Segment Foot Model for Squat 2017

禁止固定 q0 偏移、knee0 辅助力、hip1 世界角锁、kneeZ-footZ 直接反馈。

当前基线：`npm run squat → fall=1.975s`。后续只新增 `AdductionCommand`，不再往现有稳定层塞补丁。

## 11. 蹲下专用内收/支撑模块（2026-11-17）

```text
SquatDownCommand
  ├─ PoseModule
  ├─ AdductionModule   双侧独立：hip0/knee0 目标
  ├─ SupportModule     Fz/CoP/ID
  └─ PD
```

顺序固定：

```text
Pose → Adduction → Support → PD
```

Adduction：

```text
K* = footZ + 可变膝偏移
A* = footZ
额状面两连杆 IK
→ hip0Ref/knee0Ref
hip1/knee1/foot1 本地 0
```

Support：

```text
fzL + fzR = W
fzL = clamp(W/2 + Δ/2, 0.2W, 0.8W)
ID(q_ik, fz, CoP)
```

不能用固定 q0 偏移、knee0 辅助力、世界角锁，也不能让 Adduction/Support 并行改同一轴。

详见《神经命令层架构》§25.14。当前仅完成架构与稳定基线。
