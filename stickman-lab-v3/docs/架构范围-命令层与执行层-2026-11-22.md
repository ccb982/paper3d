# 架构范围：命令层、执行层、接触层（2026-11-22）

## 1. 总范围

本架构只处理：

```text
低速
双脚支撑
蹲姿稳定/小偏差
不迈步
不上身主动回正
```

目标：

```text
先稳住蹲姿
再谈 CoM/CoP/IK 预测
```

---

## 2. 分层与所有权

```text
物理/接触层
  Rapier 接触
  body linear/angular damping
  脚/地接触
  不归命令层直接写冲量

执行层
  关节 PD / D
  被动 K/B
  执行器限幅
  Drive / Executor

支撑层
  tauBase
  当前 q + LoadState(fz/CoP)
  含 hip / knee / ankle

tauCorr 层
  只修 tauBase
  低频
  有限幅/限速率
  不接管轴
  不改脚世界位姿

WorldGrip
  脚世界位姿
  始终开
  最高优先级

上层
  CoM / CoP / IK 预测
  SAG / LAT 大偏差
  暂不参与
```

单轴单帧：

```text
只有一个主动写手
tauCorr 不是第二写手
```

---

## 3. 命令层能做什么

允许：

```text
目标角
前馈力矩
tauBase 的低频修正
tauCorr 的受限修正
```

不允许：

```text
直接给脚 applyImpulse
直接写接触力
高频虚拟阻尼
改脚世界位姿
和 PD 对拉
绕过执行器限幅
```

原因：

```text
命令层是低频意识层
不是接触层
不是机械阻尼
```

---

## 4. tauCorr 范围

当前只允许：

```text
Δtau_corr = Δtau_support
```

`Δtau_support`：

```text
补 tauBase 的已知低频缺口
含 handoff 连续性
```

暂不允许：

```text
CoP 回正
CoM 回正
IK 预测
SAG / LAT
加速度闭环
```

门控：

```text
SQC_PREDICT_ON=0
SQC_ANKLE_COP_ON=0
SQC_ACC_CORR_GAIN=0
```

这些不是删除，是**当前不启用**。

---

## 5. 阻尼范围

保留：

```text
body linear/angular damping
Drive 执行层阻尼
foot2 B
人体范围 B
```

已删除：

```text
contactDamper 直接 applyImpulse
```

原因：

```text
它绕过 tauCorr、预算和关节限幅
既不是物理阻尼，也不是合法命令层修正
```

高频接触由：

```text
物理接触
执行层 B
```

不在命令层处理。

---

## 6. 观测范围

`motionAcceleration` 只做观测：

```text
qdd
body linear/angular acc
COM acc
```

不参与控制。

高精度加速度/完整 ID 尚未进入控制闭环。

## 8. 验收边界

当前阶段只验收：

```text
静态不炸
WorldGrip 不改脚
tauCorr 不改所有权
无隐藏接触冲量
无 CoP/CoM/IK 预测介入
支撑/阻尼/限幅有回读
```

稳定时间、3–4s、人体加速度水平属于下一阶段。
