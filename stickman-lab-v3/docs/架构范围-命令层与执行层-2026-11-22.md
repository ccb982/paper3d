# 架构范围：命令层、执行层、接触层（2026-11-22）

## 1. 总范围

本架构只处理：

```text
低速
双脚支撑
蹲姿稳定/小偏差
不迈步
不上身主动回正
```

目标：

```text
先稳住蹲姿
再谈 CoM/CoP/IK 预测
```

---

## 2. 分层与所有权

```text
物理/接触层
  Rapier 接触
  body linear/angular damping
  脚/地接触
  不归命令层直接写冲量

执行层
  关节 PD / D
  被动 K/B
  执行器限幅
  Drive / Executor

支撑层
  tauBase
  当前 q + LoadState(fz/CoP)
  含 hip / knee / ankle

tauCorr 层
  只修 tauBase
  低频
  有限幅/限速率
  不接管轴
  不改脚世界位姿

WorldGrip
  脚世界位姿
  始终开
  最高优先级

上层
  CoM / CoP / IK 预测
  SAG / LAT 大偏差
  暂不参与
```

单轴单帧：

```text
只有一个主动写手
tauCorr 不是第二写手
```

---

## 3. 命令层能做什么

允许：

```text
目标角
前馈力矩
tauBase 的低频修正
tauCorr 的受限修正
```

不允许：

```text
直接给脚 applyImpulse
直接写接触力
高频虚拟阻尼
改脚世界位姿
和 PD 对拉
绕过执行器限幅
```

原因：

```text
命令层是低频意识层
不是接触层
不是机械阻尼
```

## 4. tauCorr 范围

当前只允许：

```text
Δtau_corr = Δtau_support
```

`Δtau_support`：

```text
补 tauBase 的已知低频缺口
含 handoff 连续性
```

暂不允许：

```text
CoP 回正
CoM 回正
IK 预测
SAG / LAT
加速度补偿
```

门控：

```text
SQC_PREDICT_ON=0
SQC_ANKLE_COP_ON=0
SQC_ACC_CORR_GAIN=0
```

这些不是删除，是**当前不启用**。

## 4.1 加速度三阶段

顺序固定，不能跳：

```text
阶段 A：削加速度
  阻尼 / 接触 / 执行层
  先把加速度降到人体合理水平

阶段 B：精确检测加速度
  EKF / momentum observer
  只做观测，不闭环

阶段 C：tauCorr 加速度补偿
  Δtau_acc = tauNeed − tauBase
  小修正、有限幅
```

阶段 A 不做完，不进入 B。
阶段 B 不做完，不进入 C。

### 阶段 A：阻尼削加速度

目标是实际加速度水平，不是“阻尼数值”：

```text
|a_com| p95 < 0.3 m/s²
|qdd|  p95 < 100 rad/s²
接触冲量不出现单帧尖峰
```

手段：

```text
body damping
物理/接触弹簧-阻尼
执行层 B
支撑/命令 slew
降低主动 Kp/Kd
```

禁止：

```text
命令层直接 applyImpulse
用高频虚拟阻尼硬顶尖峰
用大 Kd 代替接触柔顺
```

### 阶段 B：精确检测

```text
关节 qdd：EKF / momentum observer
肢体/COM：IMU + 编码器 + 接触力
不能裸差分
不能把 comAcc 差分当控制输入
```

阶段 B 的输出：

```text
qdd_est
a_com_est
置信度 / 延迟 / 饱和标记
```

### 阶段 C：补偿

```text
Δtau_acc = tauNeed − tauBase
```

只在：

```text
检测置信度足够
加速度缺口稳定
支撑有效
```

时开启。

## 11. 下一步实施：动态支撑

不拆现有 `postureHoldFrame`，按增量做。

### Step 1：加速度观测器

```text

```

```text

```

要求：

```text
不用裸 qdd

```

### Step 2：动态支撑接口

保留：

```text
solveStaticLegTorques(...)
```

扩展：

```text
solveStaticLegTorques(..., boundary, dynamic)
```

`dynamic` 只包含：

```text
hip / knee / ankle 动态力矩
```

默认不传 = 旧行为完全不变。

### Step 3：postureHold 接入

在现有位置加：

```text
idBase = solveStaticLegTorques(..., fzBudgetTarget)
dyn    = solveLegDynamics(qdd_est, contact)
idUse  = idBase + clamp(dyn)
```

保留：

```text
fzBudget
LP + slew
PD
WorldGrip
handoff
```

`SQC_LEG_DYN_ON=0` 时行为与当前完全一致。

### Step 4：A/B 验收

先只开动态支撑：

```text

```

```text

```

未改善就保持关闭，不进入 tauCorr。

### Step 5：残差才给 tauCorr

动态支撑稳定后：

```text

```

只补残差，限幅。

CoM/CoP/IK 继续关闭。

### 12.1 阻尼

关节阻尼量级：

```text
hip  B≈8   人体约 2–9
knee B≈3   人体约 1–3
ankle B≈2  人体约 0.8–3
```

但结构不完整：

```text

腿部 wobbling mass        关闭

主动 PD 刚度               仍偏高
```

```text

```

所以：

```text
阻尼数值部分对齐
```
