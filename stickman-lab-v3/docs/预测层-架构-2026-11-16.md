# CoM / CoP 预测层架构（PredictionLayer）

> 2026-11-16 晚 approved：预测层 `lastT` 时钟已修（每帧推进，`nextT` 只控 50ms 节拍）；侧向相位源已启用并被命令层/辅助层共用。用户确认当前 Web 版本非常好，不再调相位参数。


日期：2026-11-16
适用：`stickman-lab-v3`

## 0. 结论

回正控制器不应该直接用当前 `com/cop` 做反应式 PD，而应该使用：

```text
当前状态 + 模型 → 预测未来 0.1~0.3s 的 CoM/CoP/DCM/CMP
→ 回正目标用预测值
→ 实际值只做模型误差修正/fallback
```

新增一个**只读** `PredictionLayer`：

```text
Sensors（q/qd/contact/fz/CoP/GRF）
  → PredictionLayer（当前 + 预测状态）
  → Command/Righting（用预测值算目标/刹车）
  → ConstraintLayer（软/硬约束）
  → PD/Executor
```

预测层不写力，不抢写手；它只提供状态。

## 1. 为什么现在会过头

当前控制用的是：

```text
e = ref − com(now)
tau = Kp·e − Kd·comVel(now)
```

问题：

- 力到 CoM/CoP 有延迟（执行器、接触、滤波）；
- 等误差反号才刹车，必然过冲；
- 髋的 FF/角动量没有进模型，CoM 预测失真；
- CoP 是“结果”，不是“输入”，当前 CoP 不能代表下一步 CoP。

## 2. 模型

### 2.1 CoM / DCM

```text
ω = sqrt(g / h_com)
xdd = ω²·(x − p)          # p = CoP
ξ = x + v/ω              # DCM / capture point
ξdot = ω·(ξ − p)
```

离散一步：

```text
ξ_next = ξ + dt·ω·(ξ − p)
x_next = x + dt·v
v_next = ω·(ξ_next − x_next)
```

### 2.2 CoP 预测

CoP 不是直接用当前测量值，而是预测：

```text
p_cmd = 目标 CoP / 支撑面 clamp
p_pred = p_now + α·(p_cmd − p_now)     # 一阶执行/接触延迟
```

- `α` 可标定（例如 `dt/τ_cop`，τ_cop≈0.03~0.08s）；
- 若脚失接触，切到“无支撑”模型，并触发 fallback。

### 2.3 髋 / 角动量 / CMP

```text
L = Σ [ I_i·ω_i + m_i·(r_i − com) × v_i ]     # 质心角动量
Ldot ≈ (L − L_prev)/dt
CMP = p − Ldot/(m·g)
```

髋力矩预测：

```text
Ldot_pred = Ldot_now + (τ_hip/J_hip)·dt
CMP_pred = p_pred − Ldot_pred/(m·g)
```

不需要 QP；只需要 CMM 的简化版或直接对刚体求和。

### 2.4 接触

```text
contact_l/r, fz_l/r, cop_l/r
```

接触丢失时：

- CoM 模型切自由落体/无支撑；
- 预测层标记 `contactValid=false`；
- 回正层退回实际值 + 约束层安全筒。

## 3. PredictionState

```ts
interface PredictionSample {
  t: number;
  com: { x: number; y: number; z: number };
  comVel: { x: number; y: number; z: number };
  cop: { x: number; z: number };
  dcm: { x: number; z: number };
  cmp: { x: number; z: number };
  lDot: { x: number; y: number; z: number };
}

interface PredictionState {
  now: PredictionSample;
  horizon: PredictionSample[];   // 0.1~0.3s
  overshoot: number;             // 预测越过目标的量
  timeToContact: number;         // 到支撑边界的预测时间
  contactValid: boolean;
  modelError: number;            // 上一拍预测 vs 实际
}
```

## 4. 回正怎么用预测值

### 4.1 CoM 刹车

```text
ξ_ref = 目标 DCM
ξ_pred = horizon 末端 DCM（或一步预测）
e_pred = ξ_ref − ξ_pred

p_ref = clamp(ξ_pred + k·e_pred, 支撑面), k > 1
```

- 用 `p_ref` 而不是当前 CoP 误差；
- 如果 `p_ref` 饱和，进入髋/飞轮或安全筒；
- 预测下一步 `ξ_next`，若越过 `ξ_ref`，提前减小力。

### 4.2 预测“本次力”的效果

命令层在给出候选 `τ`/`p_cmd` 前，先调用：

```ts
const pred = predictor.predict(candidate);
```

选择满足：

```text
|pred.overshoot| < tol
|pred.cmp| 在支撑面内
|pred.tau| ≤ τmax
```

的候选；不满足就减小力或换 Hip 通道。这是 1D/小范围搜索，不是 QP。

### 4.3 髋

```text
e_cmp = CMP_ref − CMP_pred
τ_hip = clamp(Kp_cmp·e_cmp − Kd_cmp·Ldot_pred, ±cap)
```

- 髋只负责 CMP/角动量，不直接追 CoM；
- 髋的预测误差大时，降低髋权重，优先 CoM/筒。

## 5. 时序

```text
ControlModule.step(dt):
  1. sensors.update
  2. predictor.update(prevCommand, dt)     # 用上一拍命令预测
  3. command/righting 用 predictor.state()
  4. constraint layer
  5. drive/executor
```

- 预测层每物理步更新；
- 控制层可以用 `predict(candidate)` 做一次前向预测；
- 预测残差在下一个传感器拍更新，用于修正/回退。

## 6. 预测误差修正

```text
modelError = |predicted_(t) − actual_(t)|
```

- 小于阈值：正常使用预测；
- 大于阈值：预测权重下降，实际权重上升（互补滤波）；
- 连续超限：重置模型/切回实际 PD，并记录 `__PRED_ERR`。

## 7. 探针

```text
t, com_act, com_pred, cop_act, cop_pred,
xi_act, xi_pred, cmp_act, cmp_pred,
overshoot, modelError
```

验收：

- 预测误差 < 5%（0.1s 内）；
- 无过冲（overshoot ≤ 1~2cm）；
- 髋 CMP 不出支撑面；
- fall time 提升。

## 9. 实施顺序

1. **只读预测层**：LIPM/DCM + CoP 一阶延迟，输出 `__PRED`，不改控制；
2. **用预测 DCM 做 CoP 目标**，A/B 过冲；
3. **加 L/CMP**（髋），预测候选力矩效果；
4. **接进唯一 ConstraintLayer**，作为 `PredictiveCopConstraint`；
5. 最后再做髋的 solver-level 硬锁，预测层不负责硬锁。

## 11. 周期发力/预测/刹车的论文支持

这种做法就是 **receding-horizon / intermittent control**：

- Kajita et al. 2003, *Biped walking pattern generation by using preview control of zero-moment point*：每个周期预测未来 ZMP/CoM，执行第一步再重算。
- Mayne et al. 2000, *Constrained model predictive control: Stability and optimality*：receding horizon 的标准框架。
- Pratt et al. 2006, Capture Point：给定当前 CoM 状态，解析算出“刹停点”。
- Koolen et al. 2012, Capturability / CMP：角动量参与后的可刹停区域。
- Sugihara & Yamamoto 2017 / Frontiers 2022, *Step-and-Brake Controller*：周期性的 step/brake，和你的“发力一小段 → 预测 → 刹车”一致。
- Bottaro et al. 2008 / Asai et al. 2009, intermittent feedback control：人类平衡也是间歇式反馈，不是连续满力。

## 12. 侧向 IP-DCM：预测层怎么被命令层消费（2026-11-16）

下一刀是**命令层**，不是继续改 PD。

```text
PredictionLayer（只读）
  → 输出 e, v, ξ, ξ_pred, TTB, CoP/CMP
  → CommandLayer IP-DCM
      OFF / ON / BRAKE / HOLD / STEP
  → 目标角 / 前馈 / CoP 目标
  → PD / Executor
```

侧向状态：

```text
ω = sqrt(g/h)
e = z - z_ref
ξ = e + v/ω
稳定流形：v = -ω e ⇔ ξ = 0
ξ_pred = predict_LIPM(e, v, τ_eff, p)
```

命令层只用预测值做相位判断：

```text
off → on   when |ξ_pred| > ξ_on
on  → off  when |ξ_pred| < ξ_off
ξ_on > ξ_off，且有 T_on_min / T_off_min
```

原则：

```text
预测层不写力；
命令层不直接写关节力矩；
PD 只执行目标/前馈；
约束层仍是唯一约束。
```
