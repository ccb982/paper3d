# 脚抓地最高优先级：重构方案（2026-11-26）

## 0. 一句话

**脚接触是 6D 硬约束，不是 FootWorldTarget + AnkleComp PD。**

支撑 W 只能在脚不滑、不转的接触域内求解；踝只负责把 W 变成关节力矩。

## 1. 当前实现

```text
FootWorldTarget
  capture foot pose

AnkleComp
  qRelTarget = shank⁻¹ · footTarget
  qRef = 当前 + 0.5 · error

FootAnkleModule
  kp/kd PD

squatClean
  worldIk / footTargetPose
  ankle direct torque
```

当前语义：

```text
脚追世界姿态目标
≠
脚固定接触约束
```

所以支撑 direct torque 仍然可以把脚推转。

## 2. 论文做法

### 2.1 固定接触

Kim et al. 2018 / Del Prete TSID / Bouyarmane：

```text
Jc(q) q̇ = 0
Jc(q) q̈ + J̇c(q,q̇) q̇ = 0
```

脚接触期间：

```text
position 不变
orientation 不变
velocity = 0
acceleration = 0
```

### 2.2 CWC

Caron 2015：

```text
U·W <= 0
```

包括：

```text
摩擦锥
CoP ∈ 支撑面
yaw moment 边界
```

### 2.3 不滑/不转判定

Rotella 2017：

```text
Fx² + Fy² <= μ² Fz²
CoP ∈ 支撑面
|τz| <= μz Fz
```

### 2.4 脚开始转

Atlas 2016：

```text
检测 foot rotation
→ 裁掉实际接触面
→ 更新 support polygon
→ 加脚姿态恢复目标
```

不是继续在旧 CoP 上加踝力矩。

## 3. 目标架构

```text
Stage 0：Foot contact task / grip gate
Stage 1：Support W QP
Stage 2：Damping in contact nullspace
Stage 3：Posture / righting
```

### Stage 0：Foot contact task

输入：

```text
foot target pose p*, q*
foot actual pose p, q
foot linear/angular velocity
contact state
CoP
CWC
fz
```

输出：

```text
gripOk
footPosErr
footRotErr
footVelErr
copInside
cwcOk
```

规则：

```text
gripOk =
  contact
  && CoP inside
  && CWC
  && fz >= fzMin
  && |posErr| < posMargin
  && |rotErr| < rotMargin
  && |vel| < velMargin
  && |angVel| < angVelMargin
```

gripOk 不成立时：

```text
支撑 W 不得继续增加
踝 direct torque 不得继续推脚
先做脚姿态/CoP 恢复
```

### Stage 1：W QP

变量：

```text
W_left, W_right ∈ R⁶
```

等式：

```text
JbᵀW = baseTarget
```

不等式：

```text
U·W <= 0
CoP ∈ 支撑面
fz >= fzMin
```

只有 gripOk 的接触脚进入 W QP。

W 不允许产生：

```text
脚 roll/pitch 的净力矩
脚切向滑动
```

### Stage 2：Damping

```text
只在接触零空间内
不能改变 CoP/CWC
不能改变脚姿态
```

### Stage 3：Posture/righting

```text
只改 qRef / CoP 目标
不生成接触力矩
```

## 4. 执行层

```text
foot：接触约束保持
ankle：相对 foot/shin 转动
```

踝力矩：

```text
τ = JᵀW
```

或完整 ID：

```text
M q̈ + C + G = JᵀW + Sᵀτ
```

不允许：

```text
支撑力矩直接推脚
foot PD 当成硬约束
```

## 5. 重构步骤

```text
1. 新建 FootContactTask
   - 从 FootWorldTarget 拿 target pose
   - 从 body 拿 actual pose/vel
   - 计算 6D pose/velocity error
   - 输出 gripOk

2. Stage 0 接入
   - gripOk 不通过 → 支撑 W 冻结/回退
   - 不再让 direct ankle torque 增加脚误差

3. Stage 1 接入
   - W QP 只包含 gripOk 的脚
   - CWC/CoP/fz_min 全量约束

4. 踝执行
   - W → Jᵀ → 关节力矩
   - 删除/降级 ankle direct support 对脚姿态的干扰

5. 验收
   - footPitch/Roll 误差 < margin
   - CoP inside
   - fz tracking
   - 不抬脚
```

## 5.1 实现状态（2026-11-26 晚）

已经做了：

```text
FootContactTask 前移到支撑/W 之前
FootPoseRecovery 默认开启
删除 grip gate/软缩放/横向力矩等实验分支
```

还没有做：

```text
W QP 没有读取 gripOk/foot contact task
support 仍然可以在脚不平时更新 W
FootPoseRecovery 仍是直接踝力矩，不是 contact task
没有 contact Jacobian 约束
没有 foot pose 恢复后再恢复 W 的状态机
```

实测仍然：

```text
footPitch/Roll 仍会变化
contact 存在，但接触模式退化
```

结论：

```text
“FootContactTask 先算”做了
“支撑不破坏抓地”还没做
“只动踝不动脚”还没真正成立
```

## 6. 当前代码问题

```text
FootWorldTarget 是目标级，不是约束级
AnkleComp 是 PD，不是接触任务
W QP 不知道脚姿态误差
ankle direct torque 会推脚
```

实测：

```text
footTargetPitch = 0°
footPitch 实际 4~12°
footRoll 实际 -12~-44°
contact 一直存在
```

说明：

```text
脚没丢接触
但接触模式在退化
```

## 7. 禁止

```text
禁止用 AnkleComp PD 代替 foot contact task
禁止支撑 W 直接推脚
禁止在脚已经 roll 时继续加支撑
禁止把 footTarget 当硬约束而不做误差/速度检查
```
