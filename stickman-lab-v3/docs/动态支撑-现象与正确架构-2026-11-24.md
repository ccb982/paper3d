# 动态支撑：当前现象、根因与正确架构

日期：2026-11-24

## 1. 这份文档解决什么

当前蹲姿交接后，脚基本站住，但髋会下沉，支撑力也跟着下降。

现象已经确认：

```text
hipY 下降
fzUse 下降
hip2Applied 下降
supportContactCount 下降
最后 fall
```

目标不是继续调一个 `fzUse` 数，而是重做支撑力：

```text
先有期望髋高/期望 COM
再有期望接触力
再有接触可行域
再有实际接触力反馈
最后才是关节力矩
```

## 3. 当前错误链路

现在的支撑计算大致是：

```text
实际 fz / fzTarget
→ fzUse
→ solveStaticLegTorques
→ idHip
→ hipFf
→ hip2Applied
```

问题：

```text
1. fzUse 跟着实际 fz 走
2. hipHeightScale 只缩放，不生成支撑目标
3. 实际 fz 低时，支撑目标反而低
4. 没有“髋高 → 期望支撑力”
5. 没有实际法向力反馈控制
6. contact count 掉时支撑模型没有切换
```

一句话：

```text
现在是“实际接触力决定支撑”
不是“期望髋高/COM 决定支撑”
```

## 4. 正确目标

支撑力必须是：

```text
持续、稳定的实际接触力
```

不是：

```text
fzUse 里的一个数
```

髋低时：

```text
支撑力增加
```

髋高时：

```text
支撑力减少
```

不是：

```text
fz 低 → 支撑低
fz 高 → 支撑高
```

## 5. 标准架构

### 5.1 最高层：世界抓地/接触约束

```text
脚世界位置
脚世界姿态
接触点集合
```

接触约束：

```text
p_foot = const
J_c q̇ = 0
J_c q̈ + J̇_c q̇ = 0
```

世界抓地是最高优先级，不能被 PD / 命令层覆盖。

只有：

```text
foot
ankle
```

是世界的；髋、膝、骨盆、上身都是局部的。

### 5.2 期望髋高/COM

```text
hipErr = hipTarget − hipY
hipVel = d(hipY)/dt

a_des = Kp_hip · hipErr − Kd_hip · hipVel
```

### 5.3 期望支撑力

```text
fzDes = 0.5 · m · (g + a_des)
```

髋低：

```text
hipErr 正
a_des 向上
fzDes 增加
```

髋高：

```text
hipErr 负
a_des 向下
fzDes 减少
```

这是方向正确的支撑力。

### 5.4 接触可行域

每只脚：

```text
fz >= 0
|ft| <= μ fz
CoP ∈ support polygon
```

必要时再分配左右脚：

```text
fzL + fzR = m(g + a_des)
```

不是单脚无限加。

### 5.5 实际 fz 反馈

```text
fzErr = fzDes − fzAct
```

如果实际接触力低：

```text
支撑目标增加
脚/腿往下压
```

不是降低支撑目标。

反馈只做修正，不能替代期望支撑力。

### 5.6 全身逆动力学

```text
τ = M(q)q̈ + C(q,q̇) + G(q) − J_c^T f_c
```

支撑力矩来自：

```text
重力 + 期望接触力 + 惯性项
```

不是：

```text
单点 fz + 拍脑袋 cap
```

### 5.7 变化率

```text
|dfz/dt| 有界
|dτ/dt| 有界
|dτ̇/dt| 有界
```

支撑可以慢，不能突变。

## 6. 正确执行顺序

```text
1. 世界抓地/接触约束
2. 期望髋高/COM
3. 期望接触力 fzDes
4. 接触可行域投影
5. 实际 fz 反馈
6. 全身逆动力学
7. tauCorr 残差
8. IK 回正
9. 最终输出
```

全部串行。

禁止：

```text
支撑和 IK 同时求解
支撑和加速度同时求解
QP 同时优化
```

## 7. 当前实现差距

| 项目 | 当前 | 应该 |
|---|---|---|
| 世界抓地 | 主要锁位置 | 位置 + 姿态 + 接触约束 |
| 期望支撑 | fzUse 跟实际 fz | hipTarget/COM → fzDes |
| 髋高 | 只缩放 | hipErr PD → fzDes |
| 实际 fz | 只观测 | 反馈修正 |
| 接触集合 | 迟滞 | 稳定接触集 + 切换 |
| 支撑 wrench | 部分投影 | fz/CoP/friction 全约束 |
| 逆动力学 | 近似 | M q̈ + C + G − Jᵀf |
| tauCorr | 小 cap | 剩余预算二次削 |

## 9. 重做步骤

### 第一步：接触集合

```text
contactLatch
contactCount
contactSince
contactLost
```

不允许单帧 contact count 掉 0 就直接清空支撑。

### 第二步：髋高 PD

```text
hipErr = hipTarget − hipY
a_des = Kp hipErr − Kd hipVel
fzDes = 0.5 m (g + a_des)
```

### 第三步：fz 反馈

```text
fzCmd = fzDes + Kf (fzDes − fzAct)
```

### 第四步：wrench 投影

```text
fz >= 0
|ft| <= μ fz
CoP ∈ polygon
```

### 第五步：逆动力学

```text
τ = M q̈ + C + G − Jᵀ f
```

### 第六步：残差

```text
tauCorr = −M qddRes
```

### 第七步：IK

```text
tauIK = IK 回正
```

只在支撑和 tauCorr 之后进入。

## 10. 验收标准

```text
1. hipY 不持续下降
2. fzDes 随 hipErr 单调变化
3. fzAct 跟随 fzDes
4. contactCount 不单帧掉 0
5. supportWrenchFeasible 保持
6. hip/knee/ankle 不长期饱和
7. 不开 IK 也能站住
8. 开 IK 后不破坏支撑
```

## 11. 一句话

```text
支撑力不是由实际 fz 决定的
是由期望髋高/COM 决定的
实际 fz 只做反馈
```
