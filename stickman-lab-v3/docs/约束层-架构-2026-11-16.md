# 唯一约束层（ConstraintLayer）架构（2026-11-16）

## 0. 目标

把关节限位、虚拟安全筒、后续 CoM/CoP 回正全部收进**一个约束层**。

```text
Sensors
  → Command（IK + base force + CoP）
  → PD / muscle（只执行）
  → ConstraintLayer（唯一外部约束出口）
  → Physics
  → project（硬约束投影，PBD 式）
```

不再新增独立的 root/lateral/foot lock/assist 写手。

## 1. 代码

```text
src/core/constraints/constraintLayer.ts
  Constraint 接口：id / priority / step / project
  ConstraintLayer：按 priority 顺序 step，物理后 project

src/core/constraints/jointLimit.ts
  JointLimitConstraint
  - 进入 squat 时捕获参考角
  - 每轴 ±25% 关节范围软带
  - 越界加回正力矩（外部通道）
  - 默认只做 hip/knee 的轴 0/2；SQC_JOINT_LIMIT_FOOT=1 加 foot

src/core/constraints/bodyTube.ts
  BodyTubeConstraint
  - 世界坐标虚拟筒
  - 半径 R、底 y0、顶 y1
  - 越界加弹簧阻尼外力
```

集成：

```text
ControlModule.constraints
  step：sensors.update 之后
  project：World.advance 物理步之后
  resetCourt：清空
```

## 2. 开关

```text
SQC_JOINT_LIMIT=1            # 默认开
SQC_JOINT_LIMIT_FOOT=1       # 默认开（包含 foot）
SQC_JOINT_LIMIT_FRAC=0.25
SQC_JOINT_LIMIT_KP/KD/CAP

SQC_TUBE=1                   # 虚拟安全筒
SQC_TUBE_R/Y0/Y1/K/D/CAP
SQC_TUBE_ALL=1               # 全刚体；默认只做 torso/spine/neck/head
```

## 3. 当前实测

```text
约束层关：monitor 1.571s / assist 4.150s
约束层开：monitor 2.081s / assist 4.008s
（joint limit hip/knee+foot 默认开）

tube upper / all：1.098 / 1.327s（仍不行，默认关）
```

结论：

- 约束层已启用：monitor 1.571→2.081，assist 4.150→4.008。
- 虚拟筒当前还不行，会顶翻；默认关。
- assist 与约束层同时开略降，但仍在 4s 级；可接受。

## 4. 下一步

1. 修 `BodyTubeConstraint`：只在摔倒风险时启用，或只做 pelvis/head + 硬投影。
2. 给 `JointLimitConstraint` 加 **PBD 投影**（project）做硬限位，而不只是软力矩。
3. 把 root/CoP 回正迁移成 `CoMConstraint` / `CopConstraint`，让 constraint layer 真正唯一。
4. 每次只加一个约束，单独 A/B，不同时开多个。
