# 唯一约束层（ConstraintLayer）架构（2026-11-16）

## 0. 目标

把**关节限位**收进唯一约束层；CoM/CoP 回正归命令层，不塞回约束层。

```text
Sensors
  → Command（IK + base force + CoP）
  → PD / muscle（只执行）
  → ConstraintLayer（唯一外部约束出口）
  → Physics
  → project（硬约束投影，PBD 式）
```

不再新增独立的 root/lateral/foot lock/assist 写手。

## 1. 代码

```text
src/core/constraints/constraintLayer.ts
  Constraint 接口：id / priority / step / project
  ConstraintLayer：按 priority 顺序 step，物理后 project

src/core/constraints/jointLimit.ts
  JointLimitConstraint
  - 进入 squat 时捕获参考角
  - 每轴 ±25% 关节范围软带
  - 越界加回正力矩（外部通道）
  - 默认只做 hip/knee 的轴 0/2；SQC_JOINT_LIMIT_FOOT=1 加 foot

src/core/constraints/hipLateral.ts
  HipLateralConstraint
  - 进入 squat 时捕获骨盆横向 z
  - 超出 ±range 时在 project 里硬夹回
  - 同时清零骨盆 z 速度（强制钉死）
  - 默认开：SQC_HIP_LATERAL=1，范围 4cm
  - 定位：残差阶段的 limit barrier + 最后硬夹；不是独立回正器（见命令层 §24.14）

```

集成：

```text
ControlModule.constraints
  step：sensors.update 之后
  project：World.advance 物理步之后
  resetCourt：清空
```

## 2. 开关

```text
SQC_JOINT_LIMIT=1            # 默认开
SQC_JOINT_LIMIT_FOOT=1       # 默认开（包含 foot）
SQC_JOINT_LIMIT_FRAC=0.25
SQC_JOINT_LIMIT_KP/KD/CAP

SQC_HIP_LATERAL=1             # 默认开
SQC_HIP_LATERAL_RANGE=0.04    # 髋/骨盆侧向允许空间 4cm
```
