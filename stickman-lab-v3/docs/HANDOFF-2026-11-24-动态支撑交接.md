## 6. 已确认的问题

### 6.1 支撑目标不等于实际力

实测：

```text
fzUse = 478
fzL = 61
fzR = 37
```

说明：

```text
支撑命令有
实际接触力没跟上
```

不能再用 `fzUse` 当成实际支撑力。

### 6.2 写手有效，但写的是关节力矩

实测：

```text
hipFf = -54.35
hip2Applied = -44.53
hip2Passive = 0
pdHip = +9.82
```

说明：

```text
squat.hip2 写手有效
PD 不是主要反向力
但它输出关节力矩
不是地面支撑力
```

### 6.3 髋高与 fz 方向曾经是反的

之前出现：

```text
hipY 下降
fzUse 下降
hip2Applied 下降
```

已改为：

```text
hipErr = hipTarget − hipY
aDes = Kp·hipErr − Kd·hipV
fzDes = 0.5·m·(g + aDes)
```

方向目标：

```text
髋低 → fzDes 增
髋高 → fzDes 减
```

### 6.4 fzUse 曾掉到 0

原因：

```text
fzTarget = 0 时
fzUse = min(fzUseRaw, fzTarget*fzMax, fzAbsMax)
→ fzUse = 0
```

已改成髋高模式下用绝对预算：

```text
fzUsePre = min(fzUseRaw, fzAbsMax)
```

### 6.5 脚会莫名抬起

一个页面：

```text
footPitch 4.5° → 43.8° → 107.6°
footWorldY 0.08 → 0.38
supportContactCount 12 → 4
fall @0.61s
```

另一页面：

```text
footPitch 4° ~ 6°
footWorldY 0.08
contact 一直 1
但 hipY 0.54 → 0.39
fall @0.87s
```

所以：

```text
脚翻不是每次都有
脚不翻时也会因为髋/支撑倒
```

### 6.6 世界抓地只锁了位置

`solveShankIKToFoot` 锁脚位置。

脚姿态仍由：

```text
FootWorldTarget
AnkleComp
```

处理。

AnkleComp 增益已从：

```text
Kp 180 / Kd 20
```

提高到：

```text
Kp 400 / Kd 40
```

但脚姿态仍可能翻。

## 7. 已验证失败的方向

不要继续重复这些：

```text
1. 继续调 hipFf / hip2 cap
   关节力矩大，不代表实际 fz 大

2. 直接拿 measureJointLoads 做支撑
   实际完整力链是反馈量，不是期望支撑
   直接前馈会正反馈，fall 0.6~0.9s

3. 继续加 fzUse 地板
   fzUse 不是实际接触力

4. 只调 tauCorr cap
   支撑不稳时 tauCorr 放大只会更乱
```

## 8. 正确方向

### 8.1 支撑力闭环

```text
fzDes（来自髋高/COM）
→ fzErr = fzDes − fzAct
→ 腿伸/脚压地
→ fzAct 跟随
→ 关节力矩
```

不是：

```text
fzUse → hipFf → 结束
```

### 8.2 世界抓地

```text
脚位置 + 脚姿态 + 接触约束
```

优先级最高。

### 8.3 串行

```text
世界抓地/接触
→ 期望髋高/COM
→ 期望 fz
→ wrench 投影
→ fz 反馈
→ 逆动力学
→ tauCorr
→ IK
```

不 QP，不同时求解。
