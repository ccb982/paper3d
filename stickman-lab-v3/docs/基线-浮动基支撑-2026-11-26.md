# 实验：浮动基支撑（2026-11-26，非默认基线）

## 结论

默认恢复稳定基线：

```text
SQC_FLOATING_ID=0
SQC_POSTURE_SEPARATE=0
```

新版浮动基支撑只作为实验开关：

```text
SQC_FLOATING_ID=1
SQC_FLOATING_MIX=0.05
SQC_POSTURE_SEPARATE=1
SQC_FLOATING_HZ=10
```

## 架构

支撑层：

```text
supportQp
→ 浮动基全维 ID（M/G/Jc）
→ hip/knee/ankle 支撑力矩
```

姿态层：

```text
IK / 姿态修正
不再混入支撑力矩
```

当前仍是静态/近似动态 ID，`C(q,q̇)` 尚未完整。
