# Full TSID 架构（2026-11-26）

## 0. 一句话

**脚接触、支撑 W、关节力矩必须在同一个 full TSID QP 里求解；踝只是 W 的执行端。**

不是：

```text
FootContactTask → 外部门控 → W QP → ankle direct torque
```

## 1. 一个 tick

```text
Snapshot
→ Contact state / foothold
→ Full TSID QP
→ τ
→ PD / current loop
```

## 2. 变量

```text
q̈       ∈ R^(6+N)
W_L,W_R ∈ R^6 each
τ       ∈ R^N
```

## 3. 等式

动力学：

```text
M(q) q̈ + C(q,q̇) + G(q)
  = Jcᵀ W + Sᵀ τ
```

脚固定接触：

```text
Jc q̈ + J̇c q̇ = 0
```

## 4. 不等式

```text
U·W <= 0          # CWC：摩擦/CoP/yaw
CoP ∈ 支撑面
fz >= fz_min
τ ∈ [τ_min, τ_max]
```

## 5. 优先级

```text
1. contact task
   foot position/orientation/velocity/acceleration

2. W 接触约束
   CWC / CoP / fz

3. support / CoM
4. damping
5. posture / righting
```

实现方式：

```text
HQP / lexicographic
或严格分阶段 QP
```

不要用一个大加权 QP 把 contact task 淹没。

## 6. 输出

```text
τ
```

踝：

```text
τ_ankle 是 JcᵀW 的结果
不是独立 ankle direct torque
```

## 7. 执行层

```text
Full TSID → τ
低层 PD/电流环执行
```

PD 只做：

```text
关节跟踪
局部阻尼
```

PD 不做：

```text
CoP
W
抓地
支撑分配
```

## 8. 失败规则

```text
contact task 不可行
→ 改 foothold / 迈步

W 不可行
→ 缩 W / 减支撑
→ 不能动脚

grip 失败
→ 不允许继续加支撑
```

## 10. 实施顺序

```text
1. 完整 M(q), C(q,q̇), G(q)
2. 双脚 Jc、J̇c
3. contact task 等式
4. full TSID QP
5. W CWC/CoP/fz 约束
6. τ 输出
7. 删除独立 ankle support
8. A/B 通过后切默认
```

## 11. 验收

```text
foot pose drift < margin
foot angular velocity < margin
CoP inside
fz tracking
τ within bounds
不抬脚
```

## 11.1 命令流水线：JointCommand / FrameCommand

最终架构必须收敛成每帧一个命令对象：

```text
JointCommand {
  dof
  qRef
  kp
  kd
  tau
  contact
  locked
}

FrameCommand {
  joints: JointCommand[]
  contact: ContactSnapshot
  stage: 0..3
}
```

规则：

```text
每帧只有一个 FrameCommand
每个关节只有一个 JointCommand
每个流水线阶段对每个关节只能提交一次修改
同一阶段内部先聚合，再提交
```

流水线：

```text
Stage 0 抓地：
  写 contact / locked / foot state

Stage 1 支撑：
  写 tau_support

Stage 2 削加速度：
  在支撑可行域内修改 tau/qRef

Stage 3 回正：
  修改 qRef / CoP 目标

PD：
  只读最终 FrameCommand，一次执行
```

硬约束：

```text
Stage 0 的 contact/locked 不允许被后面改
Stage 1 不允许改脚接触
Stage 2 不允许破坏支撑
Stage 3 不允许破坏接触
```

不再使用：

```text
proposal bus 多写手互相覆盖
同一关节多个 source 各自写
命令层和 PD 各自决定支撑
```
