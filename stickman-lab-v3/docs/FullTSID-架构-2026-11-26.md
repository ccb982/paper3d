# Full TSID 架构（2026-11-26）

## 0. 一句话

**脚接触、支撑 W、关节力矩必须在同一个 full TSID QP 里求解；踝只是 W 的执行端。**

不是：

```text
FootContactTask → 外部门控 → W QP → ankle direct torque
```

## 1. 一个 tick

```text
Snapshot
→ Contact state / foothold
→ Full TSID QP
→ τ
→ PD / current loop
```

## 2. 变量

```text
q̈       ∈ R^(6+N)
W_L,W_R ∈ R^6 each
τ       ∈ R^N
```

## 3. 等式

动力学：

```text
M(q) q̈ + C(q,q̇) + G(q)
  = Jcᵀ W + Sᵀ τ
```

脚固定接触：

```text
Jc q̈ + J̇c q̇ = 0
```

## 4. 不等式

```text
U·W <= 0          # CWC：摩擦/CoP/yaw
CoP ∈ 支撑面
fz >= fz_min
τ ∈ [τ_min, τ_max]
```

## 5. 优先级

```text
1. contact task
   foot position/orientation/velocity/acceleration

2. W 接触约束
   CWC / CoP / fz

3. support / CoM
4. damping
5. posture / righting
```

实现方式：

```text
HQP / lexicographic
或严格分阶段 QP
```

不要用一个大加权 QP 把 contact task 淹没。

## 6. 输出

```text
τ
```

踝：

```text
τ_ankle 是 JcᵀW 的结果
不是独立 ankle direct torque
```

## 7. 执行层

```text
Full TSID → τ
低层 PD/电流环执行
```

PD 只做：

```text
关节跟踪
局部阻尼
```

PD 不做：

```text
CoP
W
抓地
支撑分配
```

## 8. 失败规则

```text
contact task 不可行
→ 改 foothold / 迈步

W 不可行
→ 缩 W / 减支撑
→ 不能动脚

grip 失败
→ 不允许继续加支撑
```

```text
1. 完整 M(q), C(q,q̇), G(q)

5. W CWC/CoP/fz 约束

```

## 11.1 命令流水线：JointCommand / FrameCommand

最终架构必须收敛成每帧一个命令对象：

```text
JointCommand {
  dof
  qRef
  kp
  kd
  tau
  contact
  locked
}

FrameCommand {
  joints: JointCommand[]
  contact: ContactSnapshot
  stage: 0..3
}
```

规则：

```text
每帧只有一个 FrameCommand
每个关节只有一个 JointCommand
每个流水线阶段对每个关节只能提交一次修改
同一阶段内部先聚合，再提交
```

流水线：

```text
Stage 0 抓地：
  写 contact / locked / foot state

Stage 1 支撑：
  写 tau_support

Stage 2 削加速度：
  在支撑可行域内修改 tau/qRef

Stage 3 回正：
  修改 qRef / CoP 目标

PD：
  只读最终 FrameCommand，一次执行
```

硬约束：

```text
Stage 0 的 contact/locked 不允许被后面改
Stage 1 不允许改脚接触
Stage 2 不允许破坏支撑
Stage 3 不允许破坏接触
```

不再使用：

```text
proposal bus 多写手互相覆盖
同一关节多个 source 各自写
命令层和 PD 各自决定支撑
```

## 11.2 明确实现：full TSID 一帧怎么做

### 数据准备

```text
M(q), C(q,q̇), G(q)
每个接触脚 Jc, J̇c
FootContactTask:
  p*, q*, p, q, v, ω
  a_foot_des, ω_des
  gripOk, contactMode
```

### 变量

```text
q̈       全维加速度
W_L,W_R  双脚接触 wrench
τ        关节力矩
```

### QP

```text
min  ||contact task 误差||²
   + wW ||W − W_des||²
   + wτ ||τ − τ_prev||²
   + damping/posture 低权重

s.t.
  M(q)q̈ + C + G = JcᵀW + Sᵀτ

  Jc q̈ + J̇c q̇ = a_contact_des
  a_contact_des = 0（固定脚）

  U·W <= 0
  CoP ∈ 支撑面
  fz >= fz_min
  τ_min <= τ <= τ_max
```

### 优先级

必须严格串行/lexicographic：

```text
1. contact task
2. contact wrench CWC/CoP/fz
3. support W
4. damping
5. posture/righting
```

不要把 contact 和 support 合成一个大加权 QP。

### 脚姿态恢复

```text
不再使用 FootPoseRecovery 直接踝力矩

p*, q* 误差
→ a_contact_des
→ 进 Jc q̈ + J̇c q̇ = a_contact_des
```

如果 gripOk=false：

```text
固定脚接触约束优先
W 不再增加
必要时进入 edge/step 接触模式
```

### 输出

```text
τ
```

写入 FrameCommand：

```text
JointCommand.qRef / kp / kd / tau / passive / muscle ...
```

PD/Executor 只执行一次。

### 当前代码要做的事

```text
1. 从 floatingBaseId 导出 M/G/Jc
2. 补 C(q,q̇)
3. 新建 fullTsid.ts
4. FootContactTask 输出 a_contact_des
5. W QP 进入同一个 QP
6. τ 写入 FrameCommand
7. 删除 FootPoseRecovery direct torque
8. 删除 lower proposal 写手
```
