# Full TSID 架构（2026-11-26）

## 0. 一句话

**脚接触、支撑 W、关节力矩必须在同一个 full TSID QP 里求解；踝只是 W 的执行端。**

不是：

```text
FootContactTask → 外部门控 → W QP → ankle direct torque
```

## 1. 一个 tick

```text
Snapshot
→ Contact state / foothold
→ Full TSID QP
→ τ
→ PD / current loop
```

## 2. 变量

```text
q̈       ∈ R^(6+N)
W_L,W_R ∈ R^6 each
τ       ∈ R^N
```

## 3. 等式

动力学：

```text
M(q) q̈ + C(q,q̇) + G(q)
  = Jcᵀ W + Sᵀ τ
```

脚固定接触：

```text
Jc q̈ + J̇c q̇ = 0
```

## 4. 不等式

```text
U·W <= 0          # CWC：摩擦/CoP/yaw
CoP ∈ 支撑面
fz >= fz_min
τ ∈ [τ_min, τ_max]
```

## 5. 优先级

```text
1. contact task
   foot position/orientation/velocity/acceleration

2. W 接触约束
   CWC / CoP / fz

3. support / CoM
4. damping
5. posture / righting
```

实现方式：

```text
HQP / lexicographic
或严格分阶段 QP
```

不要用一个大加权 QP 把 contact task 淹没。

## 6. 输出

```text
τ
```

踝：

```text
τ_ankle 是 JcᵀW 的结果
不是独立 ankle direct torque
```

## 7. 执行层

```text
Full TSID → τ
低层 PD/电流环执行
```

PD 只做：

```text
关节跟踪
局部阻尼
```

PD 不做：

```text
CoP
W
抓地
支撑分配
```

## 8. 失败规则

```text
contact task 不可行
→ 改 foothold / 迈步

W 不可行
→ 缩 W / 减支撑
→ 不能动脚

grip 失败
→ 不允许继续加支撑
```

## 9. 当前代码

分散：

```text
FootContactTask
supportWrenchQp
floatingBaseId
ankleSupportCommand
```

问题：

```text
contact task 不进入同一个 QP
W QP 不知道脚姿态
踝 direct torque 能推脚
C(q,q̇) 未完整
```

## 10. 实施顺序

```text
1. 完整 M(q), C(q,q̇), G(q)
2. 双脚 Jc、J̇c
3. contact task 等式
4. full TSID QP
5. W CWC/CoP/fz 约束
6. τ 输出
7. 删除独立 ankle support
8. A/B 通过后切默认
```

## 11. 验收

```text
foot pose drift < margin
foot angular velocity < margin
CoP inside
fz tracking
τ within bounds
不抬脚
```

## 12. 禁止

```text
FootContactTask 只做观测
W QP 和 contact task 分开
踝 direct torque 推脚
脚歪后再回正
用门控/缩放代替接触约束
```
