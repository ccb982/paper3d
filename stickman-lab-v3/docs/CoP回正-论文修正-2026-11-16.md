# CoP 回正：论文依据与命令层修正（2026-11-16）

## 0. 结论

不回 QP，不回 WBC。

只做**命令层**的串级 CoP 回正：

```text
XCoM / CoP target
  → 脚踝目标角（主）
  → 小腿/膝目标角（次，慢）
  → 髋/躯干（更慢，只在大偏差时接管）
  → 基础力每帧重算
  → PD 只执行命令层给的目标 + 基础力
```

没有额外的 copFf，没有第二个 P2 控制器，没有 QP/WBC。

## 1. 论文依据

### 1.1 CoP 与踝力矩

Shafiee-Ashtiani et al. 2017（position-controlled humanoid）：

```text
p_x = τ_y,ankle / (mg)
p_y = τ_x,ankle / (mg)
```

即：**踝力矩直接决定 CoP**。因此踝是 CoP 回正的第一执行器。

论文还给出位置控制机器人的实现：不直接给力矩，而是把 CP 误差变成**踝目标角**：

```text
θ_y,ankle = kp · ξ_x,error + kd · ξ̇_x,error
θ_x,ankle = kp · ξ_y,error + kd · ξ̇_y,error
```

这正好符合我们的架构：命令层给目标，PD 执行。

- arXiv:1710.10598
- https://arxiv.org/abs/1710.10598

### 1.2 XCoM / 捕获点（CoP 目标）

Hof et al. 2005 / Hof 2008：

```text
ξ = x_com + v_com / ω0
ω0 = sqrt(g / h_com)
```

稳定条件：**XCoM 留在支撑面（BoS）内**；CoP 应放在 XCoM 附近/外侧，形成回正加速度。

- Hof 2005, J Biomech 38:1–8
- https://www.sciencedirect.com/science/article/pii/S0021929004001642
- Hof 2008, Human Movement Science 27:112–125
- https://www.sciencedirect.com/science/article/abs/pii/S0167945707000747

### 1.3 踝策略 / 髋策略

Winter 1995；Horak & Nashner 1986：

```text
小扰动：踝策略（CoP）
中扰动：髋策略（CMP / 角动量）
大扰动：步进
```

我们不步进，所以：

```text
踝：主 CoP 回正
膝/小腿：慢速姿态维持 + 垂直支撑
髋/躯干：大偏差时接 CoP/CMP
```

### 1.4 膝关节能不能帮 CoP

Iqbal & Pai 2000：允许膝关节运动可以扩大可行稳定域，尤其 COM 靠近足跟时。

Cheng 2016：膝关节运动能降低身体角动量/降低重心，对姿态控制有帮助，但不是主策略。

结论：

```text
膝/小腿是“次回正 + 垂直支撑”，不是主 CoP 控制器。
踝先动，膝后动，且膝增益更小、时间常数更长。
```

- Iqbal & Pai 2000, J Biomech 33:1619–1627
- https://pubmed.ncbi.nlm.nih.gov/11006386
- Cheng 2016, J Biomech 49:1873–1880
- https://www.sciencedirect.com/science/article/abs/pii/S0021929016305048

### 1.5 深蹲里的 CoP

- 深蹲时踝参与前后 + 垂直；膝主要参与垂直；髋主要参与前后。
  - https://pmc.ncbi.nlm.nih.gov/articles/PMC11307177
- AP-CoP 位置会显著改变踝/膝伸肌力矩；约 10% 足长位移可改变踝力矩约 30%、膝约 6%。
  - https://pmc.ncbi.nlm.nih.gov/articles/PMC9459773
- CoP 位置可预测膝关节伸肌贡献。
  - https://link.springer.com/article/10.1186/s13102-022-00523-0
- 蹲姿中 CoP 前移时踝屈曲更明显，后移时髋变化更明显。
  - https://pubmed.ncbi.nlm.nih.gov/22946311

对命令层的含义：

```text
脚踝：CoP 主控制
膝：垂直/高度，慢速辅助
髋：前后/躯干，慢速
```

### 1.6 基础力 + PD

Takegaki & Arimoto 1981：PD + 重力补偿即可稳定到目标；不需要 QP/WBC。

```text
τ = τ_gravity(q) + Kp(q_ref − q) − Kd·q̇
```

命令层每帧重算 `τ_gravity` 和基础力；PD 只执行。

- Takegaki & Arimoto 1981, ASME JDSMC 102:119–125
- https://doi.org/10.1115/1.3139651

## 2. 命令层控制律

### 2.1 CoP 目标

```text
ω = sqrt(g / h_com)
ξ_x = com_x + com_vx / ω
ξ_z = com_z + com_vz / ω        # 本项目的 z = 侧向
p_ref_x = clamp(ξ_x, support_x)
p_ref_z = clamp(ξ_z, support_z)
```

### 2.2 CoP 误差

```text
e_px = p_ref_x − cop_x
e_pz = p_ref_z − cop_z
ė_p = −cop_vel
```

### 2.3 踝目标角（主）

```text
Δθ_ankle_z = clamp(Kp_a_z·e_pz + Kd_a_z·ė_pz, ±Δmax_a_z)   # 侧向 foot/0
Δθ_ankle_x = clamp(Kp_a_x·e_px + Kd_a_x·ė_px, ±Δmax_a_x)   # 矢状 foot/2
θ_ankle_ref = θ_ankle_ik + Δθ_ankle
```

符号按关节轴标定；论文里是 CP 误差到目标角，实际用 `SQC_COP_SIGN_*` 做 A/B。

### 2.4 小腿/膝目标角（次，慢）

```text
e_shank = θ_shank_ref − θ_shank
Δθ_knee = clamp(Kp_k·e_shank + Kd_k·ė_shank
               + Kc_k·e_px, ±Δmax_k)
θ_knee_ref = θ_knee_ik + Δθ_knee
```

约束：

```text
Kp_k < Kp_a
delay_k > delay_a
ramp_k > ramp_a
```

膝只做慢速支撑；不要让它和踝抢同一个 CoP 目标。

### 2.5 髋/躯干（大偏差）

```text
if |e_p| > threshold_hip:
    Δθ_hip = clamp(Kp_h·e_p + Kd_h·ė_p, ±Δmax_h)
```

踝先饱和，髋再接管；这是论文里的 ankle→hip 策略切换，不是 QP。

### 2.6 基础力

```text
τ_base = τ_gravity(q) + τ_ik/id(q_ik, fz, cop)
```

每帧重算。CoP 回正已经体现在：

- 踝/膝目标角（位置控制）
- 或 `τ_base` 里的 CoP 力矩项（力矩控制）

**不要再单独加 `copFf`，也不要 P2 作为第二个控制器。**

### 2.7 PD 执行层

```text
τ = τ_base + Kp_pd·(θ_ref − θ) − Kd_pd·θ̇
```

PD 只执行；命令层负责“往哪回正”。

## 3. 参数起点

```text
ω: sqrt(g / comY)
Kp_a_z/Kp_a_x: 0.02~0.05 rad/m（先小）
Kd_a_z/Kd_a_x: 0.002~0.01
Δmax_a: 3~6°
Kp_k: 0.1~0.3 × Kp_a
Δmax_k: 2~4°
Kp_h: 0.05~0.15 × Kp_a
hip threshold: 0.03~0.05 m
```

这些只是起点；用探针扫。

## 4. 与现有代码的对应修改

`squatFrame`：

1. 计算 `p_ref_x/p_ref_z`（已有 XCoM/CoP target 雏形）。
2. 用 `e_p` 生成 `Δθ_foot0/Δθ_foot2`，加到 `foot0Cmd/foot2T`。
3. 用 `e_p` 和 `e_shank` 生成 `Δθ_knee2`，加到 `knee2T`（小增益、慢）。
4. 删除独立的 `copFf0/copFf2`：它们的贡献并进 2/3 的目标角。
5. 蹲姿关掉 shank P2（`SQC_PASSIVE2` 对 shank 不作为控制器）。
6. `τ_base` 每帧重算；不捕获静态 base。
7. PD 只拿 `target + τ_base`，不再有额外 `copFf` 参数。

辅助外力层保持独立；CoP 回正不靠外力。

## 6. 风险

1. CoP 目标公式/符号错：先做 ±1° 目标阶跃，读 CoP 方向。
2. 踝目标角饱和：切髋，不加大踝增益。
3. 膝/踝抢 CoP：膝增益必须小于踝，且慢。
4. 目标角基准漂移：用 IK 目标 + CoP 修正，不冻结整个姿态。
5. 不要回到 QP/WBC：这条链是 SISO 串级 + 基础力 + PD，已经够用。
