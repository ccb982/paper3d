# 动态支撑：重力补偿、加速度抑制与 IK 回正

日期：2026-11-24

## 1. 定稿结论

动态支撑不是“先摆姿态，再补力”。

正确顺序只有一条链：

```text
① 抵消重力矩（支撑第一优先）
② 支撑力/支撑 wrench（唯一的主动力矩来源）
③ 削加速度（每个关节各自阻尼，越小越好）
④ 近似静态后，才允许 IK 回正/姿态修正
```

后三步都不能破坏第①步。任何时刻：

```text
支撑力矩是主项；
加速度项、IK 项、PD 姿态项只能是残差；
残差反向最多吃掉支撑的 10%。
```

## 2. 为什么先抵消重力矩

漂浮基座动力学：

```text
M(q)ν̇ + C(q,ν)ν + G(q) = Sᵀτ + J_cᵀ F_c
```

重力项 `G(q)` 是系统里唯一持续存在、不能靠“等它自己稳”消失的力矩。第一步必须是：

```text
支撑接触产生 F_c，使 J_cᵀ F_c 抵消 G(q)
或等价的关节重力补偿 τ_gc
```

浮基重力补偿（接触刚性、无滑动假设）：

```text
τ_gc(q) = (N_c(q) Sᵀ)⁺ N_c(q) G(q)
N_c(q) = I − J_c(q)⁺ J_c(q)
```

来源：

```text
Hyon & Cheng 2006
  Gravity compensation and full-body balancing for humanoid robots
  · 把“反重力力”作为期望 GAF，分配到各接触点，再变成全身关节力矩
  · 机器人对未知外力呈被动性；最后一步再加 joint-wise damping 抑制内部运动

Henze, Ott, Lee 2016
  Passivity-based whole-body balancing for torque-controlled humanoid robots
  · 支撑 wrench 必须满足 underactuation constraint：
      Adᵀ_sup F_sup = m g + F_cpl
  · 先用支撑接触抵消重力，再谈 CoM/姿态

Fahmi et al. 2019
  Passive whole-body control for quadruped robots
  · 期望 CoM wrench = 笛卡尔阻抗 + 重力补偿 + 前馈
  · 重力补偿是势能梯度项，不是 PD 误差项
```

结论：

```text
支撑力的第一目标不是“把髋推到某个高度”，
而是“先让地面把重力接住”。
重力没接住之前，任何姿态/加速度任务都是叠加在失稳上。
```

## 3. 动态支撑的力

### 3.1 竖直支撑

```text
Fz_total = m (g + a_des)
```

- `a_des` 是“稳定修正”，不是主项。
- `a_des` 尽可能小：默认只保留阻尼项和很小的位置修正。
- 髋往下掉：`a_des > 0`，Fz 增加。
- 髋往上顶：`a_des < 0`，Fz 减少。
- 不允许用大 `a_des` 去“猛补”，否则会产生新的加速度和冲击。

### 3.2 分配到脚

```text
Fz_i = Fz_total · share_i
Σ share_i = 1
fz_i ≥ 0
|f_i,t| ≤ μ fz_i
CoP_i ∈ 支撑多边形（留边距）
```

来源：

```text
Lee & Goswami 2010 / 2012
  每只脚单独控制 GRF + CoP；双支撑时最小化踝力矩

Caron, Pham, Nakamura 2015
  Contact Wrench Cone：摩擦、CoP、yaw torque 三个条件

Herzog et al. 2016
  接触约束优先级高于动量/姿态；支撑力必须可行
```

### 3.3 变成关节力矩

```text
τ = M(q)q̈ + C(q,q̇) + G(q) − J_cᵀ f_des
```

- `f_des` 是上一步的支撑力/CoP。
- 静态时退化为 `τ_static = G − J_cᵀ f`。
- 当前实现是静态 ID + 小动态修正；完整版应按上式做全身 ID。

来源：

```text
Stephens & Atkeson 2010, DBFC
  期望 CoM 加速度 → 期望接触力 → 全身动力学 + 接触约束 → τ

Wensing & Orin 2016
  τ = Mq̈ + C + G − Jᵀf；f 必须满足接触约束
```

## 4. 削加速度

### 4.1 原则

支撑先接住重力；支撑本身可能带来加速度。加速度第二步削，且越小越好。

```text
τ_damp = − D_q q̇               （关节空间）
F_damp = − D_x ẋ               （任务空间，再 Jᵀ 映射）
```

- `D_q`、`D_x` 正定。
- 阻尼只“消耗能量”，不产生新的势能。
- 优先用速度阻尼，不用大加速度前馈。

来源：

```text
Takegaki & Arimoto 1981
  势能整形 + 阻尼注入；PD + 重力补偿的稳定性基础

Paden & Panja 1988
  PD+ 控制：重力补偿 + PD，全局渐近稳定

Semini et al. 2015
  Active impedance：关节/任务空间刚度 + 阻尼，Jacobian transpose 映射

Focchi et al. 2016
  内环力矩 + 速度反馈；阻抗/阻尼的稳定性与无源性分析

Hyon & Cheng 2006
  支撑力分配后，最后一步加 joint-wise damping 抑制内部运动
```

### 4.2 每个关节自己的削加速度

每个关节的阻尼/阻抗按“它负责什么”分开：

| 关节 | 主要职责 | 削加速度策略 | 论文依据 |
|---|---|---|---|
| 踝 | CoP / 脚姿态 / 重力矩 | 踝阻抗 + 阻尼；CoP 留边距；脚保持平；支撑踝前馈不压翻脚 | Horak & Nashner 1986；Kajita 2010；Caron 2019 |
| 膝 | 承重 / 防塌 | 膝伸展支撑 + 膝阻尼；膝柔顺任务；防过伸/过屈 | Henze et al. 2019（knee task）；Xing & Liu 2011 |
| 髋 | 水平 CoM / 髋策略 | 髋阻尼 + 髋水平任务；支撑优先，不允许髋后漂 | Horak & Nashner 1986；Kanamiya et al. 2010；CP-MPC 2024 |
| 上肢/手臂 | 配重 / 被动 | 重力补偿 + 阻尼；动态期不主动回正 | Hyon & Cheng 2006；Semini et al. 2015 |
| 骨盆/躯干 | 基座姿态 | 重力补偿 + 小阻尼；只在不破坏支撑时修正 | Henze et al. 2016；Fahmi et al. 2019 |

核心：

```text
踝管 CoP/脚姿态；
膝管承重/防塌；
髋管水平 CoM；
上肢只做重力和阻尼；
每个关节的阻尼只削自己的加速度，不互相抢支撑。
```

### 4.3 为什么肌肉削加速度这么强

人类肌肉不是“先算加速度再发力”，而是**天生就是一个速度相关的阻尼器**。机制按时间从早到晚：

```text
0 ms      短期刚度（short-range stiffness）
          激活肌肉被拉长的最初几个 % 长度内，cross-bridge 立刻提供高刚度
          → 对初始加速度/冲击零延迟抵抗
          Rack & Westbury 1974; Nishikawa et al. 2007

0–30 ms   preflex（零延迟内在反应）
          肌肉-肌腱的力-长度-速度非线性直接反抗扰动
          比任何神经反射都快一个数量级
          Brown & Loeb 2000; Daley & Biewener 2006; Frontiers 2023

0–50 ms   力-速度关系（Hill 1938）
          肌肉被拉长越快 → 主动力越大（eccentric）
          这是天然的负阻尼：速度越大，反向力越大
          离体肌肉 eccentric 力可比 isometric 高 40–80%
          在体关节力矩高 8–25%，且 ECC:CON 比随速度增加
          Edman 1988; Sports Medicine 2023 meta-analysis

20–50 ms  牵张反射（stretch reflex）
          肌梭 Ia 对速度高度敏感；短潜伏期反射 SLR 按拉伸速度缩放
          姿势威胁下 SLR-速度增益还能再提高 ~36%
          Horslen et al. 2018; Dimitriou 2014; Finley et al. 2013

50–200 ms 共同收缩（co-contraction）
          拮抗肌同时激活：净力矩不变，但两边的阻尼相加
          → 关节阻尼/刚度可调；阻尼比可提高 ~19%
          PMC3257849; PMC1635026; Wind & Rouse 2020; Kim et al. 2021
```

核心结论：

```text
肌肉“产生加速度”的能力受激活动力学限制（钙释放、跨桥循环，20–50ms）；
肌肉“削加速度”的能力由短期刚度 + 力-速度 + preflex + 反射 + 共收缩叠加，
其中前三项是零延迟/毫秒级。

所以削加速度的能力 >> 产生加速度的能力。
```

一个关键的数值事实：

```text
eccentric force-velocity 的斜率约为 concentric 的 2 倍
→ 同样速度下，拉长方向的阻尼约为缩短方向的 2 倍
（Hill-type 模型里 B_ecc ≈ 36 Nms/rad vs B_con ≈ 18 Nms/rad）
PMC3103502; Mörl et al. 2014
```

也就是说：

```text
肌肉天生“刹车比油门强”；
而且速度越快，刹车越强。
```

### 4.4 人类分部位削加速度策略

| 部位 | 人类主要策略 | 关键论文 | 机器人对应 |
|---|---|---|---|
| 踝 | 小腿三头肌 SLR 按速度调节踝刚度；踝共收缩调阻抗；踝策略把 CoP 留在脚底 | PLOS One 2011（running SLR）；Wind & Rouse 2020；Kim et al. 2021；Horak & Nashner 1986 | 踝：高阻尼 + 速度门 + CoP margin；脚姿态优先；不要用支撑踝前馈压翻脚 |
| 膝 | 股四头肌 eccentric 刹车；膝伸/屈共收缩；膝任务柔顺；蹲姿靠膝吸收冲击 | Henze et al. 2019（knee task）；Xing & Liu 2011；Sports Medicine 2023 | 膝：伸展支撑 + 膝阻尼；eccentric 方向阻尼更大；防过伸/过屈 |
| 髋 | 髋伸/屈共收缩；髋策略（CAM/角动量）；姿势威胁下反射增益提高 | Horak & Nashner 1986；Kanamiya et al. 2010；CP-MPC 2024；Horslen et al. 2018 | 髋：水平 CoM/髋策略 + 髋阻尼；髋后漂优先用髋阻尼/髋任务，不靠加 fz |
| 躯干/脊柱 | 竖脊肌/腹肌共收缩提高躯干刚度与阻尼；阻尼比 +19% | PMC1635026（trunk co-contraction）；Patel et al. 2014 | 躯干：重力补偿 + 小阻尼；动态期不回正；静态再 IK |
| 上肢/手臂 | 手臂端点阻抗由共收缩调节；快速动作伸肌 eccentric；反射含位置/速度/加速度反馈 | Patel et al. 2014；Schouten et al. 2008；Mörl et al. 2014 | 上肢：重力补偿 + 阻尼；不参与支撑；动态期不主动摆姿 |
| 全身 | preflex + 反射 + 共收缩分层；先内在稳定，再神经修正 | Brown & Loeb 2000；Nishikawa et al. 2007；Hyon & Cheng 2006 | 全身：重力补偿 → 支撑 → 逐关节阻尼 → IK 静态门 |

### 4.5 对机器人控制的直接结论

```text
1. 阻尼权限 >> 加速度前馈权限
   D_damp 的 cap 必须远大于 acc 前馈的 cap；
   acc 前馈只能做小修正，不能产生大加速度。

2. 阻尼要非对称
   拉长/远离目标方向的阻尼 > 缩短/靠近目标方向的阻尼；
   对应 eccentric > concentric。

3. 每个关节有自己的 D
   踝：高阻尼 + CoP/脚姿态
   膝：伸展支撑 + 高阻尼防塌
   髋：水平 CoM + 阻尼
   躯干/上肢：低阻尼，只做重力补偿

4. 共收缩/拮抗对
   在不改变净力矩的前提下增加关节阻尼；
   对应 musclePair 的拮抗通道。

5. 短期刚度
   小误差时高刚度，大误差时让位；
   避免小误差抖动，同时能抗冲击。

6. 反射/力反馈
   速度反馈优先，加速度反馈只做小增益；
   反射增益随状态调度（接触/动态/静态）。

7. IK 最后
   静态门 + 偏离门 + 支撑保留投影；
   动态期不抢支撑。
```

### 4.6 肌肉对加速度的控制：论文证据

有论文，而且不是“算一个阻尼数”。加速度控制有三条直接证据链：

```text
1. 肌梭 Ia 直接编码加速度
   · 人类 microneurography：Ia 放电与关节角速度、角加速度都相关，
     初始 burst 对加速度尤其敏感
     Dimitriou & Edin 2008a/b; PMC2655390
   · 2025 模型：肌梭初级传入的放电率按加速度缩放；
     只要修正 reafference，加速度反馈本身就足以控制站立/骑车平衡
     Internal sensory models ... muscle spindle acceleration feedback, 2025

2. 姿势反射的初始 burst 按加速度缩放
   · 支撑面平移：初始 EMG burst 与 peak acceleration 线性相关，
     后续 plateau 与 peak velocity 线性相关
     PMC2694108
   · 踝伸肌 medium-latency reflex 幅度随 perturbation acceleration 变化
     Finley et al. 2013
   · balance 模型里 acceleration feedback 是一个独立增益
     PLOS Comput Biol 2019

3. 肌肉本身的力学就是加速度滤波器
   · force-velocity：拉长越快，力越大（eccentric）
   · short-range stiffness：最初几 % 长度高刚度
   · preflex：0–30 ms 内在反应
   · 串联阻尼：肌腱/串联弹性吸收高频
     Hill 1938; Rack & Westbury 1974; Brown & Loeb 2000; Mörl et al. 2014
```

重要限制：

```text
short-range stiffness 只对小扰动量级有效；
大误差/大扰动时， intrinsic impedance 不够，
需要加速度/速度反馈 + 状态估计（internal model）。
Beyond muscle stiffness: state estimation ... 2014
```

所以人体不是“纯阻尼”，而是：

```text
小扰动：SRS + preflex + 内在粘弹性（零延迟）
中扰动：力-速度 + 牵张反射（20–50 ms）
大扰动：加速度/速度反馈 + 状态估计 + 共收缩（50–200 ms）
```

### 4.7 分关节 acceleration-control 映射

肌肉对 CoM 加速度的贡献不是平均的，踝/膝/髋分工很明确：

| 关节 | 人类主要加速度控制肌肉 | 论文证据 | 机器人特化 |
|---|---|---|---|
| 踝 | 比目鱼肌、腓肠肌：最大的向上/向前 CoM 加速度贡献；踝 SLR 按速度/加速度调刚度 | Hamner et al. 2010（soleus 峰值向上加速度 ~2 BW）；Liu et al. 2008；PLOS One 2011 | 踝：高加速度反馈增益 + 高阻尼 + CoP margin；支撑/推进主力 |
| 膝 | 股四头肌/vasti：early stance 的 braking + support；eccentric 膝伸刹车 | Hamner et al. 2010；Liu et al. 2008；2024 deceleration（quadriceps eccentric） | 膝：eccentric 方向高阻尼 + 膝伸支撑；防塌/防过伸 |
| 髋 | 臀大肌/臀中肌/腘绳肌：水平减速、支撑、摆动期腿加速度；hip strategy | Liu et al. 2008；Hamner et al. 2010；2024 deceleration（gluteal eccentric） | 髋：水平 CoM/髋 strategy + 髋阻尼；后漂用髋任务 |
| 躯干 | 竖脊肌/腹肌共收缩：躯干刚度/阻尼；角动量 | PMC1635026；Patel et al. 2014 | 躯干：重力补偿 + 小阻尼；动态期不回正 |
| 上肢 | 手臂对 CoM 加速度贡献 <1%，主要 counterbalance 角动量；端点阻抗由共收缩调 | Hamner et al. 2010；Patel et al. 2014 | 上肢：重力 + 阻尼；不参与支撑 |

对应到“特化关节”：

```text
踝 = 支撑/推进 + 加速度反馈（soleus 型）
膝 = 刹车/防塌 + eccentric 阻尼（quadriceps 型）
髋 = 水平减速/腿加速度 + 髋策略（gluteal/hamstring 型）
常规肌肉 = 同一个虚拟肌肉模型，参数按部位缩放
```

### 4.8 阻尼和被动刚度的目标：控加速度

以后不再“调一个 ks/bs 看它稳不稳”。

闭链动力学：

```text
M(q) q̈ + C(q,q̇) q̇ + G(q) = τ_support + τ_muscle + τ_ext
τ_muscle = τ_CE(Hill) − D q̇ − K Δq − F_SRS
```

设计目标不是“让关节不动”，而是：

```text
min  ||q̈||²  或  ||a_com||²
s.t. 支撑/接触约束
     |q̈_i| ≤ a_max,i
     支撑 ID 不被破坏
```

`D`、`K` 的取值来自这个目标，而不是手调：

```text
每关节给定：
  ω_n,i    目标闭环带宽
  ζ_i      目标阻尼比（0.7–1.0）
  a_max,i  允许加速度

反推：
  K_i = m_i · ω_n,i²
  D_i = 2 · ζ_i · m_i · ω_n,i
```

被动刚度另外受短期刚度约束：

```text
小位移：K_SRS 高，抑制初始加速度
大位移：K_SRS yield，避免把冲击传成大力矩
K_SRS · Δq_small ≤ m · a_max
```

共收缩 `C` 只负责把 `D/K` 调到目标工作点，不改变净力矩：

```text
D_i = D_i(C), K_i = K_i(C)
τ_net = τ_support + τ_CE
```

硬规则：

```text
1. G(q) 由支撑/重力前馈抵消，不用 D/K 去补重力。
2. D/K 只负责加速度响应；每个参数必须对应 ω_n、ζ、a_max 之一。
3. 不允许“这个数试出来稳”的 ks/bs。
4. 每关节有自己的 a_max：踝/膝/髋不同，不能一把尺子。
5. 验证指标是加速度：
   - 有阻尼 vs 无阻尼的 ||q̈|| / ||a_com||
   - 峰值加速度、恢复时间、超调
   - 支撑 ID 仍然占主导
```

当前 `musclePair` 里的 `ks/bs`（`drive.ts`）只是占位值；
下一步改成由 `ω_n / ζ / a_max` 反推，不再作为自由调参。

### 4.9 虚拟肌肉单元（机制，不是算术）

现有 `src/core/servo/musclePair.ts` 已经有拮抗肌对、共收缩、一阶激活；
下一步把它从“等长力 × 激活”扩成真正的人体机制：

```text
每个关节一对拮抗肌：
  CE  = a · F0 · fL(l) · fV(v)    fV 分 concentric/eccentric
  PEE = 被动弹性
  SEE = 串联弹性
  SDE = 串联阻尼
  SRS = 短期刚度（小位移高刚度，大位移 yield）
  a   = 一阶激活（20–60 ms）
  反射 = 肌梭速度 + 肌梭加速度 + 腱器官力反馈 + 交互抑制
  共收缩 C = 调刚度/阻尼，净力矩不变
```

控制层只写：

```text
C        共收缩
ref      平衡点
base     支撑/重力 operating point
```

力矩由虚拟肌肉产生；阻尼来自：

```text
fV（eccentric 更强）
+ SRS
+ SDE
+ 反射（速度/加速度/力）
+ 共收缩
```

不是再算一个 `-D q̇`。

### 4.10 与论文的差距（不要自欺）

论文不是“我们现在的代码”。论文给的是机制和方向：

```text
论文里的肌肉阻尼从来不是常数：
  · 力-速度：拉长越快，阻尼越大（eccentric）
  · 短期刚度：小位移高刚度，大位移 yield
  · preflex：0–30 ms 内在反应
  · 反射：肌梭速度/加速度反馈 + 腱器官力反馈
  · 共收缩：C 调 D/K
  · 任务/状态相关：站立、落地、减速、跑步的 D/K 不同
```

当前的 `musclePair`：

```text
ks/bs 常数 × C
一阶激活
没有 F-V 的 eccentric 分支
没有短期刚度 yield
没有加速度反馈
没有反射延迟/增益调度
```

所以：

```text
当前的 ks/bs 只是占位值，不是论文意义上的肌肉阻尼。
之前“乱调 ks/bs”不是调参问题，是模型缺机制；
没有 F-V/SRS/加速度反馈，只能用常数去硬凑。
```

下一步不是继续调 `ks/bs`，而是把机制补上：

```text
ks/bs 常数        →  ω_n / ζ / a_max 反推 + 状态相关
等长力 × 激活     →  Hill CE（fL, fV eccentric）
线性阻尼          →  SDE + SRS + 反射
无加速度反馈      →  肌梭速度 + 加速度反馈（带延迟/增益）
统一参数          →  踝/膝/髋各自 a_max、ω_n、ζ
```

### 4.11 加速度检测 → 虚拟肌肉

可以，而且现有代码已经有可用的加速度源。

```text
__ACC_OBS（观测器/EKF，优先用）
  qddHip / qddKnee / qddAnkle
  comAccX / comAccY / comAccZ
  baseAccX / baseAccY / baseAccZ
  confidence

__MOTION_ACC（运动学/动力学原始量）
  dofAcc
  bodyLinAcc / bodyAngAcc
  comAcc
  contactAcc

__LIMB_ACC
  shin_lAz / thigh_lAz / foot_lAz / torsoAz ...
```

映射到虚拟肌肉：

```text
踝：qddAnkle + comAcc → 高加速度反馈增益（soleus 型）
膝：qddKnee          → eccentric/braking 增益（quadriceps 型）
髋：qddHip + baseAcc → 髋策略/水平加速度增益（gluteal 型）
躯干/常规肌肉：comAcc/baseAcc → 低增益
```

接口需要补：

```text
PairDof:
  angle, vel, inertia, pairAxis
  + acc          ← 关节加速度
  + accRef       ← 期望加速度（通常 0）

PairChannel:
  c, ref, base
  + aRef         ← 加速度反馈参考

反射项：
  τ_reflex_acc = G_acc · (accRef − acc)
```

安全条件：

```text
1. 用 __ACC_OBS，不用裸二次差分
2. confidence 低 → 加速度反馈增益降到 0
3. 支撑/接触不稳 → 先不加加速度反馈
4. 加速度反馈只做 trim，必须过 preserveSupport
5. 每关节 G_acc、aRef、延迟不同：踝/膝/髋特化
```

这就是人类肌梭 Ia 加速度反馈在机器人里的对应通道；
现在 `musclePair` 还没接，所以这一层是缺的。

### 4.12 已接入：PD 内共享阻尼刚度控制器（时刻全开）

不是可选开关，也不是只在 `musclePair` 里。

## 5. IK 回正的位置

IK 回正不是主项，必须同时满足两个条件：

```text
① 近似静态：|v_com| 低
② 偏离量大：IK 目标与当前角的误差超过死区
```

单独满足一个都不启用：

```text
静态 + 偏离小 → 不回正（避免小误差抖动）
动态 + 偏离大 → 先削加速度，不回正
静态 + 偏离大 → 才允许 IK
```

速度门：

```text
|v_com| < v_lo  → 1
|v_com| > v_hi  → 0
v_lo < |v_com| < v_hi → 线性淡入

v_lo = 0.03 m/s
v_hi = 0.15 m/s
```

偏离门：

```text
dev = max(|ik.hip2 − hip2|, |ik.knee2 − knee2|, |ik.foot2 − foot2|)

dev < dev_lo  → 0
dev > dev_hi  → 1
dev_lo < dev < dev_hi → 线性淡入

dev_lo = 2°
dev_hi = 5°
```

代码：

```text
staticGate   = clamp(1 − (|v_com| − v_lo) / (v_hi − v_lo), 0, 1)
deviationGate = clamp((dev − dev_lo) / (dev_hi − dev_lo), 0, 1)
ikGate       = staticGate × deviationGate
ik_use       = ik · ikGate
```

并且在叠加时：

```text
base = 支撑 ID
sec  = 加速度项 + IK 项 + 姿态项
τ = preserveSupport(base, sec, opposeFrac=0.1)
```

`preserveSupport` 保证：

```text
sec 与 base 同向：可以叠加
sec 与 base 反向：最多吃掉 base 的 opposeFrac
```

来源：

```text
Herzog et al. 2016
  接触/动量/姿态分层；接触约束最高

Henze et al. 2016
  支撑 wrench 是最高优先级任务

Kim et al. 2018
  contact constraints + CoP + friction 先于任务加速度
```

## 7. 验收

唯一验收：**蹲下完整过程生存时间**。

```text
t0 = squatDown 开始
t1 = 动作层交接给 squat 伺服
t2 = 真正倒下
total = t2 − t0
descent = t1 − t0
hold = t2 − t1
```

判死放宽（不是不判）：

```text
髋高下降 > 8cm
CoM 下降 > 8cm
torso pitch 偏差 > 60°
torso roll 偏差 > 30°
双脚失接触 > 0.15s
任一满足才判死
```

每帧回读必须包含：

```text
footY / footPitch / contact
fzAct / fzUse / fzTotalDes / fzShare
hipY / hipX / comY / comVY
kneeX / knee2a
idHip / idKnee
appliedHip / appliedKnee
staticGate / accDamp
```

验收标准：

```text
1. 重力矩先被支撑抵消
2. 支撑 ID 是 applied 的主项
3. 加速度/IK 反向最多吃 10%
4. IK 只在近似静态时出现
5. 髋往下掉时 fzAct 上升，髋往上顶时 fzAct 下降
6. 脚不抬、CoP 不越界、膝盖不后漂
7. 蹲下全流程生存时间作为唯一分数
```
