# 蹲姿稳定与回正架构（2026-11-22 修订）

> 本版取代旧版“独立回正写手”的设计。
>
> 旧版把回正当成第二股力：基础支撑一套、回正一套，两个写手在同一根轴上对拉。
> 本版改为：回正不是独立力，回正是 `tauBase` 的修正量 `tauCorr`。

详细修正设计见：

```text
docs/tauCorr-CoM-CoP-修正-架构-2026-11-22.md
```

---

## 1. 设计结论

分两阶段，不是一套力打天下：

```text
小偏差阶段：
  所有下盘主动轴：StateHoldWriter 唯一写
  tauBase：完整基础支撑（含踝）
  tauCorr：支撑力的修正量
  tauCmd：tauBase + tauCorr

大偏差阶段（后续再做）：
  SAG / LAT 接管对应关节组
  接管轴上的 tauCorr 先衰减到 0
  SAG/LAT 不是和 tauCorr 同时叠加
```

所以：

```text
现阶段不存在“基础支撑 + 独立回正”两股力对拉
```

但也不永久删除 SAG/LAT：

```text
SAG/LAT 保留，作为大偏差的最终主导回正
只是后面再做
```

小偏差用修正，大偏差用接管：

```text
小偏差：tauCorr 修 tauBase
大偏差：SAG/LAT 换所有权，tauCorr 退出对应轴
```

这两者永远不同时写同一根轴。

---

## 2. 对拉的根因

旧设计：

```text
支撑力：维持当前姿态
回正力：把姿态拉回目标
两个力都写同一根轴
```

结果：

```text
支撑说“别动”
回正说“过去”
同一根轴出现两个目标/两股力矩
净输出互相抵消或低频振荡
```

根因不是增益不够，是**所有权重复**。

本版：

```text
只有一个写手
支撑力先成立
回正只改支撑力的组合方式
```

---

## 3. 核心原则

```text
同一轴、同一帧、只有一个主动写手
回正不是第二写手
回正是 tauBase 的 Delta
```

默认：

```text
StateHoldWriter 写所有下盘主动轴
```

包括：

```text
hip0 / hip1 / hip2
knee0 / knee1 / knee2
foot/ankle 的力矩通道
```

唯一例外：

```text
foot 世界位姿 / ankle 抓地目标
始终归 WorldGripWriter
```

---

## 4. WorldGrip：常开

```text
WorldGripWriter 在所有状态下始终开启
stand / squatDown / squat / 法庭 不切
交接不重置、不替换、不清目标
```

它只保证：

```text
脚世界位姿
脚不滑、不翻
```

它不参与：

```text
HOLD / SAG / LAT
回正权重
CoM/CoP 修正
```

优先级：

```text
WorldGrip（脚世界位姿 + 抓地）
  > tauBase + tauCorr
```

约束：

```text
tauCorr 不得改脚世界目标
tauCorr 不得把脚从地面解出来
tauCorr 不得新建第二个 foot 写手
踝的支撑/修正在同一个踝 PD 内叠加
```

---

## 5. 两级力

### 5.1 tauBase

```text
tauBase = 当前姿态的完整基础支撑
```

输入：

```text
当前 q
当前 qd
连续 LoadState：fz / CoP
接触
脚位姿
```

输出：

```text
hip / knee / ankle
```

要求：

```text
踝必须包含在 tauBase 里
不能只算 hip/knee
```

静态阶段：

```text
tauBase = ID_static(q, fz, CoP)
```

后续：

```text
tauBase = M(q)qdd + C(q,qd) + G(q) + J^T F_contact
```

### 5.2 tauCorr

```text
tauCorr = Δtau
```

它不是独立回正力，只修正 `tauBase`。
顺序是先补支撑缺口，再做回正：

```text
tauCorr = Δtau_support + Δtau_righting
```

第一层，补支撑缺口（首要）：

```text
Δtau_support = 所需支撑力矩 − 当前 tauBase/已输出力矩
加速度/动态项在这里抵消
```

第二层，回正（其次）：

```text
Δtau_righting = Δtau_cop + Δtau_com + Δtau_ik + Δtau_damp
```

含义：

```text
Δtau_cop：CoP 位置修正，踝优先
Δtau_com：CoM 位置/速度修正
Δtau_ik ：目标 IK 的轻量拉回
Δtau_damp：关节速度阻尼
```

这里不再单独有：

```text
Δtau_acc
```

加速度已经归入 `Δtau_support`。

特点：

```text
小
平滑
有限幅
限速率
支撑有效才开
支撑不够时自动缩小
```

### 5.3 合成

```text
tauCmd = tauBase + tauCorr
```

踝：

```text
foot2 = WorldGrip PD
      + tauBase_ankle
      + tauCorr_ankle
```

膝：

```text
knee2 = tauBase_knee + tauCorr_knee
```

髋：

```text
hip2 = tauBase_hip + tauCorr_hip
```

仍然经过：

```text
原有 PD
被动刚度
执行器限幅
```

## 6. SAG / LAT 的两阶段设计

SAG / LAT 有用，但属于**大偏差阶段**，不是小偏差阶段的修正量。

### 6.1 小偏差：tauCorr

```text
不接管
不换所有权
只做 tauBase 的小修正
```

### 6.2 大偏差：SAG / LAT 接管

```text
SAG = 接管 hip2 / knee2
LAT = 接管 foot / ankle / shank
```

接管前必须：

```text
该轴的 tauCorr 先衰减到 0
该轴的 StateHold 退出
WorldGrip 仍然不动
```

接管期间：

```text
SAG/LAT 是该轴唯一主动写手
tauCorr 不在这些轴上继续叠加
```

### 6.3 两阶段的关系

```text
小偏差：tauBase + tauCorr
大偏差：tauBase + SAG/LAT
```

不是：

```text
tauBase + tauCorr + SAG/LAT
```

所以 SAG/LAT 保留，但不会和 tauCorr 对拉：

```text
先衰减修正
再移交所有权
再进入大偏差回正
```

仍然：

```text
SAG / LAT 互斥
窗口 100–200ms
同一轴同一帧 writes=1
```

## 7. 连续 LoadState

统一：

```text
fzHeld
copXHeld
copZHeld
loadValid
lastValidT
```

规则：

```text
当前 fz/CoP 有效 → 更新
当前无效 → 保留 last-valid
超过 SQC_LOAD_HOLD=0.10s → 失效
```

使用：

```text
tauBase
tauCorr
foot support
handoff
```

都读同一份 LoadState。

禁止：

```text
交接首帧裸 fz 直接进基础力
单帧 fz=0 判定真实卸载
每帧用裸 fz 重算全部下盘
```

## 8. StateHoldWriter

职责：

```text
状态保持
基础支撑
tauCorr 修正入口
```

输入：

```text
LoadState
脚位姿
当前 q / qd
CoM / CoM 速度
目标 IK
当前支撑余量
```

输出：

```text
hip0 / hip1 / hip2
knee0 / knee1 / knee2
ankle 力矩
```

计算：

```text
tauBase[j] = ID_j(q, load, footTarget)
tauCorr[j] = clamp(correction)
tauCmd[j]  = tauBase[j] + tauCorr[j]
```

不写：

```text
foot 世界位姿 / foot qRef
```

这些始终归 WorldGrip。

### 8.1 修正不是接管

```text
tauCorr 不改变所有权
tauCorr 不建立新写手
tauCorr 不覆盖 tauBase
tauCorr 只改变 tauBase 的净力矩
```

### 8.2 修正预算

```text
|tauCorr_i| <= cap_abs_i
|tauCorr_i| <= frac_base * |tauBase_i|
|tauCorr_i(k)-tauCorr_i(k-1)| <= slew_i * dt
CoP_cmd 必须在安全支撑面内
```

建议：

```text
ankle 4 N·m
knee  4 N·m
hip   6 N·m
frac_base = 0.15
```

任一约束不满足：

```text
整体缩小 tauCorr
不是让 CoP 越界
不是让 tauCorr 压过 tauBase
```

## 9. 修正排序

按归一化严重度排序：

```text
s_cop = |CoP* - CoP| / cop_margin
s_com = |XCoM - CoP| / support_half_width
s_acc = |a* - a_measured| / a_cap
s_ik  = ||q_ik - q|| / q_band
S = max(s_cop, s_com, s_acc) + w_ik * s_ik
```

分窗：

```text
S < 0.3
  阻尼 + 很轻 IK

0.3 <= S < 0.7
  踝 CoP 为主

0.7 <= S < 1.2
  踝 + 膝 + 髋
  仍受 CoP 安全区约束

S >= 1.2
  踝可能饱和
  冻结/衰减 tauCorr
  保持 tauBase
  需要步或外部救援
```

排序只决定：

```text
先修哪个
各关节分多少
```

不决定：

```text
用大扭矩
换写手
把支撑拆掉
```

## 10. 交接

本版没有回正写手，因此没有“回正接管”的交接。

只有：

```text
LoadState 连续
tauBase 连续
tauCorr 连续
WorldGrip 不重置
```

禁止：

```text
用单帧 fz 切换所有权
首帧直接跳目标
把上一帧 applied 当新写手起点
```

## 11. 频率

```text
LoadState：每帧更新，last-valid 保持
tauBase：50–100ms 重算 + hold + slew
tauCorr：50–100Hz 外环，每帧限幅
WorldGrip：每帧
```

---

## 12. 实施顺序

```text
Phase 1
  连续 LoadState
  全下盘 StateHold
  tauBase 含踝
  tauCorr = 0

Phase 2
  tauCorr 只做踝 CoP 小修正
  验证 foot2 不再长期为 0

Phase 3
  加入 CoM 加速度 / IK 修正
  只允许在 tauBase 上叠加

Phase 4
  加入严重度排序
  小偏差仍是 tauCorr

Phase 5（后面再做）
  大偏差 SAG/LAT 接管
  接管前 tauCorr 先衰减到 0
  同一轴仍然只有一个主动写手
```

## 13. 验收

```text
同一轴同一帧 writes=1
小偏差阶段：没有第二股回正力
tauCorr 不超过基础力的 15%
CoP 修正不越界
WorldGrip 脚世界位姿不变
foot2 有踝支撑/修正输出
单帧 fz=0 不会让 target 塌陷
纯 tauBase + tauCorr 的 TTF 至少 3–4s
（不是一上来就倒；SAG/LAT 暂时不参与）

大偏差阶段（后续验收）：
  SAG/LAT 接管轴上 tauCorr=0
  交接前后 applied 连续
  没有 SAG/LAT 与 tauCorr 同轴
```

回正不是第二股力
