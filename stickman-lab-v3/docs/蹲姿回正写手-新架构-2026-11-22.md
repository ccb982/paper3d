# 蹲姿回正写手新架构（2026-11-22）

## 1. 范围

只处理下半身。

```text
默认：StateHoldWriter 独占下盘
矢状回正：SagittalRightingWriter 接管 hip2 / knee2
侧向回正：LateralRightingWriter 接管 foot / ankle / shank
```

上身：

```text
不控制
只作为重力/惯性负载
upperBase / upperRighting / spinePair 全关
```

第一版只做 StateHoldWriter。  
矢状和侧向回正先留接口，不接主动写手。

## 2. 核心原则

```text
同一轴、同一帧、只能有一个写手
回正不是叠加第二股力
回正是替换对应关节组的所有权
```

默认：

```text
StateHoldWriter 写所有下盘轴
```

启用矢状回正：

```text
SagittalRightingWriter 接管 hip2 / knee2
StateHoldWriter 不再写 hip2 / knee2
```

启用侧向回正：

```text
LateralRightingWriter 接管 foot / ankle / shank
StateHoldWriter 不再写这些轴
```

所有权表：

```text
foot 世界位姿/qRef     WorldGripWriter，始终开，不参与模式切换
hip2 / knee2           HOLD 或 SAG
ankle / shank 侧向     HOLD 或 LAT
其他下盘轴             始终 HOLD
```

### 2.1 常开世界脚抓地

```text
WorldGripWriter 在所有状态下始终开启
stand / squatDown / squat / 法庭 不切
交接不重置、不替换、不清目标
```

它不是回正写手，也不属于 HOLD/SAG/LAT 所有权。

```text
HOLD/SAG/LAT 不得写 foot 世界位姿
不得替换 WorldGripWriter
不得因为状态切换关闭脚抓地
```

WorldGripWriter 只保证：

```text
脚世界位姿
脚不滑、不翻
```

优先级：

```text
WorldGrip（脚世界位姿 + 踝抓地）
  > SagittalRighting / LateralRighting
  > StateHold
```

原因是：

```text
世界脚位姿是 IK 的固定基座
脚/踝抓地错了，后面的髋膝 IK 全部失真
```

所以回正写手只能在抓地成立的前提下分配关节力矩：

```text
不得改 foot 世界目标
不得反向破坏脚位姿
不得为了回正把脚从地面解出来
```

下半身回正只处理对应关节组的力矩/PD，不改脚世界目标。

## 3. 模式

```text
HOLD
SAG
LAT
SAG + LAT
```

模式切换只改变所有权，不改变负载计算。

```text
负载/contact/CoP 始终连续
不随 stand / squatDown / squat 切换
```

## 4. 连续负载状态

新增统一 LoadState：

```text
fzHeld
copXHeld
copZHeld
loadValid
lastValidT
```

规则：

```text
当前 fz/CoP 有效 → 更新
当前无效 → 保留 last-valid
超过 SQC_LOAD_HOLD=0.10s → 才失效
```

使用：

```text
StateHoldWriter
foot support
handoff 判断
Sagittal/Lateral feedforward
```

都读同一份 LoadState。

禁止：

```text
交接首帧裸 fz 直接进基础力
单帧 fz=0 判定真实卸载
每帧用裸 fz 重算全部下盘
```

## 5. StateHoldWriter

职责：

```text
状态保持
支撑/重力基线
不参与方向回正
```

输入：

```text
LoadState
脚位姿
当前关节角
```

输出：

```text
hip0 / hip1 / hip2
knee0 / knee1 / knee2
```

不写：

```text
foot 世界位姿 / foot qRef
```

计算：

```text
tauHold[j] = ID_j(q, load, footTarget)
footTarget 只读
```

更新：

```text
每 50–100ms 重算一次
zero-order hold
相邻更新之间 slew 过渡
```

不写：

```text
hipX / CoM 误差
侧向 shank 误差
```

这些属于回正层。

## 6. SagittalRightingWriter

职责：

```text
矢状回正
```

所有权：

```text
hip2 / knee2
```

不写：

```text
foot / ankle
spine / upper
lateral shank
```

输入：

```text
eX = xRef − hipX（或 CoM 误差）
ePitch = pitchRef − trunkPitch
```

输出：

```text
hip2 correction
knee2 correction
```

基本形式：

```text
tauSag = Jᵀ (Kp·e + Kd·ė)
```

只写 hip2 / knee2；StateHold 在 SAG 模式下不写这两轴。

小偏差：

```text
|e| 小 / 高频 → 被动 K/B
```

大偏差：

```text
|偏差| ≥ 20N 量级 → 主动回正接管
```

主动回正退出时：

```text
不是瞬间关
用上一帧 applied 平滑交还 HOLD
```

## 7. LateralRightingWriter

职责：

```text
小腿侧偏回正
```

所有权：

```text
ankle lateral torque
shank lateral correction
```

不写：

```text
foot 世界位姿 / foot qRef（始终归 WorldGripWriter）
hip2 / knee2
spine / upper
```

输入：

```text
shank roll / yaw
foot roll / yaw
左右 CoP / 负载差
```

更新：

```text
20–50Hz 重算
中间 hold
输出 slew
```

第一版不实现。

## 8. 交接

启用回正时：

```text
捕获上一帧 applied
新写手以它为起点
平滑接管
StateHold 退出对应轴
```

禁止：

```text
两个写手同帧写同一轴
用单帧 fz 切换所有权
首帧直接跳到新目标
```

交接后第一帧允许旧 `applied` 留在 ledger 里，但新物理步只能由新写手写。

## 9. 频率

```text
LoadState：每帧更新，last-valid 保持
StateHold：50–100ms 重算 + hold + slew
Sagittal：每帧
Lateral：20–50Hz 重算 + hold
```

## 10. 被动与主动边界

被动：

```text
小偏差、高频
K/B 直接作用在同一个 PD
```

主动：

```text
持续偏差超过阈值
回正写手接管
```

禁止：

```text
用大 K 代替回正
用固定时间 ramp 假装回正
用第二写手叠加对拉
```

## 11. 实施顺序

```text
Phase 1
  连续 LoadState
  StateHoldWriter 接管全部下盘
  不接 Sagittal / Lateral

Phase 2
  接 SagittalRightingWriter
  只接管 hip2 / knee2
  HOLD 退出这两轴

Phase 3
  接 LateralRightingWriter
  接管 foot / ankle / shank
  HOLD 退出这些轴

Phase 4
  验收两种回正的交接与退出
```

## 12. 验收

```text
同一轴同一帧 writes=1
HOLD/SAG/LAT 语义清晰
交接前后 applied 连续
无单帧 fz=0 导致的 target 塌陷
hip2/knee2 不被 HOLD 与 SAG 对拉
foot/ankle 不被 HOLD 与 LAT 对拉
上身无主动写手
```
