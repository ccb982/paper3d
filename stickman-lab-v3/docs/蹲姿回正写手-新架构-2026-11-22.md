# 蹲姿回正写手新架构（2026-11-22）

## 1. 范围

只处理下半身。

```text
默认：StateHoldWriter 独占下盘
矢状回正：SagittalRightingWriter 接管 hip2 / knee2
侧向回正：LateralRightingWriter 接管 foot / ankle / shank
```

上身：

```text
不控制
只作为重力/惯性负载
upperBase / upperRighting / spinePair 全关
```

第一版只做 StateHoldWriter。  
矢状和侧向回正先留接口，不接主动写手。

## 2. 核心原则

```text
同一轴、同一帧、只能有一个写手
回正不是叠加第二股力
回正是替换对应关节组的所有权
```

默认：

```text
StateHoldWriter 写所有下盘轴
```

启用矢状回正：

```text
SagittalRightingWriter 接管 hip2 / knee2
StateHoldWriter 不再写 hip2 / knee2
```

启用侧向回正：

```text
LateralRightingWriter 接管 foot / ankle / shank
StateHoldWriter 不再写这些轴
```

所有权表：

```text
foot 世界位姿/qRef     WorldGripWriter，始终开，不参与模式切换
hip2 / knee2           HOLD 或 SAG
ankle / shank 侧向     HOLD 或 LAT
其他下盘轴             始终 HOLD
```

### 2.1 常开世界脚抓地

```text
WorldGripWriter 在所有状态下始终开启
stand / squatDown / squat / 法庭 不切
交接不重置、不替换、不清目标
```

它不是回正写手，也不属于 HOLD/SAG/LAT 所有权。

```text
HOLD/SAG/LAT 不得写 foot 世界位姿
不得替换 WorldGripWriter
不得因为状态切换关闭脚抓地
```

WorldGripWriter 只保证：

```text
脚世界位姿
脚不滑、不翻
```

优先级：

```text
WorldGrip（脚世界位姿 + 踝抓地）
  > SagittalRighting / LateralRighting
  > StateHold
```

原因是：

```text
世界脚位姿是 IK 的固定基座
脚/踝抓地错了，后面的髋膝 IK 全部失真
```

所以回正写手只能在抓地成立的前提下分配关节力矩：

```text
不得改 foot 世界目标
不得反向破坏脚位姿
不得为了回正把脚从地面解出来
```

下半身回正只处理对应关节组的力矩/PD，不改脚世界目标。

## 3. 模式与调度

只有三种状态：

```text
HOLD
SAG
LAT
```

没有 `SAG + LAT`。

```text
HOLD：只跑稳定力
SAG：只接管矢状关节组
LAT：只接管侧向关节组
```

SAG / LAT 互斥，周期切换：

```text
一次只选一个回正通道
回正窗口：100–200ms
窗口之间退回 HOLD
两个窗口之间留间隔
```

原因：

```text
全身同时考虑支撑 + IK + 回正
会让所有关节同时换目标
局部回正变成全身失稳
```

规则：

```text
稳定力默认只维持当前姿态
回正通道的基础力才同时考虑 IK 姿态 + 支撑
但只动它拥有的那部分关节
其余关节继续 HOLD
```

模式切换只改变所有权，不改变负载计算。

```text
负载/contact/CoP 始终连续
不随 stand / squatDown / squat 切换
```

### 3.1 稳定力与回正力

```text
稳定力：
  当前实际 q
  当前负载
  求维持当前姿态所需的力
  不读完整 IK 目标
  不追 CoM

HOLD = 稳定力 + 很小很小的姿态修正：
  tauHold = tauStable + clamp(tauSmallCorr)
  tauSmallCorr 限幅、限速率、平滑
  小修正不能改变支撑链

回正力：
  只出现在 SAG / LAT 窗口
  基础力可同时考虑 IK 姿态 + 支撑
  只写对应关节组
  输出限幅、限速率、平滑
```

禁止：

```text
稳定力里混入 IK 姿态
回正窗口外继续跑回正
SAG 与 LAT 同时接管
回正通道重算全身
```

## 4. 连续负载状态

新增统一 LoadState：

```text
fzHeld
copXHeld
copZHeld
loadValid
lastValidT
```

规则：

```text
当前 fz/CoP 有效 → 更新
当前无效 → 保留 last-valid
超过 SQC_LOAD_HOLD=0.10s → 才失效
```

使用：

```text
StateHoldWriter
foot support
handoff 判断
Sagittal/Lateral feedforward
```

都读同一份 LoadState。

禁止：

```text
交接首帧裸 fz 直接进基础力
单帧 fz=0 判定真实卸载
每帧用裸 fz 重算全部下盘
```

## 5. StateHoldWriter

职责：

```text
状态保持
支撑/重力基线
不参与方向回正
```

输入：

```text
LoadState
脚位姿
当前关节角
```

输出：

```text
hip0 / hip1 / hip2
knee0 / knee1 / knee2
```

不写：

```text
foot 世界位姿 / foot qRef
```

计算：

```text
tauStable[j] = ID_j(q, load, footTarget)
tauSmall[j]  = 很小的姿态修正
tauHold[j]   = tauStable[j] + clamp(tauSmall[j])
footTarget 只读
```

小修正不是回正：

```text
不改变所有权
不接管 SAG/LAT 关节组
只补很小的残余误差
不能破坏支撑
```

完整 HOLD 链：

```text
命令层：
  tauStable = 当前姿态支撑力
  tauCorr   = 支撑余量内的很小修正
  tauCmd    = tauStable + tauCorr

执行层：
  tauPassive = K/B 被动刚度
  tauActual  = tauCmd + tauPassive
```

也就是：

```text
命令层先拟合主动维持力
被动刚度再做小偏差/高频补偿
两者合起来拟合真正的姿态维持力
```

更新：

```text
每 50–100ms 重算一次
zero-order hold
相邻更新之间 slew 过渡
```

不写：

```text
hipX / CoM 误差
侧向 shank 误差
```

这些属于回正层。

## 6. SagittalRightingWriter

职责：

```text
矢状回正
```

所有权：

```text
hip2 / knee2
```

不写：

```text
foot / ankle
spine / upper
lateral shank
```

输入：

```text
eX = xRef − hipX（或 CoM 误差）
ePitch = pitchRef − trunkPitch
```

输出：

```text
hip2 correction
knee2 correction
```

SAG 窗口内的基础力可以同时考虑：

```text
IK 姿态
当前支撑/载荷
```

但只分配给它拥有的关节：

```text
hip2 / knee2
```

基本形式：

```text
tauSag = ID_SAG(q, qd, qdd*, IK_target, support)
       = Jᵀ (Kp·e + Kd·ė) + 基础支撑
```

只写 hip2 / knee2；StateHold 在 SAG 模式下不写这两轴。

小偏差：

```text
|e| 小 / 高频 → 被动 K/B
```

大偏差：

```text
|偏差| ≥ 20N 量级 → 主动回正接管
```

主动回正退出时：

```text
不是瞬间关
用上一帧 applied 平滑交还 HOLD
```

## 7. LateralRightingWriter

职责：

```text
小腿侧偏回正
```

所有权：

```text
ankle lateral torque
shank lateral correction
```

不写：

```text
foot 世界位姿 / foot qRef（始终归 WorldGripWriter）
hip2 / knee2
spine / upper
```

LAT 窗口内的基础力可以同时考虑：

```text
IK 姿态
当前支撑/载荷
```

但只分布给：

```text
ankle / shank lateral
```

输入：

```text
shank roll / yaw
foot roll / yaw
左右 CoP / 负载差
```

更新：

```text
20–50Hz 重算
中间 hold
输出 slew
```

第一版不实现。

## 8. 交接

启用回正时：

```text
捕获上一帧 applied
新写手以它为起点
平滑接管
StateHold 退出对应轴
```

禁止：

```text
两个写手同帧写同一轴
用单帧 fz 切换所有权
首帧直接跳到新目标
```

交接后第一帧允许旧 `applied` 留在 ledger 里，但新物理步只能由新写手写。

## 9. 频率

```text
LoadState：每帧更新，last-valid 保持
StateHold：50–100ms 重算 + hold + slew
Sagittal：SAG 窗口内每帧
Lateral：LAT 窗口内 20–50Hz 重算 + hold
SAG / LAT 互斥，窗口之间回 HOLD
```

## 10. 被动与主动边界

被动：

```text
小偏差、高频
K/B 直接作用在同一个 PD
```

主动：

```text
持续偏差超过阈值
回正写手接管
```

禁止：

```text
用大 K 代替回正
用固定时间 ramp 假装回正
用第二写手叠加对拉
```

## 11. 实施顺序

```text
Phase 1
  连续 LoadState
  StateHoldWriter 接管全部下盘
  不接 Sagittal / Lateral

Phase 2
  接 SagittalRightingWriter
  只接管 hip2 / knee2
  HOLD 退出这两轴

Phase 3
  接 LateralRightingWriter
  接管 foot / ankle / shank
  HOLD 退出这些轴

Phase 4
  验收两种回正的交接与退出
```

## 12. 验收

```text
同一轴同一帧 writes=1
HOLD/SAG/LAT 语义清晰
交接前后 applied 连续
无单帧 fz=0 导致的 target 塌陷
hip2/knee2 不被 HOLD 与 SAG 对拉
foot/ankle 不被 HOLD 与 LAT 对拉
上身无主动写手
SAG / LAT 不会同帧同时接管
回正窗口之间 HOLD 重新稳定
```
