# 蹲下脚踝抓地：现状与重构

日期：2026-11-18  
范围：站立 → 蹲下 → 交接 → 法庭

## 1. 目标

```text
蹲下过程脚体世界位置固定
脚掌始终贴地
CoP 在脚掌内
膝/小腿不被踝带歪
交接后脚不歪、不飞、不抖
```

不是：

```text
foot q0 保持
foot kp 硬锁
qRel 直接写脚
```

## 2. 当前实现

### 2.1 模块

```text
src/core/servo/footWorldTarget.ts
src/core/servo/ankleComp.ts
src/core/servo/footAnkleModule.ts
```

`ControlModule` 全程只有一个实例：

```text
this.footAnkle = new FootAnkleModule(n)
```

`FootAnkleModule`：

```text
FootWorldTarget：捕获脚体世界位姿
AnkleComp：qRel = inverse(qShank) · qFootTarget
           rotvec → foot0/1/2
```

写手：

```text
src = lowerCommand.ankleComp
kind = angle
```

### 2.2 当前问题

```text
qRel 的 rotvec 是小腿/世界系
foot0/1/2 是关节本地轴
```

直接：

```text
foot0 += rotvec.x
foot1 += rotvec.y
foot2 += rotvec.z
```

导致：

```text
脚内收
脚歪
侧滑
交接后脚飞
```

另外：

```text
foot applied 曾长期为 0
说明踝 proposal 未进入最终执行
```

## 3. 观察到的现象

### 3.1 蹲下过程

```text
t≈2~4s: comX/comZ 仍接近 0
t≈4.5s: comZ 开始增大
t≈5.5s: comZ 9~15cm
```

脚体世界：

```text
z: 16.1 → 11.5cm
foot_l/1 applied: ±59 N·m
```

说明：

```text
foot1 被另一个写手持续扭转
脚在世界系侧滑
```

### 3.2 交接后

```text
右脚 roll: +15.8° → -44.9°
foot0/1/2 applied = 0
```

说明：

```text
交接后踝没有有效写手
脚只是被动歪
```

## 4. 根因

```text
1. qRel 轴序错误
2. 脚/踝写手未真正 applied
3. foot1 还有未清理写手
4. 蹲下与交接不是同一个有效接触闭环
```

不是：

```text
摩擦不够
脚没力
```

## 5. 新架构

### 5.1 层级

```text
FootWorldTarget
  - 脚体世界位姿
  - 接触参考

FootContact
  - 每脚 Fz/CoP
  - 摩擦锥
  - 支撑多边形

AnkleAdmittance
  - CoP 误差 → roll/pitch 角速度
  - 不给脚额外侧向力

AnkleLocal
  - 不同姿势的局部偏置

ShankGuard
  - hip/knee 保持小腿
  - 吸收踝反作用

PD
  - 唯一执行
```

### 5.2 踝

```text
CopErr = CoP_target - CoP_now
[ω_roll; ω_pitch] = A_cop · CopErr
ankleLocal += [ω_roll; ω_pitch] · dt
```

局部：

```text
ankleRef = localPose + CoP_correction
```

禁止：

```text
qRel rotvec 直接分给 foot0/1/2
```

### 5.3 脚

```text
脚体世界位姿固定
foot0/1/2 由 Ankle 唯一写
不写 q0
不做高刚度脚 PD
```

### 5.4 腿

```text
hip/knee 维持 shank
不允许踝反作用把小腿带歪
```

## 6. 写手表

```text
foot 世界位姿：FootWorldTarget
foot0/1/2：Ankle 唯一
hip/knee：ShankGuard / LegSupport
arch/mfoot：FootContact
PD：唯一执行
```

禁止：

```text
旧 squat.foot0/1/2
FootPad 写脚力矩
JointLimit 写 foot external
踝产生额外侧向力
```

## 7. 验收

```text
foot 世界位置漂移 < 2mm
foot roll/pitch < 1°
CoP 在脚掌内
每个脚轴 writes=1
foot applied 连续
fz 连续 >0
shank 角度不被踝带偏
```

## 8. 实施顺序

```text
1. 停用 qRel 版本
2. 隔离标定 foot0/foot2 对 CoP/roll 的符号
3. 实现 AnkleAdmittance
4. 实现 FootContact
5. 实现 ShankGuard
6. 接 PD
7. 全流程验证
```
