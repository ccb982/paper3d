# 蹲下脚踝抓地：现状与重构

日期：2026-11-18  
范围：站立 → 蹲下 → 交接 → 法庭

## 1. 目标

```text
蹲下过程脚体世界位置固定
脚掌始终贴地
CoP 在脚掌内
膝/小腿不被踝带歪
交接后脚不歪、不飞、不抖
```

不是：

```text
foot q0 保持
foot kp 硬锁
qRel 直接写脚
```

## 2. 当前实现

### 2.1 模块

```text
src/core/servo/footWorldTarget.ts
src/core/servo/ankleComp.ts
src/core/servo/footAnkleModule.ts
```

`ControlModule` 全程只有一个实例：

```text
this.footAnkle = new FootAnkleModule(n)
```

`FootAnkleModule`：

```text
FootWorldTarget：捕获脚体世界位姿
AnkleComp：qRel = inverse(qShank) · qFootTarget
           rotvec → foot0/1/2
```

写手：

```text
src = lowerCommand.ankleComp
kind = angle
```

### 2.2 当前问题

```text
qRel 的 rotvec 是小腿/世界系
foot0/1/2 是关节本地轴
```

直接：

```text
foot0 += rotvec.x
foot1 += rotvec.y
foot2 += rotvec.z
```

导致：

```text
脚内收
脚歪
侧滑
交接后脚飞
```

另外：

```text
foot applied 曾长期为 0
说明踝 proposal 未进入最终执行
```

## 3. 观察到的现象

### 3.1 蹲下过程

```text
t≈2~4s: comX/comZ 仍接近 0
t≈4.5s: comZ 开始增大
t≈5.5s: comZ 9~15cm
```

脚体世界：

```text
z: 16.1 → 11.5cm
foot_l/1 applied: ±59 N·m
```

说明：

```text
foot1 被另一个写手持续扭转
脚在世界系侧滑
```

### 3.2 交接后

```text
右脚 roll: +15.8° → -44.9°
foot0/1/2 applied = 0
```

说明：

```text
交接后踝没有有效写手
脚只是被动歪
```

## 4. 根因

```text
1. qRel 轴序错误
2. 脚/踝写手未真正 applied
3. foot1 还有未清理写手
4. 蹲下与交接不是同一个有效接触闭环
```

不是：

```text
摩擦不够
脚没力
```

## 5. 新架构

### 5.1 层级

```text
FootWorldTarget
  - 脚体世界位姿
  - 接触参考

FootContact
  - 每脚 Fz/CoP
  - 摩擦锥
  - 支撑多边形

AnkleAdmittance
  - CoP 误差 → roll/pitch 角速度
  - 不给脚额外侧向力

AnkleLocal
  - 不同姿势的局部偏置

ShankGuard
  - hip/knee 保持小腿
  - 吸收踝反作用

PD
  - 唯一执行
```

### 5.2 踝

```text
CopErr = CoP_target - CoP_now
[ω_roll; ω_pitch] = A_cop · CopErr
ankleLocal += [ω_roll; ω_pitch] · dt
```

局部：

```text
ankleRef = localPose + CoP_correction
```

禁止：

```text
qRel rotvec 直接分给 foot0/1/2
```

### 5.3 脚

```text
脚体世界位姿固定
foot0/1/2 由 Ankle 唯一写
不写 q0
不做高刚度脚 PD
```

### 5.4 腿

```text
hip/knee 维持 shank
不允许踝反作用把小腿带歪
```

## 10. 2026-11-21 最终设计（接触优先 / 慢回正 / 反解）

### 10.1 现象与根因

现象：

```text
脚刚开始抓地
过一会脚 roll/pitch 偏
脚稍微离地一下，全身立刻崩
```

根因不是脚刚度不够，而是：

```text
foot 接触是二值开关
fz 一低 → contact/CoP 失效 → 支撑力整段消失
脚没有 6D 位姿约束，只有关节 PD
踝用大 Kp/大力矩直接改脚，反作用把 shank 带歪
```

因此不能继续加脚 PD 刚度。

### 10.2 优先级

```text
P0 脚底接触/不滑
P1 脚体世界位姿（位置 + 姿态）
P2 CoP / GRF 分配
P3 shank 姿态
P4 踝慢回正
```

脚是**参考系**，不是末端执行器。  
踝只负责在 shank 与脚之间解出关节角。

### 10.3 脚：接触优先，位置固定

```text
footWorldTarget 在接触建立时捕获
接触期间：位置/姿态锁定（软约束）
离地：保持最后接触位姿，不瞬间清零
着地：fz > enter 连续 3 帧才切 loaded
离地：fz < exit 连续 5 帧才切 airborne
```

禁止：

```text
fz 一帧低就删 CoP
一离地就清空 ankle/脚支撑
用高刚度 foot PD 硬压
```

### 10.4 踝：逆解，不用大力矩

```text
qAnkleTarget = IK(qShank, qFootWorldTarget)
qAnkleRef    = rateLimit(qAnkleTarget, 10–30°/s)
tauAnkle     = Kp(qAnkleRef − q) + Kd(0 − qdot)
```

参数：

```text
Kp 小
tau cap 小，5–10N·m 量级
死区 1–2°
```

脚回正是**慢外环**，不是大刚度内环。

### 10.5 踝不影响 shank

严格说，关节力矩一定有反作用。能做到的是：

```text
踝力矩小 + 速率限制
hip/knee 的 ShankGuard 保持小腿
脚接触约束优先
```

如果必须完全隔离，使用：

```text
足端接触约束 + 全身 WBC/IK
踝反作用由 hip/knee 在零空间补偿
```

普通 PD 只能做到“影响很小”，不能做到物理上零影响。

### 10.6 脚稍微离地不崩

离地瞬间禁止：

```text
删支撑
删 CoP
把 ankle ff 清零
把 foot PD 目标切到 q0
```

应改为：

```text
保留最后有效 CoP / 支撑 ff，按 fz 权重衰减
foot pose 保持最后接触位姿
fz 回到 enter 后平滑恢复
contact state 用滞回，不用单帧阈值
```

### 10.7 写手表

```text
foot 世界位姿：FootWorldTarget（唯一参考）
foot0/1/2 角度：Ankle IK（唯一）
foot 支撑/CoP：FootContact（唯一 ff）
hip/knee：ShankGuard / LegSupport
PD：唯一执行
```

每个 foot 轴仍只有一个角度写手；支撑力矩只作为同一 PD 的 ff。

### 10.8 验收

```text
foot 世界位置漂移 < 2mm
foot roll/pitch < 1°
轻微离地后 0.2s 内恢复，不出现 fall
CoP 在脚掌内，摩擦不越界
foot applied 连续，无单帧跳变
shank 角度不被踝带偏
每个 foot 轴 writes=1
```
