# 2D 单相自由表面流模拟器 - 完整流程图

## 一、整体架构总览（新架构）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           FluidSimulator                                   │
│                                                                            │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                    核心渲染基础设施                                  │   │
│  │  Scene + OrthographicCamera + PlaneGeometry (全屏四边形)            │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                      纹理缓冲系统                                    │   │
│  │                                                                    │   │
│  │  ┌─────────────────────────────────────────────────────────────┐   │   │
│  │  │  速度场（双缓冲）                                              │   │   │
│  │  │  velTexA ◄─── curVelTex ───► velTexB                         │   │   │
│  │  │  RGBA: [vx, vy, 0, 1]                                        │   │   │
│  │  └─────────────────────────────────────────────────────────────┘   │   │
│  │                                    │                               │   │
│  │  ┌─────────────────────────────────────────────────────────────┐   │   │
│  │  │  Level Set 场（双缓冲）                                        │   │   │
│  │  │  phiTexA ◄─── curPhiTex ───► phiTexB                         │   │   │
│  │  │  RGBA: [phi, 0, 0, 1]  phi > 0 空气 | phi < 0 水              │   │   │
│  │  └─────────────────────────────────────────────────────────────┘   │   │
│  │                                    │                               │   │
│  │  ┌─────────────────────────────────────────────────────────────┐   │   │
│  │  │  压力场（双缓冲）                                              │   │   │
│  │  │  pressureTexA ◄─── curPressureTex ───► pressureTexB          │   │   │
│  │  │  RGBA: [p, 0, 0, 1]                                          │   │   │
│  │  └─────────────────────────────────────────────────────────────┘   │   │
│  │                                    │                               │   │
│  │  ┌─────────────────────────────────────────────────────────────┐   │   │
│  │  │  辅助纹理（单缓冲）                                            │   │   │
│  │  │  divergenceTex     - 散度场                                   │   │   │
│  │  │  forcedVelTex      - 外力后速度场                             │   │   │
│  │  │  velAfterCollisionTex - 墙碰撞后速度场                        │   │   │
│  │  │  velCorrectTex     - 速度修正后                               │   │   │
│  │  └─────────────────────────────────────────────────────────────┘   │   │
│  │                                    │                               │   │
│  │  ┌─────────────────────────────────────────────────────────────┐   │   │
│  │  │  固体相关纹理（预计算）                                         │   │   │
│  │  │  solidMaskTex      - 固体掩码（外部传入）                      │   │   │
│  │  │  solidNormalTex    - 固体法线（自动计算）                      │   │   │
│  │  │  RGBA: [nx, ny, 0, 1]  法线方向（指向固体外部）               │   │   │
│  │  └─────────────────────────────────────────────────────────────┘   │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────────────┐
│  │                      渲染层（分层渲染架构）                              │
│  │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  水体渲染着色器 - 分层合成                                  │   │
│  │  输入: curPhiTex.texture (phi), curVelTex.texture (vel)     │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                    │
│  ═══════════════════════════════════════════════════════════════   │
│                                                                    │
│  【分层渲染架构 - 各层独立计算，最终叠加】                          │
│                                                                    │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  Layer 1: 基础颜色层 (Base Color)                          │   │
│  │  - 根据 depth 混合 waterColor 和 deepColor                  │   │
│  │  - 不受光照影响                                            │   │
│  │  - 公式: baseColor = mix(waterColor, deepColor, depth)     │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              │                                      │
│                              ▼                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  Layer 2: 漫反射光照层 (Diffuse Lighting)                   │   │
│  │  - 法线与光源夹角决定明暗                                    │   │
│  │  - 公式: diffuse = baseColor × diff                        │   │
│  │  - diff = max(0.1, dot(normal, lightDir))                 │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              │                                      │
│                              ▼                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  Layer 3: 高光层 (Specular Lighting)                       │   │
│  │  - 镜面反射，单独控制强度                                    │   │
│  │  - 公式: specular = white × spec × specularIntensity      │   │
│  │  - spec = pow(max(dot(normal, halfDir), 0.0), 64.0)       │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              │                                      │
│                              ▼                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  Layer 4: 边缘发光层 (Edge Glow / Emissive)                 │   │
│  │  - 仅在水面表面附近（phi 接近 0）生效                        │   │
│  │  - 不参与漫反射计算，单独叠加                                │   │
│  │  - 公式: emissive = glowColor × edge × edgeIntensity       │   │
│  │  - glowColor = vec3(0.2, 0.6, 1.0) 淡蓝色                  │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              │                                      │
│                              ▼                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  Layer 5: 流动扰动层 (Flow Detail)                          │   │
│  │  - 速度场产生的视觉效果，作为细节噪点                        │   │
│  │  - 不大面积改变色调                                          │   │
│  │  - 公式: flowColor = vec3(0.15, 0.25, 0.35) × flow          │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                    │
│  ═══════════════════════════════════════════════════════════════   │
│                                                                    │
│  【最终合成公式】                                                  │
│  finalColor = diffuse + specular + emissive + flowColor          │
│                                                                    │
│  【渲染决策】                                                      │
│  - phi > 0.001 → discard（空气区域完全透明）                      │
│  - phi <= 0.001 → 渲染流体各层                                     │
│                                                                    │
│  【透明度】                                                        │
│  alpha = clamp(0.6 - phi * 2.0, 0.2, 0.9)                         │
│                                                                    │
│  接口: getLevelSetTexture(), getVelocityTexture()                │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 二、每帧完整计算流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              每帧 update(dt)                                │
│                                                                             │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 0 步】初始化                                                          │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  dt = min(传入的deltaTime, 0.033)  // 限制最大时间步长                │   │
│  │  resolution = [width, height]                                        │   │
│  │  dtReinit = 0.5 / min(width, height)                               │   │
│  │                                                                        │   │
│  │  // 自定义流体形状初始化（可选）                                       │   │
│  │  if (params.initialLevelSet) {                                       │   │
│  │      copyTextureToTarget(params.initialLevelSet, phiTexA/B)         │   │
│  │  } else {                                                            │   │
│  │      renderFullscreen(initLevelSetShader(), phiTexA/B)              │   │
│  │  }                                                                   │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 0.5 步】预计算固体法线（仅当 solidMask 改变时执行一次）               │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  solidMaskTex ──[计算梯度]──→ solidNormalTex                        │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                               │  │   │
│  │  │      solid_r = solidMask[x+1, y]                      │  │   │
│  │  │      solid_l = solidMask[x-1, y]                      │  │   │
│  │  │      solid_t = solidMask[x, y+1]                      │  │   │
│  │  │      solid_b = solidMask[x, y-1]                      │  │   │
│  │  │                                                               │  │   │
│  │  │      // 法线 = 梯度，归一化                                     │  │   │
│  │  │      nx = solid_r - solid_l                                    │  │   │
│  │  │      ny = solid_t - solid_b                                    │  │   │
│  │  │      normal = normalize([nx, ny])                              │  │   │
│  │  │                                                               │  │   │
│  │  │      solidNormal[x,y] = normal                                 │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  ✅ 预计算后，每帧直接读取 solidNormalTex，无需重复计算！        │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 1 步】固体边界清理 #1（可选）                                          │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: solidBoundaryClearShader()                               │   │
│  │  输入: curVelTex, curPhiTex, solidMaskTex                         │   │
│  │  输出: velTexA, phiTexA                                           │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                                       │  │   │
│  │  │      isSolid = texture2D(solidMask, uv).r                    │  │   │
│  │  │      vel = texture2D(velInput, uv).rg                         │  │   │
│  │  │      phi = texture2D(phiInput, uv).r                          │  │   │
│  │  │      if (isSolid > 0.5) {                                     │  │   │
│  │  │          vel = vec2(0.0)                                       │  │   │
│  │  │          phi = -1.0                                           │  │   │
│  │  │      }                                                         │  │   │
│  │  │      gl_FragColor = vec4(vel, phi, 1.0)                       │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  更新: curVelTex = velTexA, curPhiTex = phiTexA                    │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 2 步】速度平流                                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: velocityAdvectionShader()                                  │   │
│  │  输入: curVelTex                                                    │   │
│  │  输出: velTexB                                                     │   │
│  │                                                                        │   │
│  │  公式: vel_new = vel_old (反推法)                                    │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                                       │  │   │
│  │  │      vel = texture2D(velocity, uv).rg                         │  │   │
│  │  │      step = vel * dt / resolution                            │  │   │
│  │  │      back_uv = uv - step                                     │  │   │
│  │  │      vel_new = texture2D(velocity, back_uv).rg               │  │   │
│  │  │      gl_FragColor = vec4(vel_new, 0.0, 1.0)                  │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  更新: curVelTex = velTexB                                          │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 3 步】外力计算（重力 + 粘性 + 表面张力）                               │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: externalForcesShader()                                     │   │
│  │  输入: curVelTex, curPhiTex                                         │   │
│  │  输出: forcedVelTex                                                 │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                                       │  │   │
│  │  │      vel = texture2D(velocity, uv).rg                         │  │   │
│  │  │      phi = texture2D(levelset, uv).r                          │  │   │
│  │  │                                                               │  │   │
│  │  │      // 1. 重力                                                │  │   │
│  │  │      vel.y += gravity * dt                                   │  │   │
│  │  │                                                               │  │   │
│  │  │      // 2. 粘性扩散（Laplacian）                              │  │   │
│  │  │      vel += (viscosity/density) * dt * ∇²vel                  │  │   │
│  │  │                                                               │  │   │
│  │  │      // 3. 表面张力（仅在界面附近）                            │  │   │
│  │  │      if (|phi| < eps) {                                       │  │   │
│  │  │          f_st = sigma * kappa * delta * n                     │  │   │
│  │  │          vel += (f_st / density) * dt                        │  │   │
│  │  │      }                                                         │  │   │
│  │  │                                                               │  │   │
│  │  │      // 4. 流体注入（可选）                                    │  │   │
│  │  │      if (injectionEnabled && dist < size) {                  │  │   │
│  │  │          phi -= injectionFlowRate * dt                       │  │   │
│  │  │          vel += injectionVel                                  │  │   │
│  │  │      }                                                         │  │   │
│  │  │                                                               │  │   │
│  │  │      gl_FragColor = vec4(vel, phi, 1.0)                      │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  更新: curVelTex = forcedVelTex                                      │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 4 步】墙碰撞处理（使用预计算法线）⭐ 新增                              │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: wallCollisionShader()                                      │   │
│  │  输入: forcedVelTex, solidMaskTex, solidNormalTex（预计算）        │   │
│  │  输出: velAfterCollisionTex                                        │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                                       │  │   │
│  │  │      isSolid = texture2D(solidMask, uv).r                    │  │   │
│  │  │                                                               │  │   │
│  │  │      if (isSolid < 0.5) {                                     │  │   │
│  │  │          output = texture2D(forcedVel, uv).rg  // 直接通过    │  │   │
│  │  │      } else {                                                 │  │   │
│  │  │          // ========== 墙区域：反弹计算 ==========              │  │   │
│  │  │          normal = texture2D(solidNormal, uv).rg  // 预计算！ │  │   │
│  │  │          vel = texture2D(forcedVel, uv).rg                   │  │   │
│  │  │                                                               │  │   │
│  │  │          // 分解速度                                           │  │   │
│  │  │          vn = dot(vel, normal)  // 法向分量                 │  │   │
│  │  │          vt = vel - vn * normal  // 切向分量                 │  │   │
│  │  │                                                               │  │   │
│  │  │          // 法向反向 × 恢复系数 e                             │  │   │
│  │  │          vn_new = -vn * restitution  // e = 0.8               │  │   │
│  │  │                                                               │  │   │
│  │  │          // 切向 × 摩擦系数                                   │  │   │
│  │  │          vt_new = vt * friction  // μ = 0.95                │  │   │
│  │  │                                                               │  │   │
│  │  │          vel_new = vt_new + vn_new * normal                 │  │   │
│  │  │          gl_FragColor = vec4(vel_new, 0.0, 1.0)             │  │   │
│  │  │      }                                                         │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  ✅ 关键：直接读取预计算的 solidNormalTex，无需每帧计算梯度！   │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 5 步】计算散度                                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: divergenceShader()                                         │   │
│  │  输入: velAfterCollisionTex (或 forcedVelTex 若无固体)            │   │
│  │  输出: divergenceTex                                                │   │
│  │                                                                        │   │
│  │  公式: div = ∂vx/∂x + ∂vy/∂y                                        │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                                       │  │   │
│  │  │      vx_R = texture2D(velocity, uv+dx).x                     │  │   │
│  │  │      vx_L = texture2D(velocity, uv-dx).x                     │  │   │
│  │  │      vy_T = texture2D(velocity, uv+dy).y                     │  │   │
│  │  │      vy_B = texture2D(velocity, uv-dy).y                     │  │   │
│  │  │      div = (vx_R - vx_L) / 2dx + (vy_T - vy_B) / 2dy        │  │   │
│  │  │      gl_FragColor = vec4(div, 0.0, 0.0, 1.0)                 │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 6 步】压力求解（Jacobi 迭代）                                         │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: pressureJacobiShader()                                    │   │
│  │  输入: divergenceTex, pressureTexA/B (ping-pong)                    │   │
│  │  输出: pressureTexB/A (交替)                                        │   │
│  │                                                                        │   │
│  │  公式: p_new = (p_L + p_R + p_D + p_U - div*h²/ρ/dt) / 4          │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for i = 0 to pressureIterations:                            │  │   │
│  │  │      for each pixel (x, y):                                   │  │   │
│  │  │          p_L = texture2D(pressure, uv-dx).r                   │  │   │
│  │  │          p_R = texture2D(pressure, uv+dx).r                   │  │   │
│  │  │          p_D = texture2D(pressure, uv-dy).r                   │  │   │
│  │  │          p_U = texture2D(pressure, uv+dy).r                   │  │   │
│  │  │          div = texture2D(divergence, uv).r                    │  │   │
│  │  │          h = 1 / resolution.x                                 │  │   │
│  │  │          p_new = (p_L+p_R+p_D+p_U - density/dt*div*h*h) / 4   │  │   │
│  │  │                                                               │  │   │
│  │  │          render → pressureDst                                 │  │   │
│  │  │          [pressureSrc, pressureDst] = swap()                  │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  更新: curPressureTex = pressureSrc                                │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 7 步】速度修正（压力梯度减法）                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: velocityCorrectShader()                                    │   │
│  │  输入: velAfterCollisionTex, curPressureTex                        │   │
│  │  输出: velCorrectTex                                               │   │
│  │                                                                        │   │
│  │  公式: vel_corrected = vel - ∇p / ρ                                  │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                                       │  │   │
│  │  │      vel = texture2D(velocity, uv).rg                         │  │   │
│  │  │      p_L = texture2D(pressure, uv-dx).r                       │  │   │
│  │  │      p_R = texture2D(pressure, uv+dx).r                       │  │   │
│  │  │      p_D = texture2D(pressure, uv-dy).r                       │  │   │
│  │  │      p_U = texture2D(pressure, uv+dy).r                       │  │   │
│  │  │      vel.x -= (dt/density) * (p_R-p_L) / (2dx)               │  │   │
│  │  │      vel.y -= (dt/density) * (p_U-p_D) / (2dy)               │  │   │
│  │  │      gl_FragColor = vec4(vel, 0.0, 1.0)                       │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  更新: curVelTex = velCorrectTex                                   │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 8 步】Level Set 平流                                                  │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: levelSetAdvectionShader()                                 │   │
│  │  输入: curVelTex, forcedVelTex, curPhiTex                          │   │
│  │  输出: phiTexB                                                     │   │
│  │                                                                        │   │
│  │  公式: phi_new = phi_old (反推法)                                    │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                                       │  │   │
│  │  │      vel = texture2D(velocity, uv).rg                         │  │   │
│  │  │      step = vel * dt / resolution                            │  │   │
│  │  │      back_uv = uv - step                                     │  │   │
│  │  │      if (injectionEnabled) {                                  │  │   │
│  │  │          phi = texture2D(forcedVel, back_uv).b                │  │   │
│  │  │      } else {                                                 │  │   │
│  │  │          phi = texture2D(levelset, back_uv).r                 │  │   │
│  │  │      }                                                         │  │   │
│  │  │      gl_FragColor = vec4(phi, 0.0, 0.0, 1.0)                  │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  更新: curPhiTex = phiTexB                                          │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 9 步】Level Set 重新初始化（保持界面锐利）                            │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: levelSetReinitShader()                                     │   │
│  │  输入: curPhiTex                                                    │   │
│  │  输出: phiTexA/B (ping-pong)                                        │   │
│  │                                                                        │   │
│  │  公式: phi_new = phi - dt_reinit * sign(phi) * (|∇phi| - 1)        │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for i = 0 to reinitIterations:                              │  │   │
│  │  │      for each pixel (x, y):                                   │  │   │
│  │  │          phi_0 = texture2D(levelset, uv).r                    │  │   │
│  │  │          phi_grad = length(∇phi)                              │  │   │
│  │  │          sign = sign(phi_0)                                   │  │   │
│  │  │          phi_new = phi_0 - dt_reinit * sign * (phi_grad - 1)  │  │   │
│  │  │          gl_FragColor = vec4(phi_new, 0.0, 0.0, 1.0)          │  │   │
│  │  │      render → phiTexA/B (交替)                                 │  │   │
│  │  │      curPhiTex = 输出目标                                     │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 10 步】固体边界清理 #2（可选）                                         │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  同第 1 步：清理固体区域的速度和 Level Set                          │
│  │  更新: curVelTex, curPhiTex                                        │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 三、分层渲染架构详解

### 3.1 分层渲染设计原则

传统渲染方式将所有效果直接累加到颜色中，导致颜色过曝、整体发白。分层渲染将颜色计算拆解为多个独立层，各层使用合理的混合方式组合，最终叠加形成最终颜色。

### 3.2 分层架构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        分层渲染架构图                                        │
└─────────────────────────────────────────────────────────────────────────────┘

        ┌─────────────────────────────────────┐
        │     Layer 1: 基础颜色层              │
        │     Base Color Layer                │
        │                                     │
        │  depth = clamp(-phi * 2.0, 0, 1)   │
        │  baseColor = mix(waterColor,       │
        │               deepColor, depth)     │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     Layer 2: 漫反射光照层             │
        │     Diffuse Lighting Layer          │
        │                                     │
        │  normal = normalize(∇phi)          │
        │  diff = max(0.1, dot(normal, L))   │
        │  diffuse = baseColor × diff        │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     Layer 3: 高光层                 │
        │     Specular Lighting Layer         │
        │                                     │
        │  viewDir = (0, 0, 1)               │
        │  halfDir = normalize(L + viewDir) │
        │  spec = pow(max(dot(n,h),0), 64)  │
        │  specular = white × spec ×         │
        │             specularIntensity      │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     Layer 4: 边缘发光层              │
        │     Edge Glow / Emissive Layer      │
        │                                     │
        │  edge = 1 - smoothstep(0, edgeW,   │
        │                    abs(phi))        │
        │  glowColor = vec3(0.2, 0.6, 1.0)   │
        │  emissive = glowColor × edge ×     │
        │             edgeIntensity          │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     Layer 5: 流动扰动层              │
        │     Flow Detail Layer               │
        │                                     │
        │  flow = length(velocity) × 0.5     │
        │  flowColor = vec3(0.15, 0.25,      │
        │               0.35) × flow ×       │
        │               flowIntensity        │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     最终合成                        │
        │     Final Composition               │
        │                                     │
        │  finalColor = diffuse + specular +  │
        │               emissive + flowColor │
        │                                     │
        │  alpha = clamp(0.6 - phi*2, 0.2,    │
        │              0.9)                   │
        └─────────────────────────────────────┘
```

### 3.3 各层说明

| 层名称 | 内容 | 混合方式 | 说明 |
|--------|------|----------|------|
| Base Color | 水体的基础颜色 | 直接输出 | 根据深度混合浅蓝和深蓝 |
| Diffuse Lighting | 漫反射光照 | 乘以基础色 | 决定水体明暗，不添加额外颜色 |
| Specular | 高光反射 | 最后添加 | 白色高光，可独立控制强度 |
| Emissive | 边缘发光 | 最后叠加 | 仅在水面附近生效，不参与漫反射 |
| Flow Detail | 流动扰动 | 作为细节 | 不大面积改变色调 |

### 3.4 最终合成公式

```
finalColor = diffuse + specular + emissive + flowColor
           = (baseColor × diff) + (white × spec × specInt) + 
             (glowColor × edge × edgeInt) + (flowBaseColor × flow × flowInt)

alpha = clamp(0.6 - phi × 2.0, 0.2, 0.9)
```

### 3.5 渲染决策

```glsl
// 空气区域：完全丢弃，不参与渲染
if (phi > 0.001) {
    discard;
}

// 流体区域：渲染各层
float depth = clamp(-phi * 2.0, 0.0, 1.0);
vec3 baseColor = mix(waterColor, deepColor, depth);

// ... 计算各层并叠加
```

### 3.6 分层渲染优势

1. **互不干扰**：漫反射、高光、发光互相独立，修改边缘光强度不会影响光照强度
2. **易于调试**：可以暂时关闭某一层来观察其它层效果
3. **可扩展**：未来增加屏幕空间反射、折射等效果，只需额外添加层，不影响已有层
4. **性能不变**：依然是一次绘制，只是计算逻辑更清晰

## 四、纹理格式规范

### 4.1 速度场纹理 (velTexA/B)
```
RGBA: [vx, vy, 0, 1]
- R: 水平速度分量
- G: 垂直速度分量
- B: 未使用
- A: 未使用（固定为1）
```

### 4.2 Level Set 纹理 (phiTexA/B)
```
RGBA: [phi, 0, 0, 1]
- R: Level Set 值
  - phi > 0: 空气区域
  - phi < 0: 水体区域
  - phi = 0: 自由表面
- G, B: 未使用
- A: 未使用（固定为1）
```

### 4.3 压力场纹理 (pressureTexA/B)
```
RGBA: [p, 0, 0, 1]
- R: 压力值
- G, B: 未使用
- A: 未使用（固定为1）
```

### 4.4 固体掩码纹理 (solidMaskTex)
```
RGBA: [mask, 0, 0, 1]
- R: 固体标记
  - mask > 0.5: 固体
  - mask <= 0.5: 流体/空气
- G, B: 未使用
- A: 未使用
```

### 4.5 固体法线纹理 (solidNormalTex)
```
RGBA: [nx, ny, 0, 1]
- R: 法线 X 分量
- G: 法线 Y 分量
- B: 未使用
- A: 未使用（固定为1）
- 预计算后每帧直接读取，无需重复计算
```

## 五、关键优化点

### 5.1 预计算固体法线
- 固体法线在 solidMask 改变时计算一次
- 存储到 solidNormalTex
- 每帧墙碰撞直接读取，无需重复计算梯度

### 5.2 双缓冲 Ping-Pong
- 速度场、Level Set、压力场都使用双缓冲
- 避免读写冲突，提高 GPU 并行度

### 5.3 固体边界清理
- 第 1 步和第 10 步清理固体内部的速度和 Level Set
- 确保固体内部不会残留错误的速度或 Level Set 值

### 5.4 压力迭代的自由表面边界条件
- 当 phi > 0（空气）或 isSolid > 0.5（固体）时，压力强制设为 0
- 避免空气区域建立压力场，提高体积守恒

### 5.5 流体区域判断容差
- 使用 phi > 0.001 而非 phi > 0
- 避免线性纹理过滤导致的边缘锯齿
