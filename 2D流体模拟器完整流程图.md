│  └─────────────────────────────────────────────────────────────┘   │
│                                                                    │

│  │  Layer 1: 基础颜色层 (Base Color)                          │   │

│                              │                                      │
│                              ▼                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │

│  │  - 公式: diffuse = baseColor × diff                        │   │

│                              │                                      │
│                              ▼                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │

│  │  - 公式: specular = white × spec × specularIntensity      │   │
│  │  - spec = pow(max(dot(normal, halfDir), 0.0), 64.0)       │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              │                                      │
│                              ▼                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  Layer 4: 边缘发光层 (Edge Glow / Emissive)                 │   │

│  │  - 不参与漫反射计算，单独叠加                                │   │
│  │  - 公式: emissive = glowColor × edge × edgeIntensity       │   │
│  │  - glowColor = vec3(0.2, 0.6, 1.0) 淡蓝色                  │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              │                                      │
│                              ▼                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  Layer 5: 流动扰动层 (Flow Detail)                          │   │
│  │  - 速度场产生的视觉效果，作为细节噪点                        │   │
│  │  - 不大面积改变色调                                          │   │
│  │  - 公式: flowColor = vec3(0.15, 0.25, 0.35) × flow          │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                    │
│  ═══════════════════════════════════════════════════════════════   │
│                                                                    │
│  【最终合成公式】                                                  │
│  finalColor = diffuse + specular + emissive + flowColor          │
│                                                                    │
│  【渲染决策】                                                      │
│  - phi >= 0.0 → discard（空气和界面完全透明）                      │
│  - phi < 0.0 → 渲染流体各层                                         │
│                                                                    │
│  【透明度】                                                        │
│  alpha = clamp(0.6 - phi * 2.0, 0.2, 0.9)                         │
│                                                                    │
│  接口: getLevelSetTexture(), getVelocityTexture()                │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 二、每帧完整计算流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              每帧 update(dt)                                │
│                                                                             │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 0 步】初始化                                                          │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  dt = min(传入的deltaTime, 0.033)  // 限制最大时间步长                │   │
│  │  resolution = [width, height]                                        │   │
│  │  dtReinit = 0.5 / min(width, height)                               │   │
│  │                                                                        │   │
│  │  // 自定义流体形状初始化（可选）                                       │   │
│  │  if (params.initialLevelSet) {                                       │   │
│  │      copyTextureToTarget(params.initialLevelSet, phiTexA/B)         │   │
│  │  } else {                                                            │   │
│  │      renderFullscreen(initLevelSetShader(), phiTexA/B)              │   │
│  │  }                                                                   │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 0.5 步】预计算固体法线（仅当 solidMask 改变时执行一次）               │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  solidMaskTex ──[计算梯度]──→ solidNormalTex                        │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                               │  │   │
│  │  │      solid_r = solidMask[x+1, y]                      │  │   │
│  │  │      solid_l = solidMask[x-1, y]                      │  │   │
│  │  │      solid_t = solidMask[x, y+1]                      │  │   │
│  │  │      solid_b = solidMask[x, y-1]                      │  │   │
│  │  │                                                               │  │   │
│  │  │      // 法线 = 梯度，归一化                                     │  │   │
│  │  │      nx = solid_r - solid_l                                    │  │   │
│  │  │      ny = solid_t - solid_b                                    │  │   │
│  │  │      normal = normalize([nx, ny])                              │  │   │
│  │  │                                                               │  │   │
│  │  │      solidNormal[x,y] = normal                                 │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  ✅ 预计算后，每帧直接读取 solidNormalTex，无需重复计算！        │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 1 步】固体边界清理 #1（可选）                                          │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: solidBoundaryClearShader()                               │   │
│  │  输入: curVelTex, curPhiTex, solidMaskTex                         │   │
│  │  输出: velTexA, phiTexA                                           │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                                       │  │   │
│  │  │      isSolid = texture2D(solidMask, uv).r                    │  │   │
│  │  │      vel = texture2D(velInput, uv).rg                         │  │   │
│  │  │      phi = texture2D(phiInput, uv).r                          │  │   │
│  │  │      if (isSolid > 0.5) {                                     │  │   │
│  │  │          vel = vec2(0.0)                                       │  │   │
│  │  │          phi = -1.0                                           │  │   │
│  │  │      }                                                         │  │   │
│  │  │      gl_FragColor = vec4(vel, phi, 1.0)                       │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  更新: curVelTex = velTexA, curPhiTex = phiTexA                    │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 2 步】速度平流                                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: velocityAdvectionShader()                                  │   │
│  │  输入: curVelTex                                                    │   │
│  │  输出: velTexB                                                     │   │
│  │                                                                        │   │
│  │  公式: vel_new = vel_old (反推法)                                    │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                                       │  │   │
│  │  │      vel = texture2D(velocity, uv).rg                         │  │   │
│  │  │      step = vel * dt / resolution                            │  │   │
│  │  │      back_uv = uv - step                                     │  │   │
│  │  │      vel_new = texture2D(velocity, back_uv).rg               │  │   │
│  │  │      gl_FragColor = vec4(vel_new, 0.0, 1.0)                  │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  更新: curVelTex = velTexB                                          │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 3 步】外力计算（重力 + 粘性 + 表面张力）                               │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: externalForcesShader()                                     │   │
│  │  输入: curVelTex, curPhiTex                                         │   │
│  │  输出: forcedVelTex                                                 │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                                       │  │   │
│  │  │      vel = texture2D(velocity, uv).rg                         │  │   │
│  │  │      phi = texture2D(levelset, uv).r                          │  │   │
│  │  │                                                               │  │   │
│  │  │      // 1. 重力（UV坐标系：y=0底部，y=1顶部，向下应减小vel.y）    │  │   │
│  │  │      vel.y -= gravity * dt                                   │  │   │
│  │  │                                                               │  │   │
│  │  │      // 2. 粘性扩散（Laplacian）                              │  │   │
│  │  │      vel += (viscosity/density) * dt * ∇²vel                  │  │   │
│  │  │                                                               │  │   │
│  │  │      // 3. 表面张力（仅在界面附近）                            │  │   │
│  │  │      if (|phi| < eps) {                                       │  │   │
│  │  │          f_st = sigma * kappa * delta * n                     │  │   │
│  │  │          vel += (f_st / density) * dt                        │  │   │
│  │  │      }                                                         │  │   │
│  │  │                                                               │  │   │
│  │  │      // 4. 流体注入（只在空气中 phi > 0）                      │  │   │
│  │  │      if (injectionEnabled && dist < size && phi > 0.0) {      │  │   │
│  │  │          mask = 1.0 - smoothstep(0.0, size, dist)            │  │   │
│  │  │          phi = phi - injectionFlowRate * dt * mask          │  │   │
│  │  │          vel += injectionVel * mask                           │  │   │
│  │  │      }                                                         │  │   │
│  │  │                                                               │  │   │
│  │  │      gl_FragColor = vec4(vel, phi, 1.0)                      │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  更新: curVelTex = forcedVelTex                                      │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 4 步】墙碰撞处理（使用预计算法线）⭐ 新增                              │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: wallCollisionShader()                                      │   │
│  │  输入: forcedVelTex, solidMaskTex, solidNormalTex（预计算）        │   │
│  │  输出: velAfterCollisionTex                                        │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                                       │  │   │
│  │  │      isSolid = texture2D(solidMask, uv).r                    │  │   │
│  │  │                                                               │  │   │
│  │  │      if (isSolid < 0.5) {                                     │  │   │
│  │  │          output = texture2D(forcedVel, uv).rg  // 直接通过    │  │   │
│  │  │      } else {                                                 │  │   │
│  │  │          // ========== 墙区域：反弹计算 ==========              │  │   │
│  │  │          normal = texture2D(solidNormal, uv).rg  // 预计算！ │  │   │
│  │  │          vel = texture2D(forcedVel, uv).rg                   │  │   │
│  │  │                                                               │  │   │
│  │  │          // 分解速度                                           │  │   │
│  │  │          vn = dot(vel, normal)  // 法向分量                 │  │   │
│  │  │          vt = vel - vn * normal  // 切向分量                 │  │   │
│  │  │                                                               │  │   │
│  │  │          // 法向反向 × 恢复系数 e                             │  │   │
│  │  │          vn_new = -vn * restitution  // e = 0.8               │  │   │
│  │  │                                                               │  │   │
│  │  │          // 切向 × 摩擦系数                                   │  │   │
│  │  │          vt_new = vt * friction  // μ = 0.95                │  │   │
│  │  │                                                               │  │   │
│  │  │          vel_new = vt_new + vn_new * normal                 │  │   │
│  │  │          gl_FragColor = vec4(vel_new, 0.0, 1.0)             │  │   │
│  │  │      }                                                         │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  ✅ 关键：直接读取预计算的 solidNormalTex，无需每帧计算梯度！   │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  【第 4.5 步】构建爆炸散度源 ⭐ 新增                                          │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  输入: activeExplosions, curPhiTex, curAgeTex                     │   │
│  │  输出: explosionDivTex, curPhiTex (可选), curAgeTex (可选)        │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────┐  │   │
│  │  │  // 阶段1: 遍历活跃爆炸列表（使用帧计数计时）                       │  │   │
│  │  │  清空 explosionDivTex（必须！避免上帧残留累积）                                          │  │   │
│  │  │  for each explosion in activeExplosions:                     │  │   │
│  │  │      frameElapsed = currentFrame - startFrame                 │  │   │
│  │  │      t = frameElapsed / durationFrames                        │  │   │
│  │  │      // 二次抛物线包络：先升后降，峰值在0.5                                 │  │   │
│  │  │      u = clamp(t, 0.0, 1.0)\nenvelope = 4.0 * u * (1.0 - u)                  │  │   │
│  │  │      if (u >= 1.0 || durationFrames <= 0): remove explosion   │  │   │
│  │  │                                                               │  │   │
│  │  │      // ⚠️ 负号关键！注入负散度才能产生向外膨胀效果                 │  │   │
│  │  │      S = -strength * envelope * mask(x)                        │  │   │
│  │  │      renderToTarget(S, explosionDivTex, false)  // 不清屏叠加  │  │   │
│  │  └───────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────┐  │   │
│  │  │  // 阶段2: 水花生成（createWater=true时）                   │  │   │
│  │  │  if (createWater):                                          │  │   │
│  │  │      for each pixel in explosionRadius:                       │  │   │
│  │  │          // 仅在空气区域生成水花（phi >= 0）                   │  │   │
│  │  │          // 不修改已有水体，避免"削平"效果                     │  │   │
│  │  │          if (mask > 0.0 && phi >= 0.0):                      │  │   │
│  │  │              phi = -radius * mask * envelope * 2.0           │  │   │
│  │  │                                                               │  │   │
│  │  │      // 使用双缓冲更新 phi，避免原地读写                       │  │   │
│  │  │      phiDst = (curPhiTex == phiTexA) ? phiTexB : phiTexA     │  │   │
│  │  │      curPhiTex = phiDst                                      │  │   │
│  │  └───────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────┐  │   │
│  │  │  // 阶段3: 重置新生水花的年龄为0                           │  │   │
│  │  │  if (createWater):                                          │  │   │
│  │  │      ageDst = (curAgeTex == ageTexA) ? ageTexB : ageTexA     │  │   │
│  │  │      renderToTarget(ageResetMat, ageDst)                     │  │   │
│  │  │      curAgeTex = ageDst                                      │  │   │

│  │                                                                        │   │
│  │  ✅ 关键设计: 爆炸不直接修改速度，而是注入散度源                   │   │
│  │  → 散度源通过压力求解器生成压力梯度，再由速度修正驱动流体         │   │
│  │  → 水花只在空气中生成（phi >= 0），避免破坏已有水体结构           │   │
│  │  → 使用帧计数代替wall-clock时间，确保每次模拟结果一致            │   │

│  【第 5 步】计算散度                                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: divergenceShader()                                         │   │
│  │  输入: velAfterCollisionTex, explosionDivTex                      │   │
│  │  输出: divergenceTex                                                │   │
│  │                                                                        │   │
│  │  公式: div = ∂vx/∂x + ∂vy/∂y + explosionDiv                       │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  for each pixel (x, y):                                       │  │   │
│  │  │      vx_R = texture2D(velocity, uv+dx).x                     │  │   │
│  │  │      vx_L = texture2D(velocity, uv-dx).x                     │  │   │
│  │  │      vy_T = texture2D(velocity, uv+dy).y                     │  │   │
│  │  │      vy_B = texture2D(velocity, uv-dy).y                     │  │   │
│  │  │      div = (vx_R - vx_L) / 2dx + (vy_T - vy_B) / 2dy        │  │   │
│  │  │      div += texture2D(explosionDivTex, uv).r  // 注入爆炸散度  │  │   │
│  │  │      gl_FragColor = vec4(div, 0.0, 0.0, 1.0)                 │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  └─────────────────────────────────────────────────────────────────────┘   │

│  【第 6 步】压力求解（Jacobi 迭代）                                          │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  ⚠️ 注意: PCG求解器已创建但未启用，当前使用Jacobi迭代                │   │
│  │                                                                        │   │
│  │  新增纹理: rTex(残差), dTex(搜索方向), qTex(A*d), zTex(M⁻¹r), bTex(右侧)│   │
│  │  （PCG专用纹理，当前未启用）                                          │   │
│  │                                                                        │   │
│  │  公式: p_new = (p_L + p_R + p_D + p_U - (ρ/dt)*div*h²) / 4           │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  // Jacobi迭代（双缓冲，Dirichlet边界条件）                             │  │   │
│  │  │  pressureSrc = pressureTexA                                    │  │   │
│  │  │  pressureDst = pressureTexB                                    │  │   │
│  │  │  for i = 0 to pressureIterations:                            │  │   │
│  │  │      for each pixel (x, y):                                   │  │   │
│  │  │          p_L = texture2D(pressure, uv-dx).r                   │  │   │
│  │  │          p_R = texture2D(pressure, uv+dx).r                   │  │   │
│  │  │          p_D = texture2D(pressure, uv-dy).r                   │  │   │
│  │  │          p_U = texture2D(pressure, uv+dy).r                   │  │   │
│  │  │          div = texture2D(divergence, uv).r                    │  │   │
│  │  │          h = 1.0 / resolution.x                               │  │   │
          // Neumann边界：空气/固体邻居用中心压力代替           │  │   │
          center_p = texture2D(pressure, uv).r                 │  │   │
          // 采样邻居phi，若为空气(phi>0)或固体则替换         │  │   │
          if (texture2D(phiTex, uv-dx).r > 0.) p_L = center_p  │  │   │
          if (texture2D(phiTex, uv+dx).r > 0.) p_R = center_p  │  │   │
          if (texture2D(phiTex, uv-dy).r > 0.) p_D = center_p  │  │   │
          if (texture2D(phiTex, uv+dy).r > 0.) p_U = center_p  │  │   │
          p_new = (p_L+p_R+p_D+p_U-(ρ/dt)*div*h*h) / 4.0      │  │   │
│  │  │      render → pressureDst                                      │  │   │
│  │  │      [pressureSrc, pressureDst] = [pressureDst, pressureSrc]  │  │   │
│  │  │  curPressureTex = pressureSrc  // 最终压力场                   │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  ✅ 优点: 实现简单，GPU友好，无需全局归约                            │   │
│  │  ⚠️ 缺点: 收敛较慢，需要100~200次迭代                               │   │
│  │                                                                        │   │
│  │  📋 PCG求解器状态（已创建但未启用）:                                  │   │
│  │  - 已实现着色器: spmvShader, axpyShader, reduceShader等              │   │
│  │  - 未启用原因: 需要GPU归约实现内积计算，当前版本暂未集成              │   │
│  │  - 性能对比: PCG(15~30次迭代) ≈ Jacobi(100~200次迭代) 的收敛精度     │   │

│  【第 7 步】速度修正（压力梯度减法）                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: velocityCorrectShader()                                    │   │
│  │  输入: velAfterCollisionTex, curPressureTex                        │   │
│  │  输出: velCorrectTex                                               │   │
│  │                                                                        │   │
│  │  公式: vel_corrected = vel - ∇p / ρ                                  │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │

│  │  │      p_D = texture2D(pressure, uv-dy).r                       │  │   │

│  │  │      vel.x -= (dt/density) * (p_R-p_L) / (2dx)               │  │   │
│  │  │      vel.y -= (dt/density) * (p_U-p_D) / (2dy)               │  │   │
│  │  │      gl_FragColor = vec4(vel, 0.0, 1.0)                       │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │

│  【第 8.5 步】流体寿命系统（当 maxLifetime > 0 时启用）⭐ 新增              │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  三阶段流程：年龄平流 → 年龄更新 → 流体消散                           │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  阶段1: 年龄平流（追踪水滴而非像素）                           │  │   │
│  │  │  Shader: ageAdvectionShader()                                │  │   │
│  │  │  输入: curAgeTex, curVelTex, curPhiTex                       │  │   │
│  │  │  输出: ageTexA/B                                             │  │   │
│  │  │                                                               │  │   │
│  │  │  核心逻辑:                                                    │  │   │
│  │  │      prevPos = uv - vel * dt / resolution                    │  │   │
│  │  │      age_new = texture2D(age, clamp(prevPos, 0, 1)).r        │  │   │
│  │  │                                                               │  │   │
│  │  │  ✅ 关键：反向追踪速度场，让年龄跟随水流移动                   │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  阶段2: 年龄更新（使用真实时间）                              │  │   │
│  │  │  Shader: ageUpdateShader()                                   │  │   │
│  │  │  输入: curAgeTex, curPhiTex                                  │  │   │
│  │  │  输出: ageTexA/B                                             │  │   │
│  │  │                                                               │  │   │
│  │  │  核心逻辑:                                                    │  │   │
│  │  │      if (phi < 0) age += realDelta  // 水区域年龄增加        │  │   │
│  │  │      else age = 0                    // 空气区域年龄为0      │  │   │
│  │  │      if (注入区域) age = 0           // 新注入水重置年龄     │  │   │
│  │  │                                                               │  │   │
│  │  │  ✅ 关键：使用真实时间增量 realDelta，确保按秒计时             │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  阶段3: 流体消散（年龄达到上限）                              │  │   │

│  【第 9 步】Level Set 重新初始化（窄带限制 + 双缓冲交替，保持界面锐利）    │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Shader: levelSetReinitShader()                                     │   │
│  │  输入: curPhiTex                                                    │   │
│  │  输出: phiTexA/B (ping-pong，双缓冲避免读写冲突)                     │   │
│  │                                                                        │   │
│  │  公式: phi_new = phi - dt_reinit * sign(phi) * (|∇phi| - 1)        │   │
│  │  dt_reinit = 0.1 / min(width, height)  // 伪时间步长               │   │
│  │                                                                        │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │  // 双缓冲交替：每次迭代从 src 读取，写入 dst，然后交换         │  │   │
│  │  │  phiSrc = curPhiTex                                          │  │   │
│  │  │  phiDst = (phiSrc === phiTexA) ? phiTexB : phiTexA           │  │   │
│  │  │  for i = 0 to reinitIterations:                              │  │   │
│  │  │      for each pixel (x, y):                                   │  │   │
│  │  │          phi_0 = texture2D(levelset, uv).r                    │  │   │
│  │  │          dx = 1.0 / resolution.x                             │  │   │
│  │  │                                                               │  │   │
│  │  │          // 窄带限制：只重初始化界面附近（abs(phi) < 2*dx）    │  │   │
│  │  │          if (abs(phi_0) > 2.0 * dx) {                        │  │   │
│  │  │              gl_FragColor = vec4(phi_0, 0.0, 0.0, 1.0);    │  │   │
│  │  │              continue;                                       │  │   │
│  │  │          }                                                   │  │   │
│  │  │                                                               │  │   │
│  │  │          phi_grad = length(∇phi)                              │  │   │
│  │  │          // sign(0) = 0 会导致 phi 不演化，用 eps 区间处理     │  │   │
│  │  │          eps = 0.001                                         │  │   │
│  │  │          sign = phi_0 > eps ? 1.0 : (phi_0 < -eps ? -1.0 : 1.0)│  │   │
│  │  │          phi_new = phi_0 - dt_reinit * sign * (phi_grad - 1)  │  │   │
│  │  │                                                               │  │   │
│  │  │          // 避免符号反转                                       │  │   │
│  │  │          if (sign > 0 && phi_new < 0.0) phi_new = 0.0;       │  │   │
│  │  │          if (sign < 0 && phi_new > 0.0) phi_new = 0.0;       │  │   │
│  │  │                                                               │  │   │
│  │  │          gl_FragColor = vec4(phi_new, 0.0, 0.0, 1.0)          │  │   │
│  │  │      render → phiDst                                          │  │   │
│  │  │      [phiSrc, phiDst] = [phiDst, phiSrc]  // 交换           │  │   │
│  │  │  curPhiTex = phiSrc  // 最终结果                              │  │   │

│  │  │  阶段1: 爆炸注册                                   │  │   │
│  │  │      将爆炸加入 activeExplosions 列表            │  │   │
│  │  │      explosion = {cx, cy, radius, strength,     │  │   │
│  │  │                     createWater, startTime,     │  │   │
│  │  │                     duration}                   │  │   │
│  │  └───────────────────────────────────────────────┘  │   │
│  │                                                               │   │
│  │  ┌───────────────────────────────────────────────┐  │   │
│  │  │  阶段2: 每帧构建爆炸散度 (buildExplosionDiv)   │  │   │
│  │  │      elapsed = currentTime - startTime        │  │   │
│  │  │      envelope = exp(-t²/(2σ²))  // 高斯脉冲    │  │   │
│  │  │      S = strength * envelope * mask / (ρ*dt)  │  │   │
│  │  │      累加渲染到 explosionDivTex（不清屏叠加）   │  │   │
│  │  └───────────────────────────────────────────────┘  │   │
│  │                                                               │   │
│  │  ┌───────────────────────────────────────────────┐  │   │
│  │  │  阶段3: 水花生成（createWater=true时）        │  │   │
│  │  │      仅修改 phi，使用周围速度加权平均          │  │   │
│  │  │      新生水花速度由后续压力求解驱动            │  │   │
│  │  │      ✅ TODO: 需额外Pass重置新水年龄为0        │  │   │
│  │  └───────────────────────────────────────────────┘  │   │
│  │                                                               │   │
│  │  ✅ 核心原理:                                                    │   │
│  │  - 爆炸不直接修改速度，而是注入散度源 S                   │   │
│  │  - 散度源通过压力求解器生成压力梯度 ∇p                    │   │
│  │  - 速度修正步骤: vel -= ∇p/ρ 驱动流体向外膨胀             │   │
│  │                                                               │   │
│  │  ⚡ 参数说明:                                                    │   │
│  │  - strength: 控制散度源强度，非直接速度增量              │   │
│  │    → 推荐值: 5000~10000（新模型需重新调参）             │   │
│  │  - duration: 爆炸持续时间(秒)，默认0.1                    │   │
│  │  - createWater=true: 生成水花但不直接加速                │   │
│  │  └─────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

## 三、分层渲染架构详解

### 3.1 分层渲染设计原则

传统渲染方式将所有效果直接累加到颜色中，导致颜色过曝、整体发白。分层渲染将颜色计算拆解为多个独立层，各层使用合理的混合方式组合，最终叠加形成最终颜色。

### 3.2 分层架构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        分层渲染架构图                                        │
└─────────────────────────────────────────────────────────────────────────────┘

        ┌─────────────────────────────────────┐
        │     Layer 1: 基础颜色层              │
        │     Base Color Layer                │
        │                                     │
        │  depth = clamp(-phi * 2.0, 0, 1)   │
        │  baseColor = mix(waterColor,       │
        │               deepColor, depth)     │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     Layer 2: 漫反射光照层             │
        │     Diffuse Lighting Layer          │
        │                                     │
        │  normal = normalize(∇phi)          │
        │  diff = max(0.1, dot(normal, L))   │
        │  diffuse = baseColor × diff        │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     Layer 3: 高光层                 │
        │     Specular Lighting Layer         │
        │                                     │
        │  viewDir = (0, 0, 1)               │
        │  halfDir = normalize(L + viewDir) │
        │  spec = pow(max(dot(n,h),0), 64)  │
        │  specular = white × spec ×         │
        │             specularIntensity      │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     Layer 4: 边缘发光层              │
        │     Edge Glow / Emissive Layer      │
        │                                     │
        │  edge = 1 - smoothstep(0, edgeW,   │
        │                    abs(phi))        │
        │  glowColor = vec3(0.2, 0.6, 1.0)   │
        │  emissive = glowColor × edge ×     │
        │             edgeIntensity          │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     Layer 5: 流动扰动层              │
        │     Flow Detail Layer               │
        │                                     │
        │  flow = length(velocity) × 0.5     │
        │  flowColor = vec3(0.15, 0.25,      │
        │               0.35) × flow ×       │
        │               flowIntensity        │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     最终合成                        │
        │     Final Composition               │
        │                                     │
        │  finalColor = diffuse + specular +  │
        │               emissive + flowColor │
        │                                     │
        │  alpha = clamp(0.6 - phi*2, 0.2,    │
        │              0.9)                   │
        └─────────────────────────────────────┘
```

### 3.3 各层说明

| 层名称 | 内容 | 混合方式 | 说明 |
|--------|------|----------|------|
| Base Color | 水体的基础颜色 | 直接输出 | 根据深度混合浅蓝和深蓝 |
| Diffuse Lighting | 漫反射光照 | 乘以基础色 | 决定水体明暗，不添加额外颜色 |
| Specular | 高光反射 | 最后添加 | 白色高光，可独立控制强度 |
| Emissive | 边缘发光 | 最后叠加 | 仅在水面附近生效，不参与漫反射 |
| Flow Detail | 流动扰动 | 作为细节 | 不大面积改变色调 |

### 3.4 最终合成公式

```
finalColor = diffuse + specular + emissive + flowColor
           = (baseColor × diff) + (white × spec × specInt) + 
             (glowColor × edge × edgeInt) + (flowBaseColor × flow × flowInt)

alpha = clamp(0.6 - phi × 2.0, 0.2, 0.9)
```

### 3.5 渲染决策

```glsl
// 空气区域和界面：完全丢弃，不参与渲染
// phi >= 0 表示空气或水-空气界面（phi = 0），都不绘制
if (phi >= 0.0) {
    discard;
}

// 流体区域：渲染各层
float depth = clamp(-phi * 2.0, 0.0, 1.0);
vec3 baseColor = mix(waterColor, deepColor, depth);

// ... 计算各层并叠加
```

### 3.6 分层渲染优势

1. **互不干扰**：漫反射、高光、发光互相独立，修改边缘光强度不会影响光照强度
2. **易于调试**：可以暂时关闭某一层来观察其它层效果
3. **可扩展**：未来增加屏幕空间反射、折射等效果，只需额外添加层，不影响已有层
4. **性能不变**：依然是一次绘制，只是计算逻辑更清晰

## 四、纹理格式规范

### 4.1 速度场纹理 (velTexA/B)
```
RGBA: [vx, vy, 0, 1]
- R: 水平速度分量
- G: 垂直速度分量
- B: 未使用
- A: 未使用（固定为1）
```

### 4.2 Level Set 纹理 (phiTexA/B)
```
RGBA: [phi, 0, 0, 1]
- R: Level Set 值
  - phi > 0: 空气区域
  - phi < 0: 水体区域
  - phi = 0: 自由表面
- G, B: 未使用
- A: 未使用（固定为1）
```

### 4.3 压力场纹理 (pressureTexA/B)
```
RGBA: [p, 0, 0, 1]
- R: 压力值
- G, B: 未使用
- A: 未使用（固定为1）
```

### 4.4 固体掩码纹理 (solidMaskTex)
```
RGBA: [mask, 0, 0, 1]
- R: 固体标记
  - mask > 0.5: 固体
  - mask <= 0.5: 流体/空气
- G, B: 未使用
- A: 未使用
```

### 4.5 固体法线纹理 (solidNormalTex)
```
RGBA: [nx, ny, 0, 1]
- R: 法线 X 分量
- G: 法线 Y 分量
- B: 未使用
- A: 未使用（固定为1）
- 预计算后每帧直接读取，无需重复计算
```

## 五、关键优化点

### 5.1 预计算固体法线
- 固体法线在 solidMask 改变时计算一次
- 存储到 solidNormalTex
- 每帧墙碰撞直接读取，无需重复计算梯度

### 5.2 双缓冲 Ping-Pong
- 速度场、Level Set、压力场都使用双缓冲
- 避免读写冲突，提高 GPU 并行度

### 5.3 固体边界清理
- 第 1 步和第 10 步清理固体内部的速度和 Level Set
- 确保固体内部不会残留错误的速度或 Level Set 值

### 5.4 压力迭代的自由表面边界条件
- 当 phi > 0（空气）或 isSolid > 0.5（固体）时，压力强制设为 0
- 避免空气区域建立压力场，提高体积守恒

### 5.5 流体区域判断容差
- 使用 phi >= 0.0 丢弃空气和界面（phi = 0 是水-空气界面）
- 避免线性纹理过滤导致的边缘锯齿

## 七、调试录制功能

### 7.1 功能概述

FluidSimulator 内置了调试录制功能，可自动录制前 N 帧的关键场数据（phi、velX、velY）并导出为 JSON 文件，用于分析模拟过程中的数值变化和调试问题。

### 7.2 调试录制工作流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         调试录制流程                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. 启用录制                                                                │
│     enableDebugRecording(true, 20)  // 录制前20帧                           │
│                    │                                                        │
│                    ▼                                                        │
│  2. 每帧 update() 末尾自动捕获                                               │
│     ┌───────────────────────────────────────────────────────────────────┐   │
│     │  if (debugRecordingEnabled && debugCurrentFrame < framesToRecord)│   │
│     │      captureCurrentState()                                       │   │
│     │      debugCurrentFrame++                                         │   │
│     │      if (debugCurrentFrame >= framesToRecord) {                  │   │
│     │          debugRecordingEnabled = false                           │   │
│     │          downloadDebugData()  // 自动下载                         │   │
│     │      }                                                           │   │
│     └───────────────────────────────────────────────────────────────────┘   │
│                    │                                                        │
│                    ▼                                                        │
│  3. 数据捕获                                                               │
│     ┌───────────────────────────────────────────────────────────────────┐   │
│     │  captureCurrentState():                                           │   │
│     │      phiPixels = readTextureData(curPhiTex)                       │   │
│     │      phiData = textureTo2DArray(phiPixels, 'r')                   │   │
│     │                                                                   │   │
│     │      velPixels = readTextureData(curVelTex)                       │   │
│     │      velXData = textureTo2DArray(velPixels, 'r')                  │   │
│     │      velYData = textureTo2DArray(velPixels, 'g')                  │   │
│     │                                                                   │   │
│     │      debugRecordedData.push({ frame, phi, velX, velY })           │   │
│     └───────────────────────────────────────────────────────────────────┘   │
│                    │                                                        │
│                    ▼                                                        │
│  4. 自动导出 JSON 文件                                                      │
│     downloadDebugData() → 浏览器下载 fluid_debug_xxx.json                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 7.3 调试接口

| 方法 | 功能 | 参数 |
|------|------|------|
| `enableDebugRecording(enable, frames)` | 启用/禁用调试录制 | `enable`: boolean, `frames`: number (默认20) |
| `exportDebugData()` | 手动触发数据导出 | 无 |

### 7.4 使用示例

```typescript
const simulator = new FluidSimulator(renderer, params);

// 启用录制，记录前20帧
simulator.enableDebugRecording(true, 20);

// 正常驱动模拟
function animate() {
    simulator.update(0.016);
    // ... 渲染逻辑
    requestAnimationFrame(animate);
}
animate();

// 运行后经过20帧，浏览器会自动下载 fluid_debug_xxx.json
```
