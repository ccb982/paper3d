## 0. 定调与判定标准

### 0.1 用户定调（架构级，不可协商）
1. **一个平衡系统主动调控所有关节力矩**；静息输出即人类量级（= 姿势对齐的镜像）。
2. **主动修正机制只有一个**（阻尼和脊柱张力不算修正）。
3. **承重无上限，发力有上限**。
4. **脚不发飘/不打滑是地基；足部发力+腰部借力必须真能拉回身体**——
   这是**唯二判定标准**；**站立时间属于控制算法阶段，不是架构验收**。
5. 关节没有"可控的运动"之前，一切控制算法无从谈起（"现在是肢体都不能正常活动"）。

### 0.2 唯二判定标准（全景）
| # | 标准 | 工具 | 通过线 |
|---|---|---|---|
| ① | 脚不打滑 | `probe-frame` / `probe-support` | 每拍窜动 ≤1mm 量级；禁用 `slipV`（求解器蠕变假象） |
| ② | 发力真能拉回身体 | `probe-authority`（阶跃 τ → CoM 加速度） | ≥ 理论 `g·τ/(Fz·h)` 的 50% |

## 3. 控制层（全新：一张分层优化，每拍解出唯一 τ 向量）

### 3.0 ★★★★★ 通道宪章（用户令：**明确写入**）

> **一、所有发力通道统一受平衡系统控制。**
> 平衡系统是**唯一**的控制器。所谓"通道"（平衡/姿态/肢体/张力/阻尼）
> 全部是**它内部的结构**（任务或约束），**不是**独立的写者。
> 任何时候，同一根关节轴上**只有一个数**：平衡系统解出的 τ。

> **二、通道之间不打架——由构造保证，不靠约定。**
> v3 的"同系统相加"（`+130 / −80` 内斗，§8.9.4x 实锤 10× 权威衰减）在 v4 中
> **物理上不可能发生**，因为：
> 1. **唯一解**：每拍只解**一个** τ 向量（一张带约束的分层优化）。
>    不存在"第二条通道写同一个轴"这回事；
> 2. **严格优先级**：低优先级任务的解**投影到高优先级的零空间**里
>    （Sentis & Khatib 2005）——L2/L3 在数学上无法干扰 L1，
>    反向（L1 需要时吞掉 L2/L3 的份额）是设计允许的；
> 3. **约束同解**：限位/τmax/**摩擦锥**是同一张优化的硬约束——
>    不存在"事后封顶砍掉通道输出"导致的预算争抢；
> 4. **软墙降级**：接近约束边界时（Ju 2021），任务平滑让位而不是硬碰
>    翻转——这消灭 v3 的"逐拍翻号"；
> 5. **张力与阻尼例外条款**（用户授权）：脊柱张力（小 k）与被动阻尼
>    是**物理项**，不参与仲裁、也不与任务争预算（量级小、单项定义）。

> **三、立法权归平衡系统。**
> 任何新功能（新的修正、新的策略、新的反射）**只能**以下面两种形态加入：
> （a）作为**任务**进入对应优先级；（b）作为**约束**进入硬约束集。
> **禁止**以"再写一条通道"的形态加入——这是 v3 一切内斗的总根源。

### 3.1 形式（Escande/Mansard/Wieber 2014；Sentis & Khatib 2005）
```
min_τ  ‖J₁τ − F₁*‖²                     （L1：平衡）
 s.t.  ‖J₂τ − F₂*‖² 在 L1 的零空间内最小化 （L2：姿态）
       ‖J₃τ − F₃*‖² 在 L1,2 零空间内最小化 （L3：肢体）
       硬约束（永远满足）：
         minRad ≤ q ≤ maxRad
         |τ_j| ≤ τmax_j
         |τ_j| ≤ μ·Fv·h_j      ← 摩擦锥（§8.9.4t/s；一级约束）
         接触条件
```

### 3.2 ★★★★★ 通道明细（用户问："设计什么通道，分别怎么做"）

| 通道 | 做什么 | 输入 | 输出（任务空间） | 怎么落到 τ | 优先级 |
|---|---|---|---|---|---|
| **C-硬约束** | 保命边界 | 关节限位/τmax/摩擦 | — | **不等式**（同解） | 永远第一（高于一切任务） |
| **T1 平衡** | 把 CoP 压到 `clamp(ξ,足缘)`（唯一主动修正） | `com, vcom` → XcoM | 足底力 `F* = (Fx*, Fy*, Fz*)` | `τ = Σ_feet a_j·(r_j×F*)`（与重力补偿同一个几何式，姿态自动精确） | L1（最高任务） |
| **T2 姿态** | 腰/脊柱回到**对齐基线** | 关节角 | 期望关节 "回位力" `Δτ₂` | **投影进 T1 的零空间**（`N₁Δτ₂`） | L2 |
| **T3 肢体** | 手臂自然摆、摆动腿关键帧 | 状态机相位/角色 | 期望关节 "跟踪力" `Δτ₃` | 投影进 `N₁,₂` | L3 |

**每拍执行顺序（固定，无分支博弈）**：
```
1. 量测 → 2. T1 解 → 3. 若 T2 存在：Δτ₂ 投影 N₁ 后相加
→ 4. 若 T3 存在：Δτ₃ 投影 N₁,₂ 后相加 → 5. E1/E2 并入
→ 6. 对最终向量施加约束（软墙）→ 下发
```

### 3.2b ★★★★★ 腰部发力 = **从胯部**（用户令 + 文献落地）

> 用户：「**腰部如果不从胯部开始发力很容易倒**」——这条**完全正确，且正是文献结论**。

**文献**：
| 文献 | 条款 |
|---|---|
| **Horak & Nashner 1986**《Central programming of postural movements》| 定义**hip strategy**：躯干作为**一个刚体绕髋转动**（不是脊柱自己弯） |
| **Koleva et al. 1999**（cond-mat/9908185）| 实测：**静站（1 分钟无扰动）里上下身运动强反相关 ⇒ hip strategy 是主导机制**——"本该在大幅扰动才出现的髋策略，在小幅静站也存在" |
| **Shafiee-Ashtiani et al. 2016**（arXiv:1612.08034）| hip strategy = **调制上身角动量（CMP）**；ankle strategy = 调制 ZMP——两者统一在一个 MPC 里 |
| **Poddar et al. 2026**（arXiv:2603.08619）| 恢复谱系：小扰动 = ankle/hip 策略；大扰动 = 迈步——与本章 L1/T2 分工一致 |

**设计（T2 重定义）**：
```
✗ 错（v0 现状）：T2 = 脊柱各节的弹簧（腰自己弯）—— 头重脚轻、容易倒
✓ 对（v1）：
    T2 的任务   = 躯干（腰+脊柱+头）保持竖直（pitch/roll → 0）
    T2 的执行器 = **髋的两轴力矩**（髋 = 躯干相对骨盆/腿的力矩口）
                  Δτ₂ = −kTrunk·(躯干 pitch/roll) − bTrunk·(躯干速率)
                  落在 hip_{l,r} 的轴 2（矢状）与轴 0（侧向）
    脊柱（spine1..3）= 只留 E1 张力（小 k）+ 被动 —— **不做主动修正**
```
**力学理由**（用户原话的展开）：躯干质量占比大（头+躯干 ~45%），
支点在腰以上 ⇒ 靠脊柱自身弯曲纠偏 = **在倒立摆的顶端制造第二个倒立摆**；
从髋发力 = 把躯干当**一根杆**直接控制其角动量（CMP 通道）⇒ 动力学上可控。

### 3.3 ★★★★★ "真的不打架吗？"——数学证明（不是口号）

**v3 为什么打**（算术相加）：
```
通道A 要 +130 ／ 通道B 要 −80
τ_v3 = (+130) + (−80) = +50   ← 净值小，但 A、B 各烧掉 130/80 的预算
      ⇒ 内斗 ~210 的力气（§8.9.4x 实测权威衰减 10× 的直接原因）
```

**v4 为什么不打**（零空间投影）：
```
τ₁ = J₁ᵀ(J₁J₁ᵀ)⁻¹ F₁*                    （T1 的最小范数解）
N₁ = I − J₁ᵀ(J₁J₁ᵀ)⁻¹ J₁                 （T1 的零空间投影子）
τ₂ = τ₁ + N₁ · Δτ₂                        （T2 被投进零空间）

关键恒等式：  J₁·N₁ = J₁ − J₁ = 0          （原式代入即得）
⇒ J₁·τ₂ = J₁·τ₁ + J₁·N₁·Δτ₂ = J₁·τ₁ + 0 = J₁·τ₁
⇒ **T2 的任何数值都不会改变 T1 的任务量** —— 这是恒等式，不是调参
```

**数值例子**（同一个意图，两种架构）：
```
T1（平衡）需要踝 +30 让 CoP 前移刹车
T2（姿态）想要踝 −15 回正腰
v3：τ = +30 −15 = +15   ⇒ 平衡只剩一半力气（这就是"拉不动身体"）
v4：Δτ₂ = −15 被分解：能改变足底力的分量被 N₁ 消掉，
    剩下的分量改走**脊柱/手臂**（零空间内的自由度）
    ⇒ 踝仍是 +30（平衡全权），腰同时被回正 —— 两者都拿到 100%
```

**约束层为什么也"不打架"**：限位/τmax/摩擦锥是**同一张优化的硬约束**——
所有任务共享同一个可行域，不存在"事后各自封顶、事后互相抢预算"。

**诚实的现状标注**：`v4/control.ts` **当前是 v0**（T1 + 弱 T2 直接相加，
因为 T2 一开始给得很弱、内斗量小）。**v1 必须实现真 NSP**（上式的 `N₁`），
在那之前，"不打架"在**架构上是立法保证，在代码上尚未兑现**——本文件不撒谎。

### 3.4 ★★★★★ 架构审计（用户令："你再仔细论证一下"）——诚实的裂缝清单

**经逐条压力测试，架构在纸面成立，但有以下边界必须钉死；其中 3 处代码未兑现。**

#### 干净的四条（可放心依赖）
1. **唯一修正**：L1 = XcoM→CoP（Hof），没有第二个修正通道——成立；
2. **通道不打架**：严格优先级 + 零空间恒等式 `J₁N₁≡0`——数学成立
   （**前提**：低优先级经 `N₁` 投影，见裂缝②）；
3. **腰部从胯**：T2 执行器是髋（文献三篇支撑），脊柱退出主动修正——成立；
4. **调度/控制分离**：状态机只出"任务目标"，不写关节——成立（§4 已立法）。

#### 裂缝①（语义，必须补）：**CoP 饱和 = 迈步的发令枪，不能"静默截断"**
- 现状：L1 的 `copCmd = clamp(ξ, 足缘)`——ξ 出界时误差被 clamp 吃掉，
  **没有信号告诉调度层"该迈步了"**（Hof 的原意：CoP 饱和与迈步是**同一个机制**的两段）；
- 必须：`|ξ − copCmd| > 0` 即产生**迈步请求**（urgency 量），交给状态机——
  这是"L1 唯一修正"与"迈步"之间**唯一合法**的接口。

#### 裂缝②（代码未兑现）：当前 `v4/control.ts` 是 v0 —— T2 仍是**加法**而非零空间投影
- 即：髋上 T1 的 τ 与 T2 的 τ **此刻是直接相加的**（髋正是两者共用的执行器）；
- ⇒ 纸面的"不打架"在代码上**尚未成立**；v1 必须实现 `N₁`（§3.3 的恒等式）。

#### 裂缝③（物理归属）：摩擦锥应写在**力层**（F\*），不是 τ 层
- 现状：`τ_j ≤ μFv·h_j` 是**τ 层代理**（h_j 近似），既可能过紧也可能漏；
- 正确：摩擦是接触约束 `|Fx| ≤ μFz` ——应直接限制 L1 的 `F*`
  （在力的源头夹住），τ 层只留 τmax 硬边界。

#### 裂缝④（代码未兑现）：约束目前是"事后软墙"（输出端 tanh），不是"同解"
- 纸面 §3.3 主张"约束在同一优化里"；当前实现是**输出后处理**；
- 影响：约束不会"提前影响任务分配"（QP 的联解才有这个性质）——
  v1 用小型 QP（或至少约束感知的 NSP）补齐。

#### 裂缝⑤（语义边界）：摆动腿同时挂着 T3（关键帧）和"迈步"（裂缝①）两个身份
- 裁决（写入立法）：**迈步 = L1 的动作**（XcoM 的逻辑延伸，Hof）；
  T3 只负责"迈步已决定后，摆动腿怎么优雅地过去"——同一个腿、两个层级、
  **不同相位**，不冲突（但必须在文档里写清，否则未来会打架）。

**结论**：
> 架构在**纸面是干净的**（四条成立）；但**代码现在是"干净的草图"**——
> 裂缝②④是 v1 的必做项，①③⑤是文档立法问题（已在本节钉死）。
> 不是"已经干净了"，是"**知道哪里还不干净，且路径明确**"。

### 3.5 ★★★★★ 开工前的三条证明（用户令："确保真能发力、力真能进腰、真的不打架，然后才能开工"）

#### 证明一：真能发力（预算核算，纸面可执行）

任何任务力 `F*` 必须通过**两层预算**，在纸面上每拍核算：

```
层1 执行器：|τ_j| ≤ τmax_j                     （现有 maxTorque 表）
层2 摩擦：|F*_x| ≤ μ·F*_z 且 |F*_z| ≤ Fz_max   （力层，裂缝③的修正）
层2' 支撑：Σ F*_z = m·g（稳态）；单脚 F*_z ≥ 0 且 ≤ mg（不把脚压穿/拉离）
```
**核算结论（量级）**：站立所需 `F*_x ≤ m·g·(CoP范围/h) ≈ 560×0.13/0.9 ≈ 80 N`；
摩擦上限 `μFz ≈ 0.7×560 ≈ 390 N` ⇒ **余量 5×**。踝所需 τ ≤ 80×0.07 ≈ **6 N·m**
（人在 5~15 ✓）。**⇒ 用力层面完全可行，且宽裕。**
**裁决**：若 F* 超预算 ⇒ **在力层截断**（并产生"迈步请求"，裂缝①）——
绝不允许到 τ 层再靠封顶解决（v3 的翻号根源）。

#### 证明二：力真能进腰上（动力学定理，不是口号）

把全身分成**外部通道**与**内部通道**（Shafiee 2016 的 CMP/ZMP 分解）：

```
外部（唯一）：  m·a_CoM = F_GRF + m·g          ← 只有地面反力推动质心
                Ḣ_CoM  = (CoP − CoM) × F_z      ← 角动量变化由 CoP vs 质心给出
内部（T2）：    Ḣ_trunk = τ_hip − τ_spine…      ← 髋力矩直接改变躯干角动量
恒等关系：      CMP := CoP − Ḣ_CoM/F_z
```

**定理（力进腰的充要路径）**：
1. 地面力 `F*` 改的是 **CoM 轨迹**（外）——L1 的领地；
2. 髋力矩 `τ_hip` 改的是 **躯干角动量 Ḣ_trunk**（内）——T2 的领地，
   **它不在 CoM 方程里**（内力不出现在质心动力学中）；
3. 二者在 **CoP 处交汇**：髋力矩能重分配两脚载荷 ⇒ 移动 CoP。
