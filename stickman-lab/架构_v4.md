# 架构 v4（真源）

> 本文件是**当前施工目标**。`架构_v3.md`（1100+ 行实测档案）只在查历史证据时用，
> **不再是施工依据**。旧模块该删则删，v4 不 import 旧控制模块。

## 0. 定调与判定标准

### 0.1 用户定调（架构级，不可协商）
1. **一个平衡系统主动调控所有关节力矩**；静息输出即人类量级（= 姿势对齐的镜像）。
2. **主动修正机制只有一个**（阻尼和脊柱张力不算修正）。
3. **承重无上限，发力有上限**。
4. **脚不发飘/不打滑是地基；足部发力+腰部借力必须真能拉回身体**——
   这是**唯二判定标准**；**站立时间属于控制算法阶段，不是架构验收**。
5. 关节没有"可控的运动"之前，一切控制算法无从谈起（"现在是肢体都不能正常活动"）。

### 0.2 唯二判定标准（全景）
| # | 标准 | 工具 | 通过线 |
|---|---|---|---|
| ① | 脚不打滑 | `probe-frame` / `probe-support` | 每拍窜动 ≤1mm 量级；禁用 `slipV`（求解器蠕变假象） |
| ② | 发力真能拉回身体 | `probe-authority`（阶跃 τ → CoM 加速度） | ≥ 理论 `g·τ/(Fz·h)` 的 50% |

### 0.3 已证死、永不再犯的清单（v3 考古）
- 位置伺服 K=48 范式（`τ=K·Δθ` 放大扰动 ⇒ 12Hz PWM 载波 ⇒ 打滑 ⇒ 循环）；
- 多通道同轴相加（`+130/−80` 内斗，§8.9.4x 实锤 10× 权威衰减）；
- 硬碰边界（τ 打到 τmax 后逐拍翻号 = Ju 2021 所述的 one-step HQP 振荡）；
- "站立时间"作为架构指标（已降级）；
- CONTACTHZ/CONTACTDR（Rapier 绑定无此属性，全是无效设置）。

## 1. 物理层（保留：骨架 / 物理 / 执行器）

- `skeleton.ts` / `ragdoll.ts` / `sim.ts`：可保留（基础设施），但**执行器接口要换**：
  - **删除**：位置伺服分支（branch 1/2 的 K/D/让位链）作为控制路径的地位。
  - **新的唯一执行语义**：每拍接收一个 **τ 向量**（来自 §3 的 QP），
    外加**被动阻尼** `−B_j·q̇`（物理层，非控制）与**脊柱张力**（§3.4）。
  - 执行器内部的稳定护栏可以保留（它是数值安全，不是控制）。
- **默认大摩擦**（`groundFriction=10`，用户令）+ 高摩擦下再谈一切。

## 2. 感知层（保留 + 精简为只读）

每拍构造一个**只读状态** `V4State`：
```
CoM / vCoM（真实速度） ｜ 双脚：接触、Fz、CoP、踝位置
关节角/角速（已减静姿偏置）｜ 逐轴 Jacobian 列（足底力→关节 τ 的映射）
脊柱弯曲量 ｜ 状态机的相位与角色（只读）
```
**禁止**任何模块在感知层里写目标/力矩（v3 的多写者冲突根源）。

## 3. 控制层（全新：一张分层优化，每拍解出唯一 τ 向量）

### 3.0 ★★★★★ 通道宪章（用户令：**明确写入**）

> **一、所有发力通道统一受平衡系统控制。**
> 平衡系统是**唯一**的控制器。所谓"通道"（平衡/姿态/肢体/张力/阻尼）
> 全部是**它内部的结构**（任务或约束），**不是**独立的写者。
> 任何时候，同一根关节轴上**只有一个数**：平衡系统解出的 τ。

> **二、通道之间不打架——由构造保证，不靠约定。**
> v3 的"同系统相加"（`+130 / −80` 内斗，§8.9.4x 实锤 10× 权威衰减）在 v4 中
> **物理上不可能发生**，因为：
> 1. **唯一解**：每拍只解**一个** τ 向量（一张带约束的分层优化）。
>    不存在"第二条通道写同一个轴"这回事；
> 2. **严格优先级**：低优先级任务的解**投影到高优先级的零空间**里
>    （Sentis & Khatib 2005）——L2/L3 在数学上无法干扰 L1，
>    反向（L1 需要时吞掉 L2/L3 的份额）是设计允许的；
> 3. **约束同解**：限位/τmax/**摩擦锥**是同一张优化的硬约束——
>    不存在"事后封顶砍掉通道输出"导致的预算争抢；
> 4. **软墙降级**：接近约束边界时（Ju 2021），任务平滑让位而不是硬碰
>    翻转——这消灭 v3 的"逐拍翻号"；
> 5. **张力与阻尼例外条款**（用户授权）：脊柱张力（小 k）与被动阻尼
>    是**物理项**，不参与仲裁、也不与任务争预算（量级小、单项定义）。

> **三、立法权归平衡系统。**
> 任何新功能（新的修正、新的策略、新的反射）**只能**以下面两种形态加入：
> （a）作为**任务**进入对应优先级；（b）作为**约束**进入硬约束集。
> **禁止**以"再写一条通道"的形态加入——这是 v3 一切内斗的总根源。

### 3.1 形式（Escande/Mansard/Wieber 2014；Sentis & Khatib 2005）
```
min_τ  ‖J₁τ − F₁*‖²                     （L1：平衡）
 s.t.  ‖J₂τ − F₂*‖² 在 L1 的零空间内最小化 （L2：姿态）
       ‖J₃τ − F₃*‖² 在 L1,2 零空间内最小化 （L3：肢体）
       硬约束（永远满足）：
         minRad ≤ q ≤ maxRad
         |τ_j| ≤ τmax_j
         |τ_j| ≤ μ·Fv·h_j      ← 摩擦锥（§8.9.4t/s；一级约束）
         接触条件
```

### 3.2 三层任务（与 v3 机制的对照映射）

| 层 | 任务（目标力/矩） | 来源 |
|---|---|---|
| **L1 平衡** | 足底合力把 CoP 压到 `clamp(XcoM, 足缘)`（Hof 2010） | `com`, `vcom` → XcoM |
| **L2 姿态** | 腰/脊柱回到**对齐基线**（腿伸直/重力线穿关节；`probe-tau1` 静态 τ 人类区间为镜像判据） | 关节角 → 阻抗 |
| **L3 肢体** | 手臂自然摆、摆动腿按关键帧 | 状态机的相位 → 目标 |

### 3.3 软墙（Ju 2021 的直接吸收——治"边界振荡"）
τ 接近 τmax/摩擦锥时**不硬碰**：对约束加**距离加权软化**（软墙/松弛变量），
使靠近边界的解平滑降级（v3 的逐拍翻号就是因为硬碰）。

### 3.4 两个"不是修正"的例外（用户授权）
- **被动阻尼** `−B_j q̇`（物理层，非控制）；
- **脊柱张力**（第 5 协同；`τ = k·q + d·q̇`，小 k，自带小修正，不经平衡系统）。
