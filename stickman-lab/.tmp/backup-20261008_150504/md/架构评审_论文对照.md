```

   │  level<2 ⇒ 压低需求（不迈步）；level=2 才放行
   ▼

   │
   ▼

   │  L1 平衡   : τ = Σ_feet a_j·(r_j×F*)，F* 由 XcoM→CoP (Hof) 给出
   │  L2 姿态   : 躯干回正 = 髋两轴力矩（**从胯发力**）+ 脊柱极小刚度
   │  A 矩阵    : 每列 = 关节轴 × 力臂(用 CoP)，传力链只留 hip/knee/foot，同侧掩码
   │  分配      : 加权最小范数 / CLS（迭代钳位 + 任务回补）
   │  约束      : τmax 硬夹 + 摩擦锥软墙（tanh）+ 关节限位

   ▼
```

**这个形态本身是正确且现代的**：唯一控制器 / 单一 τ 向量 / 零空间投影意图 / CoP 力臂 / 摩擦锥。
它和 **Sentis & Khatib 2005（OSF）→ Escande/Mansard/Wieber 2014（HQP）→ IHMC Atlas WBC（1kHz 主动集）**

## 3. 为什么"强制脚腰发力还是站不起来"——三个可验证的根因

按证据强度排序，**都不是"权限没给够"**：

### 根因① ★★★ 首拍巨力自致失稳（最可能）
`架构_v4.md §4.8.1` 的实测（你自己的数据）：
```
t=0.01  τ踝=−62  τ膝=−109   （需求 W* 只有 Fx≈0 / Fz≈−39 的小量！）
t=0.06  τ踝=−120（饱和）
```
**第一拍就用巨力，而此刻姿态完好（MoS=+49mm 在界内）⇒ 巨力本身是扰动源。**
文献对应：**Ju 2021 的 one-step HQP 边界振荡**、以及"从零状态全量输出"违反软启动原则。
⇒ 用户自己给出的正解在同文件 §4.8.4：**软启动（smoothstep 渐入 ~0.2s）+ 垫脚优先分级**。

### 根因② ★★ 首拍 τ 的**来源**是姿势几何，不是控制需求
`§4.8.3` 隔离实验：纯 `A·W*` 下踝 = −47 = `Fy × 0.14`（CoM 在踝前 14cm）。
⇒ **你的静态站姿 CoM 就在踝前 14cm**，任何"把 CoP 压到 ξ"的解都必然先给一个 ~50 N·m 级的常量踝力矩。
这不是 bug，是**站姿几何**：`Appendix A.2` 实测步宽 0.327m（人类 0.075m，**4.4×**）、
重心横移需求 142mm（人类 40mm，**3.5×**）。
文献：**Perry & Burnfield** MSt 帧「Body weight passes over supporting foot」，人类只需 ~40mm。
⇒ **站距不收到 ±80mm 附近，L1 的稳态误差就是消不掉的常量。**

### 根因③ ★★ 分配目标是 `min‖τ‖` ⇒ 踝独扛/髋独扛（目标函数选错）
`附：排雷记录 #9` 你自己已经推导出来：
> 「理论-实测矛盾 → 重新推导后确认为**目标函数选错**（min‖τ‖ ⇒ 踝独扛是数学正确；
> 应改 **min-max 峰值利用率**）」
文献：**Orin & Oh 2008**（质心动力学的加权范数形式）、**Fahmi 2018**（约束一致分配 + 负载改道）。
⇒ 现在 `min‖W·τ‖²` 让"力臂大的关节"（髋 90cm vs 踝 5cm）自动少出力 —— **几何决定，不是权重**。
**minimax（峰值利用率最小化）才是"多关节协同"的正解**，也是让踝/髋都真正参与的那把钥匙。

## 5. 一句话给用户

你的关节权限**在结构上已经基本到位**（有踝、有髋两轴、有 CoP 力臂、有摩擦锥、有唯一 τ 向量）。
"强制脚腰发力还站不起来"的根因不在权限，在**三个点位**：
1. **首拍全量输出**（软启动缺失，自己造扰动）；
2. **站姿几何 CoM 在踝前 14cm**（L1 稳态误差是常量，消不掉）；
3. **分配目标 `min‖τ‖`**（几何让踝独扛，不是协同）。

修完 A0/A1/A2，再谈"协同"；修完 A3/A4，才谈"站立时长"。
