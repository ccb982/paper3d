## 6.3 L1 重构详细设计（替换什么、保留什么）

```
现状（手调）：  Fx = W/h·(com − clamp(ξ))·kv(sev)
                Fz = 同构
新设计（论文）：
  ① 状态：x = [com, vcom, com.y, vy]（4D，Caron 的 VHIP 状态）
  ② 趋势分解（Garcia 的解耦）：
       ξ = com + v/ω(com.y)        ← DCM（趋势）
       λ = com.y − g/(2·ω²)        ← 高度分量（"弹道"高度）
  ③ 控制律（极点配置，闭式）：
       ξ* = 可行域内最近点           （state viability）
       u_ξ = −K_ξ·(ξ − ξ*)          （K_ξ 由目标极点 [ζ, ω_d] 解析给出）
       u_λ = −K_λ·(λ − λ*)          （高度策略，仅当腿长可伸/屈时启用）
  ④ 可行域裁剪（best-effort）：
       τ_需求 = Jᵀ([u_ξ, Fz_nom + u_λ])
       若 |τ_需求| > 0.9·τmax ⇒ 重投影到可行边界（不硬顶——硬顶=极点出界=发散）
  ⑤ 输出：仍是唯一 W*（8 维），仍是唯一 τ
```

## 6.3b 与跌倒预测的**一体化**（用户令："还得和跌倒预测修正结合在一起"）

**一条线，三个环节，共享同一个状态**：

```
状态 (com, vcom, com.y, vy)
   │
   ▼ ① 算趋势（状态派生的两个不变量）
   ξ = com + v/ω(com.y)   （DCM：发散分量 = 跌倒趋势）
   λ = com.y − g/(2ω²)     （高度分量）
   │
   ▼ ② 预测（predict.ts 升级为 VHIP 前向）
   推演 ξ(t)/λ(t) → TTB、出界方向、不可达时刻
   │
   ▼ ③ 择优（plans.ts）
   垫脚/加髋/迈步 的候选 × 每案的**预测残留**（用①②的量）
   → level + 命令集 {kind, copX/Z, λ*, 期望ξ*}
   │
   ▼ ④ 止跌（L1 的极点配置——**执行 commander 给出的期望**）
   u_ξ = −K_ξ·(ξ − ξ*)      ← ξ* 来自③（而不是自己发明）
   u_λ = −K_λ·(λ − λ*)      ← λ* 来自③（高度策略的期望）
   │
   ▼ W* → τ（唯一）
```

**关键约束（防"多通道打架"）**：
1. 趋势只有**一处**计算（warning，①）——预测/择优/止跌全部**消费**同一个 ξ；
2. 期望状态 (ξ*, λ*) **只由 commander 给**（③）——L1 **不得**自设目标；
3. 极点配置 (K_ξ, K_λ) 是**唯一的反馈律**，其目标极点按可行性设计一次（④）。

⇒ 预测与止跌是**同一条线的上下游**：预测决定"追什么"，止跌执行"怎么追"。

# 7. 架构级重写：平衡系统对身体操控 = 全身 QP（完整设计）

> 文献：Fahmi 2018（arXiv:1811.00884，"joint limits/actuation limits 进 QP +
> 约束触发时负载自动重分配"，HyQ 实验验证）；Shi 2024（arXiv:2411.09935，双层：
> 变阻尼阻抗 + WBC-QP）；Escande/Mansard/Wieber 2014（HQP 形式化）；
> Kanoun/Lamiraux/Wieber 2009（不等式任务进优先级框架）。
> 目标（用户令）：**在架构层面重写，替换整族补丁，不留多通道**。

## 7.1 总形式（每拍一个 QP）

```
min_τ   Σ_l  ½·w_l·‖ A_l·τ − b_l ‖²          （层级任务的加权残差）
 s.t.   C_ineq·τ ≤ d_ineq                     （硬约束，全部进同一张表）
```
- 变量：`τ ∈ R^{n}`（n=18 关节 ×3 轴 = 54，含弓/中足）
- 层级（strict priority，高层的解零空间内解决低层——HQP）：
  L1 平衡（命令集） ▷ L2 姿态（腰/胸） ▷ L3 肢体温和

## 7.2 任务明细（A_l, b_l）

| 层 | 任务 | 数学形式 | 数据来源 |
|---|---|---|---|
| **L1a** | 足底力（CoM/CoP）| `A₁τ = Jᵀ⁻¹ 意义下：W(τ) = W*` | 命令集 {copX/Z, ξ*, λ*} |
| **L1b** | 重心高度（VHIP λ）| `d/dt(λ(τ)) → λ*`（一阶）| §6.3 |
| **L2** | 躯干姿态（腰+胸）| `τ_spine → −K_p·(θ−θ*) − K_d·θ̇` 作为等式目标 | 预警的 trunk 量 |
| **L3** | 肢体（臂/摆动腿）| `τ_j → τ_ff`（前馈目标，可被上层让位）| 提案包 |

## 7.3 硬约束明细（C, d）——**全部进同一张表**

| 约束 | 形式 | 触发后的行为 |
|---|---|---|
| 作动限制 | `−τmax ≤ τ ≤ τmax` | **负载自动重分配**（Fahmi 的机制）|
| **关节限位** | `C_lim·τ ≤ d_lim`（把 0.85·限位 作软边界、1.0 作硬边界）| **从解里就不可能越界**（替代 b3 救火）|
| 摩擦锥 | `|F_t| ≤ μ·F_n`（线性化四边形）| 力层截断（已有）|
| 接触 | 支撑脚不可拉离 | 等式 |

**关节限位的关键**：写成 `τ·方向 ≤ 余量·刚度`（"离限位只剩 x 度时，最多还能用 v"），
等价于一个速度/力矩的线性约束 ⇒ 髋 124° 这类**在解空间就被排除**。

**三个发现**：
1. **首拍膝尖峰 74.7**（t=0.008 单拍）——软启动的斜坡尚未生效的那一拍；

**"发力怎么做的"的诚实回答**：
```

       ②落点时两关节力方向相反（A 的分配造成"对拉"）
       ⇒ 能量在关节间循环（发力-反发力），净推进≈0
```
