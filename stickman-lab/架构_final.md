## 1. 指挥链与权限（唯一真源）

| 层 | 模块 | 权力 | 禁止 |
|---|---|---|---|
| 指挥官 | predict+plans | 决定 垫脚/加髋/迈步；出命令集 | 不涉具体落点细节 |
| 提案者 | step.ts | 落足点/时机/重心偏移/摆动轨迹 | 不下最终命令 |
| 执行者 | controlV1 | 把命令变成唯一 τ | 不自行决策 |
| 调度 | gaitState | 状态判定 + 承重腿指定 | **不命令** |
| 感知 | warning | MoS/TTB/level/扰动 | 不决策 |

## 2. 八条立法（不可协商）

```
① 唯一控制器（通道=任务/约束，禁多写者）
② 通道不打架（零空间投影 + scale-to-fit，构造保证）
③ 腰部从胯发力（hip strategy；Horak1986/Koleva1999）
④ 传力链只走 hip/knee/foot（A 行掩码）
⑤ 承重/摆动腿由状态机显式指定（禁平衡推断）
⑥ 平衡唯一数据源 = 指挥官命令 + 提案包
⑦ 弱重心偏移 ∈ 提案包（有界：STEPMAX/STEP_SLEW/shiftFMax）
⑧ 唯二判定：脚不打滑 + 力真传腰（时间不论）
```

## 4.5 ★★★★★ 精修的"不破坏架构"保证（用户问；逐条分类）

**结论：8 个精修项全部在模块边界内，不触碰层/立法/权限。**

| 精修项 | 类别 | 边界证明 |
|---|---|---|
| M1 DEC 扰动估计 | **增补**（感知内部）| warning 的输出契约不变（只加字段）|
| M2 N-step capturability | **增补**（指挥官内部）| 命令集 {kind,copX/Z,level} 契约不变 |
| M3 代价权重标定 | **纯调参** | 只是 J 的系数 |
| M4 PUSH 解锁 + IK 调优 | **内部修复** | 状态机的判定职责内；IK 是 step 内部 |
| M5 主根(CoP 几何) + minimax | **数据/内部** | CoP 是资产/输入；minimax 是执行器内部 |
| M6 b3 频率 | **纯调参** | 执行器的内部参数 |
| M7 PUSH 验收项 | **内部修复** | 状态机自己的验收表 |
| M8 脚踝初始几何 | **资产** | 骨架数据，不涉代码架构 |

**三道保险（施工纪律，写入规章）**：
1. **边界纪律**：指挥官不执行、执行者不决策、状态机不命令——
   任何修改若"越界"（例如让执行器自己决定救什么）即**立即回退**；
2. **契约纪律**：三个包（命令集/提案包/τ 向量）的**字段只增不改**；
3. **验收纪律**：每个模块改完必须跑对应探针（§5 表），全绿才算完成。
