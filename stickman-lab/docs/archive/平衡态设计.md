# 平衡态设计（VIP + 踝 CoP 策略为主力）

> 本文是 `架构设计.md` 的**专题深化**：只讲「站立时身体为什么不倒、按什么律倒不倒」。
> 结论先行：**我们一直在用「髋策略」（备选）当主力，而真正的主力「踝 + CoP」因为缺一层
> 结构而瘫着。** 本文给出按文献可落地的替代方案。

---

## 0. 本文的判据与本文要修的问题

现有平衡实现（`src/core/systems/balance.ts`）的矢状面通道：

| 通道 | 律 | 实测结果 |
|---|---|---|
| 矢状髋 | 位置伺服 `−ksagRatio·ω₀²·(capX−stanceX) − 2ζω₀·vx` | 目标到 15.4° 就饱和在 `maxHipDeg` |
| 腰矢状 | pitch 的 PD（`kTorsoHold=0.02`、`maxTorsoDeg=15°`） | pitch 只到 3.3° 就饱和 |
| 踝 CoP | 位置伺服 `−kCopSag·(ξ−CoP) − kCopSagD·vx`，`kCopSag=6` | τ 只到 30~57 N·m，踝角只走到 −3°（负向还剩 −10°） |

实测：`com.x` 从 −0.0012 单调发散到 −0.96 m，`com.vx` → 1.471 m/s，**2.2 s 倒**。

问题不在增益，在于**没有一个「刚度 + 延迟反馈」的结构**：
三个通道全是「追一个目标角」的位置伺服，彼此不知道对方在干什么，也没有围绕
「CoP 该在哪」这个物理量组织。

## 1. 文献的平衡态定义

### 1.1 DIP + VIP 模型（最干净的可实现版本）

来源：Morasso, Cherif, Zenzeri 2019, *PLOS ONE* 14(5):e0213870
「Quiet standing: The Single Inverted Pendulum model is not so bad after all」；
以及 Morasso et al. 2019（*Frontiers in Physiology*）「Integrating ankle and hip strategies
for the stabilization of upright standing: An intermittent control model」。

**DIP（Double Inverted Pendulum）**：下半身绕踝倒立摆 + 上半身绕髋倒立摆，两级串联。

**VIP（Virtual Inverted Pendulum）**：一条**从踝连到全身 CoM** 的虚拟摆，单自由度 `q_com`：

```
q_vip = atan2(com.x − ankle.x ,  com.y − ankle.y)
```

> 原文：「Although this inverted pendulum does not exist physically, its oscillations are
> **directly perceivable by standing subjects through the CoP**, namely by means of a
> combination of tactile and proprioceptive sensors of the feet.」

⇒ **VIP 摆角在物理上就等价于 CoP 在支撑面上的位置**。这不是类比，是恒等式：
CoP 必须落在重力的垂线上（净力矩为零），而重力垂线过 CoM 与地面交点。

### 1.2 关键推导：临界刚度 K_crit = m·g·h

原文：

> 「for an inverted pendulum the gravity-driven toppling torque is
> **τ_g = m·g·h·sin(q) ≈ m·g·h·q** and thus the **critical value of stiffness is
> K_crit = m·g·h**, where m is the mass of the pendulum and h is the distance
> between the hinge of the pendulum and the CoM.」

| 摆 | m | h | K_crit |
|---|---|---|---|
| SIP（绕踝，全身） | 全身 | **0.9 m** | 大 |
| DIP 上身（绕髋） | 上身 | **0.5 m** | 只有踝的一半 |

⇒ **「髋策略比踝策略省力」的力学根源在此**：髋的力臂短 ⇒ 临界刚度低 ⇒ 一点点共同收缩就够。

### 1.3 人体实测：踝刚度被**刻意调在欠临界**

来源：Loram & Lakie 2002, *J Physiol* 545:1041-1053
「Direct measurement of human ankle stiffness during quiet standing:
**the intrinsic mechanical stiffness is insufficient for stability**」

| 量 | 实测值 |
|---|---|
| 踝固有机械刚度（安静站立，左踝） | **5.2 ± 1.2 N·m/deg** = 298 N·m/rad |
| 折合临界刚度 | **91 ± 23 %** |
| 结论（原文） | 「insufficient to stabilise the human inverted pendulum」⇒ **必须主动神经控制** |

Morasso & Schieppati 1999 / Morasso 2002 的结论更硬：**踝肌刚度单独不足以稳定站立**。

⇒ 设计要点：**踝刚度取「略低于」K_crit（人体约 91%），剩下的 9% 交给神经反馈。**
既不过刚（那会像踩高跷，只剩踝在动），也不过软（那必然倒）。

### 1.4 两个策略的本质分工

来源：*Frontiers in Computational Neuroscience* 2022（用户提供的原文）

> 「the **ankle strategy** is mainly focused on the **direct control of the CoP**
> in relation with the CoM, whereas the **hip strategy** aims at the **indirect control
> of the global CoM by controlling the local CoM of the upper body**.」

| | 踝策略 | 髋策略 |
|---|---|---|
| 控制量 | **CoP** | **上半身 CoM**（间接带动全局 CoM） |
| 作用 | 全身当单摆绕踝转 | 上下身反向摆 |
| 地位 | **默认主力**（小中扰动） | **备选**（踝力矩不足时） |

### 1.5 三个关节的标准发力分工与约束

**Michaels & Ting（*Sci Rep* 2025）** 给出的关键约束：

> 「The biomechanical constraint was defined as the **center of pressure (CoP) range
> limitation to the metatarsal joint**」
> 「as perturbation magnitude increased, the model demonstrated a pattern of
> **limited ankle torque coupled with increased hip joint kinematics**」

⇒ 踝的 CoP 行程被限制在「跖骨头 ↔ 足跟」之间；一旦 CoP 走到脚掌边缘，**踝力矩自动饱和**
（flat-foot 约束保住），此时策略自动切到髋。**这不是硬切换，是同一个控制律在不同区域
的不同表现。**

**Welch & Ting 2016**：策略不是硬切换，而是目标优先级的加权：

| 优先目标 | 髋屈峰 |
|---|---|
| 最小化 CoM 偏移 | **45.5°** |
| 最小化躯干倾斜 | **13.7°** |

⇒ 权重差 **3.3 倍**。优先「CoM 不跑偏」，躯干倾斜可以忍。

**膝（Li & Levine 2010）**：「humans **keep their knee angle nearly constant**」——
安静站立时膝基本不动；它主要是摆动期的净空贡献者：
`Clearance = 髋屈 + 膝屈 + 踝背屈`。

**摆动相三关节目标值**（Front Neurorobotics 2022 / Oberg）：
踝背屈 **~7.2°**、膝屈峰 **~60–67°**、髋屈峰 **~30°**（最大净空时脚尖在髋正下方）；
蹬离相踝跖屈 **~17.2°**。

**踝:髋加速度比 = 1:3**（Morasso 2019 引 biomechanical feasibility 结论）：
> 「the set of biomechanically feasible accelerations greatly favors a combination of
> ankle and hip movement in the ratio **1:3**」

## 2. 本 rig 的实测数字（全部来自 `tools` 探针，非估算）

站姿 1 s 后实测：

| 量 | 值 |
|---|---|
| 总质量 m | **70.0 kg** |
| CoM 高度 | **0.959 m** |
| 踝关节高度 | **0.0457 m** |
| 髋关节高度 | **0.8393 m** |
| 足底 soleY | −0.0006 m |
| 摆高 `h_ankle = CoM.y − 踝` | **0.913 m** |
| 摆高 `h_hip = CoM.y − 髋` | **0.120 m** |

由此：

```
K_crit(踝) = m·g·h_ankle = 70.0 × 9.81 × 0.913 = 627 N·m/rad
K_crit(髋) = m·g·h_hip   = 70.0 × 9.81 × 0.120 =  82 N·m/rad
比值 = 7.63×
```

### 2.1 三个由此得出的关键结论

**① 踝的力矩上限完全够，缺的不是权限。**
把 24 mm 的偏移拉回需要 `τ = m·g·Δx = 70 × 9.81 × 0.024 = **16.5 N·m**`，
而踝 `τmax = 120 N·m`。**差 7 倍余量。**

**② 但踝现在只出了 30~57 N·m，且相对 K_crit 只有 7.0%。**
即使出力够，也没有形成「刚度」：
踝通道是**纯位置伺服追一个目标角**，没有 `τ = K_a·q + c·q̇` 这一项。
没有刚度就没有被动稳定，只有一个会饱和的伺服。

**③ 我们的 `h_hip = 0.120 m` 远小于文献的 0.5 m ⇒ K_crit(髋) 低 7.6 倍。**
原因是几何事实：**髋在 0.84 m 高度，几乎就在 CoM（0.96 m）所在的高度**。
这不是「上身轻」，是「髋太高」。

⇒ 对我们的**有利**后果：**髋极易超临界**（82 N·m/rad 就够，髋 `τmax` 是踝的量级）
⇒ 髋只要给一个**被动刚度**就能稳定上身，**完全符合文献结论，只是更容易**。
⇒ 不利后果：**髋的 CoM 策略效率极高**（力臂短），
所以我们不自觉地把髋当主力用还"看起来有效"—— 这掩盖了踝的缺失。

## 3. 方向性错误（用户指出，成立）

| | 文献 | 我们 |
|---|---|---|
| 踝 | **CoP 策略 = 默认主力**（直接、快、省力） | 无刚度、无结构，τ 只到 K_crit 的 7% ⇒ **瘫着** |
| 髋 | CoM 策略 = 备选（踝力矩不足才用） | **被当成主力**在用 |
| 结果 | — | 髋饱和 → CoM 冲到 0.4~1.5 m/s → 门禁拦下 → 死锁 |

⇒ 「越调越拧」的原因找到了：**在错误的执行器上使劲。**

## 4. 落地方案（按文献，替换现有矢状面）

### 4.1 平衡态（不再靠「门」猜相位）

**① VIP 摆角**
```
q_vip = atan2(com.x − ankle.x , com.y − ankle.y)      // ≡ CoP 在支撑面上的位置
```
读回来源：`rs.com`（`posture.readCom`，唯一实现）+ `doll.jointWorld(foot_l)`。

**② 踝 = 被动刚度 + 对 VIP 延迟状态的间歇反馈**

```
τ_ankle = K_a · q_vip(t) + C_a · q̇_vip(t) + u(t − δ)
K_a / K_crit(踝) = 0.85 ~ 0.91      ← 文献实测值；刻意欠临界
u(τ) = { K_p·[q_vip(τ−δ) + q̇_vip(τ−δ)/ω]  当落在 VIP 相平面扇区内
       { 0                              否则（间歇）
δ = 0.2 s                             ← Morasso 2019 实测反馈延迟
```
力学落点：`τ = K_a·q` **直接等于把 CoP 移到 `q_vip` 处**（因为 CoP 位移 = τ/F_z，
而 `F_z = m·g`），所以踝刚度**就是** CoP 权限，不经过「目标角→位置环」这一层间接映射。

**③ 髋 = 超临界被动刚度（不需要主动控制）**
```
K_h > K_crit(髋) = 82 N·m/rad         ← 我们实测的摆高算出来的值
```
只需在髋上加位置刚度项，**上身就自己稳**。这是文献里髋策略省力的根源。

**④ 平衡态判据**（替代现用阈值）
```
平衡 ⟺ |CoP − CoM| 小  且  |q̇_vip| 小        ← 最小化 CoM 加速度
```
读回：`doll.readCoP()`（`posture.ts` 唯一实现）+ `rs.dcm`。

**⑤ 膝**：安静站立**不主动控制**（Li & Levine 2010）。

### 4.2 迈步三关节（替换现有摆动相目标）

| 相 | 踝 | 膝 | 髋 |
|---|---|---|---|
| 摆动相 | 背屈 **7.2°** | 屈峰 **60~67°** | 屈峰 **30°**（最大净空脚尖在髋下） |
| 蹬离相 | 跖屈 **17.2°** | — | — |

净空判据：`Clearance = 髋屈 + 膝屈 + 踝背屈`。

### 4.3 踝:髋 加速度比 1:3

作为两个通道权重的**交叉校验**：任何调参结果若与 1:3 显著偏离，
说明权重分配错了，而不是「还没调好」。

## 5. 实施顺序与验收

| 步 | 内容 | 验收 |
|---|---|---|
| **S1** | 把踝从「追目标角的位置伺服」改成 `τ = K_a·q_vip + C_a·q̇_vip`（**不加反馈**，先只上刚度） | `K_a/K_crit ∈ [0.85, 0.91]`；静止站立 `com.x` 应收敛到 ±5 mm |
| **S2** | 髋加超临界被动刚度 `K_h > 82 N·m/rad` | 上身 pitch 波动 < 2° |
| **S3** | 加间歇反馈（延迟 δ = 0.2 s，相平面扇区切换） | 扰动后恢复时间、站立 20 s |
| **S4** | 平衡判据换成 `|CoP−CoM|` 与 `|q̇_vip|` | `probe-balance2` 用新判据 |
| **S5** | 迈步三关节目标值换成文献值 | 摆动相净空、蹬离相推进 |

**每步都必须跑**：`npm run typecheck`、`npm run build`、`npm run verify`、
`npm run probe:axisown`、`npm run uipanel`，并与基线对比（当前基线：`verify` 3 项失败、
`axisown` 3 项失败，均来自加踝时的足部几何，与控制无关）。
