# 发力体系重做：从脚发力（踝策略）2026-10-19

> 本文替换旧结论（"肌肉对/历史最佳"）。当前蹲姿问题的根因已定位：**虚空发力**。
> 总架构见《架构现状-2026-10-18.md》，蹲姿参数见《蹲姿专项架构-2026-10-19.md》。

---

## 0. 一句话结论

**当前回正力写在髋/膝/腰的关节空间，没有经过"踝→地面"的外部路径 → 脚被关节力矩甩飞。**
规则：**所有力必须从脚发**（唯一的体外力 = 地面反力）；踝可以把力"虚拟"给髋（踝→髋传导），
但预算必须从脚/CoP 申请。目标形态 = **踝策略**，髋/膝只做传递。

---

## 0.5 脚的原则（用户定调 · 最高约束）

```
· 蹲下时脚**不用动**：不滑、不抬、不滚（脚在世界中固定）。
· 但脚**必须承重**：Σfz ≈ 体重（687N），CoP 在脚掌内。
· 推论：回正只能靠 CoP 在脚掌内移动（踝力矩），脚本身不动；
  不允许迈步/垫步；任何让脚移动/离地的写手都是错的。
```

验收硬指标：**脚 x/y 位移 < 1cm、脚角速 < 1 rad/s、Σfz > 200N**；
脚一旦滑/抬/滚，整帧判定失败（不是"调参问题"）。

## 2. 新发力体系（从脚发力）

### 2.1 信号（每帧）
| 量 | 来源 |
|---|---|
| CoM / CoM 速度 | `sensors.com` / `sensors.comVel` |
| 每脚 fz / CoP | `body.footNormalForce` / `body.footCoP` |
| 标准姿势 CoM `com*` | 法庭摆姿时捕获（**释放时不再重捕**） |
| ω0 | `sqrt(g / h)`（h=CoM 高度） |

### 2.2 论文依据（踝策略）

| 论文 | 结论 | 对我们的用法 |
|---|---|---|
| Horak & Nashner 1986 (J Neurophysiol 55:1369) | 踝策略 = 绕踝关节的补偿力矩，把 CoM 移回；髋策略 = 水平剪力 | 回正力只从踝出（AP 方向） |
| Winter 1995 (Gait & Posture 3:193) | 安静站立 = 倒立摆；AP 用踝，ML 主要靠髋展/收 | 矢状面用踝；侧向暂留给髋（后置） |
| Peterka 2002 (J Neurophysiol 88:1097) | 神经控制器 = PID：`T_a = Kp·e + Kd·ė + Ki∫e`，延时 ~0.17s；CoP ∝ 踝力矩 | 踝力矩 = CoP 的执行器；先 PD，不加积分 |
| Hof 2005 (J Biomech 38:1) | `XcoM = x + v/ω0`；倒立摆 `CoP = x − ẍ/ω0²` | CoP 目标由期望 CoM 加速度反解 |
| Stephens & Atman 2007 (Humanoid Push Recovery) | CoP 平衡（踝策略）：`F_x = F_z/z_CoM · (x_CoM − x_CoP)`；CoP 在脚掌内，对应踝力矩上限 | 全身 CoM/CoP 关系对折叠腿也成立 |
| Pratt 2006 (Capture Point) | `x_cp = x + v/ω0` | 只做稳定性判据/饱和切换，不直接当目标 |

**关键**：`m·ẍ_com = F_x = N·(x_com − x_cop)/z_com` 是**全身外力关系**，与腿折叠无关。
所以"从脚发"的踝策略在蹲姿同样成立：踝力矩移动 CoP → 地面反力改变 → CoM 加速。

### 2.3 控制律（实现用）

```
ω0 = sqrt(g / z_com)                       // z_com = CoM 高度
ẍ_des = −Kp·(x_com − x*) − Kd·v_com        // 期望 CoM 加速度（PD）
Kp = ω0² · kpScale,  Kd = 2·ω0 · kdScale   // 临界阻尼；kpScale≈0.5-1 起步

copDes = x_com − ẍ_des / ω0²               // Hof eq.(11) 反解 CoP
       = x_com + (Kp/ω0²)(x_com−x*) + (Kd/ω0²)·v_com
copDes = clamp(copDes, footX − 0.12, footX + 0.12)   // 支撑多边形
N      = fz（未加载时用 W/2）
τ_ankle = −N · (copDes − x_ankle)          // 符号在仿真里实测标定
τ_ankle = clamp(τ_ankle, ±τmax_ankle)      // 320 N·m

// 髋/膝：只传递，不独立 PD
τ_j = −N · (cop − x_j)                     // 地面反力对关节的矩（预算=N·力臂）
```

**与 XcoM 的关系**：静止目标 x* 时，`XcoM = x_com + v/ω0`；若把 `copDes` 放在
`x* + (v/ω0)·damp` 是捕捉点近似（Pratt/Hof 的 constant-offset），适合先跑通；
严格版本用上面的 `x_com − ẍ_des/ω0²`（两者在 Kp=ω0²、Kd=2ω0 时等价到一阶）。

**侧向（ML）**：Winter 1995 明确安静站立 ML 主要由髋展/收承担，踝内翻/外翻权限很小；
第一版只做矢状（AP）踝策略，侧向保留现有髋通道，后续再单独设计。



### 2.3b 闭链传力（唯一正确的"脚→全身"路径，用户定稿）

```
1. 唯一体外力 = 地面反力（CoP 处）。关节力矩是内力，单独作用只能让身体各段
   相对运动——脚没被地面接住时就是"自己跳/虚空发力"。
2. 传力 = 静态一致解（沿 踝→膝→髋→腰 逐节）：
      τ_j = −[ Σ_子树 m·g·(x−x_j) + N·(CoP − x_j) ]
   这样内部力互相抵消，净效果只剩地面反力在推全身。
3. 踝只做 CoP：τ_踝 = −N·(CoP_des − x_踝)；
   CoP_des = 标准 CoM（准静态）或 XcoM（动态）。
4. 上身力矩 = 从脚传上来的矩，不是独立 PD/弹簧。
5. 成立前提：脚承重 fz≈W、CoP 在脚掌内。脚不承重时，任何"按承重算"的
   力矩都会把腿蹬开、脚离地（当前所有失败的总机制）。
```

**验收（能不能传力）**：脚固定/踩实时施加上述力矩 → `fz≈687N`、脚 x/y<1cm、
脚角速<1rad/s、CoM v≈0。任何一项不成立 = 该力矩不是静态一致解（符号/力臂错，或有额外写手）。

### 2.4 分层（实现形态）

```
┌─ 接触层（踝/CoP）——唯一回正力来源，从脚发 ─────────────────┐
│  ẍ_des = −Kp·(x_com − x*) − Kd·v_com                       │
│  copDes = x_com − ẍ_des / ω0²   （Hof eq.11）              │
│  copDes = clamp(copDes, footX ± 0.12m)                     │
│  N      = fz（未加载时用 W/2）                              │
│  τ_ankle = −N × (copDes − x_ankle)   （符号实测标定）       │
│  钳位：±踝τmax(320)、±接触容量                              │
└────────────────────────────────────────────────────────────┘
┌─ 传导层（髋/膝）——只传递地面力，不凭空发力 ────────────────┐
│  髋/膝力矩 = 地面反力对关节的矩：τ_j = −N × (cop − x_j)     │
│  「踝给髋的虚空发力」= 髋预算 = N × |cop − x_hip|           │
│  预算由踝/地面兑现；超过预算不写（申请制，自下而上）        │
└────────────────────────────────────────────────────────────┘
┌─ 基础力 = 标准姿势重力（冻结，×1.08）──────────────────────┐
│  captureSquatBase：staticBalance 捕获一次，之后原样应用     │
│  SQB_LIVE=1 回退逐帧反解；SQB_SCALE 调倍率                  │
└────────────────────────────────────────────────────────────┘
┌─ 阻尼 = 驱动粘性 + 张力（单向）────────────────────────────┐
│  受 inertiaLow 上限；不参与回正                             │
└────────────────────────────────────────────────────────────┘
```

### 2.5 写手纪律（一轴一写手）
| 轴 | 唯一写手 |
|---|---|
| 脚（踝）axis2 | 接触层 τ_ankle（回正） |
| 髋/膝 axis2 | 传导层 τ_j（由 N/CoP 计算，预算封顶） |
| 脊柱/手臂 | 基础力 + 阻尼（不参与回正） |
| 禁止 | pair + sqCorr 同轴双写；关节空间独立 PD 写髋/膝回正 |
