## 5. 拆卸顺序（建议）

1. **开分支 + 本体基线**：先确保本体当前能编译/能跑（出问题可回退）。
2. **拆引用**：按 §2/§3 清 import 与调用点（WorldMode/CommanderWiring/UI）——编译会红一片，正常。
3. **推目录**：删 `systems/swarm` → 拷 rts 版；再替换 §3 其余文件（含 §3 的“合并”项）。
4. **装配**：WorldMode 按《移植清单》§3 接 WorldWiring（端口/LiveView 钩子逐条）。
5. **回归**：编译 0 错 → 跑起来（敌人出现、行军/驻守/总攻、工事建造、回收率探针）。
6. **清理**：删旧调试/表查看器/无用 fx；本体 `arch-guard` 规则按新目录更新（G1~G9）。
