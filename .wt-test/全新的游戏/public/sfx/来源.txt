                     ★★ 血泪教训：加工链里写了 `afade=t=out:st=0:d=0.02` 想"去掉起始爆音"，
                        但 **fade-OUT 从 st 起淡到 0 后会一直保持静音** → 整段只剩 0.02s，
                        RMS 0.1625 被压到 0.0052（**31 倍**），成品"小到几乎听不见"。
                        要淡入用 t=in；要淡出必须写 st=<末尾时刻>。
                     ★ 修好后：RMS 0.169 / 0.190（旧版 0.023），比入水(0.128)还实
                     ★ 轻压缩(threshold .15/ratio 3/makeup 2) + 峰值归一 0.82 / 0.88

                     ★ 接线：`DroneEntity.playBeam()`（唯一入口）——近战挥击 / 祖宗远程 / 祖宗挖矿

                     ★ 带 40m 听距门（祖宗射程 42m，远处自动开火不该响）+ 同 id 60ms 节流

舰船着陆.mp3      <- 重击 (thud 类 id 757)，1.55s
                     ★ 加工：bass=g=12:f=110 低频增强（巨物感）+ 轻微 aecho 余韵
                     ★★ 提响：素材 crest factor 高达 4.45（峰值早就削到 +3.2dBFS 还是不显响），
                        单纯调 volume 只会更失真 → 必须**先压缩再归一**。
                        扫描 36 组参数得出最优：acompressor=threshold=0.12:ratio=6:makeup=8
                        → crest 4.45→2.60，RMS 0.247→0.385（**+3.8dB**），峰值封回 0.95 不再削波。
                        （ratio 上限是 20，不是 30；loudnorm 对 1~2s 短素材完全失效，别用）
                     ★ 64kbps 单声道 15KB
涉水_loop.mp3     <- ★ 水中持续游动循环轨（2026-09-18 换素材 + 改比例）
                     Sea swimming loop (id 1181) 6.0~7.5s —— **主层**：划水的动作冲击（首尾都在响区）
                     River water flowing (id 2454) 20~21.5s 压 6dB —— **垫底**：填掉浪间隙的静音谷，保证连续
                     ★ 加工：amix 混合 → 主体 0:1.25s + 尾 0.25s 淡出叠回（无缝）→ 归一 -1.5dBFS
                     ★ 1.28s / 64kbps 单声道 10KB；I=-16.5 LUFS、40ms 窗平均 RMS -17.9dB、
                       最大 -14.1dB（有冲击）、起伏 7.7dB
                     ★★ 为什么换掉「涉水.mp3」(Water splash id 1311)：它是一声"哗"的瞬态，
                        crest 15dB、平均 RMS 只有 -22dB，loop 起来听着"一下一下"。
                        持续声要选**平坦段**（判据 = 40ms 窗 RMS 包络起伏，不是 LUFS）。
