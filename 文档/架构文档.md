# 架构文档

## Three.js 坐标系统

### 背景
Three.js 的 `OrthographicCamera` 默认 Y 轴向上，即 `top` 为 1、`bottom` 为 0 时，Y=0 在屏幕底部，Y=1 在屏幕顶部。

### 问题
标注 JSON 中 Y=0 在底部、Y=1 在顶部，与 Three.js 默认一致。
但 UI 层使用 `new THREE.OrthographicCamera(0, 1, 1, 0, -1, 1)`，即 `top=1, bottom=0`，此时 Three.js 的 Y=0 在顶部、Y=1 在底部——与标注 JSON 相反。

### 解决
- 纹理渲染位置（绘制到屏幕上的坐标）：使用原始标注 JSON 的 Y 值（Y=0 底部，Y=1 顶部），Three.js 会自动翻转。
- 点击检测区域（hit area / buttonHit）：需要手动进行 Y 翻转，将标注 JSON 的 Y 转换为 Three.js 相机空间的 Y。
  ```
  camera_y = 1 - json_y_end
  ```
  其中 `json_y_end` 是标注区域的 Y 上限（底部坐标）。
