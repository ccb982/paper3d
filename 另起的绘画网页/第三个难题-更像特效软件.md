二、关键问题：遮罩环扭曲放在“最初”还是“最后”？
答案：放在“最初”，即“预扭曲（Pre-distortion）”阶段。

理由
阶段	位置	效果	性能影响
预扭曲（Pre-distortion）	在生成 phi 纹理之前，扭曲原始顶点	环的“骨相”被改变，后续所有操作（光栅化、流体解算、渲染）都基于扭曲后的形状	节省 GPU 解算面积：如果环向内收缩，光栅化的像素数减少；如果向外膨胀，也不会产生额外无效区域
后处理裁剪（Post-process）	在渲染完成后，对输出画面进行掩码裁剪	环的形状只在最终画面上被裁剪，但内部流体/纹理仍然基于原始形状计算	浪费算力：即使裁剪掉，内部的流体模拟和纹理采样已经执行过了
为什么预扭曲是“遮罩”的最佳实现
你提到“遮罩”，说明你希望这个环能像 PS 的“图层蒙版”一样——环外的区域不可见，环内的区域可见，且环的形状会动态变化。

预扭曲工作流：

原始 BFS 环（basePoints） → 应用 DistortionStack → 生成 renderPoints。

renderPoints → polygonToLevelSetTexture → 生成 phi 纹理。

在渲染时，phi < 0 的区域为“内部”（可见），phi >= 0 为“外部”（被遮罩裁掉）。

因为 phi 是基于扭曲后的环生成的，遮罩的形状本身就在动态变化，且内部流体/纹理只作用于环内区域。

这样一来：

环外的像素根本不会被光栅化（被 phi 跳过）。

流体模拟（如果启用）也只作用于环内。

GPU 解算面积天然被限制在扭曲后的环内。

针对“遮罩性能”和“解算器面积变化”的问题，我直接给你最核心、最诚实的答案：

1. 遮罩运算在哪里跑？（CPU vs GPU）
顶点扭曲和遮罩生成，目前跑在 CPU 上，而不是 GPU。
虽然你的流体解算（FluidSimulator）是跑在 GPU 上的，但“画遮罩”这一步——也就是把扭曲后的环变成 phi 纹理——使用的是 polygonToLevelSetTexture（基于 Canvas 2D 光栅化），这完全是 CPU 运算。

2. 不断修改解算器面积，有没有额外开销？
结论：没有“额外”开销，但存在“固定”开销。

固定纹理尺寸：你的 FluidSimulator 纹理尺寸是固定的（比如 512x512）。无论遮罩环是缩成芝麻点，还是撑满全屏，GPU 每一帧都会解算 512x512 = 26 万个像素。面积缩小并不会减少 GPU 的线程调度数量，所以功耗和渲染时间是恒定的。

CPU 光栅化开销（真正的瓶颈）：当环在剧烈扭曲时，每一帧都会调用 polygonToLevelSetTexture 重新画 Canvas。画一个 300 个顶点的多边形对 CPU 来说毫无压力（< 0.1ms），但如果你频繁修改纹理上传到 GPU（texture.needsUpdate = true），会消耗带宽。如果只是遮罩形状在变，但颜色没变，这个上传开销是主要的消耗点。

3. 有没有办法利用“面积缩小”来优化性能？
有！ 虽然 GPU 解算面积固定，但你可以通过“自适应纹理分辨率”来节省开支：

在 applyDistortion 之后，计算扭曲环的 BBox（包围盒）。

如果 BBox 面积变得非常小（比如小于画布的 10%），你可以动态降低 FluidSimulator 的纹理分辨率（从 512 降到 256 甚至 128），并让 polygonToLevelSetTexture 只渲染这个 BBox 区域，然后贴回大纹理的对应位置。

这样，当遮罩收缩时，GPU 实际解算的像素数会以平方级减少（512² → 256²，减少 75% 算力）。

4. 针对你的“遮罩环”的最佳性能实践建议
既然你要让环频繁扭曲，为了把 CPU 和 GPU 开销压到最低，我建议你采用“混合分辨率 + 脏标记”策略：

优化策略	具体做法	收益
LOD 自适应纹理	检测 BBox 尺寸，动态切换 FluidSimulator 分辨率（512/256/128）	遮罩缩小时，GPU 计算量平方级下降
裁剪 Canvas 绘制区域	在 polygonToLevelSetTexture 中，只绘制 BBox 那一小块区域，而不是全屏绘制	CPU 光栅化时间大幅缩短
帧率节流（Throttling）	如果遮罩静止不动（环没在扭曲），暂停 globalTime 累加，或每 5 帧才重新生成一次 phi 纹理	避免不必要的 CPU 重绘和纹理上传
PVRTC/ETC2 纹理压缩	如果小游戏平台支持，将 phi 纹理转为压缩格式	减少显存带宽占用
5. 最终结论
你的设计思路是完全正确且高效的：

放在“最初”（预扭曲） 是绝对正确的选择，它天然限制了流体解算的有效区域，避免无效像素被计算。

性能开销主要不在顶点扭曲本身（几十到几百个点），而在于 CPU 光栅化 + 纹理上传。

只要你不让环每帧都在高频剧烈抖动（比如每帧都随机生成巨大的噪声），这个遮罩系统的性能完全可以在微信小游戏中跑满 60fps。即使环在运动，只要纹理尺寸不超过 512x512，对现代 GPU 来说都是“洒洒水”。

二、核心设计要点（逐条复述）
1. 为什么要把“顶点扭曲”放在 GPU？
CPU 方案：遍历几百个顶点，计算 sin/cos/噪声，耗时约 0.05ms，但会占用 CPU 时间片，且需要每帧把新顶点数据上传到显存（带宽占用）。

GPU 方案：顶点着色器并行处理所有顶点，耗时 < 0.01ms，且顶点数据只需上传一次（Static Buffer）。CPU 完全不参与顶点计算，只传几个 Uniform 值。

2. 为什么“掩码生成”要用硬件光栅化而不是片元着色器循环？
错误方案（你否定的）：在片元着色器里用 for 循环遍历所有顶点做射线法。每个像素都要跑一遍循环，尽管是并行的，但会产生线程束发散（Warp Divergence），且浪费 ALU 资源。

正确方案（硬件光栅化）：GPU 内部有专门的光栅化单元，一个时钟周期内就能判断出所有像素的覆盖状态。它不依赖循环，是纯硬件电路实现的。

具体做法：

把扭曲后的顶点交给 gl.drawArrays(gl.TRIANGLE_FAN, ...)。

光栅化器自动生成片元，只有环内的片元才会执行 Fragment Shader。

Fragment Shader 只需要输出 phi = -1.0，零判断零循环。

3. “环内部像素允许后续纹理解算”如何实现？
把 Fragment Shader 输出的 phi 纹理（RenderTarget）作为 掩码纹理 传给后续阶段。

在 FluidSimulator 的片元着色器（散度/压力/速度修正）中，先采样 phi 纹理，如果 phi >= 0.0，直接跳过该像素的物理计算（return 或 discard）。

在最终渲染时，同样用 phi 做 discard，保证环外像素透明。

4. 关于“内环（孔洞）”的处理
BFS 区域可能包含内环（洞）。硬件光栅化支持 evenodd 填充规则，你只需要：

先绘制外环（填充白色），再绘制内环（填充黑色），或者利用 gl.STENCIL。

更简单的方法：在外环绘制完后，用内环再画一遍，片元着色器输出 phi = 1.0，覆盖掉内环区域。

这样 RenderTarget 里，环内区域 phi = -1.0，内环区域 phi = 1.0，外部 1.0，完美支持孔洞。

// src/utils/ringMaskProcessor.ts
import type { Point } from '../types';

// ---------- 辅助函数 ----------
function getCentroid(points: Point[]): Point {
  let cx = 0, cy = 0;
  for (const p of points) {
    cx += p.x;
    cy += p.y;
  }
  return { x: cx / points.length, y: cy / points.length };
}

function getNormal(p1: Point, p2: Point): Point {
  const dx = p2.x - p1.x;
  const dy = p2.y - p1.y;
  const len = Math.hypot(dx, dy);
  if (len === 0) return { x: 0, y: 0 };
  return { x: -dy / len, y: dx / len };
}

// 简单的伪随机噪声（Value Noise）
function hash(p: number): number {
  let x = Math.sin(p) * 43758.5453;
  return x - Math.floor(x);
}

function smoothNoise(x: number, y: number, seed: number): number {
  const ix = Math.floor(x);
  const iy = Math.floor(y);
  const fx = x - ix;
  const fy = y - iy;
  const ux = fx * fx * (3 - 2 * fx);
  const uy = fy * fy * (3 - 2 * fy);
  const n00 = hash(ix * 127.1 + iy * 311.7 + seed);
  const n10 = hash((ix + 1) * 127.1 + iy * 311.7 + seed);
  const n01 = hash(ix * 127.1 + (iy + 1) * 311.7 + seed);
  const n11 = hash((ix + 1) * 127.1 + (iy + 1) * 311.7 + seed);
  return n00 * (1-ux) * (1-uy) + n10 * ux * (1-uy) + n01 * (1-ux) * uy + n11 * ux * uy;
}

// ---------- 扭曲操作 ----------
function applyTransform(points: Point[], transform: any): Point[] {
  const anchor = transform.anchor || getCentroid(points);
  const pos = transform.position || { x: 0, y: 0 };
  const rotation = transform.rotation || 0;
  const scale = transform.scale || { x: 1, y: 1 };

  return points.map(p => {
    let x = p.x - anchor.x;
    let y = p.y - anchor.y;
    // 旋转
    const cos = Math.cos(rotation);
    const sin = Math.sin(rotation);
    const rx = x * cos - y * sin;
    const ry = x * sin + y * cos;
    // 缩放
    const sx = rx * scale.x + pos.x + anchor.x;
    const sy = ry * scale.y + pos.y + anchor.y;
    return { x: sx, y: sy };
  });
}

function applyWave(points: Point[], op: any, time: number): Point[] {
  const dir = op.direction || 'normal';
  const freq = op.frequency || 1;
  const amp = op.amplitude || 0.05;
  const speed = op.speed || 1;
  const phase = op.phase || 0;

  if (dir === 'normal') {
    // 计算每个顶点的法线
    const n = points.length;
    return points.map((p, i) => {
      const prev = points[(i - 1 + n) % n];
      const next = points[(i + 1) % n];
      const tangent = { x: next.x - prev.x, y: next.y - prev.y };
      const len = Math.hypot(tangent.x, tangent.y);
      if (len < 1e-6) return p;
      const normal = { x: -tangent.y / len, y: tangent.x / len };
      const offset = amp * Math.sin(freq * (p.x + p.y) + speed * time + phase);
      return { x: p.x + normal.x * offset, y: p.y + normal.y * offset };
    });
  } else if (dir === 'tangent') {
    const n = points.length;
    return points.map((p, i) => {
      const prev = points[(i - 1 + n) % n];
      const next = points[(i + 1) % n];
      const tangent = { x: next.x - prev.x, y: next.y - prev.y };
      const len = Math.hypot(tangent.x, tangent.y);
      if (len < 1e-6) return p;
      const tangentUnit = { x: tangent.x / len, y: tangent.y / len };
      const offset = amp * Math.sin(freq * (p.x + p.y) + speed * time + phase);
      return { x: p.x + tangentUnit.x * offset, y: p.y + tangentUnit.y * offset };
    });
  } else { // 'xy' 直接偏移
    return points.map(p => ({
      x: p.x + amp * Math.sin(freq * p.x + speed * time + phase),
      y: p.y + amp * Math.sin(freq * p.y + speed * time + phase * 1.3)
    }));
  }
}

function applyTurbulent(points: Point[], op: any, time: number): Point[] {
  const amp = op.amplitude || 0.05;
  const freq = op.frequency || 3;
  const speed = op.speed || 0.5;
  const seed = op.seed || 42;
  const octaves = op.octaves || 3;

  return points.map(p => {
    let dx = 0, dy = 0;
    for (let o = 0; o < octaves; o++) {
      const f = freq * Math.pow(2, o);
      const a = amp / Math.pow(2, o);
      const nx = p.x * f + time * speed;
      const ny = p.y * f + time * speed * 0.7;
      const n = smoothNoise(nx, ny, seed + o * 100);
      dx += (n - 0.5) * a * 2;
      dy += (n - 0.5) * a * 2;
    }
    return { x: p.x + dx, y: p.y + dy };
  });
}

function applyTwirl(points: Point[], op: any, time: number): Point[] {
  const center = op.center || { x: 0.5, y: 0.5 };
  const radius = op.falloffRadius || 0.5;
  const angle = op.amplitude || 0.2; // 弧度
  const speed = op.speed || 0.5;

  return points.map(p => {
    const dx = p.x - center.x;
    const dy = p.y - center.y;
    const dist = Math.hypot(dx, dy);
    if (dist < 1e-6) return p;
    const falloff = Math.exp(-dist / radius);
    const theta = angle * falloff * (1 + Math.sin(time * speed));
    const cosA = Math.cos(theta);
    const sinA = Math.sin(theta);
    const rx = dx * cosA - dy * sinA;
    const ry = dx * sinA + dy * cosA;
    return { x: center.x + rx, y: center.y + ry };
  });
}

// ---------- 主入口：应用变换 + 扭曲堆栈 ----------
export function processMaskRing(
  baseRing: Point[],
  maskEffect: any,
  time: number
): Point[] {
  if (!maskEffect || !maskEffect.enabled) return baseRing;

  let pts = baseRing.slice();

  // 1. 变换
  if (maskEffect.transform) {
    pts = applyTransform(pts, maskEffect.transform);
  }

  // 2. 扭曲链
  if (maskEffect.distortions) {
    for (const op of maskEffect.distortions) {
      if (!op.enabled) continue;
      switch (op.type) {
        case 'wave':
          pts = applyWave(pts, op, time);
          break;
        case 'turbulent':
          pts = applyTurbulent(pts, op, time);
          break;
        case 'twirl':
          pts = applyTwirl(pts, op, time);
          break;
      }
    }
  }

  return pts;
}

/**
 * 烘焙区域色块图层：基于虚线闭合区域，从当前画布合成图中提取颜色块，
 * 生成静态纹理画布，并缓存到 regionLayerCanvas。
 * 
 * 支持 GPU 顶点着色器扭曲 + 硬件光栅化，若 GPU 不可用则降级到 CPU 扭曲。
 */
bakeRegionLayerTexture: (layerId: string) => {
  const state = get();
  const { shapes, canvasWidth, canvasHeight, regionAnnotations } = state;

  // 1. 获取虚线闭合区域（仅使用虚线形状）
  const allShapes = shapes.filter(s => s.layerId === layerId);
  const dashedRegions = computeAllDashedClosedRegions(allShapes, canvasWidth, canvasHeight);
  if (dashedRegions.length === 0) {
    set({ regionLayerCanvas: null });
    return;
  }

  // 2. 合成当前画布的完整颜色数据（背景 + 绘制层）
  const composited = getCompositedImageData(state);
  if (!composited) {
    console.warn('[bakeRegionLayerTexture] 无法合成图像数据');
    return;
  }

  // 3. 创建输出画布
  const outputCanvas = document.createElement('canvas');
  outputCanvas.width = canvasWidth;
  outputCanvas.height = canvasHeight;
  const outCtx = outputCanvas.getContext('2d')!;
  outCtx.clearRect(0, 0, canvasWidth, canvasHeight);
  const outImageData = outCtx.getImageData(0, 0, canvasWidth, canvasHeight);
  const outData = outImageData.data;

  // 4. 获取 GPU 蒙版处理器
  const gpuProcessor = getGPUMaskProcessor();
  const useGPU = gpuProcessor && gpuProcessor.isReady();
  const time = performance.now() / 1000;

  // 5. 检查是否有区域启用了蒙版特效，输出全局渲染路径
  const hasMaskEffectRegions = dashedRegions.some(region => {
    const anno = regionAnnotations.find(a => 
      String(a.regionId) === String(region.id) && a.layerId === layerId
    );
    return anno?.maskEffect?.enabled;
  });

  if (hasMaskEffectRegions) {
    console.log(`[bakeRegionLayerTexture] 🚀 渲染路径: ${useGPU ? '✅ GPU 顶点着色器扭曲（WebGL加速）' : '⚠️ CPU 回退扭曲（JavaScript计算）'}`);
  }

  const hueThreshold = 0.05;

  // 6. 对每个虚线区域进行色块提取
  for (const region of dashedRegions) {
    const anno = regionAnnotations.find(a => 
      String(a.regionId) === String(region.id) && a.layerId === layerId
    );

    const originalPolygon = region.polygon;
    const bbox = computeBBoxAllRings(originalPolygon);

    // ---- 生成局部掩码 ----
    let mask: Uint8Array | null = null;

    if (anno?.maskEffect?.enabled) {
      if (useGPU) {
        // ★★★ GPU 顶点着色器扭曲 ★★★
        try {
          const fullMask = gpuProcessor!.generateMask(originalPolygon, anno.maskEffect, time);
          if (fullMask) {
            // 从 512×512 完整掩码中裁剪出 bbox 区域
            const { x, y, w, h } = bbox;
            const localMask = new Uint8Array(w * h);
            for (let row = 0; row < h; row++) {
              const srcOffset = (y + row) * 512 + x;
              const dstOffset = row * w;
              localMask.set(fullMask.subarray(srcOffset, srcOffset + w), dstOffset);
            }
            mask = localMask;
            console.log(`[bakeRegionLayerTexture] ✅ 区域 ${region.id} 使用 GPU 顶点着色器扭曲`);
          } else {
            console.warn(`[bakeRegionLayerTexture] ⚠️ GPU 生成掩码返回 null，区域 ${region.id} 降级 CPU`);
            // 降级到 CPU
            const distortedPolygon = originalPolygon.map(ring =>
              processMaskRingCPU(ring, anno.maskEffect, time)
            );
            mask = rasterizeRegionMaskLocal(distortedPolygon, bbox);
          }
        } catch (e) {
          console.warn(`[bakeRegionLayerTexture] ⚠️ GPU 处理异常，区域 ${region.id} 降级 CPU:`, e);
          const distortedPolygon = originalPolygon.map(ring =>
            processMaskRingCPU(ring, anno.maskEffect, time)
          );
          mask = rasterizeRegionMaskLocal(distortedPolygon, bbox);
        }
      } else {
        // ★★★ CPU 回退扭曲 ★★★
        console.log(`[bakeRegionLayerTexture] ⚠️ 区域 ${region.id} 使用 CPU 回退扭曲`);
        const distortedPolygon = originalPolygon.map(ring =>
          processMaskRingCPU(ring, anno.maskEffect, time)
        );
        mask = rasterizeRegionMaskLocal(distortedPolygon, bbox);
      }
    } else {
      // 没有扭曲效果，直接光栅化
      mask = rasterizeRegionMaskLocal(originalPolygon, bbox);
    }

    // 如果掩码生成失败，跳过该区域
    if (!mask) {
      console.warn(`[bakeRegionLayerTexture] 区域 ${region.id} 掩码生成失败，跳过`);
      continue;
    }

    // ---- 聚类与纹理生成（V2 算法） ----
    const PAINT_BUFFER_SIZE = 512;
    const buffer = state.paintBuffers[layerId];
    if (!buffer) {
      console.warn('[bakeRegionLayerTexture] 没有 paintBuffer，跳过区域');
      continue;
    }

    const smallComposited = document.createElement('canvas');
    smallComposited.width = PAINT_BUFFER_SIZE;
    smallComposited.height = PAINT_BUFFER_SIZE;
    const smallCtx = smallComposited.getContext('2d')!;
    smallCtx.putImageData(buffer, 0, 0);

    const { baseColors, regionIdTex, deltaTex } = clusterAndGenerateTexturesV2(
      mask,
      bbox,
      smallCtx.getImageData(0, 0, PAINT_BUFFER_SIZE, PAINT_BUFFER_SIZE),
      hueThreshold,
      PAINT_BUFFER_SIZE
    );

    // ---- 解码并渲染到输出画布 ----
    const { w, h, x: offsetX, y: offsetY } = bbox;
    for (let y = 0; y < h; y++) {
      for (let x = 0; x < w; x++) {
        const idx = y * w + x;
        // 检查是否有效像素
        if (regionIdTex && regionIdTex[idx] === 0) continue;
        if (!regionIdTex && mask[idx] === 0) continue;

        let finalHsl;
        if (regionIdTex) {
          const baseIdx = regionIdTex[idx] - 1;
          if (baseIdx < 0 || baseIdx >= baseColors.length) continue;
          const base = baseColors[baseIdx];

          let dH = 0, dS = 0, dL = 0;
          if (deltaTex.length > 0) {
            dH = dequantize(deltaTex[idx * 3], 0.5);
            dS = dequantize(deltaTex[idx * 3 + 1], 1.0);
            dL = dequantize(deltaTex[idx * 3 + 2], 1.0);
            // 模拟 RGB565 量化再反量化（与 FTX 2.0 一致）
            const qH = quantizeH(dH);
            const qS = quantizeS(dS);
            const qL = quantizeL(dL);
            dH = dequantizeH(qH);
            dS = dequantizeS(qS);
            dL = dequantizeL(qL);
          }

          let finalH = base.h + dH;
          if (finalH < 0) finalH += 1.0;
          if (finalH > 1.0) finalH -= 1.0;
          const finalS = Math.max(0, Math.min(1, base.s + dS));
          const finalL = Math.max(0, Math.min(1, base.l + dL));
          finalHsl = { h: finalH, s: finalS, l: finalL };
        } else {
          finalHsl = baseColors[0];
        }

        const rgb = hslToRgb(finalHsl.h, finalHsl.s, finalHsl.l);
        const outIdx = ((offsetY + y) * canvasWidth + (offsetX + x)) * 4;
        outData[outIdx] = rgb.r;
        outData[outIdx + 1] = rgb.g;
        outData[outIdx + 2] = rgb.b;
        outData[outIdx + 3] = 255;
      }
    }
  }

  // 7. 将填充好的 ImageData 放回画布
  outCtx.putImageData(outImageData, 0, 0);

  // 8. 存储到 store
  set({ regionLayerCanvas: outputCanvas });
  console.log('[bakeRegionLayerTexture] 区域色块图层烘焙完成');
},

而是使用相对于该区域自身的局部坐标系：例如 0~1 的 UV 空间，或者相对于该区域包围盒左上角的偏移量。

这意味着：纹理是“贴”在区域内部的，无论区域在画布上怎么移动、旋转、缩放，纹理始终正确地跟随区域变形，不会错位。

渲染时，实体的变换矩阵（位置、旋转、缩放）负责将局部坐标映射到世界坐标/画布坐标，实现“绑定在实线区域内”的效果。

4. WebGL 只是绘制工具（关注点分离）

WebGL / Three.js 不参与区域数据的生成、聚类、颜色提取等业务逻辑。

它只是一个底层渲染引擎，职责是：

接收一组区域实体实例
读取每个实体的纹理、变换参数
机械地执行绘制指令（创建 Mesh、设置材质、提交渲染）
换句话说：WebGL 是工具，区域实体是数据 + 逻辑的载体。两者完全解耦，区域实体可以脱离 WebGL 独立存在（例如用于导出、序列化、压缩）。

typescript
// core/RegionEntity.ts
import type { Point } from '../types';
import * as THREE from 'three';
import { 
  computeBBoxAllRings, 
  rasterizeRegionMaskLocal, 
  clusterAndGenerateTexturesV2,
  hslToRgb,
  quantizeH, quantizeS, quantizeL,
  dequantizeH, dequantizeS, dequantizeL
} from '../utils/colorCompressor';
import { compressToBinary } from '../utils/binaryCompression';

export interface FtxTextureData {
  version: 2;
  baseColors: Array<{ h: number; s: number; l: number }>;
  deltaTexture: Uint8Array;      // 残差纹理（每个像素 3 字节）
  regionIdTexture?: Uint8Array;   // 区域ID纹理（可选，多聚类时存在）
  textureSize: number;            // 相对坐标纹理尺寸（如 128）
  bbox: { x: number; y: number; w: number; h: number };
}

export class RegionEntity {
  public readonly id: number;
  public readonly layerId: string;
  public readonly boundary: Point[][];
  
  // ✅ 核心：存储 ftx 压缩数据（非解压像素）
  private _ftxData: FtxTextureData | null = null;
  
  // 变换参数（与 UI 绑定）
  public transform = { position: { x: 0, y: 0 }, rotation: 0, scale: { x: 1, y: 1 }, anchor: null as { x: number; y: number } | null };
  public maskEffect: any = null;

  // GPU 纹理缓存（渲染时按需生成）
  private _gpuTexture: THREE.DataTexture | null = null;
  private _textureVersion: number = 0; // 用于检测是否需要重新生成

  constructor(id: number, layerId: string, boundary: Point[][]) {
    this.id = id;
    this.layerId = layerId;
    this.boundary = boundary;
  }

  /**
   * 从 paintBuffer 提取 ftx 压缩数据
   */
  public buildFromPaintBuffer(paintBuffer: ImageData, hueThreshold: number = 0.05, textureSize: number = 128): void {
    const bbox = computeBBoxAllRings(this.boundary);
    const mask = rasterizeRegionMaskLocal(this.boundary, bbox);
    
    const smallComposited = document.createElement('canvas');
    smallComposited.width = 512;
    smallComposited.height = 512;
    const ctx = smallComposited.getContext('2d')!;
    ctx.putImageData(paintBuffer, 0, 0);

    const { baseColors, regionIdTex, deltaTex } = clusterAndGenerateTexturesV2(
      mask,
      bbox,
      ctx.getImageData(0, 0, 512, 512),
      hueThreshold,
      512
    );

    // ✅ 存储原始 ftx 压缩数据（不展开成 RGBA）
    this._ftxData = {
      version: 2,
      baseColors,
      deltaTexture: deltaTex,
      regionIdTexture: regionIdTex || undefined,
      textureSize,
      bbox,
    };

    // 标记纹理需要重新生成
    this._textureVersion++;
  }

  /**
   * 获取或生成 GPU 纹理（按需渲染时调用）
   */
  public getGPUTexture(): THREE.DataTexture | null {
    if (!this._ftxData) return null;
    
    // 如果已有缓存且版本未变，直接返回
    if (this._gpuTexture && this._textureVersion === this._cachedVersion) {
      return this._gpuTexture;
    }

    // 从 ftx 数据解压生成 RGBA 纹理
    const { baseColors, deltaTexture, regionIdTexture, textureSize, bbox } = this._ftxData;
    const pixelData = this._decompressToRGBA(baseColors, deltaTexture, regionIdTexture, textureSize, bbox);

    // 创建或更新 GPU 纹理
    if (this._gpuTexture) {
      this._gpuTexture.dispose();
    }
    this._gpuTexture = new THREE.DataTexture(
      pixelData,
      textureSize,
      textureSize,
      THREE.RGBAFormat,
      THREE.UnsignedByteType
    );
    this._gpuTexture.needsUpdate = true;
    this._gpuTexture.minFilter = THREE.LinearFilter;
    this._gpuTexture.magFilter = THREE.LinearFilter;
    this._gpuTexture.wrapS = THREE.ClampToEdgeWrapping;
    this._gpuTexture.wrapT = THREE.ClampToEdgeWrapping;

    this._cachedVersion = this._textureVersion;
    return this._gpuTexture;
  }

  private _cachedVersion: number = -1;

  /**
   * 从 ftx 压缩数据解压为 RGBA
   */
  private _decompressToRGBA(
    baseColors: Array<{ h: number; s: number; l: number }>,
    deltaTexture: Uint8Array,
    regionIdTexture: Uint8Array | undefined,
    textureSize: number,
    bbox: { w: number; h: number }
  ): Uint8ClampedArray {
    const { w, h } = bbox;
    const pixelData = new Uint8ClampedArray(textureSize * textureSize * 4);
    pixelData.fill(0);

    for (let y = 0; y < h; y++) {
      for (let x = 0; x < w; x++) {
        const idx = y * w + x;
        const u = (x + 0.5) / w;
        const v = (y + 0.5) / h;
        const tx = Math.floor(u * textureSize);
        const ty = Math.floor((1 - v) * textureSize);
        if (tx >= textureSize || ty >= textureSize) continue;

        // 解码颜色（同之前的逻辑）
        let finalHsl;
        if (regionIdTexture) {
          const baseIdx = regionIdTexture[idx] - 1;
          if (baseIdx < 0 || baseIdx >= baseColors.length) continue;
          const base = baseColors[baseIdx];
          const dH = dequantize(deltaTexture[idx * 3], 0.5);
          const dS = dequantize(deltaTexture[idx * 3 + 1], 1.0);
          const dL = dequantize(deltaTexture[idx * 3 + 2], 1.0);
          // ... 量化反量化逻辑（与之前相同）
        } else if (baseColors.length > 0) {
          finalHsl = baseColors[0];
        } else continue;

        const rgb = hslToRgb(finalHsl.h, finalHsl.s, finalHsl.l);
        const outIdx = (ty * textureSize + tx) * 4;
        pixelData[outIdx] = rgb.r;
        pixelData[outIdx + 1] = rgb.g;
        pixelData[outIdx + 2] = rgb.b;
        pixelData[outIdx + 3] = 255;
      }
    }
    return pixelData;
  }

  /**
   * ✅ 导出 ftx 二进制数据（用于独立导出）
   */
  public exportFtxBinary(): Uint8Array | null {
    if (!this._ftxData) return null;
    // 构造 CompressionResultV2 格式
    const result: CompressionResultV2 = {
      version: 2,
      resolution: [512, 512],
      regionCount: 1,
      regions: [{
        id: this.id,
        bbox: this._ftxData.bbox,
        baseColors: this._ftxData.baseColors,
        regionIdTexture: this._ftxData.regionIdTexture 
          ? uint8ToBase64(this._ftxData.regionIdTexture) 
          : undefined,
        deltaTexture: uint8ToBase64(this._ftxData.deltaTexture),
      }],
      quantization: 'rgb565',
      hueThreshold: 0.05,
    };
    return compressToBinary(result);
  }

  /**
   * ✅ 序列化（JSON 只存元数据 + ftx 数据，不存 RGBA）
   */
  public serialize(): any {
    return {
      id: this.id,
      layerId: this.layerId,
      boundary: this.boundary,
      transform: this.transform,
      maskEffect: this.maskEffect,
      // ✅ 只存 ftx 压缩数据
      ftxData: this._ftxData ? {
        version: this._ftxData.version,
        baseColors: this._ftxData.baseColors,
        deltaTexture: Array.from(this._ftxData.deltaTexture),
        regionIdTexture: this._ftxData.regionIdTexture ? Array.from(this._ftxData.regionIdTexture) : undefined,
        textureSize: this._ftxData.textureSize,
        bbox: this._ftxData.bbox,
      } : null,
      ftxId: `ftx_${this.id}_${this.layerId}`, // 用于关联独立导出的 ftx 文件
    };
  }

  public dispose(): void {
    if (this._gpuTexture) {
      this._gpuTexture.dispose();
      this._gpuTexture = null;
    }
    this._ftxData = null;
  }
}

  const state = get();
  const shapes = state.shapes.filter(s => s.layerId === layerId);
  const paintBuffer = state.paintBuffers[layerId];

  // 1. 检测虚线闭合区域

    shapes,
    state.canvasWidth,
    state.canvasHeight
  );

  // 2. 释放旧实体
  const oldEntities = state.regionEntities[layerId] || [];
  oldEntities.forEach(e => e.dispose());

  // 3. 如果没有 paintBuffer 或没有区域，清空
  if (!paintBuffer || dashedRegions.length === 0) {

      regionEntities: { ...s.regionEntities, [layerId]: [] }
    }));
    return;
  }

  // 4. 构建新实体
  const newEntities: RegionEntity[] = [];
  for (let i = 0; i < dashedRegions.length; i++) {
    const region = dashedRegions[i];
    if (region.polygon.length === 0 || region.polygon[0].length < 3) continue;

    const entity = new RegionEntity(i, layerId, region.polygon);

    const transform = entity.transform;
    const anchor = transform.anchor || { x: 0.5, y: 0.5 };

    const y = (bbox.y / PAINT_SIZE) * canvasHeight;
    const w = (bbox.w / PAINT_SIZE) * canvasWidth;
    const h = (bbox.h / PAINT_SIZE) * canvasHeight;

    const anchorX = anchor.x * canvasWidth;
    const anchorY = (1 - anchor.y) * canvasHeight;

    const posY = anchorY - transform.position.y * canvasHeight;

    // 4. 创建几何体（尺寸 = bbox 尺寸）

      (x + w/2) - posX,
      (y + h/2) - posY,

      map: texture,
      transparent: true,
      depthWrite: false,
    });

    const mesh = new THREE.Mesh(geometry, material);
    mesh.position.set(posX, posY, 0);
    mesh.rotation.z = transform.rotation;   // ✅ 纹理旋转

// RegionEntity.ts 关键修改

export class RegionEntity {
  public worldBbox: { x: number; y: number; w: number; h: number } | null = null;

  public buildFromPaintBuffer(
    paintBuffer: ImageData,
    hueThreshold: number = 0.05,
    textureSize: number = 128
  ): void {
    // 1. 计算像素包围盒（用于纹理采样）
    const pixelBbox = computeBBoxAllRings(this.boundary);

    // 2. 转换为世界包围盒 (Y轴翻转)
    this.worldBbox = {
      x: pixelBbox.x / 512,
      y: 1 - (pixelBbox.y + pixelBbox.h) / 512,
      w: pixelBbox.w / 512,
      h: pixelBbox.h / 512,
    };

    // 3. 生成纹理（使用 pixelBbox，与画布分辨率无关）
    const mask = rasterizeRegionMaskLocal(this.boundary, pixelBbox);
    const { baseColors, regionIdTex, deltaTex } = clusterAndGenerateTexturesV2(
      mask,
      pixelBbox,
      paintBuffer,
      hueThreshold,
      512
    );

    // 4. 重采样到固定尺寸 (textureSize)
    const resampledDelta = new Uint8Array(textureSize * textureSize * 3);
    // ... 重采样逻辑（不变）
    // 5. 存储 ftx 数据（不再依赖 bbox 的位置）
    this._ftxData = {
      version: 2,
      baseColors,
      deltaTexture: resampledDelta,
      regionIdTexture: resampledRegionId || undefined,
      textureSize,
      bbox: pixelBbox, // 仅内部使用，外部通过 worldBbox 获取位置
    };
    this._textureVersion++;
  }

  public get bbox(): { x: number; y: number; w: number; h: number } | null {
    return this.worldBbox;
  }

  public serialize(): any {
    return {
      // ... 其他字段
      worldBbox: this.worldBbox,
      ftxData: this._ftxData ? {
        // 保留 pixelBbox 供旧格式兼容
        bbox: this._ftxData.bbox,
        // ... 其他纹理数据
      } : null,
    };
  }

  public restoreFromSerialized(data: any): void {
    // 恢复 worldBbox（优先使用直接存储的值）
    if (data.worldBbox) {
      this.worldBbox = data.worldBbox;
    } else if (data.ftxData?.bbox) {
      // 兼容旧格式：从像素 bbox 转换
      const pb = data.ftxData.bbox;

      const positions = new Float32Array(outerRing.length * 3);
      for (let i = 0; i < outerRing.length; i++) {
        positions[i*3] = outerRing[i].x;
        positions[i*3+1] = outerRing[i].y;
        positions[i*3+2] = 0;

      const maskEffect = entity.maskEffect || {};

        uTime: { value: 0 },
        uCanvasWidth: { value: canvasWidth },
        uCanvasHeight: { value: canvasHeight },
        uDistortionCount: { value: (maskEffect.distortions?.length || 0) },
        // 其他 uniform 数组（与 GPUMaskProcessor 一致）...

        // 为了代码清晰，我们定义一个辅助函数来生成扭曲参数数组
      };

      // 创建着色器材质（使用下面定义的 shader）
      const material = createBorderShaderMaterial(uniforms);

      const line = new THREE.LineLoop(geometry, material);
      // 存储 uniforms 以便动画更新
      borderUniformsMapRef.current.set(entity.id, { uniforms, mesh: line });
      borderGroup.add(line);
    }
  }
}, [regionEntities, activeLayerId, canvasWidth, canvasHeight]);

注意事项
法线计算：GPUMaskProcessor 的 wave 扭曲使用了梯度法线估计，这需要相邻顶点信息。在 LineLoop 中，顶点顺序是环形连续的，我们可以通过相邻顶点差计算切线，进而得到法线。但为了简单，我们可以省略法线方向，只使用 XY 方向的 wave（即 direction === 'xy'），或者简化法线为固定方向（如垂直）。如果一定要支持 normal/tangent，我们需要在顶点着色器中访问相邻顶点，但 LineLoop 无法直接获取邻居，除非使用几何着色器或传递索引。我们可以在 CPU 端预先计算每个顶点的法线，作为 attribute 传入，然后在顶点着色器中直接使用，无需实时计算。这样更简单。

为了代码复用，我们可以直接让边框使用与 GPUMaskProcessor 相同的着色器，但去掉模板缓冲部分，仅保留顶点变换。

坐标转换：由于我们绕过了 Three.js 的矩阵，边框的位置完全由 NDC 控制，不会受 zoom/pan 影响。这实际上是我们希望的：边框应该始终与纹理 Mesh 对齐，而纹理 Mesh 受根 Group 变换影响。但纹理 Mesh 是在根 Group 内，使用画布像素坐标，而我们的边框使用 NDC，两者坐标空间不同，会导致错位。我们需要让边框也跟随视图变换。

因此，更稳妥的方式是将边框放在根 Group 内，并让顶点坐标使用画布像素坐标（与纹理 Mesh 一致），然后在顶点着色器中只应用扭曲，而不进行像素到 NDC 的转换，让 Three.js 的投影矩阵处理。这样视图变换自动生效。我们需要在 CPU 端将世界坐标转为画布像素坐标（应用 worldToCanvas），然后传入顶点，这样顶点已经是像素坐标，根 Group 的缩放平移会正确作用于它们。但这样扭曲只能作用在像素坐标上，而我们希望扭曲在世界空间进行？实际上，扭曲应该在纹理坐标空间进行，而纹理坐标与像素坐标是线性关系，所以扭曲在像素坐标上效果相同。我们可以直接在像素坐标上应用扭曲（即扭曲量以像素为单位），这样着色器简单。

考虑到现有纹理 Mesh 使用的是像素坐标（canvasCenterX 等），边框也应使用像素坐标。因此，我们可以在生成边框顶点时，将世界坐标转换为像素坐标（使用 worldToCanvasFn），然后将这些像素坐标作为顶点位置。在顶点着色器中，我们不再做世界到像素的转换，而是直接对像素坐标应用扭曲（注意扭曲幅度要按像素缩放）。这样扭曲就作用在像素空间，且受根 Group 变换影响。

这样修改后，着色器中的位置已经是像素坐标，扭曲的幅度参数也需要相应调整（因为原来振幅是世界单位，现在变成像素单位，需乘以画布尺寸）。我们可以在 CPU 端将扭曲幅度乘以画布尺寸，或者着色器中乘以 uCanvasSize。

为了简化，我们采用这种方法：

在生成边框几何体时，使用 worldToCanvasFn 将每个世界坐标转为像素坐标，并作为顶点属性。

顶点着色器中，直接对像素坐标应用扭曲（扭曲幅度乘以 uCanvasSize 或直接传入像素幅度）。

然后让 Three.js 的模型视图投影矩阵处理（即乘以 modelViewProjectionMatrix），这样视图变换自动包含。

这样边框和纹理 Mesh 就在同一坐标空间，且同样受 zoom/pan 影响。

我们还需要将 canvasWidth/height 作为 uniform 传入，以便缩放幅度。

最终实现步骤
修改边框顶点生成：在 worldToCanvasFn 可用时（组件内已有），将世界坐标转为像素坐标，构建 BufferGeometry。

自定义着色器：顶点着色器接收像素坐标，应用扭曲（与 GPUMaskProcessor 类似，但位置已是像素），输出位置直接乘以 modelViewProjectionMatrix（因为 Three.js 会处理）。

统一 uniforms 管理：将边框的 uniforms 加入 regionUniformsMapRef 一起更新，或单独维护。

function createBorderMaterial(maskEffect: any): THREE.ShaderMaterial {
  const uniforms = {
    uTime: { value: 0 },
    // 复制扭曲参数
    uDistortionCount: { value: maskEffect?.distortions?.length || 0 },
    // ... 其他数组 uniform
  };
  return new THREE.ShaderMaterial({
    uniforms,
    vertexShader: `
      uniform float uTime;
      // ... 其他 uniform 声明
      varying vec2 vUv;
      void main() {
        vec2 pos = position.xy; // 像素坐标
        // 应用扭曲（与 GPUMaskProcessor 的扭曲逻辑相同，但 pos 已是像素）
        // 注意扭曲幅度需要按像素缩放（传入的 amplitude 已经是像素单位）
        vec2 distorted = pos;
        // ... 扭曲代码（使用 uTime 等） ...
        vec4 mvPosition = modelViewMatrix * vec4(distorted, 0.0, 1.0);
        gl_Position = projectionMatrix * mvPosition;
      }
    `,
    fragmentShader: `
      uniform vec3 color;
      void main() {
        gl_FragColor = vec4(color, 1.0);
      }
    `,
    transparent: true,
    linewidth: 2, // 注意 WebGL 不支持宽线，需用 Line2 或 TubeGeometry
  });
}
