# 流体编辑器 + 绘画主页面 —— 流体架构

## 四端统一约定

四端 = 流体编辑器（`src/fluid/editor/`）/ 绘画主页面（MainCanvas）/ 特效播放器（effects-player）/ 游戏端（全新的游戏）。
**修改任何一处必须同步其他三处。** 权威清单见 `src/fluid/fluidConfigIO.ts` 顶部注释。

### 1. 残差纹理 alpha 约定（背景透明 + 残差流动可见的关键）

```
alpha = "区域存在度"：
  shape 外（regionIdTex=0 / 多边形外 / 纹理透明像素）= 0
  shape 内 = 255
  RGB 中性 128（delta≈0），shape 外填 128
```

- 合成 `finalA = max(baseA, residual.a)` → shape 外 `max(0,0)=0` → 纯透明背景
- 残差平流时 alpha 随速度扩散 → 基础色=0 区域可见流动渐变（尾迹雾气）

四端位置：

| 端 | 位置 | 说明 |
|---|---|---|
| 编辑器 | `src/fluid/editor/FluidEditorUI.tsx` buildFluidTexturesFromRawFrame | bbox 局部，区域外默认 0 |
| 主绘画页面 | `src/stores/useAppStore.ts` residTex / residBase | 全帧 / bbox 局部 |
| 主绘画页面 | `src/fluid/fluidIntegration.ts` buildBaseHslFromFrame | alpha **不反推**（保留原始纹理 alpha） |
| 特效播放器 | `effects-player/src/core/ftx.ts` buildResidualData | 按 regionIdTex 区分 |
| 游戏端 | `全新的游戏/src/vendor/player/core/ftx.ts` buildResidualData | 与播放器同款 |

★ **实体 shader 流体模式禁止 discard**（alpha<0.5 丢弃会把残差流动渐变切掉）
→ 用 alpha 混合保留（MainCanvas 无 discard，天然正确；播放器/游戏端曾踩坑已修）。

### 2. 合成公式（MCSDA scalar / vector）

```
vector: finalA = max(baseA, residual.a)
scalar: final = base + delta + off（×通道开关 uChannels，静态 delta 始终参与）

sub（减去）模式：
  H/S/L 取 -|factor×mul|   （残差为 0 处依旧被密度拉出雾气）
  A 通道取 +|factor×mul|   （雾气越浓越实，不被减去模式压没）
  factor = density / baseline
```

位置：编辑器 `FluidEditorUI.tsx`（显示）/ 各端 `FluidSolver.buildCompositeMat`（计算）。

### 3. LevelSet 模块（四端已同步）

- **reinit**：Godunov 上风格式 + φ₀ 快照（原中心差分不收敛/界面漂移）
- **双模式**：
  - 约束模式（`constrainLiquid`）= 每帧「φ 重建 + reinit + 液体约束」
  - 追踪模式（默认）= φ 平流 + 每 `reinitInterval` 帧重建（注入即同步）
- **表面张力**：CSF `δ(φ)` 归一化（`F = σ·κ·δ·n̂`），σ 需极大才可见（≈6000+），
  UI 范围 0~100000、默认 10000
- **φ 后处理**：空气钳制（`clampAirPhi`）+ 水体补偿（`compensateWaterPhi`）
- **参数导出**：`levelSetConfig{...}` 全字段经 `fluidConfigIO` 双向读写，
  各端 `config.ts` 解析键名必须一致

### 4. 参数流转链路

```
流体编辑器 buildRecipe
  → 只给绘画主页面（parseImportedFluidConfig → frameData.fluidConfig）
  → 绘画主页面导出最终版（assetBundleExport 写进 per_frame_data.physics，
     内部扁平格式）
  → 特效播放器 / 游戏端 parsePhysicsConfig 读取同一格式
```

## 已踩过的坑（历史记录）

1. **σ 量级**：表面张力 `force ≈ σ×κ×δ`（κ≈0.1, δ≈0.1）→ 每帧 Δv≈1px/s 需 σ≈6000。
   旧 UI 0~10 怎么调都没效果。
2. **残差 alpha 128 陷阱**：残差纹理全图 alpha=128（中性半透明）→ 合成
   `max(0, 0.5)=0.5` → 背景半透明灰/黑。统一为 shape 外 0 / 内 255。
3. **discard 陷阱**：实体 shader `fluid.a < 0.5 discard` → 残差流动的渐变 alpha
   （<0.5 的插值）全被丢弃 → 看不到流动。主绘画页面无此问题，播放器/游戏端已修。
4. **反推 alpha**：buildBaseHslFromFrame 曾 `bA = finalA - dA`（dA 来自残差 alpha）
   → 区域内 base alpha 被拉成 0.5 → 半透明。改为不反推 alpha。
