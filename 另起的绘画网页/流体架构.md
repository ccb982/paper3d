# 流体编辑器 + 绘画主页面 —— 流体架构

## 四端统一约定

四端 = 流体编辑器（`src/fluid/editor/`）/ 绘画主页面（MainCanvas）/ 特效播放器（effects-player）/ 游戏端（全新的游戏）。
**修改任何一处必须同步其他三处。** 权威清单见 `src/fluid/fluidConfigIO.ts` 顶部注释。

### 1. 残差纹理 alpha 约定（背景透明 + 残差流动可见的关键）

```
alpha = "区域存在度"：
  shape 外（regionIdTex=0 / 多边形外 / 纹理透明像素）= 0
  shape 内 = 255
  RGB 中性 128（delta≈0），shape 外填 128
```

- 合成 `finalA = max(baseA, residual.a)` → shape 外 `max(0,0)=0` → 纯透明背景
- 残差平流时 alpha 随速度扩散 → 基础色=0 区域可见流动渐变（尾迹雾气）

四端位置：

| 端 | 位置 | 说明 |
|---|---|---|
| 编辑器 | `src/fluid/editor/FluidEditorUI.tsx` buildFluidTexturesFromRawFrame | bbox 局部，区域外默认 0 |
| 主绘画页面 | `src/stores/useAppStore.ts` residTex / residBase | 全帧 / bbox 局部 |
| 主绘画页面 | `src/fluid/fluidIntegration.ts` buildBaseHslFromFrame | alpha **不反推**（保留原始纹理 alpha） |
| 特效播放器 | `effects-player/src/core/ftx.ts` buildResidualData | 按 regionIdTex 区分 |
| 游戏端 | `全新的游戏/src/vendor/player/core/ftx.ts` buildResidualData | 与播放器同款 |

★ **实体 shader 流体模式禁止 discard**（alpha<0.5 丢弃会把残差流动渐变切掉）
→ 用 alpha 混合保留（MainCanvas 无 discard，天然正确；播放器/游戏端曾踩坑已修）。

### 2. 合成公式（MCSDA scalar / vector）

```
vector: finalA = max(baseA, residual.a)
scalar: final = base + delta + off（×通道开关 uChannels，静态 delta 始终参与）

sub（减去）模式：
  H/S/L 取 -|factor×mul|   （残差为 0 处依旧被密度拉出雾气）
  A 通道取 +|factor×mul|   （雾气越浓越实，不被减去模式压没）
  factor = density / baseline
```

位置：编辑器 `FluidEditorUI.tsx`（显示）/ 各端 `FluidSolver.buildCompositeMat`（计算）。

### 3. LevelSet 模块

- **reinit**：Godunov 上风格式 + φ₀ 快照（原中心差分不收敛/界面漂移）
- **双模式**：
  - 约束模式（`constrainLiquid`，编辑器默认 **开**）= 每帧「φ 重建 + reinit + 液体约束」
    把平流抹开的颜色晕圈裁剪到 φ<0 内 —— "烟雾感"克星；做雾化特效时关掉
  - 追踪模式 = φ 平流 + 每 `reinitInterval` 帧重建（编辑器默认 **1**=每帧重建，
    新注入液体立刻有表面；`reinitIterations` 默认 6，≥4 SDF 才充分收敛）
- **表面张力（CSF）**：`F = -σ·κ·δ(φ)·n̂`
  - ★ 负号不可省：约定 φ<0 为水、n̂ 指向空气侧，凸液面 κ≈+1/R>0，
    丢负号则力朝外 —— σ 越大越喷（历史 bug）
  - ★ σ 双向可调：正=向内收缩成水团，负=向外扩散（爆裂/雾化），门控 `!== 0`
  - ★ 必须在**压力投影之前**施加：张力的散度要靠投影转化为整体向心流动；
    投影之后再施力 = 张力速度不参与投影，只会把颜色抹开
  - ★ 曲率差分用 1.5px 宽距 + 归一化（κ=真实曲率 1/R）：单像素差分会被
    φ 噪声打穿符号 → 界面乱流发生器
  - 量级：像素单位制下 Δv/帧 ≈ σ/300R → 有效范围 **10⁵~10⁶**
    （UI ±5,000,000；编辑器默认 +1,000,000）
- **外向速度抑制**（`outwardDamping` 0~1，编辑器默认 **1**）：
  界面窄带内削减指向空气侧的法向速度 `v -= strength·max(v·n̂,0)·n̂`。
  **确定性收拢保证**——不依赖张力符号与 φ 噪声质量；1=界面完全不可外扩。
  在速度限幅之后执行，本帧用于平流的最终速度场无外扩分量。
- **φ 后处理**：空气钳制（`clampAirPhi`）+ 水体补偿（`compensateWaterPhi`）
- **参数导出**：`levelSetConfig{...}` 全字段经 `fluidConfigIO` 双向读写，
  各端 `config.ts` 解析键名必须一致

### 3.5 自由表面压力边界（真实感核心）

Level Set 启用时，压力求解（红黑 SOR）只在液体内部进行：

```
if (obstacle || φ > 0) p = 0        // 空气区恒零压
邻域采样：墙/空气邻居的压力视为 0     // 同硬边界处理
```

- 材质 key 区分：`sor_*_fs`（带 φ）/ `sor_*_obstacle`（全域，Level Set 关闭时回退）
- 物理意义：液体是**有表面的不可压缩整体**，注入动量推的是整块水而非染色剂；
  全域求解会让动量以压力波形式辐射进空气区 → 颜色像染料一样漂（不真实感的根源）
- 来源：废弃模拟器（git 历史 `src/lib/fluid-simulator/`）的 Jacobi 边界条件移植

### 3.6 粘度（速度场扩散）

- `∂v/∂t = ν∇²v`，ν 为运动粘度（cells²/s），离散 Laplacian = 四邻和−4·自身
- 效果：剪切层/射流按 e^{−νk²t} 最快衰减，大尺度运动保留 → 水团内聚
- 稳定性：显式扩散要求 ν·dt ≤ 0.25/步 → 子步分摊（每步 ≤0.2，上限 64 步，
  ν≈770@60fps 内精确，超出安全饱和不失稳）
- 位置：力相（表面张力之后、边界/压力投影之前）；墙内速度保持
- 默认 20（水感 10~60）；UI 滑条 0~1000 + 数字框任意值
- 实现：编辑器 `FluidEditor.applyViscosity` / 播放器副本 `FluidSolver.applyViscosity`

### 3.7 渲染（Level Set 视图 = 旧库分层水渲染）

- 编辑器"Level Set"视图已改用**废弃模拟器的 φ 驱动分层水着色**（FluidEditorUI levelsetMat）：
  深度混色（waterColor→deepColor，-φ/uDepthScale）+ ∇φ 法线漫反射 + Blinn-Phong 镜面 +
  边缘发光环 + 速度流动扰动；φ≥0 discard 背景透明
- 单位适配：旧库 φ 为 UV 归一化、编辑器为像素 —— 深度/边缘/透明度按 px 标定
  （uDepthScale=40px、边缘 3px），法线差分 1.5px 与张力 pass 同款去噪
- 原"🌊 分层水渲染"开关及 alpha 近似后处理已**移除**（按 alpha 深度近似，
  无法复现 φ 法线高光；真实感来源见 3.5 自由表面边界）

## 已踩过的坑（历史记录）

1. **σ 量级**：表面张力像素单位制下 Δv/帧 ≈ σ/300R → 有效范围 **10⁵~10⁶**
   （早期估算 6000 偏小，旧 UI 0~200 怎么调都没效果；详见坑 #7/#8 的另外两个
   独立根因：符号反了 + 施力时机在投影之后）。
2. **残差 alpha 128 陷阱**：残差纹理全图 alpha=128（中性半透明）→ 合成
   `max(0, 0.5)=0.5` → 背景半透明灰/黑。统一为 shape 外 0 / 内 255。
3. **discard 陷阱**：实体 shader `fluid.a < 0.5 discard` → 残差流动的渐变 alpha
   （<0.5 的插值）全被丢弃 → 看不到流动。主绘画页面无此问题，播放器/游戏端已修。
4. **反推 alpha**：buildBaseHslFromFrame 曾 `bA = finalA - dA`（dA 来自残差 alpha）
   → 区域内 base alpha 被拉成 0.5 → 半透明。改为不反推 alpha。
5. **清屏色泄漏进场数据**（2026-08-23 事故 #001，★★★★★）：`clearGrid` 用裸
   `renderer.clear()` 清密度/颜色/速度场——它写入的是**全局 clearColor 而非零**。
   游戏端把清屏色从深蓝改成浅灰后，reset 后全场假密度 0.8 → MCSDA 整块近黑、
   周期性消散。本仓库 FluidSolver / FluidEditor（含障碍物掩码，R>0.5=墙）/ GPUOps /
   AdvectionSolver 已全部改为"强制黑透明清屏+保存恢复"。完整因果链见
   《全新的游戏/架构设计.md》事故记录 #001。
   **红线：数据纹理的 clear 必须强制黑；显示画布才可用主题色。**
6. **裸 GL 清绑导致 three 缓存失同步**：曾用 `gl.bindTexture(TEXTURE_2D, null)`
   循环断 feedback loop，但 three r185 `WebGLState.bindTexture` 有缓存跳过逻辑
   （缓存命中就不真正重绑）→ 后续材质采样空纹理（黑帧）。统一改用
   官方 `renderer.resetState()`。红线同上：禁止裸 GL 操作 three 托管状态。
7. **CSF 张力丢负号**（2026-08 水团攻坚）：`F = σκδn̂` 在 φ<0=水、n̂ 指向空气的
   约定下，凸液面 κ>0 → 力朝外，σ 越大越喷成烟雾。正确形式 `-σκδn̂`
   （Brackbill κ 取 −∇·n̂）。已改为 σ 双向：正=收缩、负=扩散。
8. **张力施力时机**：曾放在压力投影之后 → 张力速度不参与投影，直接被平流消费，
   σ 再大也只见颜色抹开。必须"先施力→后投影"。废弃模拟器正是此顺序
   （外力→散度→Jacobi×200→速度修正）+ σ=728000 饱和速度钳制，才有真实水感。
9. **κ 单像素差分噪声**：φ 从 alpha 阈值重建带锯齿，1px 差分的曲率正负乱跳
   → 张力退化为界面乱流源（表现为"无论 σ 正负都向外发散"）。
   修复：1.5px 宽距归一化差分 + 外向速度抑制兜底（确定性收拢）。
10. **粘度自由调控**：显式扩散稳定上限 ν·dt≤0.25/步；子步上限过小（8）会把
    等效粘度钳死。现 64 步（ν≈770@60fps 精确），UI 数字框可输任意值。
