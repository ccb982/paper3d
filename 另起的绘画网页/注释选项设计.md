您希望在区域注释中增加可填的选项，区分静态大纹理流体（FluidSimulatorAdapter）和小流体实体（LightFluidEntity），并能按预设模板调整参数，方便生成不同风格的流体纹理。

以下分析两个场景的关键函数与可配置参数，并给出预设模板的设计建议。

一、静态大纹理流体 (FluidSimulatorAdapter)
1. 核心调用流程
ts
// 创建模拟器，传入 FluidParams
this.simulator = new FluidSimulator(renderer, params);

// 每帧调用
simulator.update(delta);

// 获取渲染材质
simulator.getRenderMaterial();

// 可选：设置初始 Level Set 纹理
simulator.setLevelSetTexture(tex);
2. 可配置参数 (FluidParams)
参数	含义	典型范围
width, height	纹理分辨率	常用 512×256
density	密度 (kg/m³)	1000（水）
viscosity	动力粘度 (Pa·s)	0.001（水）~ 更高（粘稠）
surfaceTension	表面张力 (N/m)	0.0728（水）
gravity	重力 (m/s²，向下为正)	9.81 或 0（无重力）
pressureIterations	压力求解迭代次数	15~200（影响体积守恒）
reinitIterations	Level Set 重初始化迭代	1~5
reinitInterval	重初始化间隔帧数	1（每帧）~ 100
timeStep	固定时间步长	0.002~0.01
restitution	固体碰撞恢复系数	0.0~1.0
friction	摩擦系数	0.0~1.0
usePCG	是否使用 PCG 求解器	true/false
maxLifetime	流体最大寿命(秒)，0 为不消散	0 ~ 几十秒
injectionEnabled	是否开启持续注入	true/false
injectionPosX/Y	注入位置 (UV 空间)	0~1
injectionFlowRate	注入流量	1~500
injectionVelX/Y	注入速度	-5~5
injectionSize	注入区域半径	0.02~0.3
decoupledBoundary	解耦边界处理	true/false
boundaryRingWidth	边界环宽度 (UV)	0.01~0.05
boundaryDivDamping	散度阻尼	0~1
boundaryVelDamping	速度修正阻尼	0~1
usePerturbation	随机扰动（爆炸时）	true/false
perturbationStrength	扰动强度	0~1
fragmentCount	多团块爆炸子块数	1~8
waterColor, deepColor, edgeWidth, edgeIntensity, specularIntensity, flowIntensity, lightDir	分层渲染外观	–
enableCentering	纹理居中追踪	true/false
centeringInterval	居中追踪间隔(秒)	0.5~2
clampAirPhi	限制空气区 phi 最大值	true/false
maxAirPhi	空气区 phi 上限	0.01~0.1
compensateWaterPhi	水体区负向补偿	true/false
waterCompensationRate	补偿速率	0.01~0.5
3. 运行时修改接口（用于注入与爆炸）
ts
// 散度注入（负=膨胀，正=收缩）
addDivergenceImpulse(divergence, radius, cx, cy);
// 水花生成
addWaterImpulse(amount, radius, cx, cy);
// 速度脉冲
addLocalVelocityImpulse(dvx, dvy, radius, cx, cy, maxSpeed);
// 各向异性爆炸
explodeAnisotropic(cx, cy, radius, strength, createWater, duration, mode, phase, anisoStrength);
// 多团块爆炸
explodeFragmented(cx, cy, radius, strength, createWater, duration, fragmentCount, seed, waterMultiplier);
// 恒定散度注入（每帧）
startConstantInjection(center, radius, strength);
// 边界 phi 削弱（形成固体墙）
addBoundaryPhiDamping(strength, edgeWidth, tipGap);
4. 初始形状设置
通过 setLevelSetTexture 传入自定义纹理，或使用内置的 initLevelSetShader（默认生成圆形）。
内置圆形参数：center, radius, randomSeed（噪声）。

二、小流体实体 (LightFluidEntity)
1. 核心调用
ts
const droplet = new LightFluidEntity(id, renderer, position, velocity, waterVolume, maxAge, skipInitialVolume);
// 每帧更新
droplet.update(delta);
// 获取材质
droplet.getSimulator().getRenderMaterial();
2. 可配置参数（构造函数）
参数	含义	典型范围
waterVolume	水量占比 (0~1)，决定大小和纹理内水半径	0.1~1.0
maxAge	最大生命周期（秒）	2~10
skipInitialVolume	跳过初始水量设置（用于碎片系统）	true/false
通过 setInitialVelocity 可设置初速度		
3. 实体内部固定的模拟参数（FluidParams，位于 LightFluidEntity 构造函数内）：
ts
width: 32,
height: 64,
density: 1000,
viscosity: 0.001,
surfaceTension: 0.1,
gravity: -10,          // 注意符号（向上为正）
pressureIterations: 40,
reinitIterations: 1,
reinitInterval: 100,
timeStep: 0.01,
restitution: 0.2,
friction: 0.9,
usePCG: false,
maxLifetime: 0,
decoupledBoundary: false,
usePerturbation: false,
injectionEnabled: true,   // 持续水流注入（朝向尖端）
injectionPosX: 0.5,
injectionPosY: 0.3,
injectionFlowRate: 300.0,
injectionVelX: 0,
injectionVelY: 0.5,
injectionSize: 0.35,
enableCentering: false,
clampAirPhi: true,
maxAirPhi: 0.01,
compensateWaterPhi: true,
waterCompensationRate: -30,
这些参数目前未暴露给用户，但可以设计为可选覆盖。

4. 实体特有行为开关
trailEnabled（尾部挖空效果，默认 true）

trailRadius（挖空半径，默认 0.1）

trailOffset（挖空偏移量，默认 0.25）

gravityEnabled（是否受重力影响，默认 false）

5. 运行时修改接口（通过 IFluidForceTarget）
ts
applyFluidForce({
  worldImpulse: THREE.Vector3,
  worldAcceleration: THREE.Vector3,
  velocityInjection: { centerUV, radius, velocity },
  divergenceInjection: { centerUV, radius, divergence },
  waterInjection: { centerUV, radius, amount }
})
三、为区域注释设计的预设模板
预设类型选择

static → 使用 FluidSimulatorAdapter 风格的全局大纹理

droplet → 使用 LightFluidEntity 风格的小水滴/碎片

四、实现建议
在区域注释数据结构中增加字段：

ts
interface RegionAnnotation {
  // ... existing
  fluidConfig: {
    type: 'static' | 'droplet';
    presetId?: string;        // 预设 ID
    customParams: any;        // 用户填写的参数（覆盖预设）
  }
}
UI 表单：根据 type 动态渲染，提供预设下拉框 + 详细参数折叠面板。

运行时生成：

对于静态流体：创建一个 FluidSimulatorAdapter，调用 configureInjection，如果预设包含爆炸序列则触发 explodeFragmented。

对于小液滴：创建 LightFluidEntity，传入 waterVolume, maxAge 等，并通过 applyFluidForce 或直接设置速度。

纹理生成辅助：可以提供一个“预览”按钮，在编辑器内就地运行模拟几帧，让用户看到效果。

这样，区域注释不仅能标记位置，还能作为流体生成器的配置模板，大大增强实用性。
