为了实现高效的液滴管理并支持性能优化（LOD/帧率控制），建议在现有的 EntityManager 与 LightFluidEntity 之间引入一个中间层——FluidRegionManager（小区域流体管理器）。它可以：

管理一片区域内的多个 LightFluidEntity

接收 EntityManager 的统一调度

根据与角色距离或全局帧预算动态控制内部流体模拟的更新频率/纹理刷新

下面给出完整的设计方案与核心代码。

一、总体架构
text
EntityManager (全局单例)
├── FluidRegionManager A  (管理区域A的小液滴)
│   ├── LightFluidEntity 1
│   ├── LightFluidEntity 2
│   └── ...
├── FluidRegionManager B  (管理区域B的小液滴)
│   └── ...
└── 其他实体 (敌人、子弹等)
职责划分：

EntityManager：维护所有实体和所有 FluidRegionManager；根据全局相机位置、整体帧率等信息，计算每个区域管理器的 LOD 等级，并调用其 update(delta, lod)。

FluidRegionManager：负责该区域内液滴的创建、销毁、常规运动更新，并根据 lod 参数决定内部流体模拟器更新的频率或纹理计算精度。

LightFluidEntity：保持不变，自身仍拥有 FluidSimulator 并可独立更新。

二、FluidRegionManager 设计
typescript
// FluidRegionManager.ts
import * as THREE from 'three';
import { EntityManager } from '@core/EntityManager'; // 假设路径
import { LightFluidEntity } from '@entities/fluid';

export enum FluidLOD {
  HIGH   = 0,   // 每帧更新模拟 + 纹理刷新
  MEDIUM = 1,   // 每2帧更新模拟 + 纹理刷新
  LOW    = 2,   // 每4帧更新模拟，不刷新纹理（冻结画面）
  OFF    = 3    // 完全不更新
}

export class FluidRegionManager {
  private entities: LightFluidEntity[] = [];
  private center: THREE.Vector3;          // 区域中心
  private radius: number;                 // 区域半径
  private maxDroplets: number;
  private currentLOD: FluidLOD = FluidLOD.HIGH;
  private frameSkipCounter: number = 0;

  constructor(center: THREE.Vector3, radius: number, maxDroplets = 20) {
    this.center = center.clone();
    this.radius = radius;
    this.maxDroplets = maxDroplets;
  }

  // 添加现有液滴（由 EntityManager 创建后转入）
  addDroplet(droplet: LightFluidEntity): void {
    // 可限制总量
    if (this.entities.length >= this.maxDroplets) {
      // 移除最老的或距离中心最远的
      this.removeOldest();
    }
    this.entities.push(droplet);
  }

  // 批量创建液滴（内部调用 EntityManager 的单例创建方法）
  async createDroplets(count: number, spread?: number): Promise<void> {
    const em = EntityManager.getInstance();
    const renderer = em.getRenderer();
    if (!renderer) return;
    for (let i = 0; i < count; i++) {
      const angle = Math.random() * Math.PI * 2;
      const dist = (spread ?? this.radius) * Math.sqrt(Math.random());
      const pos = this.center.clone().add(
        new THREE.Vector3(Math.cos(angle) * dist, Math.sin(angle) * dist, 0)
      );
      const vel = new THREE.Vector3(
        (Math.random() - 0.5) * 2,
        (Math.random() - 0.5) * 2,
        0
      );
      const droplet = new LightFluidEntity(
        `fluid_${Date.now()}_${Math.random()}`,
        renderer,
        pos,
        vel,
        0.3 + Math.random() * 0.4,  // 水量
        8 + Math.random() * 4       // 寿命
      );
      em.addEntity(droplet);                 // 注册到全局管理器
      this.addDroplet(droplet);              // 由本管理器跟踪
    }
  }

  // 核心更新：由 EntityManager 每帧调用，传入 LOD 等级
  update(delta: number, lod: FluidLOD): void {
    this.currentLOD = lod;

    // 收集已失效的液滴（已在 EntityManager 中标记为非活跃的）
    this.entities = this.entities.filter(e => e.isActive);

    if (lod === FluidLOD.OFF) return;

    // 根据 LOD 决定模拟更新频率
    const updateInterval = lod === FluidLOD.HIGH ? 1 : lod === FluidLOD.MEDIUM ? 2 : 4;
    this.frameSkipCounter++;
    if (this.frameSkipCounter % updateInterval !== 0) return;
    this.frameSkipCounter = 0;

    // 逐个更新液滴的运动和模拟
    for (const droplet of this.entities) {
      // motion update (世界移动) 这部分总该更新，但也可放在高频率中
      droplet.update(delta);
    }

    // 可选：LOD = LOW 时停止纹理刷新
    if (lod === FluidLOD.LOW || lod === FluidLOD.MEDIUM) {
      // 可以调用 FluidSimulator 的一个方法让渲染材质不更新
      // 例如 droplet.simulator.freezeTextures(true);
      for (const droplet of this.entities) {
        // droplet.getSimulator().setTextureUpdateEnabled(false); // 需要扩展 FluidSimulator
      }
    }
  }

  // 获取区域中心与半径，供 EntityManager 计算距离
  getBounds(): { center: THREE.Vector3; radius: number } {
    return { center: this.center, radius: this.radius };
  }

  // 销毁整个区域（移除所有液滴）
  destroy(): void {
    const em = EntityManager.getInstance();
    for (const d of this.entities) {
      em.removeEntity(d);
    }
    this.entities = [];
  }

  private removeOldest(): void {
    // 简单删除第一个（最老），更优策略可按距离
    const oldest = this.entities.shift();
    if (oldest) EntityManager.getInstance().removeEntity(oldest);
  }
}
三、修改 EntityManager，集成 FluidRegionManager
在 EntityManager 中增加区域管理器列表，并在 update 中根据条件赋予 LOD：

typescript
// EntityManager 新增属性与方法
private fluidRegions: FluidRegionManager[] = [];
private playerPositionCache: THREE.Vector3 = new THREE.Vector3();

// 注册区域管理器
public addFluidRegion(region: FluidRegionManager): void {
  this.fluidRegions.push(region);
}

// 移除区域管理器
public removeFluidRegion(region: FluidRegionManager): void {
  const idx = this.fluidRegions.indexOf(region);
  if (idx >= 0) {
    region.destroy();
    this.fluidRegions.splice(idx, 1);
  }
}

// 更新所有实体（修改原 update 方法）
public update(delta: number, playerPosition?: THREE.Vector3): void {
  // 1. 更新普通实体（原有逻辑）
  // ...

  // 2. 更新流体区域
  if (playerPosition) this.playerPositionCache.copy(playerPosition);

  const highDist = 5.0;   // 距离 ≤5 使用 HIGH
  const mediumDist = 15.0; 
  const offDist = 30.0;

  for (const region of this.fluidRegions) {
    const { center, radius } = region.getBounds();
    const dist = center.distanceTo(this.playerPositionCache) - radius;
    let lod: FluidLOD;

    if (dist <= highDist) {
      lod = FluidLOD.HIGH;
    } else if (dist <= mediumDist) {
      lod = FluidLOD.MEDIUM;
    } else if (dist <= offDist) {
      lod = FluidLOD.LOW;
    } else {
      lod = FluidLOD.OFF;
    }

    // 还可结合全局帧率（例如上一帧耗时过多时，整体降一档）
    region.update(delta, lod);
  }
}
如果还需要基于帧率的动态控制，可以在 update 开头统计上一帧耗时，若超过阈值则全局降低一个 LOD 等级。

四、使用示例
typescript
// 初始化
const manager = EntityManager.getInstance();
manager.setRenderer(renderer);
manager.setScene(scene);

// 创建两个小区域管理器
const regionA = new FluidRegionManager(new THREE.Vector3(0, 0, 0), 3.0, 15);
const regionB = new FluidRegionManager(new THREE.Vector3(20, 5, 0), 2.5, 10);

manager.addFluidRegion(regionA);
manager.addFluidRegion(regionB);

// 预生成一批液滴
await regionA.createDroplets(10, 2.5);
await regionB.createDroplets(6, 2.0);

// 游戏循环
function animate() {
  const delta = clock.getDelta();
  const playerPos = camera.position; // 或角色位置

  // 统一更新，自动根据距离控制液滴纹理更新频率
  manager.update(delta, playerPos);
  requestAnimationFrame(animate);
}
五、扩展 FluidSimulator 支持纹理解冻
为了在 FluidLOD.LOW 时停止纹理刷新，可在 FluidSimulator 中添加标志位：

typescript
private textureUpdateEnabled = true;

public setTextureUpdateEnabled(enabled: boolean) {
  this.textureUpdateEnabled = enabled;
}

public getRenderMaterial(): THREE.ShaderMaterial {
  if (this.textureUpdateEnabled) {
    this.renderMaterial.uniforms.phiTex.value = this.curPhiTex.texture;
    this.renderMaterial.uniforms.velTex.value = this.curVelTex.texture;
  } // 否则维持上一次纹理，画面静止
  return this.renderMaterial;
}
这样 FluidRegionManager 就可以在 LOW 模式下调用 setTextureUpdateEnabled(false)，大幅减少 GPU 纹理传输和着色器更新开销。

六、性能收益总结
距离分级：远离玩家的液滴区域完全冻结甚至不更新，节省 CPU/GPU。

帧率自适应：可全局降低 LOD，保证流畅度。

批量管理：一个通道内所有小液滴统一控制生命周期，方便区域激活/休眠。

隔离性：区域管理器只影响自己的液滴，其它实体不受干扰。

这种层级设计能让你轻松管理场景中大量离散小流体效果，同时保持可接受的性能。
