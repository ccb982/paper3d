## 一、总原则（用户定调）

1. **每个伺服状态独立**——站立/蹲下各一套参数（基础力、目标角、τmax、限位、速度限位），
   原子切换（`world.switchPoseState`），互不泄漏。
2. **状态分区数据化**——所有状态相关参数集中在 `baseTable.ts` 的 `BasePose` 里，
   切换代码只是薄壳（恢复骨架原始值 → 应用当前状态配置）。
3. **蹲姿的力从约束出发算**（而不是逐关节手调）：
   - 腿链需求 = 自由体子树 + 地面反力项（CH 回读验证）
   - 标准姿势需求极小：踝 ≈0 / 膝 ±4 / 髋 −25 / 腰 −116 / 腰2 −58 / 腰3 −13
4. **显式阻尼/弹簧必须受惯量限幅**（今天四类爆点全是这个）：
   `kd ≤ 2I/dt`，`kp ≤ 4I/dt²`（dt=1/240）。轻肢体（手臂 I~0.01）的界只有 ~4.8/2300。

## 二、状态伺服分区（`src/core/servo/baseTable.ts`）

```
BasePose = {
  params: { comX, footFloor, kneeTwFloor, hipKpMul, limitBase }   // 回正力/限位基准
  tq:     { 关节轴 → N·m }                                        // 基础力矩表（写手 sqChain/sqSpine 读）
  ang:    { 关节轴 → rad }                                        // 目标角（回正力/captureAngFrom 读）
  joints: {                                                       // ★ 状态化关节伺服参数
    tauMax: [正则, N·m][]          // 力矩预算
    limits: [正则, 轴, min°, max°][] // 屈伸限位（引擎限位关节会同步更新 Rapier 关节）
    velMax: [正则, 轴(-1=全), rad/s][] // 速度限位（驱动层刹车；★ 蹲姿已关——见根因#5）
  }
}
```

### 站立（stand）
- tq：几乎全零（sup_hip0=0.9 / sup_knee0=−1.3）——支撑力由 gcomp（antiG）提供
- ang：S 形脊柱
- joints：velMax = 臂8/腿10/脊6/颈8；τmax/限位 = 骨架默认

### 蹲下（squat）
- **tq（表值 = 需求 − gcomp，全部实测）**：
  `髋 −48 / 膝 −2 / 踝 0 / 腰1 −117 / 腰2 −61 / 腰3 −15`
- ang：hip2=2.09 / knee2=−2.08 / spine1..3_2=−0.42 / shoulder2=0.5（与法庭摆姿一致）
- joints：
  - tauMax：髋800 / 膝450 / 踝320 / 腰320 / 颈150 / 臂160
  - limits：腰±45° / 髋 −120..175° / 膝 −165..5° / 踝 ±45°
  - velMax：**全部 999（=关闭）**——刹车在跌速下爆 ±480-800，是链的混沌源

## 四、释放序列（`src/core/court.ts` courtStep）

```
① 摆姿（squatCourtSetup）：teleport 蹲姿 + captureAngFrom（目标=实际读数）
② 静置期（settle，默认 2.0s）：
   - outputScale = 0（全静默——"静止期间全身不受力"）
   - 重力 = 0（w.setGravity(0)）
   - 速度每帧清零
   - 不钉脚（SQC_PIN=1 可开；钉脚 vs 解算器对打会爆）
   - 不判死
③ 放开（t > settle）：
   - 判死基线重捕（pitch/roll/com 以放开瞬间为基准）
   - 重力恢复
   - outputScale 渐入：ramp = (t−settle)/rampT，rampT 默认 0.5（SQC_RAMP 可覆盖；0.1 更快）
④ 判死：pitchΔ>20° / rollΔ>10° / offX/offZ>5cm / comY 降>10cm
```

## 五、今天查明的根因（全部有实验数据）

1. **四类显式阻尼超稳定界**（同类错误：`kd > 2I/dt` 的显式积分爆炸）：
   - 髋刹车 kd=120 → 髋 ±800 翻烧饼、脚被甩飞
   - 腰刹车 kd=60 → 腰 ±300 翻烧饼
   - 张力层（手臂）kd=70（界 4.8）→ 肘 ±269 巨力、手臂疯狂转
   - 踝链弹簧 kd=120（界 4.8）→ 踝速 3768、脚打飞
2. **关节限位超限**：髋骨架上限 100° vs 蹲姿 130-136° → 限位冲量每帧把髋拉回=发射；
   腰 ±25° 目标顶死 → 抽搐。**限位必须状态化**（且引擎限位关节要运行时 `setLimit`）。
3. **速度限位刹车**（今天新加）在跌速 v=10-20 时爆 ±480-800（髋实测 +617 vs 表值 −144）
   → 链的混沌源 → 蹲姿已关（999）。
4. **基础力表的几何副作用**：关节力矩通过链把轻脚（1kg）拽离地面（表值0=脚不动、表值开=脚升 2.3cm）。
5. **上身缺力**：脊柱表值没有写手读（ARM 循环蹲姿跳过）→ 缺口 118/61/15；已接 `sqSpine`。
6. **上身 gcomp 符号**：蹲姿前倾 43° 时翻转（站立躯干竖直符号无所谓）；只翻脊柱/颈（手臂不翻）。
7. **静置期物理**：重力关 → 放开时脚是空的（fz=0）→ 链无地面锚（恶性循环的根）。
   （"接触先建立"的实验未成功，静置物理待重设计。）
