## 一、总原则（用户定调）

1. **每个伺服状态独立**——站立/蹲下各一套参数（基础力、目标角、τmax、限位、速度限位），
   原子切换（`world.switchPoseState`），互不泄漏。
2. **状态分区数据化**——所有状态相关参数集中在 `baseTable.ts` 的 `BasePose` 里，
   切换代码只是薄壳（恢复骨架原始值 → 应用当前状态配置）。
3. **蹲姿的力从约束出发算**（而不是逐关节手调）：
   - 腿链需求 = 自由体子树 + 地面反力项（CH 回读验证）
   - 标准姿势需求极小：踝 ≈0 / 膝 ±4 / 髋 −25 / 腰 −116 / 腰2 −58 / 腰3 −13
4. **显式阻尼/弹簧必须受惯量限幅**（今天四类爆点全是这个）：
   `kd ≤ 2I/dt`，`kp ≤ 4I/dt²`（dt=1/240）。轻肢体（手臂 I~0.01）的界只有 ~4.8/2300。

## 五、今天查明的根因（全部有实验数据）

1. **四类显式阻尼超稳定界**（同类错误：`kd > 2I/dt` 的显式积分爆炸）：
   - 髋刹车 kd=120 → 髋 ±800 翻烧饼、脚被甩飞
   - 腰刹车 kd=60 → 腰 ±300 翻烧饼
   - 张力层（手臂）kd=70（界 4.8）→ 肘 ±269 巨力、手臂疯狂转
   - 踝链弹簧 kd=120（界 4.8）→ 踝速 3768、脚打飞
2. **关节限位超限**：髋骨架上限 100° vs 蹲姿 130-136° → 限位冲量每帧把髋拉回=发射；
   腰 ±25° 目标顶死 → 抽搐。**限位必须状态化**（且引擎限位关节要运行时 `setLimit`）。
3. **速度限位刹车**（今天新加）在跌速 v=10-20 时爆 ±480-800（髋实测 +617 vs 表值 −144）
   → 链的混沌源 → 蹲姿已关（999）。
4. **基础力表的几何副作用**：关节力矩通过链把轻脚（1kg）拽离地面（表值0=脚不动、表值开=脚升 2.3cm）。
5. **上身缺力**：脊柱表值没有写手读（ARM 循环蹲姿跳过）→ 缺口 118/61/15；已接 `sqSpine`。
6. **上身 gcomp 符号**：蹲姿前倾 43° 时翻转（站立躯干竖直符号无所谓）；只翻脊柱/颈（手臂不翻）。
7. **静置期物理**：重力关 → 放开时脚是空的（fz=0）→ 链无地面锚（恶性循环的根）。
   （"接触先建立"的实验未成功，静置物理待重设计。）

## 九、虚拟腿协同（2026-10-18 晚，用户：'把下身固定'）

### 动机（论文依据）
- **Bernstein 1967 冻结自由度**：新手把冗余关节锁成刚性协同=稳定的合法策略
- **SLIP/虚拟腿**（腿部机器人）：腿当一根伸缩弹簧，蹲=虚拟腿压缩——没有内部乱动自由度
- 问题实测：蹲姿髋/膝各自 PD → 腿有内部乱动空间（髋 ±350 翻转、脚角速 21.6 崩）

### 架构（`src/core/servo/virtualLeg.ts`，与 staticBalance 同级的新模块）
```
L   = |p_踝 − p_髋|（实际腿长）
F   = kpL×(L0−L) − kdL×L̇（虚拟腿弹簧；L0=静置首次调用捕获）
τ_j = F × g_j，g_j = ∂L/∂θ_j = u·(ω_j × (p_踝 − a_j))（虚功原理，ω_j=轴矢量）
```
- 只写**髋+膝的矢状轴（轴2）**；侧向（轴0）仍由逐关节 PD 管（平衡）
- **踝不在 L 里**（它只管脚掌平贴=抓地，走 supportClean 的纯阻尼路径）
- 逐关节路径跳过髋/膝矢状（`SQ_VLEG=0` 可回退对照）
- 增益：`SQ_VLEG_KP=12000 N/m`、`SQ_VLEG_KD=1300 N·s/m`（临界≈2√(kp·M_eff)）

### 首测（2026-10-18）

## 十一、肌肉对如何消费两层（2026-10-18 深夜定稿）

### 定论
- **运行时只有两层**：基础力 + 回正力（张力层被肌肉吸收=零命令；平衡=回正力的 ref 偏移输出）
- **阻尼 = 物理常数（不可控）**（用户定：选项 A——旋钮最少；要调就调 C）
- 每状态参数（C/F0）进 `baseTable.params` 状态分区

### 肌肉的代码路径（drive.ts，净力矩推导）
```
f1(主动肌) = C×(F0 + ½K×dev) + D×max(0,−v)
f2(抵抗肌) = C×(F0 − ½K×dev) + D×max(0,+v)
净 = f1 − f2 = C×K×dev + D×(单向阻尼)
```
**关键事实**：
1. **F0 在净力矩中抵消**（共模项）——基础力不直接出力矩
2. 净出力 = **C×K×dev（回正力）** + 内置单向阻尼——回正力是唯一净出力通道

### 两层在肌肉里的真实角色
```
基础力 = F0（共模预紧/tone）:
  · 两肌同时绷紧 → 抬高 _fmax 帽内余量（防饱和）
  · 刚度的工作点（共收缩的生理本体）
  · 不产生净力矩——"支撑"不是它的直接出力

回正力 = C（刚度档）+ ref（平衡点）:
  · 净力矩 = C×K×(ref−θ)
  · **支撑的真身**：重力压出 dev → C×K×dev 顶回 → 平衡在微垂处
  · 平衡（CoM/CoP）→ ref 偏移（EP 假设），不另加力矩
```

### 三层架构 → 两层的收编结果
| 原三层 | 收编后 | 肌肉旋钮 |
|---|---|---|
| 基础力（支撑） | F0 tone + 回正力的平衡点 | F0 |
| 回正力（姿势） | C + ref | C, ref |
| 张力层（单向阻尼） | 肌肉内置（零命令） | —（物理常数） |
| （平衡） | ref 偏移 | ref |
