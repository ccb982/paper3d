## 二、五件套（缺一不可，按因果顺序）

### 1. 张力层重做 = 单向阻尼（用户设计定论）
- 文件：`src/core/stability.ts` 的 ⓪ 块（contributeBaseline 开头）
- 旧实现：`kp·(目标−角)` 弹簧 PD（kp≈607）→ 腿关节出 **+104** 把基础力抵光（全场打架的根源）
- 新实现：**只有往外偏才阻尼、回程零写入**，无弹簧无目标：
  ```ts
  const devT = rest - d.angle;              // rest：腿=首帧捕获标准站姿；肩=内收位；其余=0
  const outward = devT * d.vel > 0;
  if (outward && kdT > 0) propose({ dof, kind: 'torque', pri: PRI.servo, tau: -kdT * d.vel, src: 'tension' });
  this.drive.setAngle(d.dofIndex, d.angle, 0);   // 主动释放旧 PD 残留
  ```
- `kdT = postureTone * 2`；腿的标准位用 `legRest`（首帧捕获）Map。

### 2. gcomp 逐关节符号标定（髋是反的！）
- 文件：`src/core/body.ts` gravityComp
- 默认（踝/足 '+', 髋/膝 '−'）中，**HIP0/HIP2 实际应为 '+'**——默认 − 时把重力**加倍**（越偏越推 → 漂移/弯腰）
- 实现：`GC_SGN_<关节><轴>` env 可覆盖；默认已烤入 `(/^(foot|ankle|hip)_/ ? '+' : '-')`
- 标定方法：每次只翻一个符号，看法庭判死时间/roll 峰（HIP0 翻转：roll 峰 2.7→0.4 静置）

### 3. 膝惯量下限（tCap 削力）
- 文件：`src/core/drive.ts` 的 `Icap`
- 膝无下限时一步收敛护栏把 −118 削到 −22；**下限 3.0**（`KNEE_IFLOOR` env 可调）
- 参考：踝 1.5、髋 0.8（都带全身载荷）

### 4. 站立套静偏置清零（env 名注意）
- committed supportClean 的站立套偏置 env 是 `SC_KNEE0/SC_HIP0/...`（不是 `SC_B0_*`）
- `SC_KNEE0=96` 等旧标定值会在纯基础力测试里偷出力（ff −117+96=−21 的假象来源）

### 5. 连续载荷混合（支撑侧判定）
- 文件：`src/core/stability.ts` 的 ① 重力补偿调用
- `wL = EMA(fl/(fl+fr), τ=0.08s)`；`gravityComp(gBuf, gY, supSide, wL, 1−wL)`
- 每腿 τ = w·互补 + (1−w)·子树；端点=旧行为，中间连续（无阈值阶跃）
- **注意**：高度映射对"折起来的腿"误判（脚低≠腿在承重）——必须用**载荷 fz + EMA 平滑**（裸载荷抖）
- `body.ts` gravityComp 签名：`(out, gY, supSide, wL=0.5, wR=0.5)`
