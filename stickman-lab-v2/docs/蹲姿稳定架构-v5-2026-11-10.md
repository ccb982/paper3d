base 是神经命令，但对拉肌肉执行器负责把它变成力矩。

## 11. 对拉肌肉怎么被命令层驱动（2026-11-10）

### 11.1 命令层只给三样

```text
base：前馈
co：共收缩/张力
ref：平衡点
```

可选：

```text
kp/kd：小的误差反馈
```

注意：

```text
co 已经产生刚度
再叠大 kp 会双算刚度
```

### 11.2 对拉肌肉

```text
net = kp·(ref − q) − kd·q̇

aA_target = clamp(co + net/(2F0), 0, 1)
aB_target = clamp(co − net/(2F0), 0, 1)
```

激活动力学：

```text
da/dt = (a_target − a) / tau
```

肌肉长度：

```text
lA = l0 + r·(q − q0)
lB = l0 − r·(q − q0)
```

肌肉力：

```text
F = a·F0·fl(l)·fv(v) + Fpassive(l,v)
```

关节力矩：

```text
τ_active = (FA − FB)·r
τ = τ_active + base + jointDamper
```

### 11.3 扰动衰减

对拉肌肉提高的是：

```text
关节刚度
阻尼
```

小扰动：

```text
I·δq̈ + b·δq̇ + k·δq = τ_dist
```

静态位移：

```text
δq = τ_dist / k
```

k 提高 10 倍 → 位移约降到 10%。

但：

```text
只在高频/小扰动成立
低频/大扰动会饱和
```

### 11.4 论文依据

共收缩增加关节刚度/稳定：

```text
Hogan 1984, Adaptive control of mechanical impedance by coactivation of antagonist muscles
Kim & Hwang 2018, PLoS One, ankle co-contraction under perturbations
https://pmc.ncbi.nlm.nih.gov/articles/PMC6264860
```

稳定肌定义 = 共收缩 + 早期激活：

```text
https://pmc.ncbi.nlm.nih.gov/articles/PMC4403366
```

短程刚度不是纯弹簧，单靠它不能保证稳定：

```text
https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0307977
```

肌肉 tone = 被动黏弹性 + 主动紧张：

```text
https://pmc.ncbi.nlm.nih.gov/articles/PMC11665217/
```

### 11.5 结论

```text
对拉肌肉对扰动衰减有用
但不是无限有用
必须：
  小扰动：刚度/阻尼
  慢偏差：baseTrim
  大偏差：righting
```

### 11.6 当前 v5

```text
模型/命令链有了
但静态保持还没过
所以还不能声称扰动衰减有效
```

## 14. base 到底是什么状态（2026-11-10）

### 14.1 当前公式

```text
base0 = captureStaticBase() 一次
base  = base0 + clamp(kLoad·(fzL − fzR), ±trimMax)
```

### 14.2 动态部分

```text
只修左右负载差
不追 CoM
不追 IK
不每帧重算 base0
```

### 14.3 会不会清零

```text
不会每帧清零
base0 捕获后保持
base 只在 cap/tauMax 处饱和
```

### 14.4 维持稳定是谁

```text
base：前馈
对拉肌肉：主动/被动刚度阻尼
关节阻尼：独立
baseTrim：慢负载差
```

当前 base 不负责 CoM 稳定。

### 14.5 现在的问题

```text
base0 单独托不住
```

所以 base 不是“动态稳定器”，只是动态前馈。

### 14.6 下一步

```text
1. base-only + 无肌肉 + 无阻尼
2. 对比静态需求力矩
3. 查 base0 sign/scale
4. 再恢复肌肉/阻尼
```
