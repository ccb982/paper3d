# 蹲姿稳定架构 v4（2026-11-10）

## 0. 目标

重开一个最小、干净、可收敛的蹲姿基线：

```text
IK 只算一次
命令层只用极简式子
肌肉层增强为对拉肌肉模型
第一道防线不启用 righting
```

旧 v3 控制链冻结，只作为参考，不再往旧 flag 堆里加机制。

## 1. 只有两层

```text
神经命令层
  base
  simple command
  tone

肌肉执行器
  agonist / antagonist 对拉
  passive stiffness / damping
  activation dynamics
  saturation
```

没有：

```text
QP
MPC
每帧 IK
每帧静态 ID
常开 righting
```

## 2. IK 一次性

```text
t0 / release：
  计算一次 base0
  捕获一次 ref
```

之后：

```text
ref 不变
base0 不变
baseTrim 极慢修正
```

不允许每帧追 IK。

## 3. 命令层

极简：

```text
net = base + kp·(ref − q) − kd·q̇
co  = tone(phase, contact, load)
```

输出只有：

```text
net torque command
co-contraction command
```

不直接算肌肉力，不直接写关节。

## 4. 肌肉层

每个矢状关节一对拮抗肌：

```text
aA = clamp(co + net/(2F0), 0, 1)
aB = clamp(co − net/(2F0), 0, 1)
```

输出：

```text
τ_active = (aA − aB)·F0·r
τ_passive = k1·e + k3·e³ + b·ė
τ = clamp(τ_active + τ_passive, ±cap)
```

其中：

```text
e = q − ref
co 越大，刚度越高，净力矩不变
```

肌肉层可以复杂：

```text
一阶激活动力学
力-长度
力-速度
非线性被动刚度
阻尼
slack/deadband
饱和
```

但只能输出一个 torque，不能变成第二套控制器。

## 5. 第一道防线

```text
righting = off
base + simple command + tone + muscle
```

验收：

```text
fall > 5s
无高频抖振
base 几乎不变
左右负载稳定
两次法庭一致
```

## 6. righting

第一道防线达标后再接：

```text
righting = 有意识短时介入
不常开
不改 base
只在肌肉模型入口叠加命令
```

## 7. baseTrim

极简：

```text
eLoad = fzL − fzR
trimTarget = clamp(kLoad·eLoad, ±trimMax)
trim += (trimTarget − trim)·dt/tau
base = base0 + trim
```

时间常数 1–3s，不做 IK/CoP 预测。

## 8. 新基线代码

```text
src/core/servo/squatV4/
  types.ts
  antagonist.ts
  command.ts
  base.ts
  controller.ts
  index.ts
```

旧文件不删，先冻结。

## 9. 收敛顺序

```text
1. base0 + passive muscle 能撑住
2. 加 co-contraction，小扰动不振荡
3. 加 simple command 的 kp/kd
4. 加 baseTrim
5. 验收第一道防线
6. 再接 righting
```

每次只动一层。

## 10. 禁止

```text
旧 squatClean 和新 v4 同时写同一关节
tone 外部 FF 双算
passive 独立 writer

righting 补第一道防线
QP/ID 进第一道防线
```

## 12. 马步模式（2026-11-10）

### 12.1 定义

```text
蹲马步 = 高共收缩、接近最大肌肉激活的等长支撑
不是普通放松蹲
```

### 12.2 肌肉激活

```text
co ≈ 1
aA、aB 接近最大
```

对拉肌肉同时紧张：

```text
刚度最大
净力矩由 base + 简单命令决定
```

### 12.3 净力矩

```text
net 不需要开到最大
```

原因：

```text
aA/aB 都饱和 → 没有调节余量
baseTrim / 小扰动修正无法再分配
```

目标：

```text
肌肉激活接近最大
净力矩保留小余量
```

### 12.4 马步 base

```text
base0 一次静态 ID
baseTrim 极慢
```

base 负责：

```text
重力
姿势
左右负载
```

肌肉对拉负责：

```text
刚度
阻尼
小扰动
```

### 12.5 第一道防线

```text
righting off
马步 co 高
base + 对拉肌肉
```

### 12.6 验收

```text
fall > 5s
无高频抖振
肌肉不长时间饱和
base 几乎不变
左右负载稳定
两次法庭一致
```

### 12.7 禁止

```text
把“激活最大”当成“净力矩最大”
两侧同时长期饱和
只加 co 不加阻尼
马步靠 righting 维持
```
