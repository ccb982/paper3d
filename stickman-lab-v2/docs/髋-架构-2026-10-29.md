# 髋层架构（2026-10-29）

> 踝做局部 CoP/小腿回正；膝做竖直支撑；髋做 COM/XCoM 预测调节。
> 髋不是“把 hip 锚点推到目标角度”的位置 PD。

---

## 1. 髋的定位

```text
踝：快、局部，调小腿和 CoP
膝：腿伸展、竖直支撑
髋：预测 COM/XCoM，把骨盆/COM 提前拉回支撑区
```

髋不负责：

```text
直接造总竖直力
替代脚底 N
替代膝伸展
```

髋负责：

```text
左右脚 N 的分配
骨盆/COM 的侧向回收
大偏差时的髋策略
```

---

## 2. 论文依据

```text
Horak & Nashner 1986
  小扰动：踝策略
  大扰动：髋策略 / 躯干策略

Hof 2005
  XCoM 是动态稳定预测量
  只看当前 COM 不够

Kuo 1995
  平衡控制需要状态反馈/预测，不是纯位置 P

Peterka 2002
  感觉整合和延迟决定反馈结构

Mirshams Shahshahani & Ashton-Miller 2020
  髋策略通过脚底剪切力/CoP 影响 COM
  CoP 不能出 BOS

Winter 1998
  踝力矩控制 CoP，但权限受脚掌边界限制

Loram & Lakie 2002 / Loram et al. 2005
  踝主动控制是间歇的，不能被当成无限权限

Caron 2019
  髋力矩必须满足 N/CoP/摩擦约束

Neumann 2010
  髋外展肌控制骨盆侧倾
```

结论：

```text
髋是预测调节器
踝是局部 CoP 执行器，不需要长时程预测
```

## 3. 几何目标 vs 控制目标

### 3.1 几何目标（只用于诊断/显示）

由脚落点得到骨盆和髋的“应处位置”：

```text
pelvisZGeom = (footZ_L + footZ_R) / 2
hipZGeom_L  = pelvisZGeom + hipHalf
hipZGeom_R  = pelvisZGeom - hipHalf

hipXGeom = 释放姿态髋 x
hipYGeom = 释放姿态髋 y
```

释放实测：

```text
supportZ = +0.14cm
hipHalf  = 12.50cm

targetHip L = (-22.31, 50.50, +12.64)cm
targetHip R = (-22.31, 50.50, -12.37)cm
```

但这只是**几何参考**，不是直接驱动 `hip/1` 的误差。

### 3.2 控制目标（真正驱动髋）

```text
控制目标是 COM/XCoM 回到支撑中心
不是 hip 锚点回到某个坐标
```

```text
xcomZ = comZ + comVelZ / ω
ω = sqrt(g / comY)

xcomErrorZ = xcomZ - xcomTargetZ
```

`xcomTargetZ` 默认是支撑中心。

## 4. 髋的正确力链

```text
XCoM / COM 误差
  ↓
期望骨盆/地面侧向力 F_des
  ↓
hip torque 在脚上产生剪切力
  ↓
CoP 偏移
  ↓
地面反力推动骨盆/COM
```

控制量：

```text
F_des = −Kx·xcomError − Dx·comVel − Ma·comAcc
```

髋力矩：

```text
τ_hip = Jᵀ_hip · F_des
```

不能是：

```text
e = targetHipZ − actualHipZ
τ = K·e − D·v
→ 直接写 hip/1
```

原因：

```text
hip/1 的锚点在骨盆上
转 hip/1 不会直接移动自己的锚点
它转动大腿/骨盆链
真正移动骨盆的是脚底反力
```

所以髋必须是：

```text
COM/力控制
```

不是：

```text
hip anchor 位置控制
```

---

## 5. 输出轴

```text
hip/0：额状外展/内收（辅）
hip/1：额状骨盆调节（主）
hip/2：归基础 pair，不被 HipTaskPD 改写
```

髋不写：

```text
knee
foot
ankle
spine
```

---

## 6. 脚底预算

髋力矩必须满足：

```text
N > 0
CoP ∈ 脚掌
|F_t| ≤ μN
τ_hip ≤ N · CoP_margin · k
```

不是：

```text
有误差就无限加髋力矩
```

髋可以改变：

```text
N_left / N_right 分配
```

不能直接增加：

```text
N_total
```

总竖直力仍来自：

```text
脚底接触 + 膝伸展 + 基础力
```

---

## 7. 优先级

```text
1. 脚接触 / N / CoP
2. 踝局部 CoP / 小腿回正
3. 膝竖直支撑
4. 髋预测 COM/XCoM
```

踝/CoP 没权限时，髋不能硬拉。

## 8. 验证

```text

2. hip 力矩不超过 N·CoP 预算
3. 左右脚 fz 分配合理
4. CoP 不越界
5. N 不卸载
6. comY 不持续下降
7. 骨盆不出现扭转/反相
```
