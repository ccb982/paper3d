## 22. 基础力简单版与维持稳定（2026-11-10）

### 22.1 当前不是简单版

```text
squatClean 还在用 baseSag / IK
supportClean 还在跑 CoM/XCoM 方向项
```

所以现在不是“只要基础力”。

### 22.2 目标

```text
base0：一次静态 ID/旧表
base：base0 + 简单慢修正
```

简单慢修正：

```text
base = base0
     + kLoad·(fzL − fzR)
     + kSlow·(comX − feetMidX)
```

不做：

```text
IK
QP
MPC
每帧 baseSag
```

### 22.3 回正力

```text
righting = off
```

去掉：

```text
supportClean 的 CoM/XCoM 方向项
squatClean 的 righting/IK 回正
```

保留：

```text
脚接触/fz
基础力
PD
```

### 22.4 基础力怎么维持稳定

```text
静态：base0 抵消重力
慢偏差：kSlow 修 CoM
左右差：kLoad 修 fz
快扰动：PD/肌肉
```

### 22.5 顺序

```text
1. 关 righting
2. 删 baseSag/IK
3. base 用 base0 + 慢修正
4. 保留脚接触
5. PD 执行
```

### 22.6 禁止

```text

base 追 IK
base 和 supportClean 双算
righting 常开
```
