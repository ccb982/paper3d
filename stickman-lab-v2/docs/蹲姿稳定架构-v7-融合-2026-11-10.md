## 37. 髋-腿维持算法，不是回正（2026-11-10）

### 37.1 回正 vs 维持

```text
回正：
  CoM/IK 目标
  追误差
  已关闭

维持：
  髋相对脚的位置
  左右腿负载
  极慢修正
```

### 37.2 输入

```text
hipPos
feetMid
fzL / fzR
hipVel
```

不输入：

```text
IK
CoM 目标
QP
```

### 37.3 算法

```text
eHip = feetMid − hipPos
vHip = hipVel

hipCorr = clamp(kHip·eHip − dHip·vHip, ±capHip)
loadCorr = clamp(kLoad·(fzL − fzR), ±capLoad)

baseL = base/2 + (hipCorr + loadCorr)/2
baseR = base/2 + (hipCorr − loadCorr)/2
```

### 37.4 特点

```text
两腿共同承担 hipCorr
loadCorr 只修左右差
极慢
不追 CoM
```

### 37.5 避免侧偏

```text
不要按单腿 fz/hipHigh/roll 各削各的
否则容易侧偏
```

### 37.6 分工

```text
维持层：极慢 hip/load
PD/肌肉：快扰动
righting：关
```

## 38. 论文依据：髋-腿维持、侧向扰动、躯干前倾（2026-11-10）

### 38.1 髋粘弹性/方向

Huang 2020：

```text
hip stiffness/viscosity 随施加力增大
扰动方向只有小依赖
```

https://pubmed.ncbi.nlm.nih.gov/32217480

结论：

```text
不能只靠“哪边偏就猛加哪边刚度”
刚度主要由力和共收缩决定
```

### 38.2 侧向扰动下的双侧髋

Zhu 2023：

```text
侧向骨盆扰动
双侧髋外展力矩增加
frontal/transverse 运动增加
肌肉共激活改变
```

https://pubmed.ncbi.nlm.nih.gov/37784076

结论：

```text
侧向扰动是双侧髋协调
不是单侧硬锁
```

### 38.3 双侧不对称髋刚度

Abdikadirova 2023：

```text
双侧不对称 hip stiffness 会引起适应
```

https://www.umass.edu/robotics/sites/default/files/2023-08/Abdikadirova%20et%20al.%20-%202023%20-%20Bilateral%20asymmetric%20hip%20stiffness%20applied%20by%20a%20ro.pdf

结论：

```text
左右刚度差会造成侧偏/适应
应避免长期不对称
```

### 38.4 蹲姿躯干前倾

2024 squat review：

```text
躯干前倾改变 hip/knee moment 分配
前倾增加 hip moment，减少 knee moment
```

https://pmc.ncbi.nlm.nih.gov/articles/PMC10987311

### 38.5 蹲姿 COM/trunk

2024：

```text
蹲姿是 knee + trunk 混合控制
COM 下降与躯干控制相关
```

https://pmc.ncbi.nlm.nih.gov/articles/PMC11307177

### 38.6 对算法的结论

```text
髋-腿维持应：
  双侧协调
  负载分配
  慢修正
  避免单侧硬锁

躯干前倾：
  会改变 hip/knee 负载
  不应只加偏侧刚度
```

### 38.7 当前 v7
