# 被动刚度定稿（2026-10-22）

> 场景：**静态蹲姿伺服**，双脚固定，小/中扰动，目标永远是法庭姿态。
> 目标：被动层承担约 90% 的小扰动，主动层只修剩余约 10%。

---

## 1. 定稿结论

1. **pairPD + base 退役**，不再作为被动刚度层。
2. 新的被动层叫 `PassiveStiffness`，它不是单一公式，而是五层组合：
   - base feedforward
   - tone / co-contraction
   - short-range stiffness
   - damping
   - joint compression
3. 被动层 **不写 CoP、不主动发侧向力**；侧向力是关节弹簧/压缩经地面反力的结果。
4. 主动层（踝/髋）只做 **residual**，目标也是 court，预算 ≤10%。
5. 允许抢写手，但必须走 **soft ownership + budget**，不能整轴覆盖。

---

## 2. 分层

```text
L0  Court / reference
      q_ref = 法庭姿态（释放瞬间捕获）

L1  PassiveStiffness
      L1.0 BaseFeedforward      τ_ff
      L1.1 Tone                 C, 关节压缩
      L1.2 ShortRangeSpring     K(q, Fz, history, direction)
      L1.3 Damping              B, 独立
      L1.4 JointCompression     jointLoad

L2  ActiveResidual（10%）
      ankle CoP + hip CMP，目标 court

L3  Supervisor
      deadband / budget / offX / TtB / abort
```

---

## 3. 每一层的作用

### L1.0 BaseFeedforward

```text
τ_ff = staticBalance(baseBuf) + legSupport + gravity compensation
```

- 来自释放瞬间捕获的 base 表；
- 负责抵消重力/静态支撑；
- **不负责回正**，回正由 K 负责；
- base 对侧向通常为 0；侧向靠 L1.2。

### L1.1 Tone / co-contraction

```text
C = tone(Fz, risk, phase)
F_compression = C · target_joint_load
```

- 共激活提高关节压缩和刚度，净力矩可以≈0；
- 不直接产生侧向力；
- C 有上限，过强会 bistable。

### L1.2 Short-range stiffness

```text
e = q_ref − q

K = K0(direction) · load(Fz) · history(t)
soft = |e| <= θ_sr ? 1 : θ_sr / |e|
τ_spring = K · soft · e
```

- 小位移高 K；
- 大位移软化/力饱和；
- K 随 Fz/W 增加；
- 静息恢复、运动降低（thixotropy，可后置）；
- 矢状/侧向分开 K。

### L1.3 Damping

```text
τ_damp = −B(direction, Fz) · qdot
```

- 独立层，不进 muscle pair / drive 肌肉阻尼；
- 只耗散，不定义平衡点；
- 速度/力矩限幅，避免求解器共振。

### L1.4 Joint compression

```text
jointLoad: 等大反向，沿骨段
净力矩 = 0
目标低档：hip 0.5BW / knee 0.5BW / ankle 0.4BW
ramp 0.3~0.5s
```

- 增加关节约束力/“锁死感”；
- 不直接回正；
- 必须和 K 分开记账。

## 4. 侧向执行器选择（定稿）

```text
矢状：
  hip/2、knee/2、ankle/foot/2、spine/2
  由 L1.2 + L1.0 接管

侧向：
  ankle/foot/0 为主（权限最大）
  hip/0、spine/0 为辅（小 K）
  不再使用 pair 轴0
```

理由：

- pair 轴0 实测 C 越大越倒；
- foot/0 权限大，但串矢状，必须加 **sagittal guard**；
- 侧向 K 先小，逐步加；不追求一开始 90%。

## 6. 允许抢写手，但不能过分

### 6.1 原则

```text
PassiveBase 拥有 baseline；
Active 用不同 kind（ext）叠加，不覆盖 baseline；
只有安全层可以用 PRI.direct 整轴接管。
```

### 6.2 预算

```text
active_cap = min(
  0.1 · |τ_passive| + 2N·m,
  joint_cap
)
```

- 主动层超过预算 → clamp + 日志；
- 每个轴记录 passive/active 能量占比；
- 目标：小扰动 passive ≥90%。

### 6.3 冲突规则

```text
同 dof 同 kind：高优先级覆盖（仅安全层允许）
同 dof 不同 kind：叠加（passive torque + active ext）
同轴多写手：必须登记 owner，否则禁止
```

## 7. 状态机

```text
SETTLE      释放前，无输出
PASSIVE     释放后：base + K + B + compression
RESIDUAL    |e|/|v| 出死区，或 TtB 低 → active ≤10%
ABORT       出支撑/capture，停止加力
```

---

## 8. 标定与验收

### 8.1 单轴 authority

```text
对每个轴：
  给 q_ref 阶跃/斜坡
  测 Δτ/Δq → K
  撤掉后衰减 → B
  测 ΔCoM/ΔCoP/ΔF_joint
```

### 8.2 KPI

```text
A. J=0，10s：
   |comZ| < 1cm
   |roll| < 1°
   hip 中心漂移 < 1cm
   passive-only 不 fall

B. J=0.5 / 1：
   passive 能量/位移占比 ≥90%
   active ≤10%

C. J=2：
   passive 占比可降低；
   active/hip 接管；不要求 90%。
```

---

## 9. 实施顺序

```text
1. 新建 PassiveBase（独占矢状轴2）
2. 搬 legSupport/coactivation/baseBuf
3. 加 K/B，J=0 10s
4. 加 ankle/foot 侧向小 K + sagittal guard
5. 加 hip/0、spine/0 小 K
6. 加 jointLoad 低档 + ramp
7. 开 ActiveResidual ≤10%
8. 最后做 90% 能量验收
```

---

## 10. 一句话

**被动刚度 = base + tone + short-range K + damping + compression 的层级系统；不是 pair 的补丁，也不是一个 K(e) 公式。**
