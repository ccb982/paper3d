# 蹲姿肌肉群架构 v6（2026-11-10）

## 0. 前提

旧 v5 下盘控制已删除。

当前 squat 活动路径只剩：

```text
court 摆姿
UpperTaskPD
```

v6 从零设计下盘肌群，不接旧 drive/tension/support/squatClean。

---

## 1. 设计原则

```text
力矩大的部位 → 肌群多
力矩小的部位 → 肌群少
脚 → 不主动，沿用旧版柔性足
```

不是按解剖肌肉逐根建，而是按**功能对拉肌群**建。

每个肌群：

```text
joint
axis
role: agonist / antagonist
F0
momentArm
co
passive
```

---

## 2. 部位分配

```text
髋：多组
膝：中多组
踝：少组
脚：无主动肌群
```

原因：

```text
髋承担最大力矩
膝次之
踝小
脚负责柔性接触
```

---

## 3. 肌群表

| 部位 | 轴 | 肌群 | 数量 | 容量占比 | 第一道防线 |
|---|---|---:|---:|---:|---|
| 髋 | 矢状 hip2 | 伸 2 组 + 屈 1 组 | 3 | 35% | 主动 |
| 髋 | 额状 hip0 | 外展 1 + 内收 1 | 2 | 12% | 低 tone |
| 髋 | 横状 hip1 | 内旋/外旋 1 | 1 | 5% | 被动 |
| 膝 | 矢状 knee2 | 伸 2 + 屈 1 | 3 | 25% | 主动 |
| 膝 | 额/横 | 韧带 | 0 | 0 | 被动 |
| 踝 | 矢状 ankle2 | 跖屈 1 + 背屈 1 | 2 | 13% | 低 tone |
| 踝 | 额状 | 内翻/外翻 | 0 | 0 | 被动 |
| 脚 | - | 柔性足 | 0 | 5% | 旧版 |

总原则：

```text
髋 6 组
膝 3 组
踝 2 组
脚 0 组
```

大腿多、小腿少、脚柔性。

## 7. 容量分配

每个关节总容量：

```text
hip2：35%
hip0：12%
hip1：5%
knee2：25%
ankle2：13%
foot：5%
```

单组 F0：

```text
F0 = 关节容量 × 分配比例 / momentArm
```

不要所有肌群同一个 F0。

---

## 8. 对拉结构

每个轴至少一对：

```text
A 肌：正方向
B 肌：反方向
```

多组时：

```text
同方向多组并联
总力 = 各组力之和
总刚度 = 各组刚度之和
```

## 9. 命令层

```text
base0：一次静态 ID/旧表
base：base0 + 慢 trim
ref：释放时捕获
co：按关节/phase/contact 调制
```

命令层不直接写肌肉力。

---

## 10. 肌肉模型

```text
lA = l0 + r·(q − ref)
lB = l0 − r·(q − ref)

aA_target = clamp(co + net/(2F0), 0, 1)
aB_target = clamp(co − net/(2F0), 0, 1)
```

激活：

```text
da/dt = (a_target − a) / tau
```

力：

```text
F = a·F0·fl(l)·fv(v) + Fpassive(l,v)
```

第一版：

```text
先不用 fv
先线性/三次被动
```

---

## 11. 独立关节阻尼

```text
τ_damper = dampTorque(q̇)
```

独立于肌肉，不塞进肌群。

---

## 12. 抗扰动

```text
本征：co 高 → 刚度
反射：被拉长的肌群加激活
阻尼：独立关节阻尼
饱和：大扰动允许屈服
```

分工：

```text
髋：主方向、大容量
膝：保持对折
踝：小容量
脚：柔性
```

验收：


## 16. 阻尼与被动刚度（2026-11-10）

### 16.1 两个层次

```text
肌群内部：
  被动刚度
  被动阻尼

关节层：
  独立阻尼
```

不要：

```text
关节再加一套被动刚度
和肌群被动刚度双算
```

### 16.2 肌群被动

每条肌肉：

```text
x = max(0, |l − l0| − slack)
Fpassive = k1·x + k3·x³ + b·v
```

参数按肌群容量缩放：

```text
k1 ∝ F0 / lengthRange
b  ∝ F0 / vmax
```

### 16.3 关节总被动

```text
k_joint = Σ k_group
b_joint_muscle = Σ b_group
```

### 16.4 独立关节阻尼

```text
τ_damper = dampTorque(q̇)
```

不放进肌群，不放进被动刚度。

### 16.5 分配原则

| 部位 | 被动刚度 | 肌群阻尼 | 关节阻尼 |
|---|---|---|---|
| hip2 | 中 | 中 | 高 |
| hip0 | 高 | 中 | 中 |
| hip1 | 高 | 低 | 低 |
| knee2 | 中 | 高 | 高 |
| knee0 | 高 | 中 | 中 |
| ankle2 | 高 | 低 | 低 |
| ankle0/1 | 高 | 低 | 低 |
| foot | 旧版柔性足 | 旧版 | 旧版 |

原因：

```text
髋2/膝2 主动多，被动中
髋0/1 侧向稳定靠被动
膝0 韧带被动
踝主动少，被动多
脚柔性
```

### 16.6 多肌群叠加

```text
同方向多组：
  力相加
  被动刚度相加
  被动阻尼相加
```

所以：

```text
力矩大的部位肌群多
→ 总被动也更大
```

### 16.7 第一版参数

```text
passiveRatio = 0.05–0.15
dampingRatio = 0.05–0.12
slack = 0.01–0.03
k3 = 5–10 × k1
jointDamp = 旧版 dampTorque
```

不要所有关节同一组。

### 16.8 收敛顺序

```text
1. passive-only
   co=0, kp=0, kd=0
2. 加关节阻尼
3. 加 co
4. 加反射
5. 加扰动
```

### 16.9 禁止

```text
被动刚度和关节阻尼双算
所有肌群同一 k1/b
踝给高主动阻尼
脚加主动肌群
```

---

## 17. 结论

```text
肌群数量按力矩分配
被动刚度在肌群内部
关节阻尼独立
脚沿用柔性足
```

## 18. 论文：被动刚度够不够（2026-11-10）

### 18.1 关键结论

```text
被动刚度/阻尼有用
但不能单独维持全身稳定
```

### 18.2 踝

Loram & Lakie 2002：

```text
安静站立时 intrinsic ankle stiffness ≈ 91% 临界刚度
仍不足以稳定
需要主动力矩调制
```

https://pmc.ncbi.nlm.nih.gov/articles/PMC2290720

Morasso & Schieppati 2002：

```text
实际踝刚度 ≈ 546.5 Nm/rad
临界 ≈ 784.5 Nm/rad
```

https://journals.physiology.org/doi/full/10.1152/jn.2002.88.4.2157

Vlutters 2015：

```text
intrinsic ankle-foot stiffness
0.93 → 0.44 × mgh
幅度越大越低
仍不足
```

https://pubmed.ncbi.nlm.nih.gov/25843262

### 18.3 短程刚度

Loram 2007：

```text
short-range (<0.2°) stiffness ≈ 67% mgh
long-range stiffness ≈ 13% mgh
```

https://pubmed.ncbi.nlm.nih.gov/17823209

PLOS One 2024：

```text
short-range stiffness 像 Maxwell 元件
单靠它不能稳定关节
即使完全激活也不够
```

https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0307977

### 18.4 触变

Sakanaka 2016：

```text
sway 增大时 passive stiffness 可下降 43%
```

https://pubmed.ncbi.nlm.nih.gov/26607292

### 18.5 主动阻尼

Cenciarini 2010：

```text
老年人同时增加 active stiffness 和 damping
只加刚度不如刚度+阻尼稳定
```

https://pmc.ncbi.nlm.nih.gov/articles/PMC3070169

### 18.6 对 v6 的结论

```text
被动刚度：
  负责第一下、小位移
  不能负责全身长期稳定

主动 co/反射：
  补足被动缺口

独立阻尼：
  必需

baseTrim/righting：
  慢偏差/大偏差
```

### 18.7 参数含义

```text
被动刚度不要按 100% 临界刚度设计
被动负责 30–90% 的小扰动
主动/反射补剩余
```

### 18.8 禁止

```text
认为 passive 够用
认为 co 够用
认为 short-range stiffness 能包打天下
忽略 damping
忽略 thixotropy/幅度依赖
```

## 19. 肌肉 PD 还缺哪些被动机制（2026-11-10）

### 19.1 当前已有

```text
slack
k1·x
k3·x³
b·v
关节独立阻尼
```

### 19.2 缺的机制

```text
1. 短程刚度 SREC
2. 触变 thixotropy
3. 串联弹性肌腱
4. 双关节肌耦合
5. 非线性指数被动
6. 髋关节囊/韧带末端刚度
7. 激活依赖被动刚度
8. 非线性阻尼/滞后
```

### 19.3 短程刚度

```text
|x| < x_sr：
  k = k_sr（很硬）
|x| > x_sr：
  k = k_lr（变软）
```

文献：

```text
short-range < 0.2°
long-range 刚度大幅下降
```

### 19.4 触变

```text
静止一段时间 → 刚度升高
运动后 → 刚度下降
```

状态：

```text
k = k_lr + (k_sr − k_lr)·s
ds/dt = rest − movement
```

### 19.5 串联弹性肌腱

```text
肌肉不是纯弹簧
更像 Maxwell：
  spring + damper 串联
```

模型：

```text
dF/dt = k_t·v − F/tau
```

这决定短程刚度会不会“顶一下就泄”。

### 19.6 双关节肌

大腿/髋最重要：

```text
股直肌：髋屈 + 膝伸
腘绳肌：髋伸 + 膝屈
内收大肌：髋伸 + 髋内收
```

长度：

```text
l = l0 + r_hip·e_hip + r_knee·e_knee
```

所以：

```text
髋动会改膝的被动张力
膝动会改髋的被动张力
```

当前单关节模型没有这个耦合。

### 19.7 非线性指数被动

```text
F = k1·x + k3·x³ + kexp·(exp(a·x) − 1)
```

末端更硬，中段更软。

### 19.8 髋关节囊/韧带

```text
中段：低刚度
末端：高刚度
```

尤其：

```text
hip0 外展末端
hip1 旋转末端
髋屈/伸极限
```

### 19.9 激活依赖被动刚度

```text
k_passive = k0 + c·a
```

紧绷时被动也变硬，不是固定弹簧。

### 19.10 优先级

```text
1. SREC + 触变
2. 双关节肌耦合
3. 串联弹性肌腱
4. 非线性指数被动
5. 髋关节囊末端
6. 非线性阻尼/滞后
```

### 19.11 大腿/髋最缺

```text
短程刚度/触变
双关节肌耦合
髋关节囊末端刚度
```

不是再堆一个 k1。

## 20. 马步模式：大腿/髋接近极限力矩（2026-11-10）

### 20.1 定义

```text
马步 = 高屈髋/屈膝等长支撑
大腿/髋肌群接近最大力矩
```

不是普通放松蹲。

### 20.2 激活预算

```text
hip2 伸肌组：0.9–1.0
hip2 屈肌组：0.4–0.7
hip0 外展组：0.7–0.9
hip0 内收组：0.4–0.6
knee2 伸肌组：0.9–1.0
knee2 屈肌组：0.4–0.7
ankle2：低
foot：柔性
```

原则：

```text
主动方向接近极限
拮抗方向保留共收缩
不要两侧同时 1.0
```

### 20.3 净力矩

```text
净力矩 = 主动 − 拮抗
```

马步：

```text
主动接近最大
拮抗中等
净力矩仍由 base + 小 net 决定
```

不是：

```text
所有肌群 1.0
净力矩也最大
```

### 20.4 为什么不能两侧都 1.0

```text
两侧饱和 → 没有方向余量
baseTrim 无法再分配
扰动时无法再加力
```

所以：

```text
极限力矩 ≠ 极限共收缩
```

### 20.5 髋/大腿

```text
hip2 ext1/ext2：接近最大
hip2 flex：中等
hip0 abd：高
hip0 add：中等
hip1：被动
```

双关节肌：

```text
股直肌、腘绳肌、内收大肌
要参与髋膝耦合
```

### 20.6 膝

```text
knee2 ext1/ext2：接近最大
knee2 flex：中等
knee0/1：被动韧带
```

### 20.7 踝/脚

```text
ankle2：低 tone
ankle0/1：被动
foot：旧版柔性足
```

### 20.8 饱和策略

```text
主动肌饱和：
  降低拮抗 co
  保留方向余量

拮抗肌饱和：
  降低 co
  不让两侧互顶

仍不够：
  baseTrim/righting
```

### 20.9 热/疲劳

```text
极限力矩不能无限持续
需要 fatigue/thermal 降额
```

第一版可以先不做疲劳，但参数要留余量。

### 20.10 结论

```text
马步 = 高激活、高刚度、接近极限力矩
但不是所有肌群同时 100%
主动侧接近极限
拮抗侧保留共收缩
净力矩由 base + 小 net 给
```

## 24. kSr/co/damp 的人体量级（2026-11-10）

### 24.1 换算

模型：

```text
r = 0.1 m
关节短程刚度 ≈ 2·kSr·r²
```

所以：

```text
kSr = 16000 N/m
→ 关节刚度 ≈ 320 Nm/rad
```

### 24.2 人体参考

膝：

```text
passive knee stiffness ≈ 15.7 Nm/rad
active knee stiffness ≈ 54–203 Nm/rad
passive knee damping ≈ 1.0 Nms/rad
```

Koopman 2016：

```text
https://ris.utwente.nl/ws/files/6910054/Koopman%20Estimation%20of%20Human%20Hip%20and%20Knee%20Multi-Joint%20Dynamics%20Using%20the%20LOPES%20Gait%20Trainer%202016.pdf
```

髋：

```text
hip critical stiffness ≈ 175 Nm/rad
hip muscles larger
```

https://www.frontiersin.org/journals/computational-neuroscience/articles/10.3389/fncom.2022.956932/full

### 24.3 结论

```text
kSr = 16000 N/m
→ 关节 320 Nm/rad
```

对髋：高但可能，主动肌可以到。
对膝：偏高，接近高主动刚度。
对纯被动：偏高。

```text
co = 0.9
```

```text
接近最大激活
马步短时可能
长时间不现实
```

```text
damp = 40 Nms/rad
```

