# 蹲姿回正最终架构

## 1. 目标

```text
静态蹲姿：
  髋水平/稳定
  大腿方向稳定
  上身水平/可控
  膝/踝稳定支撑
  脚不滑
  尽量无限久保持
```

约束：

```text
不改感知/状态/预测层
保留旧写手作为 legacy / fallback
不通过加力硬顶解决稳定性
```

## 2. 理论闭环

```text
level error
→ 所需 hip/spine 力矩
→ 所需脚底反力/CoP
→ Fz/CoP/摩擦可行性
→ 可行则下发；不可行则限幅/退让
```

关键方程：

```text
ΔFz ≈ τ / stanceWidth
Fz_L = W/2 + ΔFz
Fz_R = W/2 - ΔFz
Δp ≈ τ / Fz
|Ftan| ≤ μ Fz
```

## 3. 分层架构

### L0 感知/状态（冻结）

```text
CoM, CoMvel, CoP
左右脚 Fz/contact/slip
hip/knee/ankle 角
torso pitch/roll, thigh world direction
```

### L1 参考

释放瞬间捕获：

```text
hip center / pelvis level
thigh direction
torso level
knee/ankle baseline
foot support
```

允许：

```text
三角整体平移/旋转
上身大角度倾斜，但 CoM 留在支撑内
```

### L2 任务

```text
T0 硬约束：
  脚接触
  摩擦锥
  CoP 在脚掌内
  关节限位
  力矩上限

T1 髋/大腿：
  pelvis level
  thigh direction
  hip/0, hip/2 主控制

T2 上身：
  torso pitch/roll 水平
  以骨盆/髋-膝三角为基座

T3 膝/踝：
  基线姿态
  低带宽保持
  承重/CoP

T4 负载：
  L/R 接近 50/50
  允许 CoM 偏移时转移
```

### L3 逆动力学 + QP

```text
变量：
  hip/knee/ankle joint torque
  contact force

目标：
  T1 > T2 > T3 > T4

约束：
  M qdd + C + g = S^T τ + Jc^T fc
  contact / friction / CoP / joint limit / torque cap
```

### L4 执行

```text
rate limit
torque cap
slip 时降权
饱和回读
```

## 4. 控制循环（240Hz）

```text
1. state update
2. reference/task error
3. desired joint torque
4. required Fz/CoP
5. feasibility check
6. QP / allocation
7. apply
8. readback cmd/applied/sat
```

