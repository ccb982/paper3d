# 蹲姿回正最终架构（论文版）

## 1. 目标

```text
永久蹲下
  legs vertical
  pelvis/hip level
  CoM in support
  feet not slipping
  upper body within controllable range
```

不依赖某个“法庭初始姿态”：
目标是**世界/重力相对不变量**，不是回到某个固定前倾角。

## 2. 两条控制律

### Posture（常开）

```text
foot upright
pelvis/hip level
knee above foot
torso level
```

```text
连续、小力矩、高精度
PI + integral trim
rate limit
small cap
```

### Recovery（间歇）

```text
CoM / XCoM
```

```text
大 cap
comfort gate / dead zone / hysteresis
只在离开舒适区时工作
```

**Posture 不乘 comfort gate；Recovery 才乘。**

## 3. 力耦合（论文核心）

任何 hip/spine 回正力矩都必须有对应脚力：

```text
ΔFz ≈ τ / stanceWidth
Fz_L = W/2 + ΔFz
Fz_R = W/2 - ΔFz
ΔCoP ≈ τ / Fz
```

约束：

```text
Fz_i > 0
|ΔFz| ≤ 可用载荷转移
|ΔCoP| ≤ 脚掌范围
|Ftan| ≤ μFz
```

不可行：

```text
先降 τ
不硬推
```

## 4. 任务层级

```text
T0 硬约束：
  接触、摩擦、CoP、关节限位、力矩上限

T1 髋/骨盆水平：
  pelvis roll → 0
  hip/0 共同 + 差动

T2 腿竖直：
  kneeRelZ → 0
  knee/torso level

T3 CoM / XCoM：
  支撑内，留 margin

T4 上身：
  torso pitch/roll 水平

T5 负载：
  L/R 50/50，允许 CoM 偏移
```

## 5. 写手/仲裁

```text

```

## 7. 验收

```text
长时间 pelvis roll ~0
kneeRelZ ~0
foot0 对称
load L/R 接近 50/50
hip torque 不持续饱和
Fz/CoP/摩擦可行
```

## 8. 结论

```text
髋水平 + 腿竖直 + 脚力配对
才是永久蹲下的必要条件。
```
