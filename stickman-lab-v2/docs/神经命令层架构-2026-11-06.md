## 2. 神经命令层

```text
① 矢状基础力
   髋高 / 支撑 / 重力前馈
   常开
   不参与回正

② 矢状回正
   CoM / 负载 / H* / hip 实际状态 / 力链
   输出 hip 目标 + hipFf
   优先级 P0 → P3

③ 侧向回正
   一条 active 小腿
   力链 / IK 目标 / 抓地
   support 腿 hold
   不写 hip

④ 上身
   保持现有 drive / 任务 PD
   本轮不重构
```

调度：

```text
sagittal / lateral 轮流
base / support 永远在线
同一帧只有一条 active 小腿
```

## 3. 神经信号契约

命令层只允许输出：

```text
关节目标角

active / hold 状态

```

不允许：

```text
直接 executor.addTorque

直接改 td
新增第三套回正策略
新增隐藏写手
```

## 4. 髋矢状命令

职责：

```text
CoM 居中
左右脚负载
H* / 髋高
髋力链
posture
```

输入：

```text
CoM / XCoM
fzL / fzR
CoP
contact / friction
H* / IK
hip 实际角度 / 角速度
hip2Target / hip2Actual
力链
```

输出：

```text
hip0 / hip1 / hip2 目标
hipFf
```

优先级：

```text
P0 左右脚负载
P1 CoM / 髋力链
P2 H*
P3 posture
```

基础力与回正力：

```text
baseFf    = 高度 / 支撑 / 重力前馈
rightFf   = 负载 / CoM / 力链
hipFf     = baseFf + rightFf
```

命令层独立，PD/td 只执行。

---

## 5. 侧向命令

职责：

```text
只修一条 active 小腿
knee0 侧向
foot0 抓地
support 腿 hold
```

不负责：

```text
hip
CoM
CoP 全身分配
```

状态：

```text
ALIGN：力链未通，先修力链
RETURN_IK：力链已通，回 IK
```

禁止：

```text
fPerp × 常数 → knee0
sideSign 猜方向
在线 J 猜增益
foot0 承担小腿回正
```

## 6. 写手规则

```text
每个关节：
  一个命令 owner
  + PD 肌肉/阻尼
  + td 执行器阻尼

不是：
  两个命令 owner
  两个回正策略
```

td 不算命令写手；它是执行器/关节阻尼。
