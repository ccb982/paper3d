## §9.93 重力补偿来源、检测精度与下一步（2026-10-22）

### 9.93.1 蹲姿重力补偿

```text
stability.ts:870
if (gravityComp && baseState() !== 'squat')
```

结论：

```text
蹲姿 antiG gravityComp 是关闭的；
重力由 squatPairBase 捕获的基础角/基础力抵消。
```

所以“被动层包含重力补偿”成立，但来源是 **pairBase**，不是 `gravityComp`。

### 9.93.2 检测精度

```text
LateralSense.parts.trunk.z / roll
LateralSense.parts.head.z / roll
vzRel / rollRate
```

是连续的 mm/度级量，仿真里足够做亚毫米回正。

但事件阈值：

```text
trunk 8mm / 1°
head 10mm / 1.5°
```

只用于 `score/onset`，不能当伺服误差。精确回正必须用连续 `z/roll`。

### 9.93.3 当前限制

```text
SQC_BSS_DEAD_Z=4mm
SQC_BSS_DEAD_R=1°
```

是控制器死区，不是传感器精度。

### 9.93.4 下一步：精确回正伺服

```text
1. 释放瞬间锁存 court：trunk z/roll + CoM
2. P/D 用平滑死区（防噪声）
3. 积分 trim 用未死区误差（消稳态 mm 级偏差）
4. 积分限幅 + CoP/CoM 安全冻结
5. 记录 target/current/error/integral/CoM/CoP
```

## §9.95 2–4s 为什么没回正（高精度回读，2026-10-23）

### 9.95.1 目标是对的

```text
t=2.5  trZ=-1.1mm  eZ=0
t=2.9  trZ=-11.7   eZ=7.7
t=3.0  trZ=-12.2   eZ=8.2
t=3.4  trZ=-7.9    eZ=3.9
```

目标 `trZ≈0`，误差方向正确，**不是目标错/符号反**。

### 9.95.2 但主动输出太小

```text
FZ=2000 N/m
eZ=7.7mm → F≈15N
```

相对体重约 700N，15N 几乎不可见。

脊柱：

```text
tau≈-12N·m（cap=20）
```

也不足以把胸廓拉回。

### 9.95.3 更关键：roll 被死区截断

```text
DEAD_R=1°
```

回读：

```text
t=3.0 roll=0.59° → eR=0
t=3.4 roll=0.27° → eR=0
```

所以：

```text
z 还有一点 P 力
roll 完全没主动修正
```

结果：

```text
躯干 z 慢慢漂
头/胸 roll 不修
→ 看起来“没回正”
```

### 9.95.4 CoM 也没进伺服

```text
t=2.9 comZ=-2.3mm
t=3.0 comZ=-3.8mm
t=3.9 comZ=-5.6mm
```

主动层只看 trunk，不看 CoM；所以它不知道整体在往外走。

### 9.95.5 结论

```text
不是“高精度检测看不见”
不是“方向反了”
是：
  1. eR 被 1° 死区截断
  2. eZ 的 FZ 太小（15N）
  3. 没有 CoM 项
  4. 没有积分，停在死区边缘
```

### 9.95.6 下一步

```text
1. roll 死区降到 0.2~0.3°，或用平滑死区
2. FZ 只对超过死区的残差提高，不同时放大噪声
3. 加 CoM 前馈/外环
4. 积分 trim 只补稳态，不抢瞬态
```

## §9.97 背肌灵敏度与脚抓地实测（2026-10-23）

### 9.97.1 背肌回正为什么不灵敏

```text
3.0s：eR=0（roll 0.59° < 1° 死区）
3.4s：eR=0（roll 0.27° < 1°）
3.0s：eZ≈8.2mm，FZ=2000 → F≈16N
脊柱 tau≈-12N·m
```

结论：

```text
roll 被 1° 死区截断；
z 的力只有十几 N；
背肌差动没有真正进入小误差区。
```

### 9.97.2 脚抓地测试

工具：`tools/_probe-foot-grip.ts`

2–4s：

```text
双脚 contact=1
fz 左右都 >0
CoP 可到 L≈197 / R≈-206mm
3.6s 起出现 slip 标志
foot z 速度可到 ±78mm/s
```

结论：

```text
2–4s 脚始终着地；
但 CoP 已到边缘，抓地余量不大；
3.6s 后偶发滑移。
```

### 9.97.3 脚能不能不对称发力

能，而且现在已经在被动发生：

```text
fzL/fzR 差异大（例：3.1s 245/485）
CoP 左右移动
```

但还没有**显式的脚不对称力/CoP 伺服**；目前主要是踝/髋/strut 的副产物。

### 9.97.4 下一步

```text
1. roll 死区平滑化，不用硬 1°
2. 小误差区加低增益灵敏度，不放大噪声
3. 脚：显式 CoP 差分（ankle inversion + load share）
4. 监测 slip/CoP 边缘，接近边缘时冻结回正、先保脚
```

### 9.97.5 结论

```text
背肌不是没力，是小误差区被死区挡住；
脚不是没抓地，是 2–4s 够用、3.6s 后余量变小。
下一步做“小误差灵敏度 + 脚 CoP 差分”，不是继续加大背肌。
```

## §9.98 脚滑：主动回正缺失，不是抓地力先不够（2026-10-23）

### 9.98.1 代码事实

```text
squatAnkleVector：
  if (passiveOnly) Mx = 0;
```

被动分支里：

```text
踝侧向 Mx = 0
只剩 passiveAnkle 的 foot/0 弹簧
```

所以脚**没有主动 CoP 回正**。

### 9.98.2 摩擦不是主因

```text
groundFriction = 60
bodyFriction   = 20
```

摩擦很高。

滑移标志：

```text
3.6s 起偶发 slip
foot z 速度 50~80mm/s
```

更像：

```text
脚被踝/髋/负载转移拖着走
而不是 μ 不够
```

### 9.98.3 开启脚 CoP 主动后

```text
SQC_FOOT_COM_K=0   → 8.637s，slip 7 次
SQC_FOOT_COM_K=300 → 10.192s，slip 5 次
SQC_FOOT_COM_K=1000→ 6.771s
```

结论：

```text
脚主动 CoP 回正确实有用；
但增益过大又会过冲/滑。
```

### 9.98.4 判断

```text
第一问题：脚缺少主动回正
第二问题：CoP/负载转移没有限幅/滑移保护
抓地力本身不是第一瓶颈
```

### 9.98.5 下一步

```text
1. 打开小增益脚 CoP（FOOT_COM_K≈300）
2. CoP 接近边界时饱和，不再加
3. 加 slip guard：slip 时减 hipStrut/CoP
4. 测接触切向力，区分“摩擦饱和”与“被拖动”
```

## §9.99 脚压力内收/CoP 侧移：论文依据（2026-10-23）

### 9.99.1 论文结论

- **van Leeuwen et al. 2021, Sci Rep 11:21481**：
  踝力矩驱动 ML CoP；脚放得太内侧 → 外侧 CoP，放得太外侧 → 内侧 CoP；
  peroneus longus / soleus / tibialis anterior 参与。
- **Biomechanical response to mediolateral foot-placement perturbations 2020**：
  内侧扰动 → 踝内翻力矩增加 → CoP 外侧；
  外侧扰动 → 内翻减少 → CoP 内侧。
- **PLOS Comp Biol 2023（踝内外翻外骨骼）**：
  外翻力矩 → CoP 内侧；内翻力矩 → CoP 外侧。
- **Winter 1995**：
  双脚并排站立时，侧向主要靠 **hip abductors/adductors**；
  踝内外翻在非 tandem 站立中作用很小。
- **2024/2025 frontal perturbation 研究**：
  大侧向扰动主要靠 hip strategy / stepping，ankle 是辅助。

### 9.99.2 对应到我们

```text
foot/0 = 内外翻
外翻 → CoP 内侧
内翻 → CoP 外侧
```

所以“脚压力主动往内收”是**有论文依据的**，但准确说法是：

```text
用踝内外翻把 CoP 移到需要的位置
不是固定往内
```

方向取决于：

```text
CoM 偏哪边
当前脚在哪只脚承重
需要加速还是刹车
```

### 9.99.3 当前实现

```text
squatAnkleVector 被动分支：
  if (passiveOnly) Mx = 0;
```

→ 脚没有主动 CoP 侧移。

已有实验开关：

```text
SQC_FOOT_COM_K
```

```text
K=0    → 8.637s，slip 7
K=300  → 10.192s，slip 5
K=1000 → 6.771s，过冲
```

说明：

```text
脚 CoP 主动有用；
但符号/限幅/slip guard 没做完。
```

### 9.99.4 正确策略

```text
CoP_target = clamp(
  ankZ + Kcom·(comZ−com0) + Kvel·comVelZ,
  ankZ−limit,
  ankZ+limit
)
```

再由 foot/0 内外翻去追 CoP_target。

### 9.99.5 结论

```text
论文支持“脚压力内收/CoP 内移”是一种策略，
但它不是万能方向；
我们的脚现在确实缺主动 CoP，
下一步是带限幅和 slip guard 的 CoP 伺服，不是固定内收。
```

## §9.101 CoM 余量 vs 踝/CoP 余量（2026-10-23）

### 9.101.1 实测

```text
CoM z ≈ -1 ~ -4mm
脚中心 z ≈ L+160 / R-160mm
脚宽半宽 ≈ 55mm
```

几何支撑边界约：

```text
L +215mm / R -215mm
CoM 在中间，几何余量很大
```

但：

```text
CoP L≈197 / R≈-206mm
离脚中心偏移 ≈36~46mm
离脚边缘只剩 ~9~19mm
```

### 9.101.2 结论

```text
不是 CoM 几何余量不够
是 CoP / 踝控制余量不够
```

脚踝一直用大 CoP 去拉全身：

```text
CoP 到边缘 → 踝力矩接近饱和
→ 脚开始歪
→ 膝吃反作用 → 膝盖不稳
```

### 9.101.3 “腿竖直”的正确做法

```text
CoM 居中
CoP 保持在脚中心附近（±20mm）
踝只做小力矩
髋做骨盆/腿姿态
```

而不是：

```text
把 CoP 推到脚边缘去救全身
```

### 9.101.4 下一步

```text
1. 记录 CoP margin / ankle torque margin
2. CoP 目标限幅到脚中心 ±20mm
3. 超出部分交给 hip/step
4. 慢积分把 CoM 拉回中心
5. 再做脚内侧 arch 压力，不要用大 CoP
```
