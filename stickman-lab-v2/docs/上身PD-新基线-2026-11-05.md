# 上身 PD 新基线（2026-11-05）

## 目标

```text
上身撑住
姿势可以不标准
髋不被上身抬起来
只有一个 PD
```

## 控制

目标 `q*` = 释放瞬间的 spine1/spine2/spine3/neck 三轴角度。

```text
τ_i = G_i + Kp·(q*_i − q_i) − Kd·q̇_i
```

```text
i   = 每个脊柱/颈关节的每个轴
G_i = 该关节子树重力矩（逐节逐轴，当前姿态计算）
```

输出限幅：

```text
PD 限幅  ±120 N·m
总力矩   ±tauMax
单写手   squat.upperSupport
单通道   support
优先级   PRI.servo
```

## 参数

```text
SQC_UPPER_KP       160
SQC_UPPER_KD       24
SQC_UPPER_CAP      120
SQC_UPPER_VEL_LP   0.35
SQC_UPPER_RAMP     0.05s
```

## 为什么这样最简单

```text
PD + 重力前馈 = 标准 computed torque
目标不是标准姿势，而是释放瞬间姿势
上身只保持自己，不追全局 pitch
不读 CoM / CoP / 髋高度
不写下身任何关节
```

论文依据：

```text
Peterka 2002
  姿势控制 = 主动力矩 + 被动刚度；低增益连续反馈，刚度配阻尼

Horak & Nashner 1986
  躯干/髋策略；躯干倾角与角速度是自然输入

Winter 1995
  关节力矩沿链传递，重力支撑必须逐节
```
