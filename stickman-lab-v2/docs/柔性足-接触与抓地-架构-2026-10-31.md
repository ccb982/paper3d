# 柔性足接触与抓地架构（2026-10-31）

## 1. 目标

柔性足不是三个独立关节，而是一组接触执行器：

```text
foot_*
arch_*
mfoot_*
```

第一任务永远是：

```text
贴地
```

第二任务才是在贴地前提下活动脚部。

禁止：

```text
用外部力钉住脚
脚离地还追脚位置目标
arch 单独跳目标
foot PD 把腿拉向空中
```

## 2. 模块划分

```text
FootSampler       每帧采样 fz / CoP / 分块压力 / 滑移
GroundDetector    判断贴地、离地、滑移
CopController     CoP 目标、误差、限幅
NormalController  目标法向力、N 误差、腿伸展请求
FootTarget        统一脚目标（位置/姿态/arch/mfoot）
FootExecutor      只执行，不产生目标
```

## 3. FootSampler

每只脚每帧输出：

```text
fz
copX / copZ
copValid
slip
footPartN: foot / arch / mfoot
footPose
footVel
```

采样只读，不写执行器。

## 4. GroundDetector

```text
contact =
  fz > fzMin
  && copValid
  && cop 在脚底支撑多边形内
```

状态：

```text
airborne      脚离地
touchdown     刚接触
loaded        稳定承重
slipping      接触但轴向/侧向速度过大
```

接触丢失时：

```text
禁止脚位置 PD
禁止把脚往初始目标拉
进入找地模式
```

## 5. CopController

```text
copTarget = 支撑中心
copError = cop - copTarget
```

约束：

```text
cop 必须留在脚底多边形内
超出只允许到边界
```

输出：

```text
foot/0 侧向修正
foot/2 矢状修正
```

CoP 控制只在：

```text
contact == true
```

时生效。

## 6. NormalController

目标法向力：

```text
fzTarget = totalWeight × loadShare
eN = fzTarget - fz
```

`N` 不能直接当踝力矩用。  
N 误差用于：

```text
腿伸/屈
足弓目标
脚掌接触姿态
```

规则：

```text
N 太小：
  腿伸展找地
  禁止脚位置 PD

N 足够：
  允许 CoP / 脚位置控制

N 过大：
  减小伸展，避免过压
```

## 7. FootTarget

每只脚只有一个目标对象：

```text
position: 初始脚底接触点
pose: 初始脚掌姿态
fzTarget
copTarget
archTarget
mfootTarget
```

`FootTarget` 由接触模块维护，执行器只读。

## 8. 柔性足执行

```text
foot/0、foot/1、foot/2：
  关节 PD + 软限位

arch：
  N/压力分配目标，速率限制

mfoot：
  与 arch 同一个 FootTarget 的接触分配，不单独维护目标
```

arch/mfoot：

```text
随脚掌接触状态一起进入
不单独先动
不单独退出
```

## 9. 控制优先级

```text
1. 贴地
2. CoP 在脚底内
3. 目标 N
4. 脚位置/姿态
5. 关节软限位
```

低优先级不得破坏高优先级。

## 10. 与基础力、髋 PD 的关系

```text
基础力：
  矢状重力补偿

HipTaskPD：
  COM / 髋平衡

FootContact：
  接触、CoP、N、脚位置
```

脚抓地模块不负责髋平衡。  
髋 PD 不负责脚底 N。

## 11. 验收

```text
脚接地时 fz 跟随目标
CoP 不离开脚底
脚离地时不再追位置目标
腿能重新伸向地面
arch/mfoot 不单独跳
```

以上任何一条不满足，都视为抓地模块失败。

## 12. 承重权与回正权分离（2026-10-31）

### 12.1 分工

```text
FootContact：
  只汇报 fz 缺失、CoP、接触状态
  不直接发力

HipTaskPD：
  根据 N 缺失
  命令 hip/knee 施加承重

ShankTaskPD / foot PD：
  只负责回正和接地姿态
  不负责产生 N
```

### 12.2 链路

```text
脚接地
→ FootContact 报 N 不足
→ HipTaskPD 让髋/膝伸腿
→ N 传到地面
→ 小腿/踝 PD 只保持回正和接触姿态
```

### 12.3 权力边界

```text
承重权：髋
回正权：小腿、踝、脚
感知权：脚底接触模块
```

### 12.4 禁止

```text
脚 PD 为了制造 N 把脚拉飞
FootContact 直接写关节力矩
小腿 PD 同时负责承重和回正
```

### 12.5 验收

```text
N 不足时由髋/膝响应
脚只报告接触和 N
小腿/踝只回正
脚不因追 N 而离地
```

当前代码还没有把该分工接进蹲下法庭；FootContact 目前只在隔离试验中。
