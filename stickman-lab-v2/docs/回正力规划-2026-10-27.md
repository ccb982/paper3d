## 1. 论文依据

### 1.1 平衡与足底力

```text
Horak & Nashner 1986   ankle/hip strategy
Winter 1995            GRF/CoP 与关节力矩
Hof 2005/2008          standing equations / XCoM
Kuo 1995               CoM state feedback
Peterka 2002           sensorimotor feedback
Caron et al. 2019      contact wrench cone / CoP
Vukobratovic & Borovac 2004  ZMP/CoP
Hyon 2006/2009         whole-body force distribution
```

核心：

```text
CoM 只能被外力改变；唯一外力来自脚底 GRF/CoP。
髋/膝/脊柱力矩是内力，必须通过脚反作用。
```

### 1.2 髋/膝/踝

```text
Escamilla 2001 MSSE    深蹲膝生物力学
Schoenfeld 2010 JSCR   深蹲运动学/动力学
Kutzner 2010 J Biomech 膝关节载荷
Powers 2010 JOSPT      髋力学对膝的控制
Souza & Powers 2009    髋力量/膝运动学
Neumann 2010           髋外展肌
Hemmerich 2006         髋/膝/踝 ROM
```

膝盖结论：

```text
膝是矢状铰链；没有主动侧向力矩。
侧向稳定来自髋外展 + 脚 CoP + 被动韧带。
膝只做蹲姿矢状对齐（膝在脚上方/小腿竖直）。
```

### 1.3 脊柱被动刚度

```text
Panjabi 1992                 脊柱稳定子系统
Cholewicki & McGill 1996     腰椎被动稳定
Shahvarpour 2015 J Biomech   腰椎被动转动刚度上限 ~412N·m/rad
Maaswinkel 2015              脊柱刚度梯度
Hodges 2005 / El Bojairami 2021  TLF/IAP 静态稳定贡献
```

被动组织：

```text
竖脊肌、多裂肌、腰髂肋肌、胸腰筋膜、
关节囊、椎间盘、髂腰韧带、旋转肌/横突间肌。
```

当前取值：

```text
spine K=200N·m/rad, B=6
K=400 出现 flip，不能直接拉满
```

### 1.4 预测与渐入

```text
Massion 1992          anticipatory postural adjustments
Wolpert & Flanagan 2001  internal models / prediction
Peterka 2002          feedback latency
Geng et al. 2024      upright stance near critical stability
```

预测只提前发力，不替代脚预算。

## 2. 统一结构

```text
Sensors
  fzL/fzR, CoP, slip
  CoM/comVel
  trunk roll/rate
  joint angle/vel
        │
        ▼
FootBudget
  CoP ∈ foot
  |Ft| ≤ μFz
  fz margin
        │
        ▼
RightingCoordinator (唯一 active owner)
  ankle: CoP + foot/2
  knee : squat knee alignment
  hip  : pelvis level + hip support
  spine: HAT/back
        │
        ▼
PassiveLayer (独立，不仲裁 active)
  spine/0,1 damping
  hip/knee/foot neutral stiffness
        │
        ▼
BaseFF (重力/GRF)
```

硬规则：

```text
1. 每条 active 轴只有一个 owner
2. passive 不参与 active 仲裁，不能和 active 同轴相加
3. hip/back 命令必须附带脚 CoP/GRF 申请
4. 脚预算不足 → 该通道=0
5. 下盘无安全区；上盘才有安全区
```

## 3. 规划

### Phase 0：写手分账

- [ ] active owner 表固定：ankle/knee/hip/spine
- [ ] 同轴 passive 改成纯阻尼或单独 passive 通道
- [ ] 移除/停用旧回正入口
- [ ] 回读 `cmd/applied/passive/pair`，确认 active 不再被吃掉

验收：

```text
URtau≈20 → spine applied ≥ 15
```

### Phase 1：脚底力标定

- [ ] `foot/0` 单脉冲：τ→CoPz 的符号/增益/延迟
- [ ] `foot/2` 单脉冲：τ→CoPx
- [ ] 单脚卸载/加载的 CoP 重分配
- [ ] 摩擦锥、CoP 边界、fz 门控
- [ ] 步进/正弦响应，不再用闭环猜 B

验收：

```text
τ_foot0 = 10N·m → CoPz 方向正确、无高频翻号
CoP 始终在脚掌内
```

### Phase 2：下盘

- [ ] hip/2、knee/2 倒向侧支撑曲线
- [ ] 髋水平（hip0 差动）/膝竖直/脚抓地
- [ ] 下盘高刚度、无安全区
- [ ] 力链：hip→knee→ankle→foot fz

验收：

```text
倒向侧 fz > 对侧
hipY 倒向侧更高
knee2 倒向侧更伸展
foot0 不饱和
```

### Phase 3：上盘

- [ ] HAT 预测窗 0.1~0.2s
- [ ] 安全区：inner 1.2° / outer 3.5°
- [ ] 滞回 + 渐入 0.2s / 渐出 0.35s
- [ ] 上盘 active 独占 spine/0
- [ ] 上盘命令先申请脚预算

验收：

```text
URtau ≥ 0.8 × 需求
spine applied ≈ URtau 分配和
trunk roll 不单调增大
```

### Phase 4：整套联调

- [ ] 侧向冲量/斜坡扰动
- [ ] CoM 安全区、CoP 安全区
- [ ] fz/滑移/单脚卸载
- [ ] 渐入渐出不产生阶跃
- [ ] 旧回正不回潮
