## 1. 目标

两个下盘 PD 只执行 QP 输出的关节力矩。

```text
QP

```

## 2. QP 变量

```text
qdd
tau
f
```

`f` 是接触力/接触 wrench。

## 3. 动力学

```text
M(q) qdd + h(q, qd) = S^T tau + Jc^T f
```

## 4. 接触

```text
Jc qdd + Jc_dot qd = 0
f in friction cone
```

## 5. 任务

```text
CoM:
  J_com qdd + J_com_dot qd = a_com*

CoP:
  由接触 wrench 决定
  p = p(f)
```

## 6. 约束

```text
q_min <= q <= q_max
tau_min <= tau <= tau_max
CoP in support polygon
Fz >= 0
friction
```

## 12. 重力符号（论文）

### 12.1 动力学

```text
M qdd + h = S^T tau + Jc^T f
h = C qd + g
```

### 12.2 反解

```text
tau = M qdd + h - Jc^T f
```

### 12.3 gravityComp

```text
gravityComp = -g
```

所以：

```text
tau = M qdd - gravityComp - Jc^T f
```

不是：

```text
tau = M qdd + gravityComp
```

### 12.4 结论

```text
上次符号用反
膝支撑从 +105 变 -68
```

### 12.5 下一步

```text
用 RNEA 得 h
加 Jc^T f
```
