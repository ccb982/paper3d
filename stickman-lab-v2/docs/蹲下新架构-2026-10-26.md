# 蹲下新架构（2026-10-26）

> 目标：以 **正常蹲下稳定高度 55.5cm** 为唯一标准，重做蹲下过程与蹲姿伺服。
> 先闭合髋稳定算法，再优化下落 CoM 居中，最后优化脚发力。
> 本文是新架构设计，不包含实现；现有 `squatHipStrut` / 蹲下法庭不在此次重写范围内。

---

## 1. 唯一标准姿态（Normal Squat 55.5）

```text
comY = 55.5cm（允许 54~57）
comX = +1.0cm（允许 ±2cm）
comZ = 0（允许 ±2cm）

hip2  = 103.1°
knee2 = -102.1°
foot2 = 0°（脚掌平贴）
spine1/2/3 = -25.7 / -15.9 / -26.4°
neck  = 2.3°
shoulder = 25.8°

站距：左右脚 z ≈ ±16.4cm（保持正常蹲下站距）
```

法庭参数：

```text
SQC_K   = 1.8
SQC_A   = 0.45
SQC_L   = -0.378
SQC_ARM = 0.45
```

动作终点（PPATH p=1）必须与上表一致；当前动作终点 ankle=24°、comX=-6.4cm，是旧路径遗留问题，需要在本架构中修掉。

## 2. 架构总原则

```text
1. 一个 DoF 同一时间只能有一个写手。
2. 所有力必须有来源：
   - 基础力 = 当前姿态的 staticBalance（体重 + GRF）
   - 回正力 = 关节空间 PD / 任务空间 JᵀF
   - 地面力 = 脚 CoP / GRF
   禁止 raw hip↔foot 力对、禁止凭空外力。
3. 基础力按“当前实际姿态 + 速度≈0”标定，不跨姿态复用。
4. 先稳髋，再稳 CoM，最后做脚发力；顺序不能反。
5. 保持相禁止新增独立写手；所有保持力归入同一个 hip/leg 控制器。
```

---

## 3. 状态机

```text
S0 站立
  ↓ 播放 squatDown
S1 下降（动作层）
  - 矢状 p 路径 + 基础力前馈 + CoM 闭环
  - 侧向单一写手（anti-adduct）
  - 脚：CoP / 站距保持
  ↓ 到达标准姿态 + 速度≈0
S2 交接冻结
  - 清零残余速度
  - captureAngFrom + captureSquatBase（按标准姿态）
  - 髋高度/roll 闭环从 0 渐入
  ↓ 稳定判据通过
S3 蹲姿伺服
  - base + hip 闭环 + 脚 CoP + 小上身 PD
  - 不再有动作层写手
```

判死：

```text
S1：只判 CoM 出脚 / 脚离地 / 姿态严重偏离；不按单一关节角提前判倒
S2/S3：以标准姿态为基准；y0 = 标准 comY（55.5），不是交接瞬间高度
```

## 4. 层与写手（新）

### L0 基础力（唯一前馈）

```text
staticBalance(标准姿态) → τ_base[hip/knee/ankle/spine/neck]
通过 kind:'ext' 施加，不经过 pair。

要求：
- 标定发生在标准姿态、速度≈0；
- 每次进入 S2 重新标定一次；
- 不把 court seat（47.6）的 base 复用到 55.5。
```

### L1 髋稳定闭环（核心，新写）

髋稳定不是 pair PD，而是任务空间闭环：

```text
输入：
  hipY / hipVy         髋锚点高度 / 垂直速度
  roll / rollRate      骨盆/躯干 roll
  comX / comZ / vCom   质心与速度
  fzL / fzR / CoP      双脚负载

任务 1：髋高度
  eY = y_ref - hipY
  Fy = KpY·eY + KdY·(-hipVy) + KiY·∫eY
  Fy = clamp(Fy, ±FyMax)

任务 2：骨盆 roll
  eR = roll_ref - roll
  τR = KpR·eR + KdR·(-rollRate)
  τR = clamp(τR, ±τRMax)

任务 3：CoM 居中（只做小误差）
  eZ = 0 - comZ
  τZ = KpZ·eZ + KdZ·(-vComZ)
  τZ = clamp(τZ, ±τZMax)
```

分配到关节：

```text
τ = Jᵀ·[Fy, τR, τZ] 的等价关节力矩
或：
  hip2/knee2 ← 髋高度 + 矢状 CoM
  hip0 差动  ← 骨盆 roll + 侧向 CoM
  ankle CoP  ← 侧向/矢状小误差
```

约束：

```text
- 临界阻尼：Kd ≈ 2√(Kp·I)
- 速度/力矩硬限幅；CoP 到边界时冻结对应任务
- 积分只在 |eY| 小、脚不滑时工作；反向泄漏
- 同一时刻只有一个 hip/leg 写手
```

验收：

```text
|hipY - y_ref| < 1cm
|roll| < 1°
|comZ| < 2cm
无正负翻号；连续 >8s 不倒也
```

### L2 脚发力（CoP，不做 raw 力对）

```text
脚不是“被虚拟支撑推”的对象；脚是地面力入口。

目标 CoP：
  pDes = clamp(ankle + Kp·eCom + Kd·vCom, ankle ± limit)
  limit < 脚掌半宽，保留 margin

执行：
  foot0/foot2 内外翻 + 跖屈/背屈
  Mx/Mz 由 ankleVec 统一分配

站距：
  脚 z 误差 → hip0 外展 + foot0 CoP
  不允许 hip↔foot raw force pair
```

### L3 上身（小力矩）

```text
只保留有 cap 的 PD：
  spine/neck：Kp 小、cap 小（目标 <60 N·m）
  shoulder/elbow：只做轻度保持

禁止：
  spine pair 打到 320 饱和
  BSS/HAT/backMuscles 同时抢同一轴
```

### 阻尼

```text
关节临界阻尼，集中在同一个 hip/leg 控制器内；
不再叠加 pair C×Damp + passiveDamp + tension 三层。
```

## 5. 被停用/让位的写手

```text
pair PD（squatPairBase 的 C/ks/bs）        → 保持相停用，只保留 base
hipStrut 侧向 raw 力对                     → 停用（本架构不再使用）
squatRightingV2 / RC2                      → 保持相停用
squatNewBase / NB                          → 保持相停用
squatSagittalAssist                        → 保持相停用
squatJointLoad                             → 保持相停用
squatPassiveStiffness（2 N·m cap）          → 不作为承重，只留极小
supportClean 腿环                          → 蹲下段让位给动作层
supportClean.arm / BSS / HAT / backMuscles → 上身只留一个 cap PD
FootPad                                    → 蹲姿不写脚
```

旧问题记录：

```text
- pair PD kp≈280 / kd≈8.4，严重欠阻尼；加大阻尼会饱和。
- 只关 pair PD 会直接塌：base 撑不住，passive stiffness cap 只有 2 N·m。
- hip 力矩实测 -156 → +180 → -265 N·m 正负交替，超人体稳定范围。
```

## 6. 下降过程 CoM 居中（任务 2）

### 6.1 侧向

```text
目标：comZ ≈ 0，脚 z 漂移 <2cm

写手：
  anti-adduct：hip0 外展 + foot0 CoP
  supportClean 在动作层接管的轴上让位

禁止：
  多个 hip0/foot0 写手对拉
  用髋平移/脚差动硬拉
```

### 6.2 矢状

```text
目标：comX 沿 p 路径到 +1.0cm

控制：
  eX = x_ref(p) - comX
  小误差：ankle CoP
  中误差：hip2/knee2 PD
  大误差：降低 p 速度，先回 CoM

禁止：
  固定 hip/knee 力
  到末端用 24° 踝硬推
```

### 6.3 脚

```text
脚掌平贴；CoP 在脚掌内；
fz 双脚 >50N；
站距保持；不内收。
```

## 7. 交接

```text
S1 → S2 条件：
  |hip - 103.1°| < 5°
  |knee + 102.1°| < 5°
  |foot2| < 5°
  |comX - 1.0cm| < 2cm
  |comZ| < 2cm

  清零残余速度
  captureAngFrom

  hip 闭环从 0 渐入
```

## 8. 验收

```text
法庭（55.5cm）：
  >8s，多 seed 不倒也
  hipY 误差 <1cm
  roll <1°
  comZ <2cm
  spine 力矩 <60 N·m
  hip2 不饱和、不翻号

下降：
  comZ <2cm
  comX 到 +1.0cm ±2cm
  footZ 漂移 <2cm
  双脚 fz >50

交接：
  标准姿态误差 <5°
  comY 55.5 ±2cm
  交接后 1s 内 hipY 不再下降
```

## 9. 实施顺序

```text
M1 标准姿态 + base 标定
  - 法庭/动作统一到 55.5
  - base 在标准姿态捕获

M2 髋稳定闭环
  - base + 髋高度/roll PD
  - 停用 pair PD / 多余写手
  - 法庭 55.5 >8s

M3 下降 CoM 居中
  - 侧向 anti-adduct 单一写手
  - 矢状 comX 闭环
  - 脚 CoP / 站距

M4 脚发力与交接
  - CoP 限幅 / slip guard
  - 标准姿态交接
  - 长时间保持验收
```

## 10. 风险

```text
1. 55.5cm 比 47.6cm 更直，髋力矩需求和几何都变了；
   旧 pair/base 参数不能直接复用。
2. 髋高度闭环与脚 CoP 可能互相抢；必须明确优先级：
   脚 CoP 安全 > 髋高度 > roll > 上身姿态。
3. 基础力标定必须在速度≈0 的标准姿态；运动中标定无效。
4. 任何新增写手必须先登记，保持相不允许并行写手。
```
