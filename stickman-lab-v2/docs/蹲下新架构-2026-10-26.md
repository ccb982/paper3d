## 2. 架构总原则（v2）

```text
1. 一个 DoF 同一时间只能有一个写手。
2. 所有力必须有来源：
   - 基础力 = 当前姿态的 staticBalance（体重 + GRF），释放瞬间捕一次
   - 修正力 = 关节空间 PD / 任务空间闭环
   - 地面力 = 脚 CoP / GRF
3. 基础力按"当前实际姿态 + 速度≈0"标定，不跨姿态复用。
4. 先稳髋，再稳 CoM，最后做脚发力。
5. 保持相禁止新增独立写手。
6. ★ 新增：**不新增写手**。要加修正，只能改既有写手的既有字段
   （`squatPairBase` 的 `base` / `ref` / `c`；`squatAnkleVector` 的 `targetX` / `Mdes`）。
7. ★ 新增：**先标定再调参**。调增益前先量"指令 → 实际"的执行效率；
   等效环路增益 = 指令增益 × 执行效率，效率 < 1 时单看指令会把环路做进发散区。
8. ★ 新增：**单变量 + ≥5 seed**。单 seed 是噪声（同一配置 2.48~3.63s）。
9. ★ 新增：**判死要分类**（pose / com / physical），否则"倒了"这句话没有信息量。
```

任务量必须是**躯干世界 pitch**，不是脊柱关节角：

```text
读：spine4（缺则 spine3）刚体四元数 → up 向量 → pitch = atan2(ux, uy)
    p0 = 释放瞬间捕获（复用法庭已捕的 st.p0，不新增状态）
    rate = 80ms 低通后的 dpitch/dt
误差：e = p0 − pitch            // e<0 = 趴过头（越折叠）
力矩：q = clamp(−kp·e + kd·rate, ±cap)   // q>0 = 要把躯干"往后扶"
```

分配（实测符号，不是推的）：

```text
① 上身承担 q·wS：
   spine1/2/3 += q·wS·[0.29, 0.33, 0.38]   // +τ 减小 pitch；权重按实测增益比归一化
   hip_*2     += −q·(1−wS)/2               // ★ **反号**：+hip 会**增大** pitch
② 脚承担反作用：                     ← 用户：「都要脚发力传到上身」
   squatAnkleVector 的 Mz += −q·footK/2    // 左右各半，由地面反力承担
```

**为什么必须把反作用给脚**（实测，不是理论）：

| 做法 | pitch 漂移 @1s | maxDev | 保持 | 失败模式 |
|---|---|---|---|---|
| 关（基线） | 9.2° | 12.9° | 3.300s | offX（前后） |
| 只在上身加力矩 | 4.7° | 14.8° | 2.960s | **offZ（侧向）** ← 反作用把骨盆顶偏 |
| 上身 + 脚承担反作用 | 5.4° | 8.6° | 2.954s | offX |

### 4.2 符号标定（`tools/_tmp-backsign.ts`）

单轴 ±10 N·m 注入，rel 0.05~0.35s：

```text
spine1 +10 → pitch −1.33°     spine2 +10 → −1.53°     spine3 +10 → −1.75°
hip_l2  +10 → pitch **+0.60°**（反号）
foot_l2 +10 → comX **+1.33cm**、fall 3.30→1.38s（脚权限最大，裸推必倒）
```

⇒ 脊柱是扶躯干的有效杠杆（0.13~0.18°/N·m），髋是反向的，脚是大权限但会推倒。
