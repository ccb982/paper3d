## 1. 核心思想

```text
第一层：无意识稳定
  智能基础力
  + PD 关节张力
  + 被动刚度/阻尼

第二层：有意识主动介入
  矢状回正
  侧向回正
```

理想情况下：

```text
只靠第一层就能持久蹲下
第二层只在扰动/误差出现时短时介入
```

不是：

```text
基础力固定表一直发
被动刚度硬抗所有侧移
回正层长期大扭矩
```

---

## 2. 分层

```text
① 接触
② 智能基础力
③ PD / 被动关节张力
④ 矢状回正
⑤ 侧向回正
```

### 2.1 接触

```text
脚底接触
CoP
摩擦
支撑多边形
```

接触是硬边界，不是控制目标。

### 2.2 智能基础力

```text
不是一次性 captureSquatBase
不是固定力矩表
```

每一小段时间根据当前状态重新求静态平衡：

```text
τ_base = ID_static(q, contact, CoP, Fz, load)
```

含义：

```text
当前姿态、当前接触、当前负载下
维持静态平衡所需的关节力矩
```

特点：

```text
开环/准静态
不追 IK 目标
不追 CoM 误差
不产生未来预测
只负责“当前状态撑住”
```

### 2.3 PD / 被动关节张力

```text
PD target = IK/中立目标
PD stiffness/damping = 肌肉主动张力
passive = 关节被动刚度/阻尼
```

第一道防线的稳定来源：

```text
基础力承担静态重力
PD 把关节锁在目标附近
passive 吸收小扰动
```

不是：

```text
PD 目标自己每帧乱跳
passive ref 跟着 IK 目标跑
```

### 2.4 矢状回正

```text
有意识主动介入
只在第一层不够时工作
```

消费：

```text
IK 目标
CoM / XCoM
左右负载
Fz 低侧/高侧
kneeOut
```

输出：

```text
hip0/1/2 修正
knee2 修正
```

### 2.5 侧向回正

```text
有意识主动介入
只在小腿/踝局部失稳时工作
```

消费：

```text
eLat / fLat
CoP
foot0 / ankle
```

输出：

```text
foot0 侧向
必要时 foot1/foot2
```

## 3. 无意识 / 有意识的边界

```text
无意识层：
  基础力
  PD
  passive
  接触约束

有意识层：
  矢状回正
  侧向回正
```

无意识层必须：

```text
稳定
连续
不依赖 IK 误差
不依赖未来预测
```

有意识层必须：

```text
短时
小幅度
高灵敏
可快速退出
```

不能：

```text
用有意识回正去补无意识层的失稳
```

## 4. 智能基础力

### 4.1 输入

```text
q
q̇
脚接触
CoP
Fz
左右负载
骨盆/脚位置
```

### 4.2 求解

```text
q̈ = 0
q̇ = 0
```

求：

```text
τ_base
F_base
左右支撑分配
```

### 4.3 输出

```text
hip0/1/2 基础力矩
knee2 基础力矩
foot2 基础力矩
左右 Fz 参考
```

### 4.4 更新频率

```text
基础力不是每帧硬算
也不是 20–50Hz 循环重算
```

只在：

```text
t0 / 参考姿态改变
接触模式改变
阶段切换
```

重捕一次。中间保持。

### 4.5 禁止

```text
固定表永远不变
基础力读 IK 误差
基础力追 CoM 目标
基础力和回正层双算
```

## 5. PD / 被动张力

### 5.1 PD 目标

```text
主动回正使用 IK 目标 q_ik
基础姿态使用释放/中立目标 q_ref
```

### 5.2 被动参考

```text
passive ref = 固定中立/释放位
```

不能：

```text
passive ref = q_ik
```

否则：

```text
实际角跟着 IK 走
e=0
被动刚度不出力
```

### 5.3 力矩预算

```text
人体量级优先：

被动：
  hip0/1 ≈ 8–12 Nm/rad
  knee0 ≈ 60 Nm/rad（韧带）
  knee2 ≈ 30 Nm/rad
  foot0 ≈ 20–30 Nm/rad
  foot2 ≈ 20–30 Nm/rad

主动软限位：
  hip0/1 cap ≈ 40–60 Nm
  hip2 cap ≈ 100–120 Nm
  knee2 cap ≈ 80–100 Nm
  foot0 cap ≈ 20–30 Nm
  foot2 cap ≈ 60–80 Nm
```

禁止：

```text
用 800–1200 Nm/rad 的被动刚度硬顶
用 150–200 Nm 的 cap 长期运行
```

## 13. 修正：IK 一次性消费与稳定目标（2026-11-09 用户定稿）

### 13.1 基础力 / passive 只消费一次 IK

```text
释放/参考时刻：
  q_ik
  → 一次静态 ID
  → base 力矩
  → passive 参考位
```

之后不再每帧用 IK 重算 base。

```text
base = 一次 IK 静态平衡参考
passive ref = 一次 IK / 中立参考
```

### 13.2 后续唯一目标

```text
不是持续追 IK
而是维持稳定
```

第一层目标：

```text
保持接触
保持 CoP / 摩擦
保持关节张力
保持姿态不要快速漂移
```

稳定状态下：

```text
偏离目标 IK 的速度很慢
不需要每帧回正
```

### 13.3 回正层的接入

回正是**有意识主动介入**：

```text
实际姿态偏离到需要修正
或扰动使稳定性下降
→ 矢状/侧向回正接入
→ 目标重新指向 IK 姿态
```

回正可以：

```text
修改 righting target
增加 short-term Δ
```

但不：

```text
每帧重算 base
把 base 当 IK 跟踪器
```

### 13.4 正确时序

```text
t0:
  IK → base + passive ref

t0 之后:
  base 保持
  PD/passive 维持稳定
  righting off

实际偏差/扰动:
  righting 主动接入
  回到 IK 目标

稳定后:
  righting 退出
  回到 PASSIVE
```

### 13.5 与旧 §4.4 的关系

```text
§4.4 的“20–50Hz 重算 base”
不再作为默认。
```

只有：

```text
参考姿态改变
接触模式改变
阶段切换
```

才允许重新捕获 base。

### 13.6 一句话

```text
IK 是一次性参考
base/passive 是稳定器
righting 是主动回 IK
不是每帧追 IK
```

## 14. 被动刚度的作用区间（2026-11-09 用户定稿）

### 14.1 原则

```text
被动刚度不是大偏差救援
而是小偏差阶段就持续回正
不让姿态偏差继续增大
```

作用顺序：

```text
小偏差：
  passive stiffness 立即出力

中等偏差：
  PD / base 继续维持

大偏差：
  righting 才主动介入
```

### 14.2 正确特性

```text
deadband 很小
ref 固定
从第一个小偏差开始连续出力
不需要 15N/100N 软启动才动
```

不是：

```text
偏差小 → 不动
偏差大 → 突然介入
```

### 14.3 当前实现问题

```text
hip0 passive:
  ref 跟着 IK，e=0
  → 小偏差也不出力

foot0 主动:
  softLo=15N
  → 小偏差阶段先不动

knee0:
  passive ref=0，但 cap/ROM 限制
```

所以当前实际是：

```text
小偏差：passive 不动
偏差变大：主动/righting 才介入
```

这与设计相反。

### 14.4 修正方向

```text
1. passive ref 固定
2. deadband 降到很小
3. 小偏差阶段 passive 立即出力
4. righting 只在 passive 不足时接入
5. 不靠提高 cap 硬顶
```

### 14.5 验收

```text
小偏差 1–3°：
  passive 有连续力矩
  姿态偏差不继续增长

中偏差：
  PD/base 接管

大偏差：
  righting 短时介入
```

## 15. 无意识肌肉张力（baseline muscle tone）

### 15.1 定义

```text
无意识肌肉张力
  = 持续共收缩/基础激活
  = 不是被动组织
  = 不是有意识回正
```

人蹲下初期稳定主要靠：

```text
基础力
+ baseline muscle tone
+ PD 关节张力
```

不是靠被动组织几 Nm。

### 15.2 三层区分

```text
被动组织：
  k 小，几 Nm/rad
  只抗小偏差

baseline tone：
  持续激活/共收缩
  力矩可以大
  但不需要意识介入

righting：
  误差驱动
  短时主动修正
```

### 15.3 当前实现

当前代码：

```text
passive：有
PD：有
base：固定表
baseline tone：没有独立建模
```

`HipTaskPD` 的共收缩 `co` 是误差/ff 驱动，不是持续基础张力。

### 15.4 设计要求

```text
baseline tone：
  常开
  目标中立
  低权限但持续
  不追 IK 误差
  不替代 righting

righting：
  只在 tone/base/PD 不足时接入
```

### 15.5 结论

```text
蹲下初期稳定 =
  base + baseline tone + PD + passive

不是：
  passive 几 Nm 硬撑
```

当前 3.95s 基线缺少持续 baseline tone；下一步应把它加到 PD 层，而不是继续加 passive k。

## 16. 初始 IK 只是启动参考，不是持续硬目标

### 16.1 启动阶段

```text
t0：
  IK 目标 q_ik
  → base 初始化
  → baseline tone 初始化
  → passive 参考初始化
```

只消费一次。

### 16.2 之后

```text
无意识层目标：
  维持稳定
  不是锁死初始姿态
```

允许：

```text
缓慢偏离 q_ik
小幅姿态漂移
关节角变化
```

不允许：

```text
为了锁初始姿态牺牲稳定
用大扭矩硬拉回 q_ik
```

### 16.3 回正层

```text
需要回到 IK 姿态时
righting 主动接入
```

righting：

```text
短时
主动
消费 q_ik
修正后退出
```

### 16.4 正确关系

```text
初始 IK：
  启动参考

无意识层：
  维持稳定，允许慢漂

righting：
  需要时回 IK
```

不是：

```text
初始 IK 永远硬目标
每帧追 q_ik
```

### 16.5 验收

```text
无 righting：
  姿态可慢漂
  但不能快速恶化

righting 接入：
  能回到 q_ik
  退出后不振荡
```

当前 3.95s 基线不变。

```text
righting off

```

```text
每帧追 IK
```

```text
让蹲姿初期肌肉是“紧绷”的
```

```text
active target = q_ik
```

当前问题：


不能：


### 17.6 缺口 5：力矩预算

```text
passive：
  hip 8–12 Nm/rad
```

```text
fLat / fPerp / fParallel
```

```text

```

### 17.8 缺口 7：righting 状态机

```text
PASSIVE
SAGITTAL_ACTIVE

```

规则：

```text
PASSIVE 默认
误差/扰动才进入 ACTIVE
```

### 17.9 补齐顺序

```text
1. passive ref 分离
2. baseline muscle tone
3. base 一次性静态 ID
4. 人体力矩预算
5. 力链/CoP 验收

```

验收门槛：

```text

  多次法庭
  fall 不早于 3.95s
  passive 小偏差有连续出力
  fLat/fPerp 不快速恶化

接 righting：
  fall 不早于第一层
  righting 只在误差段工作
  退出后回 PASSIVE
```

### 17.10 passive ref 分离首轮结果

```text
全部 passive ref 分离：
  hip0/hip1/knee2/foot2 → 3.72s（变差）

只分离 hip0/hip1：
  → 3.87s

只分离 hip0：
  → 3.95s（与基线一致）
```

结论：

```text
hip0 passive ref 固定到释放位：
  不改善 fall，但架构正确，保留

hip1/knee2/foot2 passive ref 分离：
  当前会变差，先不默认
```

当前：

```text
hip0 active target = IK
hip0 passive ref = 释放位
其他 passive ref 暂时保持原状
fall = 3.95s
```

## 18. Baseline tone 的关节/相位/接触调制（2026-11-09）

### 18.1 原则

```text
每个关节的紧绷程度不同
每个阶段的紧绷程度不同
每个接触状态下的紧绷程度不同
```

不是：

```text
一个全局 SQC_TONE_CO
一个固定 FF
```

### 18.2 关节分配

```text
hip0 / hip1：
  中低持续外展/旋转张力
```

## 25. 第一道防线与最终控制链（2026-11-09 定稿）

### 25.1 控制链

```text
接触/传感
  ↓
神经命令层
  base（一次 IK 前馈）
  tone（基线激活）
  righting（有意识，第一道防线关闭）
  ↓
肌肉模型/执行器
  主动 PD
  被动刚度/阻尼
  饱和/限幅
  ↓
唯一关节 writer
```

### 25.2 基础力

```text
base = 一次 IK/静态 ID 计算
不是每帧 IK
不是每帧重算
```

之后：

```text
base 只允许极慢修正
理想状态：几乎不变
```

慢修正只允许在：

```text
接触模式改变
阶段切换
左右负载持续偏移
```

不允许：

```text
每帧追 IK
每帧追 CoM
和 righting 抢同一误差
```

### 25.3 tone

```text
tone = 基线神经激活
输入肌肉模型
不独立写关节
```

按：

```text
关节不同
phase 不同
contact 不同
load 不同
```

调制。

foot/ankle：

```text
不加主动 tone
只保留被动刚度/阻尼
```

### 25.4 PD/肌肉模型

```text
PD = 肌肉模型 = 执行器
```

主动：

```text
tone
kp·e
kd·ė
```

被动：

```text
k_passive·e_passive
b_passive·ė
```

最终只输出一个关节 torque。

### 25.5 被动层要加的机制

不是为了 righting，是为了模拟无意识肌肉紧绷：

```text
1. slack / deadband
2. 非线性刚度（先软后硬）
3. 阻尼
4. 速度相关阻尼
5. phase/contact 增益
6. 平滑 ramp
7. 饱和/限幅
8. 防抖/防翻号
9. 关节特异参数
```

关节分配：

```text
hip0/hip1：侧向被动 + 低 tone
hip2：矢状主动 + 被动
knee0：韧带被动，无主动侧向
knee2：矢状主动 + 被动
foot0/foot2：被动为主，无主动 tone
```

### 25.6 第一道防线

```text
SQC_RIGHTING_OFF=1
SQC_KNEEOUT_ACTIVE=0
QP 关闭
IK 不追
两个回正力都不开
```

只保留：

```text
base + tone + PD/passive
```

这就是“无意识维持”。

### 25.7 righting

```text
righting = 有意识主动接入
第一道防线不启用
```

以后只在：

```text
误差超过阈值
第一道防线不够
```

时短时介入。

### 25.8 实施顺序

```text
1. 冻结第一道防线开关
2. 把 supportPassive 收进 pdGroups 肌肉模型
3. baselineTone 改成肌肉激活输入
4. 删外部 FF/passive 双写
5. base 一次 IK/静态 ID + 极慢 trim
6. tone 按关节/phase/contact/load 调
7. 实际网页 A/B
8. 达到第一道防线验收，再开 righting
```

### 25.9 第一道防线验收

```text
两个回正力关闭
无 QP
无 IK 追逐
fall > 5s
无高频抖振
base 几乎不变
左右负载稳定
两次法庭一致
```
