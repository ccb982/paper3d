## 0. 结论

```text
命令层
  └─ 下肢 QP：base 6 + 18 joints
       解 qdd(24), tau(18), f(12)
       硬接触 + 摩擦/CoP + 力矩

  └─ 两段 PD / muscle，对 18 轴逐轴执行

  └─ 不参与 WBC，作为刚性负载
```

- 下肢 QP 是命令层，不存在“两段 PD 命令层”。
- 两段 PD/solve 的调用和 QP fallback 已删除；`SQC_WBC=off` 返回 0，不回到旧 PD。
- 论文是全身 ID-WBC；我们只做下肢，所以不能把论文的全身稳定性直接等同。
- **论文没有 IK 基础力前馈**。支撑力由浮动基动力学和 CoM/躯干任务决定。

## 1. 论文实际做法（Sovukluk 2025, Eq.6）

优化变量：

```text
ν̇ (24), τ (18), f_c (12)
```

动力学与约束：

```text
M ν̇ + Cν + g = Sᵀτ + Jcᵀ f_c
Jc ν̇ + J̇c ν = 0
|f_x,l| ≤ μ f_z,l / √2
|f_y,l| ≤ μ f_z,l / √2
f_z,l ≥ 0
τ_min ≤ τ ≤ τ_max
```

任务（软）：

```text
ẍ_i,d = ẍ_i,ref + Kd(ẋ_ref − ẋ) + Kp(x_ref − x)
min Σ (ẍ_i,d − ẍ_i)ᵀ W_i (ẍ_i,d − ẍ_i)
```

论文任务：

- CoM；
- 躯干/身体姿态；
- 支撑脚 6D pose；
- 摆动脚 6D pose；
- 手臂。

论文**没有**：

- IK 基础力前馈；
- `f_zL + f_zR = mg`；
- qdd 硬上限；
- tau-rate 硬约束；
- 关节速度硬约束；
- 显式 CoP 任务；
- 接触/CWC slack。

求解：Pinocchio 算 `M, h, Jc, J̇c`，ProxQP 解 QP。  
实验：全身 Kangaroo，20 cm / 0.4 Hz 正弦蹲。

关键点：**f_c 是 QP 决策变量**。前 6 行浮动基动力学没有 τ；CoM/躯干任务要求什么加速度，QP 就解出对应的 f_c。

| 项目 | 论文 | 我们 | 影响 |
|---|---|---|---|
| 模型 | 全身 | 下肢 18 | 上身不参与平衡 |

结论：**不能用“论文这样写，所以我们也一定稳”来推理**。我们做的是论文 Eq.6 的下肢子集，且多了 IK 前馈、法向、分配、速率。

## 4. 为什么现在脚不发力

不要先怪 IK 前馈。按顺序查：

1. **前 6 行动力学**
   - `M` 基座块、`h[0..5]`、`Jcᵀ f` 的基座行；
   - 如果 CoM/躯干任务的目标加速度为 0，而 `f` 很小，说明基座行/模型不对。

2. **CoM/base 任务**
   - `comTarget` 是否等于当前 CoM；
   - `baseTarget` 是否等于当前躯干姿态；
   - 任务误差为 0 时，QP 没有理由要支撑力。

3. **IK 前馈**
   - `tauFF` 只作用在 `tau`，不影响前 6 行；
   - 它可以让关节“看起来有力”，但不能代替 `f`；
   - 论文没有它，验证时应先关掉。

4. **接触**
   - `Jc` 是否对；`J̇c` 是否解析正确；
   - 脚 body 角速度是否已经被 QP 打到 100+ rad/s；
   - 接触点锁存是否真的保持。

5. **执行层**
   - `supportKd` 是否在 QP 模式关闭；
   - 是否有第二套基础力叠加。

当前已观测：

```text
1.98s  fL_y=343, fR_y=343, 总法向 686 = mg
2.08s  QP 失败
2.19s  QP 恢复但 qdd=1576
```

说明法向任务本身能给出 686，但 2.08s 的模型/接触先坏，之后脚才“不发力”。

## 5. 正确的下一步

### 5.1 先回到论文最小集

1. `SQC_WBC_WTAUFF=0`：关掉 IK 前馈，确认支撑力来自 QP。
2. `SQC_WBC_WNORMAL=0`、`SQC_WBC_WWEIGHT=0`：先去掉论文外扩展。
3. `SQC_WBC_WPOST=10`，foot2 不作为 posture 目标。
4. 保留硬接触、摩擦/CoP、力矩；无 qdd 硬边界。
5. 速率只保留软任务 + 输出 clamp，不进硬约束。

### 5.2 检查基座行

在 1.98s / 2.08s 打印：

```text
M_base, h_base, (Jcᵀf)_base
comTarget − com, comVel
baseTarget 误差
fL, fR
```

判断：

- 若 `h_base` / `Jcᵀf` 基座行量级不对 → 模型错；
- 若任务误差为 0 而 `f≈0` → 任务/权重错；
- 若 `J̇c` 大 → 接触/脚速错。

### 5.3 模型校验

1. 静态：`baseRes ≈ 0`，`f_zL+f_zR ≈ mg`。
2. 接触点锁存后 `J̇c` 不应随支撑点漂移。
3. 脚 body 角速度不应到 100 rad/s。
4. 解析 `h`、`J̇` 与有限差分 A/B 对照一次。

### 5.4 验收

- 5 seeds；
- 静态 10s；
- 慢蹲 16s；
- 无 PD fallback；
- QP 失败即倒，不允许偷偷回旧 PD。
