# 单腿站立控制架构 · 快照（2026-10-16 深夜版）

> 本文是**干净现状卡**（只描述当前有效的机制与写手账）。历史演进/试撤记录见《重设计-四层架构.md》§7q。

## 0. 总则（定稿原则）
1. **单腿保持期 = 独立层**：外部写手（span/sagittalStab/leanReflex/stepPhases-B）全部让位或入 C 清零。
2. **一轴一主**：单腿期每根轴只被一个写手命令。
3. **所有力走申请制**：接触(fz)→踝→膝≤300→髋≤228→脊≤456 → `pairCap`；pair 单肌 f≤2×cap。无 setTorque/ff 旁路。
4. **肌肉 = 动态单向阻尼**（drive pair）；**张力 = 共激活 C + F0 预紧**（执行层）。
5. **救援律 = 纯角度驱动（0° 即发力）+ 随倾倒升挡 + 99% 阻尼（速率低通）**，单实现于 `servo/rescue.ts`。
6. **上身写手 = 单模块** `servo/upperBase.ts`（2026-10-15 实装）：前后/左右独立参数 + 肌肉对通道；**planeSag / lateralStab 已作废**（用户定调，调用点同址替换）。
7. **每方向修正公式唯一**：单一实现（`corrOf`），前后/左右各一份参数；单腿保持期脊柱 6 轴唯一命令写手 = `upperBase`（其余仅执行层被动/张力件：骨刚、F0、单向阻尼、重力补偿）。

## 1. 上身写手（upperBase.ts，唯一架构；2026-10-15 定稿）

**结构（脊柱 9 轴：spine1/2/3 × 轴0/轴1/轴2；每帧；各方向独立）**——单实现 `commandMusclePair(dof, C, λ)`：

| 方向 | 基础力矩 B_d（N·m） | 基础修正 G_d |
|---|---|---|
| 左（轴0−） | `UPPER_B0N` | `UPPER_G0N` |
| 右（轴0+） | `UPPER_B0P` | `UPPER_G0P` |
| 前（轴2−） | `UPPER_B2N` | `UPPER_G2N` |
| 后（轴2+） | `UPPER_B2P` | `UPPER_G2P` |
| 正旋（轴1+） | `UPPER_B1P` | `UPPER_G1P` |
| 负旋（轴1−） | `UPPER_B1N` | `UPPER_G1N` |

**唯一公式（每帧）**：
1. **需求矩（受力驱动）**：`τ_need = −W·(comErr + comVel/ω₀)`（体重 × XcoM 偏差，N·m）；
2. **指令矩**：`τ_cmd = B_d + G_d·τ_need`（方向 d 按需求矩符号选；**G=1 = 不抢不欠**）；
3. **入肌肉**：`λ = θ₀ + wg[k]·τ_cmd/(C·K_pair·kStage)`（经肌肉对刚度换算，钳 ±LCLAMP）→ `commandMusclePair(dof, C, λ)`；
4. C（张力档）= 分轴分侧常档 + `KC·|dev|`——肌肉对刚度来源（非方向参数）；
5. **盆骨通道（腹部两侧肌肉）**：信号 `dy = 承重髋高 − 摆动髋高`（+ 速率低通）；需求矩 `τ_pelv = B（常档基础力矩）+ P_dir·dy + D_dir·dyd`；输出 = 加到腰段(spine1)轴0 的 λ（盆骨通道全责在腰；肌肉对 f1−f2 **天然"一侧多发力"**），钳 ±0.05。（用户定调："腹部两侧肌肉给盆骨服务——把盆骨拉到水平位置，处理摆动腿处下跌"+"摆动腿侧的需要基础力矩"；B 符号实测标定。）
6. **轴1（旋转）通道**：单腿成立时捕获初始朝向 `sp0T`；需求矩 `τ_need1 = −KROT·(转角误差 + TAUR·角速度)`（回初始朝向）；同"基础力矩+修正"逐方向结构；（用户定调："轴1也要发力——把身体转回初始位置"。）

通道 = 肌肉对 → **申请制**（pairCap 脊柱=470）；单向阻尼 / 弧度生长 / F0 张力全走 drive 内建（用户："不需要再改"）。生效：单腿相 && `standardPose` 已建立 && `!upperOff()`；调用点 = stepPhases B 相 + C 保持。★ 无第二套实现（时间不作优化目标）。

**当前参数**：B 四方向=0（待标定）；G 四方向=1；C0=0.2 / C2=0.4；LCLAMP=0.08；WG=0.2,1,1。（对照记录见《对照实验》§8-9。）

**脚/踝结论（用户定调 + 冻结实测）**：上身稳定时脚/踝自身完全稳定（冻结态支撑 fz 700±19N、髋角 ±0.02°）→ **不再动脚/踝**；问题框架 = 上身通道 + 骨盆-腿闭环。

## 8. 单腿发力统一式（2026-10-15 定稿；用户："所有关节=能维持稳定的默认力+小幅度回正力"）

**式（所有已改关节）**：
```
λ = θ₀（单腿成立捕获的初始位置）
  + B0（默认力，N·m，静态常数——来自冻结实测/对照标定，**不动态变化**）
  + 小幅度回正（限速+低通+钳制；如髋横=dy 律、髋矢=pitch 律）
经者：commandMusclePair（肌肉对/EP 模型）→ 提案总线（申请制）→ 唯一施加
```

**已标定默认力（冻结实测净值为准）**：
| 轴 | B0 | 依据 |
|---|---|---|
| 支撑髋·轴0（横） | **64.5 N·m** | 冻结实测净值 64.5±1.9（pitch 4.9°、roll 7.0°、2.11s） |
| 支撑髋·轴2（矢） | **70 N·m** | 冻结净值 −67.8±0.1（本阶段最佳：2.32s、pitch 28→9.5°） |
| 膝/踝 | 0（式已就位，待填冻结值） | rollout 待办 |

**配套机制**（同日）：
- **提案制全收编**：upperBase/supportColumn/stepPhases 全部提案化，全库零直写（manual=直控通道设计内）；提案总线：直控100>反射60>动作40>伺服20，逐轴仲裁、统一施加。
- **救援默认归零**：盆骨职责迁入支撑柱清洁 dy 律（低通/限速/钳制）。
- **大腿 λ 显式上限**（±0.5）+ 接触容量信封（`_footCap=fz×足宽×0.8`）。
- **脚=两种力**：向上=腿柱保持（θ₀+B0+接触反力，被动）；侧向（含矢状）=踝 CoM 权限回正（CoP 向量式，四方向一体）。
