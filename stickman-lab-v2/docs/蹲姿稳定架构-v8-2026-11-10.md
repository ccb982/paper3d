## 2. CoP 安全区

脚内不是一个点，是一个小区域：

```text
inner：安全
warn：接近边界
rescue：出区域
```

建议：

```text
safe = 0.45 × foot half
warn = 0.70 × foot half
rescue = 0.85 × foot half
```

原则：

```text
出区域就得救
快出脚再救肯定救不回来
```

## 4. CoP controller

目标：

```text
support CoP = foot center
swing CoP = 轻微侧偏
```

控制：

```text
e = copTarget − cop
tau = kp·e − kd·copVel
```

输出：

```text
ankle PD
shank PD
foot PD
```

约束：

```text
CoP 必须在脚内
F_lat ≤ μ·Fz
ankle torque cap
```

## 5. 髋/大腿

输入：

```text
CoM
support CoP margin
```

许可：

```text
comRange = k·copMargin
```

规则：

```text
CoM 只能在 comRange 内
超出 comRange：不追
```

髋/大腿一般不参与救急：

```text

```

## 6. 上身

输入：

```text

```

许可：

```text

```

规则：

```text

```

## 25. 论文：髋/大腿受力复杂（2026-11-10）

### 25.1 髋接触力不是常数

```text
bodyweight squat: hip JCF ≈ 2.5–3.0 BW
single-leg squat: hip JCF ≈ 8.4 BW
```

https://pmc.ncbi.nlm.nih.gov/articles/PMC12289039

### 25.2 髋接触力随动作变化

```text
bounce squat vs standard squat
hip JCF 更高
主要来自 hamstrings + gluteus maximus
```

https://pmc.ncbi.nlm.nih.gov/articles/PMC13020382

### 25.3 髋伸力矩由多肌群分担

```text
gluteus maximus
hamstrings
adductors
```

https://pubmed.ncbi.nlm.nih.gov/33136769

### 25.4 躯干角度会重分配髋/膝力矩

```text
躯干直立：膝屈矩↑，髋屈矩↓
躯干前倾：髋屈矩↑，膝屈矩↓
```

https://pmc.ncbi.nlm.nih.gov/articles/PMC10987311

### 25.5 大腿是双关节耦合

```text
hamstrings / rectus femoris
同时跨髋、膝
髋伸策略会改变股四头肌用力
```

https://pubmed.ncbi.nlm.nih.gov/25895990

### 25.6 结论

```text
髋/大腿受力：
  多肌群
  多关节
  随蹲深/躯干/速度/负载变化
```

不是静态标量。

### 25.7 对 base 的含义

```text
hip base 必须随高度/躯干/CoM 修正
小腿/踝/脚 base 可以慢变
```

