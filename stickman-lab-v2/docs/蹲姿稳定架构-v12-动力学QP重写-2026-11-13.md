## 3. 核心依赖

没有 Body 三量，QP 就是假的。

### 3.1 massMatrixBlock

```ts
massMatrixBlock(axes: number[], out: Float64Array): void
```

只算指定轴子块：

```text
hip2, knee2, foot2
```

必须包含耦合项：

```text
M_ij
```

不能用 `jointInertia` 对角代替。

### 3.2 pointJacobian

```ts
pointJacobian(px, py, pz, out: Float64Array): void
```

任意世界点的 3×n 雅可比。

脚接地时用互补侧逻辑，和 `comJacobianComplement` 一致。

这是 `Jc` 的唯一来源。

### 3.3 biasForce

```ts
biasForce(out: Float64Array): void
```

```text
h = C(q,qd)qd + g(q)
```

第一版允许：

```text
h ≈ gravityComp
```

但接口必须存在，并标 TODO：

```text
Coriolis 未进
```

## 4. QP 变量

```text
x = [
  qdd_h, qdd_k, qdd_f,
  tau_h, tau_k, tau_f,
  fn_L, ft_L,
  fn_R, ft_R
]
```

共 10 维。

## 5. QP 目标

```text
min
  wCom * ||J_com qdd + Jd_com qd - a_com*||²
+ wPosture * ||qdd - qdd*||²
+ wTau * ||tau - tau*||²
+ wF * ||f - f*||²
```

```text
a_com* = Kp(com* - com) - Kd(comVel)
```

CoM 必须包含：

```text
x
y
z
```

## 6. QP 约束

### 6.1 动力学

```text
M qdd + h = S^T tau + Jc^T f
```

3 条。

### 6.2 接触

```text
Jc qdd + Jc_dot qd = 0
```

4 条。

### 6.3 摩擦锥

```text
|ft| <= mu * fn
```

4 条。

### 6.4 力矩界

```text
tau_min <= tau <= tau_max
```

6 条。

### 6.5 法向力

```text
fn >= 0
```

2 条。

## 7. CoP

CoP 不是 QP 变量。

```text
CoP = f(fn, ft, contact points)
```

约束：

```text
cop_min <= CoP <= cop_max
```

竖直方向由：

```text
fn
```

控制，不由 CoP 控制。
