## 4. 两个 QP

### 4.1 CoP QP

先解接触层。

变量：

```text
f = [fx, fz]
tau_ankle
```

目标：

```text
min ||cop(f) - cop*||² + wf||f - f0||²
```

约束：

```text
cop_min <= cop(f) <= cop_max
fz >= 0
|fx| <= mu fz
|tau_ankle| <= tau_max
```

输出：

```text
f
tau_ankle
```

CoP 是二维：

```text
x, z
```

竖直方向由 `fz` 管，不由 CoP 管。

### 4.2 CoM QP

后解近端。

变量：

```text
qdd_prox
tau_prox
```

目标：

```text
min ||J_com qdd - a_com*||² + wtau||tau_prox||²
```

动力学：

```text
M_prox qdd + h_prox = tau_prox + Jc^T f
```

`f` 来自 CoP QP。

任务：

```text
CoM x
CoM y
CoM z
```

`CoM y` 必须有，否则髋/腿会上顶。

约束：

```text
tau_min <= tau_prox <= tau_max
qdd_min <= qdd_prox <= qdd_max
```

输出：

```text
tau_hip
tau_knee
```

## 14. 被动刚度/阻尼实现

### 14.1 论文结论

```text
Hill 型肌肉 = 被动弹性 + 阻尼
对拉肌在 co-contraction 时提高刚度/阻尼
无激活时对拉退化为关节弹簧
```

- Heitmann 2012：对拉肌共收缩提高阻尼/刚度  
  https://www.frontiersin.org/journals/neurorobotics/articles/10.3389/fnbot.2011.00005/full
- Günther 2007：串联阻尼不能省  
  https://pubmed.ncbi.nlm.nih.gov/17598125
- 被动 Hill 参数估计  
  https://pubmed.ncbi.nlm.nih.gov/24290234

### 14.2 推荐

```text
不做对拉
做关节级被动弹簧-阻尼
```

原因：

```text
PD 不允许主动发力
无激活的对拉等价于关节弹簧
对拉只增加参数和状态
```

### 14.3 确定性实现

```text
e = q - q_ref
e = softzone(e, dead)
tau_passive = -k * e
tau_damp = -b * qd
tau = clamp(tau_passive + tau_damp, -cap, cap)
```

```text
softzone(e, dead) =
  0                     |e| <= dead
  sign(e)*(|e|-dead)    |e| > dead
```

### 14.4 参数

```text
k, b, dead, q_ref, cap
```

每关节固定，不做状态机，不做 gain。

### 14.5 对拉式

```text
l1 = l0 + r*q
l2 = l0 - r*q
F_i = k_i*softzone(l_i-l_rest) + b_i*ldot_i
tau = r*(F1 - F2)
```

只作为可选扩展；当前架构不启用。

```text
先控 GRF / CoP
```

指出 Lee/Goswami 把接触力和关节加速度分成两个优化问题：

```text
更容易解
```
