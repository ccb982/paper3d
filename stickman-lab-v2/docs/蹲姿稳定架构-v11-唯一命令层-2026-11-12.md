### 2.3 PD 纪律

```text
不得自主回正
不得位置伺服
只执行命令层 tau
本地只加阻尼 + 关节张力
```

PD 公式：

```text
tau_joint = tau_cmd
          + tau_damp
          + tau_tension
```

`tau_damp`、`tau_tension` 有上限，不参与 CoM/CoP 决策。

唯一出口：

export interface SquatCommand {

约束：

```text

```

## 4. 两个 QP

### 4.1 CoP QP

先解接触层。

变量：

```text
f = [fx, fz]
tau_ankle
```

目标：

```text
min ||cop(f) - cop*||² + wf||f - f0||²
```

约束：

```text
cop_min <= cop(f) <= cop_max
fz >= 0
|fx| <= mu fz
|tau_ankle| <= tau_max
```

输出：

```text
f
tau_ankle
```

CoP 是二维：

```text
x, z
```

竖直方向由 `fz` 管，不由 CoP 管。

### 4.2 CoM QP

后解近端。

变量：

```text
qdd_prox
tau_prox
```

目标：

```text
min ||J_com qdd - a_com*||² + wtau||tau_prox||²
```

动力学：

```text
M_prox qdd + h_prox = tau_prox + Jc^T f
```

`f` 来自 CoP QP。

任务：

```text
CoM x
CoM y
CoM z
```

`CoM y` 必须有，否则髋/腿会上顶。

约束：

```text
tau_min <= tau_prox <= tau_max
qdd_min <= qdd_prox <= qdd_max
```

输出：

```text
tau_hip
tau_knee
```

## 8. 迁移顺序

### 第 1 步：唯一出口

```text

其他写路径降为只读
```

判据：

```text

```

### 第 2 步：CoP QP

```text

```

```text

```

### 第 3 步：重切 PD

```text

DistalPD: shank + ankle + foot
```

判据：

```text
每块 PD 只拿到自己链上的 dof
```

### 第 4 步：PD 融合态

```text

```

删除：

```text

SQC_QP_TOTAL
```

判据：

```text

```

### 第 5 步：上身参数接入 CoM QP

```text
upperTaskPD 保留

```

判据：

```text
髋 QP 能感知上身质量/CoM 偏移

```
