## 13. 人腿感受的是什么

### 13.1 局部感受

脚/小腿能直接感受：

```text
脚底压力
足底剪切
关节角
肌肉长度/张力
关节运动
```

不能直接感受：

```text
全身 COM
XCoM
```

### 13.2 重心

COM 是中枢估计：

```text
脚底压力
本体感觉
前庭
视觉
→ 中枢融合
```

不是某个小腿局部感受器。

### 13.3 论文

```text
Kavounoudias et al. 1998
  foot sole mechanoreceptors / pressure distribution

Roll et al. 2002
  plantar cutaneous inputs and balance

Proske & Gandevia 2012
  proprioception: muscle spindles / joint / force

Peterka 2002
  multisensory integration

Horak & Nashner 1986
  local ankle/hip strategies
```

### 13.4 结论

```text
脚/小腿：只能感受局部压力、关节角、倾斜
COM/XCoM：中枢估计，不是局部传感器
```

所以：

```text
local PD 只看角度/接触残差
COM 不进入脚/小腿 PD
```

## 26. 为什么小腿偏了但不回正


```text

```

### 26.2 关键

如果脚和 shank 一起滚：

```text

```

于是：

```text

```

### 26.3 结果


## 51. 脚受力是否全给地面

### 51.1 不是

关节力矩不会自动全部变成地面反力。

只有落在接触锥内的分量：

```text
N ≥ 0
|Ft| ≤ μN
CoP ∈ 脚掌
```

才会变成地面反力。

超出部分会：

```text
转动脚掌
抬起脚
加速脚
```

### 51.2 当前

```text
foot/0=40N·m
foot/2=66N·m
roll=37°
fz 7175 → 0
```

说明：

```text
力矩没有全部传给地面
一部分把脚掌滚起来/踢飞
```

### 51.3 为什么

```text
1. CoP 到边缘
2. 脚掌开始滚
3. 接触面积/摩擦下降
4. fz 掉
5. supportN 继续加 foot/2
6. 正反馈
```

### 51.4 结论

```text
脚不是“把力全给地面”
是力超过接触能力后
变成脚的旋转/离地
```


## 52. 力是否沿小腿与 CoP 居中

### 52.1 条件

如果合力严格沿小腿并通过脚掌中心：

```text
CoP ≈ 脚掌中心
```

如果踝/膝产生额外力矩：

```text
合力线偏离脚中心
CoP 偏移
```

### 52.2 当前

```text

foot/2=66N·m

```

说明：

```text

踝力矩把力线拉偏
```

### 52.3 让 CoP 居中

方法：

```text
1. 目标 CoP = 脚掌中心
2. 踝力矩只做 CoP 误差反馈
3. 膝/髋把合力线移到脚中心
```

## 53. 踝发力的方向

### 53.1 论文

```text
Winter 1995
  踝力矩控制 CoP
  GRF 从 CoP 指向 CoM

Hof 2005
  XCoM/CoP 关系

Neptune & Perry 2019
  跖屈肌推进 CoM

Caron 2019
  接触力必须满足接触约束
```

### 53.2 关键

踝肌肉产生的是：

```text
关节力矩
```

不是：

```text
一个可任意指定方向的力
```

地面反力方向由：

```text
CoP → CoM
摩擦
脚掌接触
```

决定。

### 53.3 “指向 CoP”是什么意思

CoP 是：

```text
地面反力作用点
```

不是力矩方向。

踝力矩改变 CoP：

```text
τankle → CoP 偏移
```

不是：

```text
踝力沿 CoP 方向推
```

### 53.4 为什么会飞

如果踝力矩超过接触能力：

```text
脚掌滚转
CoP 到边缘
N/摩擦下降
→ 脚离地
```

不是因为“踝力方向错”，而是：

```text
力矩把脚掌滚起来
```

### 53.5 结论

```text
踝发力方向：关节力矩
GRF 方向：CoP→CoM
不是踝力直接指向 CoP

脚飞：力矩超过接触能力
```


## 54. 侧向踝正确时不应让脚飞

### 54.1 用户判断

```text
如果侧向踝设计正确
不应该这么容易让脚飞
```

正确。

### 54.2 当前问题

当前侧向踝是：

```text
foot/0 = 角度 PD
```

输出可到：

```text
40N·m
```

但没有 CoP 反馈/限制。

结果：

```text
力矩超过脚掌接触能力
→ 脚掌滚转
→ 飞
```

### 54.3 正确侧向踝

侧向踝应该以 CoP 为物理约束：

```text

τlat = -Kcop·eCop - B·foot0Rate
```

并限制：

```text
|τlat| ≤ N · marginZ
```

当 CoP 到边缘：

```text
τlat 饱和
脚掌不再滚
```

不是继续加角度 PD。

### 54.4 结论

```text
侧向踝设计正确：
  以 CoP/接触为约束
  不是裸角度 PD

当前：
  角度 PD 直接 40N·m
  没有 CoP 限幅
  → 脚飞
```

## 67. 6N·m 为什么还会侧翻

```text
τ = N · ΔCoP
```


```text

```

```text

```


## 75. 方向对但为什么没变化

### 75.1 数据

```text
t=0.50 tilt=-8.0  foot/0=-28.3 footRoll=-8.0 fz=475
t=0.54 tilt=-11.6 foot/0=-32.8 footRoll=-23.2 fz=264
t=0.58 tilt=-19.7 foot/0=0.0  footRoll=-27.3 fz=0
```

方向是对的，但：

```text
tilt 继续变负
footRoll 继续变负
fz 掉到0
```

### 75.2 原因

踝力矩是内力：

```text
踝力矩 = 脚 ↔ 小腿 力偶
```

如果脚没有稳定接触：

```text
力矩先转脚
不是转小腿
```

结果：

```text
foot/0 越大
footRoll 越大
fz 越小
→ 力矩没有外部反力
```

### 75.3 结论

```text
方向对 ≠ 能改变小腿
```

需要：

```text
脚掌接触
CoP 在脚掌内
N/摩擦
```

才能把踝力矩变成小腿/身体的回正。

### 75.4 当前失败链

```text
踝力矩
→ 脚掌滚
→ fz=0
→ 脚离地
→ 力矩没有作用点
```


## 76. 初始触地为何不能持续回正

### 76.1 初始触地

```text
t=0 N>0
```

只说明：

```text
脚底一开始有接触
```

不代表：

```text
踝力矩可以持续增加
```

### 76.2 接触能力

```text
τ ≤ N · CoP_margin
```

初始 N 大，但：

```text
marginZ 只有约4.7cm
N≈500N
→ 最大约23N·m
```

如果踝输出到：

```text
28~33N·m
```

已经超过接触能力：

```text
CoP 到边缘
→ 脚掌滚
→ N 下降
→ 能力更低
```

### 76.3 正反馈

```text
τ 大
→ 脚滚
→ margin 更小
→ cap 更小
→ 接触更差
```

### 76.4 结论

```text
初始触地：是
持续回正：不行
原因：踝力矩超过脚掌当前 CoP margin
```

要持续回正：

```text
τ踝 ≤ N·margin
+ 脚掌压力分配
+ 超出转 knee/hip
```

## 80. 目标姿态具体怎么算

### 80.1 捕获

释放瞬间：

```text
sag0 = atan2(kneeX − ankleX, kneeY − ankleY)
```

左右取平均：

```text
targetSag = (sag0_L + sag0_R) / 2
```

脚：

```text
targetFoot0 = average(foot0_L, foot0_R)
targetFoot2 = average(foot2_L, foot2_R)
```

侧向：

```text
targetTilt = 0
```

### 80.2 目标膝位置

给定踝 A、小腿长 Ls：

```text
K*_x = A_x + Ls·sin(targetSag)
K*_y = A_y + Ls·cos(targetSag)
K*_z = A_z
```

### 80.3 关键

`targetSag` 来自释放瞬间的当前小腿角。

所以释放时：

```text
K* = 当前 K
```

目标线和当前小腿线重合。

### 80.4 画出来是什么

```text
脚位置：当前
脚掌角：当前
小腿目标线：当前小腿方向
```

也就是：

```text
目标姿态 = 释放瞬间姿态快照
```

不是：

```text
独立设计的正确蹲姿
```

### 80.5 结论

```text
目标不是“理想姿态”
目标只是“保持释放瞬间的小腿方向”
```

如果释放姿态本身内收/歪，目标也跟着错。
