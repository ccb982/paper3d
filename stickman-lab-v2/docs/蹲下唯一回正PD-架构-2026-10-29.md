## 13. 人腿感受的是什么

### 13.1 局部感受

脚/小腿能直接感受：

```text
脚底压力
足底剪切
关节角
肌肉长度/张力
关节运动
```

不能直接感受：

```text
全身 COM
XCoM
```

### 13.2 重心

COM 是中枢估计：

```text
脚底压力
本体感觉
前庭
视觉
→ 中枢融合
```

不是某个小腿局部感受器。

### 13.3 论文

```text
Kavounoudias et al. 1998
  foot sole mechanoreceptors / pressure distribution

Roll et al. 2002
  plantar cutaneous inputs and balance

Proske & Gandevia 2012
  proprioception: muscle spindles / joint / force

Peterka 2002
  multisensory integration

Horak & Nashner 1986
  local ankle/hip strategies
```

### 13.4 结论

```text
脚/小腿：只能感受局部压力、关节角、倾斜
COM/XCoM：中枢估计，不是局部传感器
```

所以：

```text
local PD 只看角度/接触残差
COM 不进入脚/小腿 PD
```

## 26. 为什么小腿偏了但不回正


```text

```

### 26.2 关键

如果脚和 shank 一起滚：

```text

```

于是：

```text

```

### 26.3 结果


## 51. 脚受力是否全给地面

### 51.1 不是

关节力矩不会自动全部变成地面反力。

只有落在接触锥内的分量：

```text
N ≥ 0
|Ft| ≤ μN
CoP ∈ 脚掌
```

才会变成地面反力。

超出部分会：

```text
转动脚掌
抬起脚
加速脚
```

### 51.2 当前

```text
foot/0=40N·m
foot/2=66N·m
roll=37°
fz 7175 → 0
```

说明：

```text
力矩没有全部传给地面
一部分把脚掌滚起来/踢飞
```

### 51.3 为什么

```text
1. CoP 到边缘
2. 脚掌开始滚
3. 接触面积/摩擦下降
4. fz 掉
5. supportN 继续加 foot/2
6. 正反馈
```

### 51.4 结论

```text
脚不是“把力全给地面”
是力超过接触能力后
变成脚的旋转/离地
```


## 52. 力是否沿小腿与 CoP 居中

### 52.1 条件

如果合力严格沿小腿并通过脚掌中心：

```text
CoP ≈ 脚掌中心
```

如果踝/膝产生额外力矩：

```text
合力线偏离脚中心
CoP 偏移
```

### 52.2 当前

```text

foot/2=66N·m

```

说明：

```text

踝力矩把力线拉偏
```

### 52.3 让 CoP 居中

方法：

```text
1. 目标 CoP = 脚掌中心
2. 踝力矩只做 CoP 误差反馈
3. 膝/髋把合力线移到脚中心
```

## 53. 踝发力的方向

### 53.1 论文

```text
Winter 1995
  踝力矩控制 CoP
  GRF 从 CoP 指向 CoM

Hof 2005
  XCoM/CoP 关系

Neptune & Perry 2019
  跖屈肌推进 CoM

Caron 2019
  接触力必须满足接触约束
```

### 53.2 关键

踝肌肉产生的是：

```text
关节力矩
```

不是：

```text
一个可任意指定方向的力
```

地面反力方向由：

```text
CoP → CoM
摩擦
脚掌接触
```

决定。

### 53.3 “指向 CoP”是什么意思

CoP 是：

```text
地面反力作用点
```

不是力矩方向。

踝力矩改变 CoP：

```text
τankle → CoP 偏移
```

不是：

```text
踝力沿 CoP 方向推
```

### 53.4 为什么会飞

如果踝力矩超过接触能力：

```text
脚掌滚转
CoP 到边缘
N/摩擦下降
→ 脚离地
```

不是因为“踝力方向错”，而是：

```text
力矩把脚掌滚起来
```

### 53.5 结论

```text
踝发力方向：关节力矩
GRF 方向：CoP→CoM
不是踝力直接指向 CoP

脚飞：力矩超过接触能力
```


## 54. 侧向踝正确时不应让脚飞

### 54.1 用户判断

```text
如果侧向踝设计正确
不应该这么容易让脚飞
```

正确。

### 54.2 当前问题

当前侧向踝是：

```text
foot/0 = 角度 PD
```

输出可到：

```text
40N·m
```

但没有 CoP 反馈/限制。

结果：

```text
力矩超过脚掌接触能力
→ 脚掌滚转
→ 飞
```

### 54.3 正确侧向踝

侧向踝应该以 CoP 为物理约束：

```text

τlat = -Kcop·eCop - B·foot0Rate
```

并限制：

```text
|τlat| ≤ N · marginZ
```

当 CoP 到边缘：

```text
τlat 饱和
脚掌不再滚
```

不是继续加角度 PD。

### 54.4 结论

```text
侧向踝设计正确：
  以 CoP/接触为约束
  不是裸角度 PD

当前：
  角度 PD 直接 40N·m
  没有 CoP 限幅
  → 脚飞
```

## 67. 6N·m 为什么还会侧翻

```text
τ = N · ΔCoP
```


```text

```

```text

```


## 75. 方向对但为什么没变化

### 75.1 数据

```text
t=0.50 tilt=-8.0  foot/0=-28.3 footRoll=-8.0 fz=475
t=0.54 tilt=-11.6 foot/0=-32.8 footRoll=-23.2 fz=264
t=0.58 tilt=-19.7 foot/0=0.0  footRoll=-27.3 fz=0
```

方向是对的，但：

```text
tilt 继续变负
footRoll 继续变负
fz 掉到0
```

### 75.2 原因

踝力矩是内力：

```text
踝力矩 = 脚 ↔ 小腿 力偶
```

如果脚没有稳定接触：

```text
力矩先转脚
不是转小腿
```

结果：

```text
foot/0 越大
footRoll 越大
fz 越小
→ 力矩没有外部反力
```

### 75.3 结论

```text
方向对 ≠ 能改变小腿
```

需要：

```text
脚掌接触
CoP 在脚掌内
N/摩擦
```

才能把踝力矩变成小腿/身体的回正。

### 75.4 当前失败链

```text
踝力矩
→ 脚掌滚
→ fz=0
→ 脚离地
→ 力矩没有作用点
```

## 80. 目标姿态具体怎么算

### 80.1 捕获

释放瞬间：

```text
sag0 = atan2(kneeX − ankleX, kneeY − ankleY)
```

左右取平均：

```text
targetSag = (sag0_L + sag0_R) / 2
```

脚：

```text
targetFoot0 = average(foot0_L, foot0_R)
targetFoot2 = average(foot2_L, foot2_R)
```

侧向：

```text
targetTilt = 0
```

### 80.2 目标膝位置

给定踝 A、小腿长 Ls：

```text
K*_x = A_x + Ls·sin(targetSag)
K*_y = A_y + Ls·cos(targetSag)
K*_z = A_z
```

### 80.3 关键

`targetSag` 来自释放瞬间的当前小腿角。

所以释放时：

```text
K* = 当前 K
```

目标线和当前小腿线重合。

### 80.4 画出来是什么

```text
脚位置：当前
脚掌角：当前
小腿目标线：当前小腿方向
```

也就是：

```text
目标姿态 = 释放瞬间姿态快照
```

不是：

```text
独立设计的正确蹲姿
```

### 80.5 结论

```text
目标不是“理想姿态”
目标只是“保持释放瞬间的小腿方向”
```

如果释放姿态本身内收/歪，目标也跟着错。

## 82. 软限位统一收敛到两个 PD（2026-10-31）

### 82.1 原则

软限位不再由独立的 `squatLateralLimit` 硬夹关节，而是进入两个 PD 的目标和力矩：

```text
HipTaskPD:
  hip/0
  knee/2

ShankTaskPD:
  knee/0（膝内外翻 / 侧向）
  knee/1（膝轴向旋转）
  foot/0
  foot/2
```

### 82.2 形式

每个关节维护一组姿势相关限位：

```text
q_lo(pose), q_hi(pose)
```

PD 内部：

```text
q*_safe = clamp(q*, q_lo + margin, q_hi - margin)
τ = -Kq·(q - q*_safe) - Dq·q̇
```

接近限位时增加软约束力矩：

```text
q < q_lo: τ_limit = -Klim·(q - q_lo) - Dlim·q̇
q > q_hi: τ_limit = -Klim·(q - q_hi) - Dlim·q̇
```

再与任务力矩合成，不另开写手。

### 82.3 姿势限位

限位由当前阶段决定：

```text
stand
court_freeze
court_released
fallen
```

并随阶段做渐变，禁止一帧跳变。

### 82.4 硬限位

硬限位只保留为最后安全边界，不再参与日常回正。日常回正全部由两个 PD 的软限位完成。

### 82.5 取消的层

```text
squatLateralLimit 的硬夹
```

不再作为蹲姿回正层写手。

## 83. 脚部统一与贴地优先（2026-10-31）

### 83.1 原则

脚不是三个独立关节，而是一组统一接触结构：

```text
foot_*
arch_*
mfoot_*
```

它们必须服从同一个足底目标，不能各自维护目标。

### 83.2 最高优先级

```text
贴地
```

贴地包括：

```text
法向接触
CoP 在支撑面内
不滑移
不侧翻
```

脚部任何关节动作都不得破坏贴地。贴地优先级高于：

```text
踝角
arch 压力目标
mfoot 目标
关节软限位
```

### 83.3 次级任务

贴地满足后，脚部关节只做有限范围内的活动：

```text
foot/0、foot/1、foot/2
arch/0
mfoot/0
```

它们用于：

```text
压力分配
CoP 调整
足弓缓冲
```

不是独立回正写手。

### 83.4 控制归属

```text
HipTaskPD：
  hip/0、knee/2

ShankTaskPD：
  knee/1、foot/0、foot/1、foot/2 的目标角与软限位

足底统一层：
  foot/arch/mfoot 的接触目标
```

`arch` 和 `mfoot` 不再由单独的压力环独立驱动。

### 83.5 预载

冻结期最后阶段：

```text
arch 目标固定
mfoot 目标固定
足底接触目标建立
```

释放后：

```text
接触目标先保持
foot/arch/mfoot 一起渐入
```

禁止：

```text
arch 单独先动
mfoot 保持旧目标
foot 关节单独硬拉
```

### 83.6 结论

```text
脚部第一任务：贴地
第二任务：在贴地前提下活动脚部肌肉
```

任何脚部控制如果让 CoP 出支撑面、脚掌滚动或 fz 跳变，都视为失败。

```text
τ_ankle_ff = J_ankleᵀ·F_support
```

```text
τ_ankle_fb = -Kp·(q - q*) - Kd·q̇
```

刚度随负载：

```text
Kp = K0 + Kload·|F_support|
```

中段软，接近限位快速变硬。

### 103.5 力链

```text

→ 膝/小腿
```

## 109. 运行时力链闭合（2026-10-31）

```text
N_total <= 可支撑总量

同一关节只有一个主动写手
```


目标不是“静态算出来闭合”，而是“实际运行时每帧都闭合”。

|---|---|---|---|
| 接触丢失 | fz 掉到 0 | contact/fz | 取消脚位置目标，腿找地 |

```text
τ_req = Jᵀ · F_support
```

执行条件：

```text
xHipError = hip.x - supportCenter.x
```

## 118. 髋-踝协同修正小腿侧向（2026-11-01 定稿）

本节是髋/踝侧向协同的唯一真源；此前 §17/§81 中把 `knee/1` 当侧向主写手的表述作废。

### 118.1 解剖职责

```text
hip/0   髋外展/内收：大腿带着整条小腿侧向移动（主权限）
knee/0  膝内外翻：小腿相对大腿的额状面修正（次权限）
knee/1  膝轴向旋转：不是侧向主写手
foot/0  踝内外翻：足底局部侧向辅助（小权限）
```

### 118.2 权限层级

```text
髋/大腿 > 小腿 > 踝
```

不是三个写手各算一套侧向目标。

```text
HipTaskPD:
  髋高度 + 髋倾斜 + COM/XCoM（消费，不直接覆盖髋高度目标）
  → hip/0 主侧向
  → H*(t) 目标髋位置

ShankIK:
  实际脚踝 A(t) + H*(t)
  → knee/0、foot/0 每帧 IK 目标

ShankTaskPD:
  只追 IK 的 knee/0、foot/0 目标
  → foot/0 小权限辅助
```

### 118.3 禁止

```text
HipTaskPD 直接写 foot/0
ShankTaskPD 反向覆盖 hip/0 主目标
用固定释放角代替每帧 IK
把 knee/1 当侧向主写手
用 CoM/CoP 替代髋高度/髋倾斜的本地回正
```

### 118.4 侧向 IK

```text
A(t) = 实际脚踝
H*(t) = HipTaskPD 输出的目标髋位置
  ↓
targetHip0 / targetKnee0 / targetFoot0
  ↓
HipTaskPD（hip/0）与 ShankTaskPD（knee/0、foot/0）各写自己的轴
```

髋通过改变 `H*` 影响小腿目标；踝只在 IK 目标内做小范围修正，不能反向夺走髋的主权限。

### 118.5 输出归属

```text
hip/0    HipTaskPD
knee/0   ShankTaskPD
knee/1   ShankTaskPD（轴向）
foot/0   ShankTaskPD（小权限）
```

同一轴不允许第二个主动写手；同一任务力可以分层，但输出必须单一 owner。

### 118.6 验收

```text
H*(t) 随髋高度/倾斜变化
A(t) 不变时，H* 侧移会改变 targetKnee0/targetFoot0
foot/0 的输出始终小于 hip/0 的主侧向权限
小腿侧偏时 knee/0 先出中等力，踝只补小力
不出现 hip/0 与 foot/0 对拉
```

## 119. 髋-膝 IK 一致性：大腿修正必须带动膝盖，且小腿不侧移（2026-11-01 定稿）

本节是 §118 的补充：**大腿的侧向修正也必须通过同一个 IK 解，不能给 knee/0 再写一个独立目标。**

### 119.1 唯一任务源

```text
HipTaskPD:
  目标髋内收/外展
  → H*(t)（目标髋位置）

ShankIK:
  实际脚踝 A(t)
  + H*(t)
  → targetKnee0(t)
  → targetFoot0(t)

ShankTaskPD:
  只执行 targetKnee0(t)/targetFoot0(t)
```

髋不能直接写 `knee/0`。髋只能改变 `H*`，膝盖目标由 IK 从 `H*` 解出。

### 119.2 髋内收必须改变膝盖目标

```text
targetHipAdduction
→ H*.z = refHip.z + Khip × (targetHipAdduction - refHipAdduction)
→ targetKnee0 = IK(A(t), H*(t))
```

如果 `H*.z` 变了但 `targetKnee0` 不变，说明 IK 链路断了。

### 119.3 最优目标：小腿不产生独立侧移

```text
脚接地时：A(t) 由脚目标/接触决定
髋移动时：H* 带动腿链 IK
约束：shank lateral target = 0（相对脚/世界参考）
```

不允许：

```text
髋移动后，ShankTaskPD 再自行制造一个侧向偏移
髋和踝各写一个不同的小腿侧向目标
```

正确顺序：

```text
大腿/髋决定 H*
→ IK 解出膝/踝目标
→ 膝/踝只追解
→ 小腿没有额外侧移自由度
```

### 119.4 权限

```text
hip/0：大权限，决定 H*.z
knee/0：次级，执行 IK 目标
foot/0：小权限，只补接触/局部残差
knee/1：轴向旋转，不参与侧向
```

这是权限层级，不是三个独立 PD。

### 119.5 写手归属

```text
HipTaskPD:   hip/0、hip/2
ShankTaskPD: knee/0、knee/1、foot/0、foot/1、foot/2
```

`hip/0` 只写髋；`knee/0` 只写 Shank。二者通过 `H*` 耦合，不直接对写同一轴。

### 119.6 验收

```text
H*(t) 随髋内收目标变化
targetKnee0(t) 随 H*(t) 变化
actual knee0 跟随 targetKnee0
小腿没有独立侧移目标
hip0 与 foot0 没有反向对拉
```

如果出现：

```text
髋内收、H* 变了、膝盖目标不变
```

就是 IK 一致性未通过，不能继续调 PD 增益。

## 120. HipTaskPD 的支撑侧选择与对侧保护（2026-11-01 定稿）

本节是 HipTaskPD 内部的支撑/预算层，不是新增写手。`hip/0`、`hip/2` 仍只由 HipTaskPD 写。

### 120.1 问题

一侧髋外展/内收会通过骨盆和闭链传到另一条腿；不能左右各跑一个独立 hip PD，否则一侧修正会把另一侧带崩。

### 120.2 支撑侧选择

输入：

```text
左右 fz
左右 CoP margin
XCoM / COM 速度
骨盆 roll
```

输出：

```text
support = 'l' | 'r' | 'both'
```

要求：

```text
带滞回
优先选 fz 足够、CoP 余量大的一侧
XCoM 已明显偏一侧时，优先该侧支撑
```

### 120.3 负载分配

```text
support 侧目标承重：65%~75%
other 侧目标承重：25%~35%
```

通过髋 common/diff、骨盆 target、H* 分配实现，不直接改 N。

```text
τ_support = common + diff
τ_other   = common - diff
```

`diff` 由 support 选择、fz、CoP margin、骨盆 roll 决定。

### 120.4 对侧保护

```text
支撑侧 hip/0：主侧向修正
非支撑侧 hip/0：卸载/防塌，不追同一个 H*
骨盆 roll：闭环抵消支撑侧产生的反力矩
```

禁止：

```text
左右 hip0 同时等幅外展
非支撑侧继续追支撑侧的 H*
把骨盆反力矩直接留给另一条腿承担
```

### 120.5 H* 按侧独立

```text
H*_support：由支撑任务和髋高度决定
H*_other：只做卸载/稳定，不强行跟随支撑侧
```

ShankIK 每侧使用自己的 H*，不允许共用一个 H* 把两条腿绑在一起。

### 120.6 验收

```text
支撑侧 fz 明显增加
非支撑侧 fz 不归零
骨盆 roll 不持续单调
两侧 hip0 不同时同向硬顶
另一条腿没有出现新的侧向失稳
```

如果一侧髋修正导致另一侧 fz 掉到 0 或侧向抖动，说明支撑侧/预算层未通过，不是继续加 hip0 Kp。

## 121. 髋的目标不是点，是合理区间内的最优解（2026-11-01 定稿）

髋高度/侧向不是精确锁死目标；只要在合理区间内都合法，再在合法集合中选回正最优、最居中的解。

### 121.1 可行域

```text
hipY ∈ [yMin, yMax]
hipZ ∈ [zMin, zMax]
hipRoll ∈ [rollMin, rollMax]
```

区间以释放髋高/骨盆中心为基准，允许合理活动范围。

```text
区间内任意髋形态都合法
不是只有一个 targetHipY / targetHipZ
```

### 121.2 目标函数

在可行域内最小化：

```text
w_h · (hipY - yPref)²
+ w_z · (hipZ - zCenter)²
+ w_r · (hipRoll - rollPref)²
+ λ · 关节偏移/力矩
```

其中：

```text
yPref    = 合理高度中心
zCenter  = 支撑中心/骨盆中心
rollPref = 0 附近
```

### 121.3 IK 冗余选择

```text
小腿目标给 K*
|H* - K*| = L1
H* 是圆上的点
在圆与髋可行域的交集中选最优 H*
```

优先级：

```text
1. 脚接触/小腿目标
2. 髋在可行域内
3. 髋尽量居中、接近 yPref
4. 力矩/关节偏移最小
```

如果圆与可行域无交集：

```text
缩小小腿目标
降低 H* 侧向要求
不允许髋硬顶出可行域
```

### 121.4 与 PD 的关系

```text
HipTaskPD 输出 H*（可行域内最优）
hip0/hip2 只追 H* 对应的目标
ShankIK 用 A(t)+H* 每帧重解 knee/foot
```

不是：

```text
把髋锁死在一个精确高度
把侧向锁死为 0
```

### 121.5 验收

```text
hipY 始终在 [yMin,yMax]
hipZ 不超过 [zMin,zMax]
hipZ 尽量接近支撑中心
区间内无硬顶
H* 变化时 knee 目标每帧变化
```

## 122. 大腿双向侧向回正 + 对侧保护 + 可行域最优（2026-11-01 定稿）

大腿对小腿的侧向回正是**双向**的，同时不能破坏另一条腿。

### 122.1 双向回正

```text
小腿向外偏 → 髋内收方向 H* 回正
小腿向内偏 → 髋外展方向 H* 回正
```

`hip/0` 必须能双向出力，不能用固定一侧符号。

### 122.2 H* 在髋合法区间内

```text
zMin ≤ H*.z ≤ zMax
yMin ≤ H*.y ≤ yMax
rollMin ≤ H*.roll ≤ rollMax
```

区间内任意形态合法；不允许为了回正把髋顶出区间。

### 122.3 优化目标（按优先级）

```text
1. 脚接触 / 小腿目标可行
2. H* 在髋可行域内
3. 改善 COM（尽量接近支撑中心）
4. 髋侧向尽量居中
5. 关节力矩/偏移最小
```

也就是：

```text
先满足脚和髋约束
再选 COM 更优、髋更居中的 H*
```

### 122.4 不破坏另一条腿

```text
支撑侧 hip/0：主回正
对侧 hip/0：卸载/支撑，不追同一个 H*
对侧骨盆 roll：补偿支撑侧反力矩
H* 左右独立，不共用一个目标
```

禁止：

```text
左右 hip0 同时同向硬顶
对侧腿被支撑侧 H* 强行拖动
把支撑侧髋外展反力矩全部传给对侧
```

### 122.5 输出

```text
H*_l / H*_r 各自在合法区间内选优
→ hip/0、hip/2 目标
→ ShankIK 的 targetKnee0
→ knee/0 只执行 IK
```

### 122.6 验收

```text
小腿外侧偏时髋内收
小腿内侧偏时髋外展
H* 始终在合法区间
COM 不因回正变差
髋侧向保持居中
对侧 fz 不归零
两侧 hip0 不同时同向硬顶
```

## 123. 髋-大腿侧向修正的完整几何与力矩（2026-11-01 定稿）

### 123.1 坐标与角度

```text
+z = 左
A(t) = 实际脚踝
K(t) = 实际膝
H(t) = 实际髋
L1 = 大腿长度
L2 = 小腿长度
φ = atan2(K.z - A.z, K.y - A.y)
```

目标：

```text
φ* = 0
```

即小腿不产生独立侧移，膝目标在踝正上方。

### 123.2 左偏/右偏同一目标

```text
小腿偏左：φ > 0
小腿偏右：φ < 0
```

目标统一为：

```text
K* = A + L2·[0, 1]
```

不允许把释放角当侧向目标，也不允许踝额外生成侧向偏移。

### 123.3 由 K* 选 H*

```text
|H* - K*| = L1
yMin ≤ H*.y ≤ yMax
zMin ≤ H*.z ≤ zMax
rollMin ≤ H*.roll ≤ rollMax
```

在圆与髋可行域的交集中：

```text
min w_z(H*.z - zCenter)² + w_y(H*.y - yPref)²
```

髋必须尽量居中、在合理高度；无交集时缩小小腿目标，不允许硬顶。

### 123.4 力矩方向

```text
q_hip* = IK(H*, K*)
τ_hip = Kp(q_hip* - q_hip) - Kd·q̇_hip
```

或 task-space：

```text
F_corr = -Kf·e - Df·ė
τ_hip = J_hipᵀ·F_corr
```

方向由 IK 目标自动给出：

```text
小腿偏左 → K* 向右 → H* 向右 → 左髋内收
小腿偏右 → K* 向左 → H* 向左 → 左髋外展
```

左右镜像，但增益和符号规则相同；不允许 sideSign 改控制符号。

### 123.5 膝必须被 IK 带动

```text
H* 变化
→ ShankIK 重解 A + H*
→ targetKnee0 变化
→ knee/0 PD 追 targetKnee0
```

如果 `H*` 变了而 `targetKnee0` 不变，或 `targetKnee0` 变了而实际 knee0 不动，则分别为 IK 链路断开和 PD 权限/方向错误，不能继续加增益。

### 123.6 对侧保护

```text
support = l/r/both（带滞回）
支撑侧 hip0 主回正
对侧 hip0 只卸载/稳定
骨盆 roll 补偿支撑侧反力矩
H*_l / H*_r 独立
```

禁止：

```text
左右 hip0 同时同向硬顶
一侧 H* 强行拖另一侧
支撑侧反力矩全部留给对侧
```

### 123.7 验收

```text
左偏：K*.z = A.z，H* 右移，左髋内收，targetKnee0 变化
右偏：K*.z = A.z，H* 左移，左髋外展，targetKnee0 变化
H* 在髋可行区间
对侧 fz 不归零
无 hip0/foot0 对拉
```

```text
Horak & Nashner 1986
  hip strategy 是大扰动策略
Winter 1995
  髋外展/load-unload

Hogan 1985
  impedance control：控制刚度/阻尼，不是单一力矩
```

```text
HipTaskPD 不是普通 joint PD
```

```text
comX/comZ       只做预算/监督
```

```text
yMin ≤ hipY ≤ yMax
```

```text
min w_y(hipY-yPref)² + w_z(hipZ-zCenter)²
```

### 124.5 髋高度阻抗

```text
eY = clamp(yPref - hipY, -eYmax, eYmax)
```

### 124.6 髋倾斜/侧向阻抗

```text
eR = clamp(rollPref - hipRoll, -eRmax, eRmax)
τ_r = K_r·eR - D_r·rollDot
```

`hip/0` 负责侧向/骨盆 roll；权限大于膝/踝，但受支撑侧预算限制。

### 124.7 间歇控制

```text
|error| < deadband 且 |vel| < vdead 时保持上一目标/阻尼
|error| 超过 deadband 才更新阻抗输出
方向切换必须满足：
  滞回 + 最小保持时间
```

避免每帧满增益和左右高频切换。

### 124.8 支撑侧与对侧保护

```text
support = l/r/both（带滞回）
支撑侧 hip0 主回正
对侧 hip0 只卸载/稳定
骨盆 roll 抵消支撑侧反力矩
H*_l / H*_r 独立
```

### 124.9 与 ShankIK 的关系

```text
HipTaskPD 选 H*（可行域内的髋目标）
→ ShankIK(A(t), H*)
→ targetKnee0 / targetFoot0
→ ShankTaskPD 只追 IK 目标
```

禁止：

```text
HipTaskPD 直接写 knee/0
ShankTaskPD 在 IK 之外自行加小腿侧移
```

### 124.10 验收

```text
hipY 在高度区间
hipZ 接近支撑中心
髋倾斜不单调
支撑侧 fz 增加，对侧 fz 不归零

三局 fall 不差于 baseline
```

## 125. 被动刚度是突发冲量的第一道防线（2026-11-01 定稿）

突发释放/落地冲量发生时，主动 PD 的反馈来不及；等角度误差出现再回正，身体已经被压塌。第一道防线必须是被动层。

### 125.1 人的机制

```text
被动组织（肌腱/韧带/筋膜/肌肉短程刚度）
  即时吸收冲量
  不依赖神经反馈
主动反馈
  需要感知→决策→肌肉激活
  有 100~200ms 级延迟
```

只有**做好准备/预激活**时，主动层才能在冲量前参与；突发冲量主要靠被动刚度和阻尼。

### 125.2 架构要求

```text
被动层不是可选参数
是承重链的一部分
```

必须提供：

```text
刚度 K
阻尼 B
力/力矩 cap
释放前预载
接近限位非线性变硬
```

不能只有：

```text
低 K、低 cap、零预载
然后等主动 PD 回正
```

### 125.3 被动层位置

```text
现有 Drive/Actuator 被动通道
不新增写手
不与主动 PD 抢 active
```

作用对象：

```text
hip/0、hip/2：侧向/高度预载
knee/2、foot/2：矢状承重兜底
```

### 125.4 与主动层的关系

```text
被动层：先挡住冲量，限制初始位移
主动 PD：在被动层基础上做剩余回正
```

禁止：

```text
用主动 PD 代替被动冲击吸收
用高 K 主动把关节锁死
被动层 cap 太小导致形同虚设
```

### 125.5 验收

```text
释放瞬间关节位移被限制
被动 stiff/damp 通道有实际输出
不出现只靠回正 PD 追冲量
被动层不引起高频振荡
接近限位时刚度上升
```

## 126. 蹲姿被动层配置与优先级（2026-11-01 定稿）

### 126.1 结论


两者不是替代关系：


### 126.2 当前缺口

```text

foot/2：K≈10N·m/rad，cap≈8N·m
```

### 126.3 目标被动参数


## 128. 基础力/被动层/主动 PD 的时间尺度（2026-11-01 定稿）

### 128.1 分工

```text
基础力：承重
被动层：吸收冲击、提高瞬时刚度
主动 PD：小幅、低频修正
```

主动 PD 不能设计成：

```text
每帧满增益
大幅追目标
高频翻号
```

人的意识/长环路反馈来不及修正大量高频偏差；高频部分应由被动刚度和阻尼承担。

### 128.2 时间尺度

```text
被动层：连续、即时（每物理步）
主动 PD：低频/事件触发
  建议 10~20Hz 级更新
  或误差超过死区才更新
  或支撑侧切换时更新
```

主动层必须有：

```text
死区
低通
速率限制
最小保持时间
```

### 128.3 当前问题

当前 `squat` 主动 PD 是每物理步执行，且：

```text
hip0 Kp=1200
foot2 Kp=600
knee/foot 每帧追目标
```

这会导致：

```text
主动层承担了高频修正
与被动层职责重叠
容易翻号、抽搐
```

### 128.4 正确层级

```text
高频/冲量：被动层
低频/持续误差：主动 PD
静载：基础力
```

主动 PD 只处理：

```text
慢漂
支撑侧切换后的剩余误差
姿态目标的可达性修正
```

不去追每一帧的瞬时偏差。

### 128.5 验收

```text
主动 PD 不做高频满幅修正
被动层有实际 stiff/damp 输出
基础力承担主要静载
主动层更新频率明显低于物理步频
```

当前实现与本节不一致：主动 PD 仍然每步高频执行，需要把高频职责移回被动层。

## 129. 软限位强度与 3° 目标力（2026-11-01 定稿）

### 129.1 当前问题

```text
knee/2：3° 约 1.0N·m
foot/2：3° 约 0.5N·m
hip/0、hip/2：无被动
```

相对于蹲姿静态支撑，基本等于没有软限位。

### 129.2 3° 目标软限位力

| 关节 | 3° 目标力 | K_soft |
|---|---:|---:|
| hip/0 | 25~35N·m | 480~670N·m/rad |
| hip/2 | 25~35N·m | 480~670N·m/rad |
| knee/2 | 15~25N·m | 290~480N·m/rad |
| foot/2 | 8~15N·m | 150~290N·m/rad |

计算：

```text
K_soft = τ_target(3°) / 0.05236
```

### 129.3 软限位形态

```text
|e| < 1°：低 K，几乎自由
1°~3°：K 非线性快速上升
3°：达到目标软限位力
>3°：cap 限制，不无限增长
```

公式：

```text
τ_soft = -K_eff(e)·e - B·q̇
K_eff 随 |e| 上升
```

必须有：

```text
弹性
阻尼
有限 cap
```

禁止：

```text
3° 直接无限刚度锁死
硬约束替代软限位
```

### 129.4 层级

```text
关节硬限位：每局只设一次
3° 软限位：被动层，随伺服状态调整
基础力：承重
主动 PD：低频剩余回正
```

### 129.5 验收

```text
3° 偏差时软限位有明显力
卸载后能回位但不强反弹
不出现硬锁死高频
髋/膝/踝软限位都覆盖
```

## 131. 被动刚度总纲（2026-11-01 重写，§126/§127/§129/§130 以本节为准）

### 131.1 定位

```text
把软限位写成硬锁
每帧修改关节硬限位
```

```text
有阻尼
```

不是硬锁，不是无限刚度。

## 132. 大腿发力必须沿小腿（硬约束，2026-11-01 定稿）

本项目规定：髋/大腿的侧向与矢状回正力，其合力方向必须沿小腿轴，不得偏离。

### 132.1 定义

```text
A = 脚踝位置
K = 膝位置
u_shank = normalize(A - K)        // 膝 → 踝
F_thigh = 髋/大腿传到膝的合力
```

硬约束：

```text
F_thigh ∥ u_shank
```

即：

```text
F_perp = F_thigh - (F_thigh · u_shank)u_shank ≈ 0
```

### 132.2 当前问题

回读：

```text
hip → knee ≈ (+0.406, -0.083, +0.078)
knee → ankle ≈ (-0.181, -0.330, -0.025)
```

两者方向明显不平行，当前大腿力线偏离小腿轴。

### 132.3 执行规则

```text
1. 髋/大腿只能沿小腿轴发力
2. 不允许用 hip2/knee2 产生垂直于小腿轴的力
3. 如果 H* 导致力线偏离：
     调整 H* / IK 目标
     不允许继续硬加 hip 力矩
4. 膝/踝只负责把沿轴力链传递下去
```

### 132.4 力矩约束

用关节雅可比：

```text
τ = Jᵀ F
F = J⁻ᵀ τ
```

要求：

```text
|F × u_shank| / max(1, |F|) < tol
```

`tol` 为力线偏差容差。

不满足时：

```text
降低 hip 目标/力矩
重解 H* 与 ShankIK
不在原方向继续加力
```

### 132.5 验收

```text
hip/knee/foot 的合力线沿小腿轴
foot2 不再接近 0
髋偏离 H* 时不产生垂直小腿的力
力链在膝/踝连续
```

这条约束优先于“髋偏离越多、hip2 越大”的简单前馈。

## 134. 生理上的“沿小腿发力”定义（2026-11-01 定稿）

```text
解剖肌肉层面：
  肌纤维/肌腱有各自力线
```

```text
F_perp ≈ 0
```

直接形成正反馈，破坏平衡。



输出：

```text

direction
confidence
```

