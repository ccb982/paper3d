# 蹲下唯一回正 PD 架构（2026-10-29）

> 一个 ShankTaskPD。
> 侧向目标永远是 0；矢状小腿角是唯一需要标定的目标。
> 脚负责承重/摩擦，踝负责调小腿，膝负责支撑高度。

---

## 1. 范围

唯一回正控制器：

```text
ShankTaskPD
```

控制：

```text
小腿
膝
踝/脚（只转接、承重）
```

不碰：

```text
hip/0
hip/2
spine
上盘
Pelvis

```

## 2. 物理链路

```text
脚：接触、N、摩擦、CoP
  ↓
踝：把小腿力转到脚，并调小腿方向
  ↓
膝：支撑高度、腿伸展
```

不是三个独立关节 PD；是一个任务力沿链路分配。

脚不是回正执行器：

```text
脚只承重和抓地
不能靠 foot/0 把脚滚边来追 CoP
```

踝是转接枢纽：

```text
踝力矩改变小腿方向
CoP 是踝力矩的结果
CoP 必须在脚掌内
```

膝是支撑层：

```text
保持 comY
腿伸展
踝 CoP 饱和后分担
```

## 3. 目标姿态

小腿侧向目标固定：

```text
targetTilt = 0
```

矢状小腿目标：

```text
dx = knee_x − ankle_x
dy = knee_y − ankle_y
sag = atan2(dx, dy)
targetSag = (sag_l + sag_r) / 2
```

左右使用同一个 `targetSag`。

释放实测：

```text
左：dx=17.48cm  dy=33.52cm  sag=27.55°
右：dx=17.22cm  dy=33.62cm  sag=27.13°
targetSag = 27.34°
左右差 = 0.42°
```

脚落点：

```text
左踝 ≈ (-0.1, 4.7, 16.4)cm
右踝 ≈ ( 0.0, 4.6, -16.0)cm
```

禁止：

```text
targetTilt = 当前 tilt
targetTilt = 释放姿态侧向角
左右手写镜像
反解 hip / knee/1 / foot/0
```

## 4. PD 形式

侧向：

```text
e_lat = 0 − tilt
task_lat = K·e_lat − B·tilt_rate + Kcom·comPredicted
```

矢状：

```text
e_sag = targetSag − sag
task_sag = K_sag·e_sag − B_sag·sag_rate
```

输出：

```text
knee/1
foot/0
knee/2
foot/2
```

踝不是独立 PD：

```text
foot 输出是踝转接力矩
只在 N>0、CoP 有余量时允许
```

## 5. 脚掌 / CoP 权限

脚掌实测：

```text
脚中心 z ≈ ±16.3cm
脚掌半宽 ≈ 3.8cm
支撑外缘 ≈ ±20.1cm
```

基础法向力：

```text
N = baseFz
```

CoP 预算：

```text
SQC_COM_FOOT_HALF = 0.038
```

踝力矩权限：

```text
CoP_margin = min(CoP − copMin, copMax − CoP)
|τ_ankle| ≤ N · CoP_margin · 0.8
```

到边沿自动缩小，不允许继续滚脚。

## 6. 当前标定

lateral 方向多次静态标定：

```text
左 knee/1：dTilt/dTau ≈ -0.2115°/Nm
左 foot/0：dTilt/dTau ≈ -0.2929°/Nm
右 knee/1：dTilt/dTau ≈ -0.3203°/Nm
右 foot/0：dTilt/dTau ≈ -0.4525°/Nm
```

结论：

```text
左右两侧都是 +力矩 → tilt 往负方向
e>0 应给正力矩
```

当前代码对应：

```text
kneeTau = +wK·task_lat
footTau = +footSign·N·demand
```
