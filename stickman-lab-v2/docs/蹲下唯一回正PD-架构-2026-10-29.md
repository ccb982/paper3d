## 3. 两个 PD

### 3.1 ShankTaskPD

控制：

```text

```

目标：

```text

foot/0     = 足底中性/接触约束
foot/2     = 足底中性/接触约束
```

作用：

```text

脚掌保持接触
knee/1 辅助
```

### 3.2 HipTaskPD

控制：

```text
knee/2
hip/0
hip/1
```

目标：

```text
髋水平 / 骨盆方向
knee/2 大腿支撑方向
```

髋不独立侧向推：

```text
HipTask 产生 N 请求
→ 对应脚多承力
→ 地面反力推骨盆
```

## 5. 力链

### 5.1 腿部

```text
F_leg = Kp·(targetShank − shank)
      + Kd·(targetRate − rate)
```

分配：

```text
τ_shank = J_shankᵀ · F_leg
τ_hip   = J_hipᵀ   · F_leg
```

`F_leg` 沿小腿/大腿方向，不生成独立横向 pusher。

### 5.2 髋

```text
HipTask → N_L* / N_R*
→ 对应脚多发力
→ GRF 推髋
```

不是：

```text
hip/0 直接扭骨盆
```

### 5.3 脚掌

```text
脚掌贴地 = 接触约束
踝力矩 = 回正执行器
```

脚掌不是独立回正 PD；脚不能为了追目标滚边。

## 12. PD 只看角度残差

### 12.1 决定

```text
ShankTaskPD：只读 shank 角度残差
HipTaskPD：只读 hip/knee 角度残差
```

不读：

```text
COM
XCoM
CoP target
```

### 12.2 形式

```text
u = Kp·(targetAngle − angle) − Kd·rate
τ = Jᵀ·u
```

只受：

```text
joint cap
joint rate damping
```

### 12.3 目标来源

```text
targetAngle = 闭链/姿态目标
```

不是：

```text
COM → hip torque
```

### 12.4 基础力

```text
B0/pair/passive：承重
PD：角度回正残余
```

CoP 只用于安全限制，不作为 PDE 主目标。

### 12.5 结论

```text
PD 只做角度残差
COM 不进入髋 PD
```


## 13. 人腿感受的是什么

### 13.1 局部感受

脚/小腿能直接感受：

```text
脚底压力
足底剪切
关节角
肌肉长度/张力
关节运动
```

不能直接感受：

```text
全身 COM
XCoM
```

### 13.2 重心

COM 是中枢估计：

```text
脚底压力
本体感觉
前庭
视觉
→ 中枢融合
```

不是某个小腿局部感受器。

### 13.3 论文

```text
Kavounoudias et al. 1998
  foot sole mechanoreceptors / pressure distribution

Roll et al. 2002
  plantar cutaneous inputs and balance

Proske & Gandevia 2012
  proprioception: muscle spindles / joint / force

Peterka 2002
  multisensory integration

Horak & Nashner 1986
  local ankle/hip strategies
```

### 13.4 结论

```text
脚/小腿：只能感受局部压力、关节角、倾斜
COM/XCoM：中枢估计，不是局部传感器
```

所以：

```text
local PD 只看角度/接触残差
COM 不进入脚/小腿 PD
```

## 16. CoP 也归髋层

### 16.1 分工

```text

  只追关节角目标
  CoP 只作为安全/接触约束
```

### 16.2 CoP 不是髋直接出力

髋不直接产生 CoP：

```text

→ 脚/踝通过力矩和接触实现
```

所以：

```text

```

```text

  COM → CoP 目标 + N 分配

  角度残差 → foot/knee

  承重
```

### 16.4 结论

```text
CoP 目标：髋层
CoP 执行：脚/踝
小腿 PD：只看角
```

## 19. 髋对膝盖的控制能力

### 19.1 当前

`HipTaskPD` 输出只写：

```text
hip/0

```

不写：

```text
knee/2
```

`knee/2` 当前由：

```text

+ pairBase
```

承担。

### 19.2 结论

```text
髋当前不能主动控制膝盖下压
髋和膝盖没有形成伸展协同
```

所以：

```text
hip 出力
→ 不能带动 knee/2
→ 不能通过大腿下压膝盖撑起自己
```

### 19.3 需要

```text
HipTask → F_thigh
→ Jᵀ
→ hip/2 + knee/2
```

让髋和膝形成同向伸展：

```text
髋伸 + 膝伸 → 撑起
```

不是：

```text
hip/0 单独扭
knee/2 单独 base
```
