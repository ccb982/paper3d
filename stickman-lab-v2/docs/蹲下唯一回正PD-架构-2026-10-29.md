# 蹲下唯一回正 PD 架构（2026-10-29）

> 只做一个膝/踝/脚回正 PD。
> 目标姿态只确定一个量：**矢状小腿角度**。
> 脚的位置已经由落点确定，不再反解髋、foot/0、knee/1。

---

## 1. 范围

唯一回正 PD：

```text
ShankTaskPD
```

处理对象：

```text
小腿
膝盖
踝/脚（只转接、承重）
```

不碰：

```text
hip/0
hip/2
knee/2 以外的新写手
foot/2 独立 PD
spine
上盘
Pelvis
LegChain
JR
closedChain
```

---

## 2. 物理图像

```text
小腿轴向力
  ↓
踝（转接）
  ↓
脚掌承重
  ↓
地面反力 / CoP
```

踝不是独立任务：

```text
踝不追自己的角度
踝不做单独 PD
踝只把小腿力转到脚
```

脚是承重端：

```text
N = 脚底法向力
CoP = 脚底反力位置
```

---

## 3. 目标姿态

脚落点固定后，唯一要确定的是：

```text
矢状小腿角度
```

计算：

```text
dx = knee_x − ankle_x
dy = knee_y − ankle_y
sag = atan2(dx, dy)
```

目标：

```text
targetSag = (sag_l + sag_r) / 2
```

左右使用同一个 `targetSag`，保证对称。

侧向目标固定：

```text
targetTilt(侧向) = 0
```

小腿出现侧向角度不是目标，是 PD 回正方向错了。

不做：

```text
不反解 hip
不反解 foot/0
不反解 knee/1
不反解 closedChain
不在每个关节上单独定目标
```

## 4. 释放实测

法庭释放瞬间：

```text
左：
  dx = 17.48cm
  dy = 33.52cm
  sag = 27.55°

右：
  dx = 17.22cm
  dy = 33.62cm
  sag = 27.13°

targetSag = 27.34°
左右差 = 0.42°
```

脚落点：

```text
左踝 ≈ (-0.1, 4.7, 16.4)cm
右踝 ≈ ( 0.0, 4.6, -16.0)cm
```

结论：

```text
矢状小腿目标左右对称
27.3° 与释放姿态一致
脚落点位置合理
```

---

## 5. PD 形式

任务误差：

```text
e_sag = targetSag − sag
```

任务力：

```text
F_task = K·e_sag − B·sag_rate
```

分配：

```text
τ = Jᵀ · F_task
```

输出只允许：

```text
膝盖
踝/脚转接
CoP
```

不是：

```text
knee 一个 PD
foot 一个 PD
ankle 一个 PD
```

---

## 6. CoP 闭环

基础力负责：

```text
baseFz
baseCoP
脚掌接触
基础支撑
```

回正 PD 只加增量：

```text
CoP_target = baseCoP + ΔCoP
τ_foot = N · (CoP_target − CoP)
```

要求：

```text
N > 0
CoP_target ∈ 脚掌
|F_t| ≤ μN
```

脚没承重：

```text
不发回正力
```

可用 CoM 预算：

```text
SQC_COM_FOOT_HALF = 0.038
```

不是旧的 2cm 人工限制。

---

## 7. 写手归属

`SQC_TASKPD=1` 时：

```text
ShankTaskPD 唯一写回正相关轴
squatFrontalPassive 不得抢同一轴
squatHipLevelAssist 不存在
squatShankPD 不存在
ankleWriter 不存在
```

基础力可以保留，但不能和回正 PD 抢同一个轴。

---

## 8. 验证顺序

```text
1. 释放瞬间固定脚落点
2. 计算 targetSag
3. 验证左右 sag 差 < 1°
4. 验证 targetSag 与释放姿态一致
5. 固定脚，只验证矢状小腿角
6. 通过后再接 CoP/法向力
7. 最后才在法庭释放后运行
```

验收：

```text
targetSag 左右对称
侧向 targetTilt = 0
脚落点不漂
小腿不反向
CoP 不越界
N 不卸载
```
