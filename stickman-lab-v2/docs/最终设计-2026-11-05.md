# 最终设计（2026-11-05）

> 本文件是当前最终架构。旧的蹲下/上身架构文档只作历史参考。

## 1. 总原则

```text
唯一执行出口：executor
写手全部提案制
每个轴唯一 owner
基础力与回正力分离
检测层只读
理论目标左右对称，实际载荷可以不对称
上身允许非标准姿势，但不能持续上顶、不能抬髋
```

---

## 2. 分层

```text
目标层
  IK → q*（关节角）+ F*/u*/CoP*（理论力链）

命令层（下身 3 个）
  ① 矢状基础力
  ② 矢状回正
  ③ 侧向回正

检测层（只读）
  扰动检测
  力链检测

执行层（下身 2 个 PD）
  HipTaskPD
  ShankTaskPD

上身
  upperBase（基础力）
  upperRighting（1 个 PD）
```

---

## 3. 上身

### 3.1 结构

```text
一个 PD
基础力和回正力分通道
目标 = 交接瞬间的上身姿态
```

### 3.2 基础力

```text
squat.upperBase
  τ_base_i = −(该关节子树重力矩)
  逐节逐轴
  当前姿态计算
  channel = support
```

### 3.3 回正力

```text
squat.upperRighting
  τ_right_i = Kp(q* − q) − Kd·q̇
  全部脊柱/颈三轴
  另加：只作用在 spine1 矢状轴的间歇高度修正
  channel = active
```

高度修正：

```text
目标：交接瞬间胸高 h*
误差：e = h − h*
死区：hi / lo
占空比：0.2s 通 / 0.3s 断
限幅：20 N·m
腰偏角上限：0.12 rad
```

### 3.4 边界

```text
不读下身
不追标准姿势
不持续上顶
不抬髋
```

---

## 4. 下身 3 个命令层

### 4.1 矢状基础力

```text
纯前馈
维持目标姿势
不参与回正
不参与扰动响应
channel = support
```

### 4.2 矢状回正

```text
输入：
  e_q = q* − q
  e_F = F*_sag − F_actual_sag

输出：
  矢状目标/误差
  交给 HipTaskPD / ShankTaskPD
```

### 4.3 侧向回正

```text
只回正力链
不追关节角

输入：
  e_F_lat
  CoP 侧向分量
  骨盆侧向扰动

输出：
  侧向力链目标
  通过 hip0（大腿为主）
  foot0（踝辅助）
```

### 4.4 命令层边界

```text
命令层不直接写关节力矩
命令层只出目标/误差
侧向不产生关节角目标
```

---

## 5. 下身 2 个执行 PD

### 5.1 HipTaskPD

```text
髋 + knee/2（大腿/膝伸展）

负责：
  hip/0
  hip/1
  hip/2
  knee/2
```

### 5.2 ShankTaskPD

```text
小腿 + 踝 + 脚

负责：
  knee/0
  knee/1
  foot/0
  foot/1
  foot/2
```

### 5.3 执行层边界

```text
每个轴唯一 owner
基础力可以叠加，但不算回正
PD 只执行，不生成策略
```

---

## 6. 检测层

### 6.1 扰动检测

```text
矢状扰动
侧向扰动
骨盆扰动
```

### 6.2 力链检测

```text
F_parallel / F_perp
CoP
接触
tau
利用率
```

### 6.3 比较

```text
目标 IK：
  q*
  u*
  F*
  CoP*

实际：
  q
  u_actual
  F_actual
  CoP_actual

误差：
  e_q = q* − q
  e_F = F* − F_actual
```

### 6.4 边界

```text
检测层只读
不写执行器
不生成动作
```

## 7. 数据流

```text
IK
  ↓ q*, F*, u*, CoP*
下身 3 个命令层
  ↓ 目标/误差
HipTaskPD / ShankTaskPD
  ↓ 关节力矩
executor
```

```text
实际传感器
  ↓
扰动检测 / 力链检测
  ↓ 只读
矢状回正 / 侧向回正
```
