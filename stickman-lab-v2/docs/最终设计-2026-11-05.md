## 3. 上身

### 3.1 结构

```text
上身 = 简化负载模型
不是人体上身控制的 claim

一个 PD
基础力和回正力分通道
目标 = 交接瞬间的上身姿态
```

### 3.2 基础力

```text
squat.upperBase
  τ_base_i = −(该关节子树重力矩)
  逐节逐轴
  当前姿态计算
  channel = support
```

### 3.3 回正力

```text
squat.upperRighting
  τ_right_i = Kp(q* − q) − Kd·q̇
  全部脊柱/颈三轴
  另加：只作用在 spine1 矢状轴的间歇高度修正
  channel = active
```

高度修正：

```text
目标：交接瞬间胸高 h*
误差：e = h − h*
死区：hi / lo
占空比：0.2s 通 / 0.3s 断
限幅：20 N·m
腰偏角上限：0.12 rad
```

### 3.4 边界

```text
不读下身
不追标准姿势
不持续上顶
不抬髋
允许小范围自然摆动
质量/惯量/CoM 必须真实
```

### 3.5 验证口径

```text
不看 EMG / 肌肉协同
不看是否像人的多关节上身控制

只看：
  骨盆反力矩是否合理
  髋高度是否被上身带高
  胸腔高度/速度是否收敛
  是否向下盘注入额外扰动
  是否产生能量泵入
```


### 5.4 抗阻层（阻尼 / 被动刚度）

位置：

```text
HipTaskPD / ShankTaskPD 的执行路径内
不是 drive 的另一条隐藏写手
```

实现：

```text
drive.resistTorque(i) 只计算
squatClean.applyResistance 写入 squat.resist
channel = passive
```

覆盖：

```text
hip/0
knee/2
foot/0
foot/2
```

公式：

```text
e = q − q_ref
deadband / soft zone / hardening
k_eff = k0 + hardK·(over/soft)^n·transient
b_eff = max(b0, 1.6·sqrt(k_eff·I))
tau = −k_eff·eff − k3·norm³ − b_eff·q̇
cap
```

开关：

```text
SQC_RESIST_IN_PD=0（默认，保留旧路径；=1 启用新路径）
SQC_DAMP_IN_PD=0（默认，drive td 保留；=1 由 PD 层接管）
```

注意：

```text
提案下一帧生效，比原 drive 直写多一帧延迟。
行为会变，需要按新路径重新调参。
```

## 13. 力链检测：人类水平与高精度实现

### 13.1 人类水平

力/力矩：

```text
Feyzabadi 2013（IEEE Trans Haptics）
  关节力辨别 Weber fraction：
    wrist 0.11 / elbow 0.13 / shoulder 0.08
  最小可感知力约 0.04 N

Cai 2020（Sci Rep）
  肘力矩匹配误差：
    single-joint 2.7–6.9 N·m
    multi-joint 3.0–6.9 N·m
```

足底/CoP：

```text
Viseux 2024（J Appl Physiol）
  足底感知阈值不是平衡控制的好指标
  踝力矩方差与 CoP 速度方差更相关
  加载后 sensorimotor loop noise 约 +88%
```

工程验收目标（不是论文直接给的常数，是保守下限）：

```text
Fz            ±5%
F_parallel    ±10%
F_perp        ±15–20%
关节力矩       ±10–15%
CoP           ±3–5 mm
关节角         ±1–2°
```

结论：力链检测只要不低于这些下限，就算“比人类好或同级”。

### 13.2 当前实现的短板

`fullInverseDynamics.ts`：

```text
用有限差分算加速度和角动量导数：
  ax = (v - v_prev) / dt
  hx = (H - H_prev) / dt
高频噪声大，F_perp/tau 在快速动作时可能比人差。
```

`actualForceChain.ts`：

```text
F/CoP 来自 Rapier 接触样本 → 准
tau 来自 measureJointLoads → 差分噪声
F_parallel/F_perp 用足底力投影到小腿轴 → 只是估计，不是真正的膝/踝力链
```

### 13.3 高精度方法

1. **广义动量观测器**（De Luca & Mattone 2005）
   - 不差分加速度
   - 用 `p = M(q)q̇` 和动量残差估计外力/外力矩
   - 对噪声更稳，适合实时

2. **动量观测 + Kalman/强跟踪滤波**
   - Yan 2025（Sensors）：变分贝叶斯 Kalman
   - Xie 2026（Biomimetics）：模糊遗忘因子强跟踪 Kalman
   - 用于接触力/外力矩估计

3. **模型型扰动观测器**
   - Pi 2025（Sensors）
   - 用动力学模型估计接触力，不依赖力矩传感器

4. **接触一致的全逆动力学**
   - 足底接触力作为已知外力
   - 递归 Newton–Euler 从脚向上传播
   - 得到真正的膝/髋关节反力与力矩
   - 需要低通/正则化，避免差分噪声

5. **验证**
   - 用 Rapier 接触冲量/施加力矩当真值
   - 逐项对比 Fz、CoP、关节力矩、F_parallel/F_perp
   - 误差超过 13.1 的下限就不能进高频回正

### 13.4 推荐落地顺序

```text
① 保留 Rapier 接触样本作为 Fz/CoP 真值
② 用广义动量观测器替换 fullInverseDynamics 的差分 tau
③ 用接触一致 RNEA 计算膝/髋关节反力
④ F_parallel/F_perp 从关节反力取，不再用足底力投影
⑤ 低通 10–20 Hz + 置信度/残差门控
⑥ 写验证探针：估计值 vs Rapier 真值
```

目标：

```text
Fz ±5%
F_parallel ±10%
F_perp ±15–20%
关节力矩 ±10–15%
CoP ±3–5 mm
```

### 13.5 已落地（2026-11-05）

`fullInverseDynamics.ts`：

```text
① 修复加速度差分 bug
   原先在关节循环里逐体更新 velPrev，
   同一体属于多个子树时会被提前刷成当前速度 → 加速度≈0。
   现在先对全身做一次差分快照，再进关节循环。

② 输出完整 3D 关节力矩和关节反力
   moment {x,y,z}
   force  {x,y,z}
   保留 torque（轴2投影）兼容旧调用。

③ 15 Hz 低通
   SQC_FORCE_LP_HZ（默认 15，0=关闭）
   重力项精确、不过滤；
   只对“接触 + 惯性”项做 EMA，raw 值单独保留。
```

`actualForceChain.ts`：

```text
F_parallel / F_perp 改为来自膝关节反力，
不再用足底力投影。
chain: { force, axis, parallel, perp }
```

新增探针：

```text
node tools/run.mjs _probe-forcechain-accuracy
```

实测（squatcourt）：

```text
t=2.00 左：
  contactF = 456 N
  kneeF    = 414 N（滤波）  raw = 414 N
  chain    = 361 / 202（par / perp）
  tau K    = 64 / 64（滤波 / raw）
  校验：456 − 414 ≈ 42 N ≈ 小腿+脚重量 ✓

t=2.30 左：
  contactF = 319 N
  kneeF    = 415 N（滤波）  raw = (375,941,-212)
  tau K    = 63 / 77

结论：
  原始差分力已不可用（高频爆点）；
  重力精确 + 接触/惯性 15 Hz 滤波后，
  膝反力在静态点与“接触力 − 远端重量”一致，
  可作为力链检测输入。
```

下一步可选：

```text
① 用广义动量观测器替换差分 tau（更彻底）
② 用 Rapier 真值做逐项误差统计（Fz/CoP/tau/F_par/F_perp）
③ 置信度/残差门控，低置信度不进高频回正
```

### 5.5 侧向膝盖回正（左腿修复）

目标：

```text
targetKneeZ = sign · kneeAbs
kneeAbs = 左右捕获膝 z 的平均绝对值
```

误差：

```text
eKneeZ = targetKneeZ − kneeZ
```

分配：

```text
hip0  = 主
foot0 = 辅
knee0 不做侧向主动
```

参数：

```text
SQC_KNEE_LAT_HIP_K      3.0
SQC_KNEE_LAT_FOOT_K     1.2
SQC_KNEE_LAT_DEAD       0.005 m
SQC_KNEE_LAT_HIP_MAX    0.15 rad
SQC_KNEE_LAT_FOOT_MAX   0.08 rad
SQC_LAT_DAMP_CAP        15 N·m
SQC_KNEE_LAT_TGT        knee | ankle
```

实测（squatcourt 3s）：

```text
左膝 z     0.102 → 0.167
左踝 z     0.168
左小腿 lat 14° → 0.2°
右膝 z     −0.190（目标 −0.201，基本不变）
```

结论：

```text
左腿不再往里滚，膝回到踝上方；
右腿基本不受影响；
squat 判死仍是矢状 offX=10cm，不是左腿。
```

注意：

```text
侧向 PD 的阻尼项加了 ±SQC_LAT_DAMP_CAP，
避免速度低通滞后时阻尼盖过位置项。
```
