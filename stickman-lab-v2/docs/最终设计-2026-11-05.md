## 3. 上身

### 3.1 结构

```text
上身 = 简化负载模型
不是人体上身控制的 claim

一个 PD
基础力和回正力分通道
目标 = 交接瞬间的上身姿态
```

### 3.2 基础力

```text
squat.upperBase
  τ_base_i = −(该关节子树重力矩)
  逐节逐轴
  当前姿态计算
  channel = support
```

### 3.3 回正力

```text
squat.upperRighting
  τ_right_i = Kp(q* − q) − Kd·q̇
  全部脊柱/颈三轴
  另加：只作用在 spine1 矢状轴的间歇高度修正
  channel = active
```

高度修正：

```text
目标：交接瞬间胸高 h*
误差：e = h − h*
死区：hi / lo
占空比：0.2s 通 / 0.3s 断
限幅：20 N·m
腰偏角上限：0.12 rad
```

### 3.4 边界

```text
不读下身
不追标准姿势
不持续上顶
不抬髋
允许小范围自然摆动
质量/惯量/CoM 必须真实
```

### 3.5 验证口径

```text
不看 EMG / 肌肉协同
不看是否像人的多关节上身控制

只看：
  骨盆反力矩是否合理
  髋高度是否被上身带高
  胸腔高度/速度是否收敛
  是否向下盘注入额外扰动
  是否产生能量泵入
```

## 4. 下身 3 个命令层

### 4.1 矢状基础力

```text
纯前馈
维持目标姿势
不参与回正
不参与扰动响应
channel = support
```

### 4.2 矢状回正

```text
职责：救全身

输入：
  e_q   = q* − q
  e_F   = F*_sag − F_actual_sag
  e_CoM = CoM* − CoM
  e_Hip = hip* − hip

输出：
  F_H = Kp(H* − H) − Kd·vH
  τ = J_Hᵀ · F_H
  交给 HipTaskPD / ShankTaskPD
```

规则：

```text
髋偏了、CoM 偏了 → 矢状层管
大腿发力把髋/骨盆拉回来
不是髋关节自己动
```

### 4.3 侧向回正

```text
职责：保抓地、保力链
不负责救全身

输入：
  e_F_lat
  CoP 侧向分量
  接触/摩擦/抓地状态

输出：
  小腿/脚的小幅调整
  foot0、shank 局部目标
```

允许：

```text
力链偏了 → 小腿动一下
目的：保证抓地和力链畅通
```

禁止：

```text
用侧向层救 CoM
用侧向层大幅改 hip0
把侧向层当全身平衡器
```

### 4.4 命令层边界

```text
命令层不直接写关节力矩
命令层只出目标/误差

髋/CoM 偏差 = 矢状层
抓地/力链   = 侧向层

侧向层大幅救 CoM = owner 违规
```

### 5.6 PD 内部方程

```text
u        = 命令层神经信号
a        = 肌肉激活状态
a_dot    = (u − a) / τa          τa = 50–100ms

τ_active = a · Jᵀ · F_max · fL(θ) · fV(ω)
τ_passive = −K_pass(θ)·(θ−θ0) − B_pass(θ)·ω

c = clamp(c0 + kF·|F_joint|/BW + kω·|ω| + ke·|e|)
K_eff = K_pass + c·K_co
B_eff = B_pass + c·B_co

τ = τ_active + τ_passive − K_eff·e − B_eff·ω
F_joint = fullInverseDynamics / force chain
tension = F_joint
```

硬规则：

```text
共收缩净力矩 = 0
只增加 K/B 和关节压缩
不允许 tau += 常数“张力”
张力只做读数/反馈，不做第三个写手
每个轴仍只有一个 owner
命令层永不直接写关节
```

力量级：

```text
hip joint 2–4 BW；深蹲 5–8 BW
knee joint 3–6 BW；深蹲 7–8 BW
ankle joint 2–4 BW
hip extensor 1–2.5 Nm/kg
hip passive stiffness 0.5–1.5 Nm/deg（中段）
```

当前参数：

```text
P2 hip: K150 Nm/rad = 2.6 Nm/deg, B10, cap50
P2 knee: K30 Nm/rad = 0.52 Nm/deg, B3, cap15
P2 foot0: K80 Nm/rad, B4, cap40
```

结论：

```text
K150 不低；cap50 偏低
优先补：末端非线性 K、共收缩、关节反力反馈
不要单纯加 K，也不要把张力做成常数力矩
```

## 12. 文献对照

| 模块 | 最接近文献 | 支持程度 | 差异 / 备注 |
|---|---|---|---|
| 提案总线 / 单写手 / 仲裁 | Brooks 1986（subsumption）；行为仲裁 | 工程类比 | 软件架构选择，不是人体生理结论 |
| 状态化控制（stand/squat/single-leg） | d'Avella et al. 2003（肌肉协同）；混合控制 | 部分 | 人体是连续渐变；状态表是工程离散化 |
| 上身单 PD + 重力前馈 | Peterka 2002；Winter 1995；Feldman 1966 / Hogan 1984 | 工程降阶 | 上身是简化负载模型，不是人体上身控制 claim；只验证扰动/反力矩/髋高 |
| 上身高度间歇修正 | Bottaro 2005 / Asai 2009（间歇控制）；Winter 1995（CoM） | 弱 / 工程选择 | 目标高度是自定目标；需真人胸/CoM 数据验证 |
| 矢状基础力 | Winter 1995；Featherstone RNEA；computed torque | 强（工程） | 基础力/回正力分离是标准前馈+反馈结构 |
| 矢状回正（角度+力链） | Peterka 2002；Horak & Nashner 1986；Kuo 1995；Hof 2005 | 强 / 部分 | 人用 CoP/GRF/本体感觉；F_parallel/F_perp 是工程分解 |
| 侧向回正（只力链） | MacKinnon & Winter 1993；Neumann 2010；Powers 2010；Mirshams Shahshahani & Ashton-Miller 2020 | 强 | 髋外展肌是额状面主控；踝/脚辅助；“不追角度”符合力控思想 |
| 两个执行 PD 组 | Hogan 1985（阻抗）；Siciliano（task-space）；d'Avella 2003 | 部分 | Hip/Shank 分组是工程分解；人不是两个 PD 组 |
| 力链检测 | Winter 1995（inverse dynamics）；kinetic chain（Steindler / Putnam 1993）；Hof 2005 | 部分 | 人体文献是 kinetic chain / load path，不是 F_parallel/F_perp |
| 扰动检测 | Proske & Gandevia 2012；Kavounoudias 1998；Roll 2002；Peterka 2002 | 强（通道存在） | 具体检测器是工程实现 |
| 目标 IK | Whitney 1969；Flash & Hogan 1985；Todorov & Jordan 2002 | 强（方法） | 目标 IK 是参考；对称目标不是生理事实 |
| 对称理论目标 / 不对称载荷 | Sadeghi et al. 2000（gait symmetry）；Winter 1995 | 部分 | 人本身不对称；对称目标只是控制参考 |
| 检测层只读 | 感觉-运动分离（综述性结论） | 工程原则 | 无单一论文；符合控制架构 |

结论：

```text
一半以上模块有强/部分文献支持；
少数模块（上身高度目标、两个 PD 分组、力链 F_perp 分解、固定占空比）
是工程选择，没有直接论文。
这不是问题：集成架构本来就是文献缝隙里的工作。
但这些自造模块必须用内部指标验证，不能靠“论文没反对”来证明。
```

## 13. 力链检测：人类水平与高精度实现

### 13.1 人类水平

力/力矩：

```text
Feyzabadi 2013（IEEE Trans Haptics）
  关节力辨别 Weber fraction：
    wrist 0.11 / elbow 0.13 / shoulder 0.08
  最小可感知力约 0.04 N

Cai 2020（Sci Rep）
  肘力矩匹配误差：
    single-joint 2.7–6.9 N·m
    multi-joint 3.0–6.9 N·m
```

足底/CoP：

```text
Viseux 2024（J Appl Physiol）
  足底感知阈值不是平衡控制的好指标
  踝力矩方差与 CoP 速度方差更相关
  加载后 sensorimotor loop noise 约 +88%
```

工程验收目标（不是论文直接给的常数，是保守下限）：

```text
Fz            ±5%
F_parallel    ±10%
F_perp        ±15–20%
关节力矩       ±10–15%
CoP           ±3–5 mm
关节角         ±1–2°
```

结论：力链检测只要不低于这些下限，就算“比人类好或同级”。

### 13.2 当前实现的短板

`fullInverseDynamics.ts`：

```text
用有限差分算加速度和角动量导数：
  ax = (v - v_prev) / dt
  hx = (H - H_prev) / dt
高频噪声大，F_perp/tau 在快速动作时可能比人差。
```

`actualForceChain.ts`：

```text
F/CoP 来自 Rapier 接触样本 → 准
tau 来自 measureJointLoads → 差分噪声
F_parallel/F_perp 用足底力投影到小腿轴 → 只是估计，不是真正的膝/踝力链
```

### 13.3 高精度方法

1. **广义动量观测器**（De Luca & Mattone 2005）
   - 不差分加速度
   - 用 `p = M(q)q̇` 和动量残差估计外力/外力矩
   - 对噪声更稳，适合实时

2. **动量观测 + Kalman/强跟踪滤波**
   - Yan 2025（Sensors）：变分贝叶斯 Kalman
   - Xie 2026（Biomimetics）：模糊遗忘因子强跟踪 Kalman
   - 用于接触力/外力矩估计

3. **模型型扰动观测器**
   - Pi 2025（Sensors）
   - 用动力学模型估计接触力，不依赖力矩传感器

4. **接触一致的全逆动力学**
   - 足底接触力作为已知外力

## 14. 蹲下后的侧向 / 矢状回正分工（最终定稿）

### 14.1 定调

```text
力链偏了：
  侧向回正可以让小腿动一下
  目的是保抓地、保力链畅通
  不负责救全身

髋偏了、CoM 偏了：
  必须由矢状面调控
  矢状面救全身
```

```text
侧向层 = 局部稳定（接触 / 抓地 / 力链）
矢状层 = 全身回正（CoM / 髋 / 大腿力链）
```

### 14.2 文献依据

| 文献 | 结论 | 对应设计 |
|---|---|---|
| MacKinnon & Winter 1993, J Biomech | 额状面平衡由**髋外展肌**控制骨盆/CoM；踝几乎没有侧向权限 | 全身 CoM 侧偏不能靠 foot0；要靠髋/大腿链 |
| Ashton-Miller 2020/2022, PLOS One | 单腿髋外展需求 >50% MVC；恢复靠 **RTD**；不够时躯干同侧弯（降需求 37%）或迈步 | 矢状/髋链要快起手；预算不足时侧弯/迈步 |
| Inman 1947, JBJS | 髋外展力矩下界 = 体重 × 髋间距/2；约一半由 IT band 被动承担 | 被动组织要计入，不能全给主动 PD |
| Rogers & Pai 1990, Exp Brain Res | 快速横向转移的初始冲量 **4:1 来自移动腿屈曲**；慢速才支撑腿先行 | 快速侧移可让对侧腿短促推蹬 |
| Neumann 2010 / Powers 2010 / Souza & Powers 2009 | 髋外展控制骨盆下沉和膝额状面 | 膝盖侧向靠大腿，不靠 knee0 |
| Winter 1992, Phys Ther | 摆动脚是端点控制；支撑髋外展对轨迹敏感 | 脚落点/抓地先成立，再谈回正 |
| Geyer & Herr 2010 / Blickhan 1989 | 落地腿弹簧 + 抓地窗口 | 接触/抓地是力链前提 |
| Winter 1995 / Hof 2005 | CoP/GRF 与关节力矩关系 | 侧向层只消费 CoP/GRF；矢状层用 CoM/XCoM |

直接研究“蹲下后侧向回正”的论文很少；但额状面平衡、髋外展、抓地的文献结论一致。

### 14.3 人体机制：反向作用

```text
脚抓地
  ↓
大腿成为固定端
  ↓
髋外展/内收肌收缩
  ↓
把骨盆拉向大腿
  ↓

```

所以：

```text

```

不是：

```text

foot0 自己把 CoM 拉回
knee0 单独把身体拉正
```

### 14.5 硬规则


### 14.7 回退与重新设计（2026-11-05）

已回退：

```text
comRighting.ts
  CoM 力 → comJacobianComplement → hip2/knee2

sagittalPlanner 的 eComX / hip2 目标偏置

原因：
  CoM 力直灌腿链会造成伸腿、抬髋、起身，
  不是“把髋拉回来”。
```

正确策略：**髋位置力控制**

```text
H* = 释放时髋位置（或 IK 给定的 H*）
H  = 实际髋位置
vH = 髋点速度

eH = H* − H
F_H = Kp·eH − Kd·vH，限幅
```

脚固定时，髋点对腿关节的雅可比：

```text
J_H,i = −( u_i × (H − a_i) )
```

输出：

```text
τ_i = J_H,i · F_H
执行到 hip2 / knee2 / foot2
侧向分量可到 hip0
```

规则：

```text
脚是锚点：fz / CoP / 摩擦不成立就不出力
hip2 不是髋位置主执行器；腿链共同拉
CoM 是下游结果
若 CoM 侧偏归矢状层，把它变成 H* 的偏置
支撑腿 = 加载侧
对侧腿可短促推蹬
预算不足 → 侧弯 / 迈步
```

实现顺序：

```text
① 释放时捕获 H*（每侧 hip anchor）
② 计算髋点速度 vH
③ 由 u_i、a_i、H 算 J_H
④ F_H → τ，单独通道，限幅
⑤ 抓地门控 / 支撑腿选择
⑥ 验证：hip 位置误差、CoM、fz、roll、fall
```

禁止：

```text
CoM 力直灌 hip2/knee2
用 hip2 目标偏置代替髋位置控制
用侧向层救 CoM
```
