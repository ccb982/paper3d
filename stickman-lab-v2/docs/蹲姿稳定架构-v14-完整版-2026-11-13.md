## 1. 目标

蹲姿命令层使用逆动力学 QP，在姿态约束下回正 CoM/CoP。

两个下盘 PD 只执行 QP 输出。

```text
World
→ Frame
→ Model
→ QP
→ Command
→ ProximalPD / DistalPD
```

上身保留自主修正，同时作为负载参数进入模型。

## 4. QP 变量

```text
qdd: 18
fL: fx, fy, fz, mx, my, mz
fR: fx, fy, fz, mx, my, mz
```

## 5. 动力学

```text
tau = M qdd + h - Jc^T f - Jm^T m
```

当前 QP 内 `tau` 由上式消去。

## 6. 接触约束

每只脚：

```text
Jc qdd + Jdot qd = 0
```

包含：

```text
平移 3
角 2
```

每脚 5 行。

## 7. 摩擦与 CWC

```text
|fx| <= mu fz
|fy| <= mu fz
fz >= 0
|my| <= 0.2 fz
```

当前是线性近似，不是完整 CWC。

## 8. CoP

```text
copMinX <= footX - mz/fz <= copMaxX
copMinZ <= footZ + mx/fz <= copMaxZ
```

线性化为 QP 不等式。

## 9. Fz

```text
fzL + fzR = 0.9 mg
```

当前是硬等式。

## 10. 任务

### 10.1 CoM

```text
Jcom qdd = a_com*
a_com* = Kp(com* - com) - Kd comVel
```

CoM 包含 x/y/z。

### 10.2 姿态

```text
qdd* = Kp(q* - q) - Kd qd
```

`q*` 来自 IK/命令目标。

### 10.3 脚 roll

```text
Jw qdd = 0
```

软任务。
