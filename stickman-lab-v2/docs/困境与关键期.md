## 二、困境的准确描述

1. **剩余问题的性质变了**：从"还原已知机制"变成"**本系统独有的动态协调问题**"。
   机制全部落地了，剩下的是**它们在时间上的配比**——瞬态里谁先出力、出力多少、
   何时交给谁（踝→髋→脊柱→落点）。这是**乘法项**，不是加法项。

2. **必须动态调整脊柱/腿部发力**（用户点题）：每个瞬时都有一个"分配问题"。
   但注意我们刚验证了一个关键边界：
   - **目标空间**（lean 值）是躯干协调的自然场所（单标量=双纪录）；
   - **力矩空间**是伺服的地盘（M-mode 力版三配置全败）。
   → 动态调整应优先写在**目标/事件空间**。

3. **没有合适论文**：文献给的是机制与方向（Hof 说三机制、Latash 说模式存在、
   Rankin 给落点规则），但没有一篇给出"带步态事件的多关节**动态分配律**"。
   这一步是真正的前沿——**我们的探索本身就是研究**。

4. **走钢丝的风险**（为什么用户这次的感觉是对的）：
   - 近两周所有**参数扫描**（增益/阻尼/限幅上百次）几乎全部无效或虚假改进——
     唯一有效的是**结构改动**（XcoM 形式、单模式、机制②、早落步、共收缩刚度）。
   - 当问题是"配比"时，人天然会去拧参数——这就是走钢丝。
   - **走钢丝的定义**：改动说不出来源（哪条文献/哪个机制/哪个测量），
     只凭"试试看"。已证明该模式在本项目产出率为零。

## 三、为什么说"最关键的时期"（真实原因）

1. **平台期特征**：加法项没了，剩下的都是耦合/时序项——难度陡增但回报也最大
   （跨过去 = 单腿站真正成立）。
2. **可观测性刚刚补齐**：之前多次"视觉 vs 数据"打架（渲染混叠、CoP 盲区、
   只看侧向漏看前后）——现在仪器齐了，**第一次有资格谈"动态调整"**（看得见才调得动）。
3. **方法论的十字路口**：从这里开始，"查文献→还原"不再够用；
   需要进入"**用仪器测量本系统 → 假设 → 最小结构改动 → 双纪录对照**"的实习研究模式。
   这一步走对了，就是正路；走回拧参数，就是走钢丝。

## 四、纪律（写死）

1. **每个动态调整必须能报出来源**：文献坐标 / 机制推导 / 测量数据三者之一。
   说不出来的，先测量再说话。
2. **优先结构解**：新通道、新任务变量、新事件触发；**最后**才动增益。
   （排序依据：本会话结构改动命中率 >> 参数改动。）
3. **顺序 = 测量先行**：天平 HUD / 帧导出 / 单帧步进——先看见，再动手。
4. **双纪录对照**：每次改动后看 危险动量（∫|vz|）与 削力效率（削力/危险），
   任何单项恶化都要有理由。
5. **不得单帧特调**：不许为了某一帧"看起来对"而写特例分支（除物理/文献依据）。

## 八、设计定稿："锁踝 + 大腿调整"（用户定调，2026-10-13）

> 用户原话："脚踝可以不会发力，但是可以上锁，然后大腿侧向发力回正。"
> "我觉得我的设计堪称完美。" —— 立档固化。

### 原理（为什么这个设计对）
- **踝 = 锚**：承重升沿**及时上锁**（相对角锁定 + 贴地守卫），零发力要求；
  踝越硬，髋的力才能通过脚-地界面传出去（洗脱的根治方向）。
- **大腿 = 回正执行器**：在踝锚上做侧向回正（M2：CoM−支撑脚 PD + 漂移增益调度 ×15/×100）。
- **躯干 = 让位/配合**：漂移期脊柱伺服**静默**（不吃髋力）；静止期预测+间歇（XcoM）。
- 边界（实测）：踝锁刚度有**数值上限 220–300**（400/600 均失稳=小惯量×高刚度的离散泵能）；
  "硬锁"的下一步 = **引擎电机路径**（solver 级，arch 同款）。

### 力度战役结账（四层根因，全部实锤）
1. **直控被覆盖**（pelvisBearing 帧后段 setTorque 覆盖 manual）→ 已修（写手让位）；
2. **力度差 2–3×**（同漂移：−100 按不住 / −300 按住）→ 漂移档 ×100 标定；
3. **洗脱池 = 躯干伺服**（LAT_KZ=0 实验：逮捕立即回来）→ 漂移期静默；
4. **脊柱力不是纠偏通道**（共发原号加速爬行、翻号逆冲 −34→−56）→ 禁用留档。
**纪录**：危险动量 0.0199–0.027（基线 0.93 的 **1/35–1/47**）；效率 11039。
**最深遗留**：同一个 −300 在早期态能逮捕、晚期爬行态按不住——**腿的传递随状态变化**（下一场：多状态透射率标定）。

### 当前战线（2026-10-13 夜）：矢状面
- 问题：**腰前后塌、"前后持续发力"没做到**（侧向战役的矢状面对偶题）。
- 现状盘点：spine 轴 2（bend）写手 = sagittalStab + bendAuto/qXf + iap 共收缩 + lumbar 被动；
  疑与侧向同构的问题结构（多写手/缺持续力/对拉）——**先测量，再动刀**（纪律）。

## 九、站稳的本质（用户定稿，2026-10-13；与 `架构.md` §3.15 同文）

> 用户原话："一个天平在 ±10 度的范围内缓慢精细调控（因为上身很慢，所以到达边界点也不应该有很大的
> 加速度），超过了直接全身绷直 + 大力矩拉回。"

- **① 内部（≤ ±10°）**：慢精修——天平慢摆；张力层持续紧绷（Gurfinkel 两层）+ 平衡层低速率调整；
- **② 越界（> ±10°）**：全身绷直（张力拉满）+ 大力矩回拉（危险墙=全身协同收缩僵直，非关节锁死）；
- **③ 回归**：回到内部，恢复慢精修。
- **"慢"是前提**：慢 → 边界处加速度小 → ②拦截无需对抗大动量。快 = 饱和/振荡（力度战役教训）。
- **真读数（up 向量，纠错后）**：单腿 A/B/C/D = **17.5 / 22.8 / 54.9 / 66.5°**——**未达标**；
  达标（把 ±10° 做成真的）就是下一阶段唯一课题。
- 结构真相：整线倾倒住在浮动基座（踝/髋）；三脊柱关节对"整线倒"结构性无感（相对角≈0）。
  抓捕主力 = 踝锚 + 髋 M2 + 越界墙；脊柱只在"弯折"上有作为。
