# 蹲下回正总架构（2026-11-01）

## 1. 目标

```text
蹲下过程中
脚底接触维持
力链顺畅
矢状/侧向分别回正
上身独立稳定
```

## 2. 物理原则

```text
所有回正力从脚底接触开始
脚 → 踝 → 小腿 → 膝 → 大腿 → 髋
不允许悬空直接推髋
```

## 3. 目标 IK

```text
q* / F* / CoP* / tau*
```

性质：

```text
前馈参考
左右对称
不读实际力链
```

## 4. 实际力链

```text
F_n / CoP
F_parallel / F_perp
tau_hip/knee/ankle
jointForce
contact / copInside / tauUtil
```

精度定位：

```text
法向力/CoP：可信
tau：近似
切向：不做精确
```

## 5. 检测层

```text
力链检测：内部载荷/薄弱点，只报
扰动检测：矢状/侧向/骨盆/皮肤，只报
```

检测层不写执行器。

精度目标：

```text
人体级
不追求逐点切向力
```

## 6. 基础力

```text
tau_base = IK 目标平衡力
```

性质：

```text
纯前馈
维持目标姿势
不参与回正
不参与扰动响应
```

## 7. 三个下身命令层

### 7.1 矢状回正

```text
输入：关节角误差 + 力链误差
输出：knee/2、foot/2
```

```text
eJoint = q* - q
eF     = F* - F_actual
```

### 7.2 矢状承重

```text
输入：F*_z - F_n
输出：knee/2 支撑前馈
```

独立命令层，不和回正混。

### 7.3 侧向回正

```text
输入：力链 + 扰动 + 骨盆 offsetZ/roll/velZ
输出：hip/0 阻尼/小刚度
foot/0 仅辅助
```

不追左右关节角。

## 8. 上身

```text
upperPlanner
独立 PD
只维持 spine/neck
不参与下身回正
```

## 9. 执行层

只有两个 PD 组：

```text
HipTaskPD：
  hip/0
  hip/2
  knee/2

ShankTaskPD：
  knee/0
  knee/1
  foot/0
  foot/1
  foot/2
```

PD 只执行命令，不做检测、不做策略。

## 10. PD 内部结合体（目标）

每个 PD 组内部不是单关节独立，而是耦合矩阵：

```text
tau_group = -K_group·(q-q*) - D_group·q̇ + ff_group
```

HipTaskPD：

```text
hip0 / hip2 / knee2 之间有耦合
```

ShankTaskPD：

```text
knee0 / knee1 / foot0 / foot1 / foot2 之间有耦合
```

目的：

```text
模拟大腿-小腿-脚是一条连续肌肉链
```

当前状态：

```text
PD 内部仍是单关节独立
耦合矩阵未实现
```

## 11. 总流程

```text
IK
实际力链
扰动
→ 基础力
→ 矢状回正命令
→ 矢状承重命令
→ 侧向回正命令
→ 上身 PD 命令
→ HipTaskPD / ShankTaskPD
→ 执行器
```

## 12. 硬约束

```text
基础力与回正分离
矢状与侧向分离
检测层只读
PD 只执行
回正必须满足接触/CoP/tauUtil
侧向不追关节角
```

## 13. 当前完成度

```text
基础力：独立，但仍是旧 base
矢状回正：命令层已接，力链未接
矢状承重：命令层已完成
侧向回正：命令层已接，仍是骨盆/CoP 角度目标
上身：独立 PD
PD 内部耦合：未实现
pairPD：取消（矢状关节角由普通 PD 负责）
```

## 14. 后续顺序

```text
1. 矢状回正接 eF/eTau
2. 侧向改为阻尼/力链，不追角度
3. PD 组内耦合矩阵
4. 组内关节角 PD 已覆盖矢状，取消 pairPD
5. 清理旧 base
```
