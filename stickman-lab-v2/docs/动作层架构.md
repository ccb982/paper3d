# 动作层架构（Action Layer）

> 定位：`架构.md` 的动作层展开手册。用户定调（2026-10）：**动作层定义明确、完整的动作
> （轨迹/相位/事件/安全出口）；伺服层只负责细节纠正**。当前伺服层质量不足、机器学习
> 效果不明显，**暂不投入**；本层独立演进。
> 唯一真源仍是 `架构.md`；冲突以它为准。

---

## §1 角色与边界

| 属于动作层 | 不属于动作层 |
|---|---|
| 动作的**完整轨迹**：关节角/力矩关键帧、质心轨道、相位时序 | 平衡细节纠正（垫脚 CoP、差动加载、目标守护） |
| 动作的**成功判定**：触地/离位/载荷/到位等**事件**与安全出口 | 摔倒预警的预测量（CoM/XCoM/间隙） |
| 动作期间的**姿势主动保持**（如蹲起"上身竖直"的髋补偿、单脚的髋接管） | 反射弧（垫脚/消力/负载撑住）——它们只做让位与兜底 |
| 空闲行为（微摆/重心转移/手势等，随机参数） | 关节层（`executor/drive`，已冻结重建）的执行细节 |

纪律：
1. **动作要"明确"**：每一相必须有可检验的事件、明确的目标与速率、超时安全出口；
2. **不依赖伺服成功**：动作自己完成轨迹与姿势；伺服缺席时动作应"安全退化"（放弃/收尾），
   而不是半途悬空；
3. **唯一写手经整合器**：动作只出姿态/力矩/质心目标（`poseTargets/torqueTargets/comTarget`），
   由控制模块整合下发；动作可 `pin` 声明"这些自由度归我"（伺服反射让位）；
4. **写进去的都要能交还**：动作结束（含超时）必须 `clearAngle`/解钉，交还姿势基线。

## §2 接口

### 2.1 关键帧动作（`ActionScript`，actions.ts）
```ts
interface ActionScript {
  name: string;
  frames: Keyframe[];        // { t, pose?: {关节/轴: rad}, torque?: {关节/轴: N·m} }
  comTrack?: ComPoint[];     // { t, x, z } 质心目标轨道（smoothstep 插值）
  expect?: string;           // 验收摘要
}
```
适合"姿态类/演示类"动作（鞠躬、蹬地挺腰）；`ActionSystem.play(id)` 播放，
播放期间脚本写到的关节自动 `pinScript`。

### 2.2 相位程序（`Phase[]`，program.ts）——**复杂动作首选**
```ts
interface Phase {
  name: string;
  timeout: number;                       // 到时强制推进并调用 onTimeout（安全出口）
  enter?(ctx): void;                     // 相位进入：捕获几何量、设初始目标
  update?(ctx, dt): void;                // 每帧：读传感器 → 写目标（限速）
  done(ctx): boolean;                    // **事件**完成条件（不依赖时间）
  onTimeout?(ctx): void;                 // 超时兜底（绝不悬空）
}
// ctx = { sensors, bal(StabilityWarner), body }；写入经 bal.manual / bal.setComTarget
```
事件优先于时间（如落腿必须**真触地**）；所有相位必须有超时兜底。

### 2.3 仲裁（唯一写手）
- 直控（`manual`）> 动作（pin/脚本）> 伺服反射；动作 `pin(joint,axis)` 后反射执行方跳过该轴；
- **程序式 pin 不在 ActionSystem 记账里**——相位结束（含完成路径）必须自己解钉；
- 动作写入的角度目标会盖住姿势基线的内收偏置等常量，需要时把偏置并进目标。

## §4 单脚站立：动作层明确规格（参考样板）

支撑侧 `support`（示例右腿支撑，抬左腿）；`lift` 侧 = 另一侧。

| 相 | 目标（明确） | 速率 | 完成事件 | 超时/安全出口 |
|---|---|---|---|---|
| **A 重心转移** | CoM 目标 → 支撑脚上方（粗移 0.08 m/s 到 80%，精靠 0.03 m/s） | 目标限速 | 支撑脚 >0.7W && 抬脚 <0.2W && \|comZ−目标\|<0.035 && **\|vz\|<0.05（已收敛）** | 7s → 不抬腿，目标交还 0 |
| **B 抬腿** | 抬架：髋 +0.65 / 膝 −1.05 / 踝 +0.08（几何脚高 ~7cm；0.45/−0.75 会相消只抬 1cm） | 1.5 rad/s 限速逼近 | 抬脚离地 >0.06m | 2s → 由 C/D/E 继续兜底 |
| **C 保持（=准备下落）** | ★ 用户定调：不举深收腿架——**摆动脚降到低位“待落点”**（髋0.30/膝−0.45/踝0.05，脚近地），外摆软带（kp40）到**计算出的安全落点**（CoM 外推 0.35s → 夹到可达域 → 换算外摆角）；CoM 目标 = 支撑脚 +0.05 内侧；抬腿侧髋软目标避免持续反作用 | 1.0 rad/s | 时间到 或 **安全早落**（|comZ−目标|>0.06 或 |vz|>0.15 **或 伺服 supportState.marginZ<0** → 立即落腿接住） | — |
| **D 落腿** | 抬架降档（髋 +0.12 / 膝 −0.20 / 踝 0）；**外摆 0→+0.55（蹬回自己一侧、加宽接住面）**；CoM 目标仍压支撑脚 | 1.2 rad/s | **触地** Fz ≥0.25W | 2.5s → 全零压下 |
| **E 站稳** | CoM 目标 0.05 m/s 回中；腿角限速回零；解钉交还 | — | 双脚各 0.3–0.7W && \|comZ\|<0.03 | 3s → 全零回中并解钉 |

纪律：A 不收敛不抬腿（安全放弃优于勉强）；B 的目标角用**限速逼近**（防猛扫）；
E 的完成路径也必须解钉/交还。

**★ 通用原则（用户定调 2026-10）**：
- **所有抬起/腾空的脚都要计算下落的安全点**：用 CoM 外推（`T_LAND≈0.35s`）得到落点，
  再夹进支撑侧可达域，换算成摆动腿的外摆角——单脚动作 C 相已按此实现，后续迈步/落地类
  动作沿用同一帮助函数；"安全点"的**选择**是动作层的职责。
- **着地 = 屈膝消力 + 抓地（反射）**：触地 0.3s 抓地窗口（踝放平贴地、撑稳）由消力反射
  负责（见 `保护预警与反射弧.md` §3.1/§3.2），动作层不重复实现。

**两层分工（用户定调 2026-10）**：
- **落点选择（安全点）与"准备下落" = 动作层**（Bauby & Kuo 2000：foot placement 是侧向平衡的主机制）；
- **"落点是否真能撑住身体"的判断 = 伺服层**：`StabilityWarner.supportState`（marginX/marginZ/
  loadOk/suggest）常驻只读，动作层读它做早落决策——两层间只流只读数据。

**文献依据（迈步的单支撑期重心）**
- **MacKinnon & Winter 1993**（J Biomech `10.1016/0021-9290(93)90027-c`）：行走额状面平衡由**髋外展肌**主动控制骨盆/CoM，踝无 lateral 权限——对应我们的"抬腿侧髋接管/软目标"；
- **Bauby & Kuo 2000**（J Biomech `10.1016/s0021-9290(00)00101-9`）：侧向平衡**需要主动控制**，**落脚点（foot placement）是主机制**，单步即可拦停侧向失稳——对应本动作把"落腿接住"作为核心安全手段（早落 + 宽接）；
- 设计推论：单脚动作的成败主要取决于**落点与放腿时机**（动作层职责），而不是踝部微调——与 §4 的实现方向一致。

**已知缺口（伺服侧，动作层暂无法兜底）**：单支撑保持期存在**横向持续漂移**
（支撑髋承重力矩 ~70–85 N·m 与骨盆侧倾的耦合把 CoM 推离支撑；实测 ~0.2–0.9 m/s 漂移），
属伺服侧向环问题（用户定调：暂不管伺服层）。动作层的缓解已做：
抬腿侧髋软目标（消除 25 N·m 的持续反作用）、A 相收敛门、D 相分脚落地。

## §5 实测教训（动作层相关）

1. **蹬地挺腰重标**：原力矩键会把身体发射离地（Fz 0/0 弹跳）→ 定档"深蹲 −40 / 轻蹬 +24·髋−16·踝+6"，
   末胸站住、行程 ~1cm（需更大另调）；
2. **消力动作抑制**（伺服配合）：动作播放中 +1.0s 尾随消力让位——"蹬地腿抖"根因是动作结束解钉
   瞬间消力以 depth 0.5 猛压膝盖；
3. **屈膝配平**（空闲）：屈膝时同步髋屈补偿 0.8×，上身倾角 5.1°→2.4°；
4. **抬腿几何**：髋 0.45/膝 −0.75 竖直相消（抬 1cm）；深抬架 0.65/−1.05（抬 ~7cm，实测最高 53cm
   为摆动路径峰值）；
5. **横向漂移的真实来源（关键）**：单支撑保持期把抬腿侧髋**硬按在 0**（kp400）会持续出
   ~25 N·m（骨盆侧倾下自然角 ≈−0.16）→ 反作用持续推骨盆离支撑（±0.24 m/s²）——
   改为**软目标**后消除；支撑侧的承重力矩环属伺服问题。

## §6 空闲行为（按部位归类 + 每部位独立概率）

无动作 2.5–6s 随机后插入一次**部位复合**事件；每个部位独立掷概率：

| 部位 | 子动作 | 触发率 |
|---|---|---|
| head | 点头(颈2)/摆头(颈1)/侧头(颈0) | 75/65/30% |
| arm_l, arm_r（独立） | 摆臂(肩2)/屈肘(肘2)/收展(肩0) | 45% × 各自 60/50/40% |
| torso | 转腰(脊柱1)/侧屈(脊柱0) | 30% |
| waist | 腰部转动（髋1 骨盆 + spine1–3 同向跟随 = 腰和上身一起转） | 35% |
| ankle | 单/双脚内外翻或俯仰 | 25% |
| knee | 屈膝回弹/单膝 + 次级轴（膝0/1、髋0） | 30% |
| secondary | 肩扭转/髋外展/踝扭转 次级轴微动 | 25% |
| gesture | **叉腰 / 双手交叉抱胸 / 摸头 / 摸下巴**（手臂+腰胯同包络同步发力；摸头带反向配重侧倾） | 22% |
| weight | 横向重心转移 5–10cm（移→保持→回中） | 40% |

验收 `tools/_probe-idle.ts`：30s ≥4 次、不摔、重心带受限、躯干最大倾角 ≤6.5°。
