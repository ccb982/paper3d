## 6. QP

变量：

```text
x = [qdd, tau, f]
```

目标：

```text
CoM x/y/z
姿态
接触力/CoP
```

硬约束：

```text
M qdd + h = S^T tau + Jc^T f
Jc qdd + Jc_dot qd = 0
friction cone
CoP in support
tau_min <= tau <= tau_max
```

不允许：

```text
动力学软惩罚
接触软惩罚
有限差分梯度
tau 后处理
```
