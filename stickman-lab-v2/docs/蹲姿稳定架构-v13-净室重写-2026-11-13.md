## 28. 姿态约束怎么做

### 28.1 目标

```text
QP 在姿态约束下
解 CoM/CoP 回正
```

### 28.2 姿态约束

```text
q_min <= q + dt qd + 0.5 dt^2 qdd <= q_max
```

这是 qdd 的线性不等式。

### 28.3 姿态任务

```text
qdd* = Kp(q* - q) - Kd qd
```

作为软任务。

### 28.4 CoM

```text
J_com qdd = a_com*
```

必须含 y。

### 28.5 CoP

```text
CoP(f) in support
```

接触力硬约束。

### 28.6 两个 PD

```text
ProximalPD ← hip/knee tau
DistalPD   ← foot/ankle tau
```

### 28.7 结论

```text
不是不行
是当前 QP 还没加姿态约束/任务
```
