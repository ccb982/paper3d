# 下盘两 PD 重构（2026-11-05）

## 0. 结论

下盘只有两个肌肉 PD：

```text
HipTaskPD   : hip0 / hip1 / hip2
ShankTaskPD : knee0 / knee1 / knee2 / foot0 / foot1 / foot2
```

所有下盘关节力矩，包括主动、被动刚度、阻尼、共收缩、力矩饱和，全部由这两个 PD 输出。  
命令层只出神经信号（目标 / 前馈），不直接写关节力矩。

关节限位不属于 PD。它是执行器/引擎的硬约束，继续留在执行器与引擎。

上身不在本次范围：`drive` 对脊柱、颈、肩、肘的阻尼、被动、pair、IAP、SRS 全部保留。

---

## 1. 下盘三层命令

```text
① 矢状基础力
② 矢状回正（髋 + knee2 目标）
③ 侧向回正（只给 shank/foot 目标）
```

### 1.1 矢状基础力

```text
纯前馈
维持目标姿势
不参与回正
输出给 PD 的 ff
不直接写执行器
```

### 1.2 矢状回正

```text
输入：H* / CoM / hip 误差 / 髋高
输出：hip0 / hip1 / hip2 / knee2 / foot2 目标 + 髋前馈
交给 HipTaskPD / ShankTaskPD
```

### 1.3 侧向回正

```text
只负责局部力链 / 抓地
只输出 foot0 / shank 目标
不写 hip0
不写 hip2
不负责救全身 CoM
```

硬规则：

```text
侧向层不碰髋
髋偏差归矢状层
侧向层不允许再出现独立 kp/kd 的第三套 PD
```

## 2. 两个 PD 的内部模型

每个 PD 内部包含四类机制，但只有一个写手：

```text
① 主动
   a      激活动力学
   co     共收缩
   fL/fV  力-长度 / 力-速度

② 被动刚度
   kEff   关节囊 / 韧带 / 肌腱 / 被动弹簧
   slack / deadband / hardening

③ 阻尼
   kd     关节阻尼
   bEff   被动黏性阻尼

④ 读数
   tension 关节张力，只读，不产生额外力矩
```

输出：

```text
τ = τ_active
  + τ_passive_stiffness
  + τ_passive_damping
  − kd·v
```

约束：

```text
同一 DOF 只允许一个力矩写手
τ 先由 PD 汇总，再统一 propose
不允许 drive 再对同一轴 addPassiveTorque / addTorque
```

## 3. 被动 / 抗阻层归属

### 3.1 搬进 PD

```text
P2:
  resistTorque 的 kEff / bEff / deadband / hardening

drive td:
  仅下盘 PD-owned 轴

passiveSquatKneeK / passiveSquatFootK:
  作为 PD 被动兜底，不能与 P2 重复叠加
```

### 3.2 保留在 drive

```text
上身 spine / neck / shoulder / elbow 的阻尼、被动、pair、IAP、SRS
```

### 3.3 不进 PD

```text
关节 min/max
限位冲量
hard stop
preRing / engine motor
接触 / 摩擦 / CoP
base 前馈本身
```

## 4. 被动参考与“虚拟支撑”

当前 P2 的参考角来自 `squatClean` 设置的 IK 目标：

```text
setPassiveRef(..., ik.*)
```

这不是纯被动，而是隐藏的虚拟弹簧/支撑。收敛分两种情况：

```text
纯被动：
  ref = rest / slack / neutral
  只保留被动刚度 + 单向阻尼

显式支撑：
  作为命令层目标进入 PD
  不允许藏在 drive 里
```

在完成这一步前，P2 的数值和公式保留，不能直接关闭；关闭会掉蹲姿时长。

---

## 5. 执行边界

```text
命令层
  → 目标 / 前馈
  → HipTaskPD / ShankTaskPD
  → 唯一 propose
  → 执行器/引擎
  → 关节限位、限位冲量、hard stop
```

PD 内部可以有：

```text
τmax 饱和
力矩 cap
激活状态
张力读数
```

PD 内部不能有：

```text
关节角 min/max 修正
限位冲量
第二条 drive 直写通道
```

---

## 6. 禁止项

```text
1. 侧向层写 hip0 / hip2
2. 第三套侧向 PD
3. drive 对下盘 PD-owned 轴直写 P2 / td / passive
4. 同一轴 PD 和 drive 双阻尼
5. 命令层直接写力矩
6. 把关节限位塞进 PD
7. 全局关闭 drive（上身会塌）
```

## 7. 验收

```text
① tsc 通过
② 下盘每个 PD-owned 轴 applied == cmd（允许执行器饱和）
③ 下盘没有 drive.addPassiveTorque / drive.addTorque 直写
④ 上身力矩/阻尼与重构前一致
⑤ gate 不因重构明显下降
⑥ live 蹲下法庭不短于基线
```

## 8. 实施顺序

```text
A. PD 类内部接入被动/阻尼
B. drive 对下盘 PD-owned 轴停止 P2 / td / 被动兜底
C. 删除 squat.resist 旧路径
D. 跑 writer 审计与 gate
E. 保存基线

G. 最后做命令层调度
```
