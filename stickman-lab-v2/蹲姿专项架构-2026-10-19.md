## 二、三层架构（与站立同构）

```
┌─ 基础力 = 固定前馈（用户：'基础力就是固定的力'）──┐
│ **捕获式**：释放时用 staticBalance 算一次        │
│   （目标姿势处的抗重力力 τ_j = −[N×(CoP−x_j)    │
│    + Σ子树 m·g·(x−x_j)]），之后**每帧原样应用**  │
│   ——不重算！（每帧反解=和回正力对抗=不稳真因）    │
│ 论文: Kuo 1995（前馈固定+反馈纠偏=协同）；       │
│   Loram & Lakie 2002（刚度只是临界的91%）        │
│ SQB_LIVE=1 = 调试（每帧反解旧行为）              │
│ 状态隔离: 离开蹲姿清缓存                        │
└─────────────────────────────────────────────────┘
┌─ 回正力 = 反馈（肌肉对）────────────────────────┐
│ 命令: (C, ref)——C=0.7（共收缩）、ref=法庭 ang0  │
│ 肌肉净力矩 = C×K×dev（K=1100，kmul=1，腿×1.0）  │
│ **双向 dev 缩放阻尼**（用户：'回程正常/离远大'） │
│   dampK=1.5 + |dev|×50（双向=真耗散）           │
│ 全轴覆盖: hip/knee/foot/spine×3/**shoulder/elbow**│
│   （手臂固定到捕获角——'手臂乱动'修复）          │
└─────────────────────────────────────────────────┘
┌─ 张力层（单向阻尼，耗散）───────────────────────┐
│ τ = −kdT×vEff（只抗"偏离扩大"方向，回程零写入）  │
│ kdT = min(70, 30×部位系数 + |dev|×280)          │
│ 惯量帽: kdT ≤ 0.5×2I/dt（显式稳定域）           │
│ 速度上限: vEff = clamp(v, ±2)（防释放瞬态爆）    │
│ **pair 让位**: 肌肉管的轴（pairCTarget>0）张力跳过 │
└─────────────────────────────────────────────────┘
┌─ 被动阻尼（状态隔离！）─────────────────────────┐
│ kdUse（NaN 回退）: 站立=0.02×tauMax（原值保持） │
│                   蹲姿=min(0.02×tauMax, 0.5×2I/dt)│
│ （'为什么容易高频抖动'真身：踝预算320→6.4 巨型   │
│  被动阻尼；预算≠阻尼尺度！站立依赖故隔离）        │
└─────────────────────────────────────────────────┘
```
