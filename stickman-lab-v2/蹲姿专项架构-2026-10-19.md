## 二、三层架构（与站立同构）

```
┌─ 基础力（antiG 直接写）────────────────────────┐
│ staticBalance（约束静态平衡）:                  │
│   τ_j = −g×[ N×(CoP−x_j) + Σ子树 m·g·(x−x_j) ] │
│   腿=子树+GRF项（N=W×share、CoP=CoM投影钳位）    │
│   增益: SQB_GH=1.2（髋）/ SQB_GU=1.0（脊柱）     │
│   SQB_ON=1 时 tq 表值让位（单一来源）            │
└─────────────────────────────────────────────────┘
┌─ 回正力（肌肉对）──────────────────────────────┐
│ 命令: (C, ref)——C=0.7（共收缩）、ref=法庭 ang0  │
│ 肌肉净力矩 = C×K×dev（K=1100，kmul=1）          │
│ 纯姿势（dev），零阻尼（阻尼归张力层）             │
│ 全轴覆盖（0/1/2——每个轴都要有）                 │
└─────────────────────────────────────────────────┘
┌─ 张力层（单向阻尼，耗散）───────────────────────┐
│ τ = −kdT×vEff（只抗"偏离扩大"方向，回程零写入）  │
│ kdT = min(70, 30×部位系数 + |dev|×280)          │
│ 惯量帽: kdT ≤ 0.5×2I/dt（显式稳定域）           │
│ 速度上限: vEff = clamp(v, ±2)（防释放瞬态爆）    │
│ **pair 让位**: 肌肉管的轴（pairCTarget>0）张力跳过 │
└─────────────────────────────────────────────────┘
```
