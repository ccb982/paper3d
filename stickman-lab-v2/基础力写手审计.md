# 基础力写手审计（2026-10-16）

> 本文的公理（用户定调）：
> 1. **基础力 = 只包含基础力和张力**；回正力是单独的（"回正力是用来回正的"）。
> 2. **对抗重力的力用关节发力，要走审批（提案总线），别凭空发力。**
> 3. **只需要基础力就必须保持单腿稳定站立**；重心天然就是偏的，基础力维持的是单脚站着的状态。
> 4. **抬腿结束那一刻 = 标准态**；放开瞬间重力与主动力必须**互补**，全身始终维持这个状态。
> 5. 侧向：**"侧向力反正是完全不够"** —— 竖直打通后，回正力是最后的战场。

### 4.2 全关节×全轴回正力矩阵（新体系 —— 46 轴全覆盖）

**通则**（用户 2026-10-16 定调："每个关节每个轴都要有回正力"）：
1. 每轴回正力 = **回标准态弹簧**（`kp·(θ_std−θ) + kd·(−ω)`）+ **方向修正项**（仅承重/平衡链）+ **预算帽**（仅承重链）
2. 标准态 `θ_std` = 抬腿结束那一刻捕获（`captureSupportPose`/`standardPose`，与法庭 ④ 同源）
3. 回正力独立于基础力：基础力（gcomp+张力）先稳住身体，回正力在其上拉回标准态 + 动态修正
4. 一轴一写手（提案总线；通道复用 torque/pair/angle/motor）

### 4.4 设计原则

1. 回正力**独立于基础力**（基础力必须能单独站立）
2. 权限按脚上力预算（`fz·fw·copK`），不许凭空发力
3. 一轴一写手（提案总线仲裁；直写者待迁）
4. **旧回正力（本表之前的一切调参）全部作废**
5. 回正力 = 回标准态（弹簧）+ 动态修正（CoP/CoM/XCoM）两层职责
