## 1. 论文依据

| 文献 | 结论 | 对实现的约束 |
|---|---|---|
| **Hill 1938**（力-速度关系） | 肌肉力-速度是双曲线 `(F+a)(v+b)=(F0+a)b`，阻尼本质来自**速度** | 阻尼必须 ∝ 速度，不得含位移项 |
| **Haeufle et al. 2014**（J Biomech 47:1531） | Hill 四元件：CE + PEE + SEE + **串行阻尼 SDE**；串行阻尼是抑制高频振荡的关键 | 阻尼是独立耗能元件，不与弹性（回正）混写 |
| **Günther et al. 2007** | 被动肌腱组织阻尼负责抑制高频振荡 | 高频抖动必须由阻尼吸收，不能靠加大回正力 |
| **Lorentz & Martin 1999；Martin et al. 1994** | 黏性系数 `B(v)` 是**速度的函数**，与位移无关 | 禁止 `|dev|×k` 这类位移项 |

**结论**：阻尼 = 纯速度耗散项。位移项（弹簧）属于回正力，不属于阻尼。

## 2. 系统定义（唯一写手）

```
写手：stability.ts 的张力层（⓪），全项目唯一
公式：τ_damp = −b · ω        （仅当 outward = dev·ω > 0 时施加）
系数：b = tensionK × I_eff × 2·dampBand
      I_eff   = body.jointInertia(dof)     （子树绕关节轴的有效惯量）
      tensionK, dampBand = BASE_TABLE[state].params（每状态一组）
通道：damp 桶（绝不写入 ff / servo / act）
```

- 全身**同一公式、同一套参数**，不存在分部位倍率；
- 速度为零 → 阻尼为零（静止不发力）；
- 只耗能，不产生任何回正目标。

---

## 3. 禁止事项（硬约束）

1. ❌ 分部位阻尼（LEG/SPINE/NECK/ARM × SAG/LAT 倍率表）；
2. ❌ 位移项（`|dev|×280` 这类"偏移越大阻尼越大"）；
3. ❌ 第二套阻尼（`srsSpineDamping`、drive 的 `td`、各处零散 `damp`）；
4. ❌ 阻尼写入 `ff` 桶（导致基础力读数混入阻尼）；
5. ❌ 为了站位/蹲位单独新增阻尼写手。

新增任何一条 = 违反规范，必须回退。

---

## 4. 参数表（数据，非代码）

**架构/实现只有一套**：同一个写手、同一公式 `τ = −b·ω`、同一段代码。
**参数是数据**，按"状态 × 部位"存于 `BASE_TABLE`：

```ts
BASE_TABLE[state].damp = {
  leg:   { tensionK, dampBand },
  spine: { tensionK, dampBand },
  neck:  { tensionK, dampBand },
  arm:   { tensionK, dampBand },
}
```

- 站立/蹲姿各自一套数值；
- 腿/脊柱/颈/臂各自一套数值；
- 但**代码只有一份**：查表 → 算 b → 施加，无任何部位分支。

调参流程：
1. 冲击测试（给关节一个初始速度）；
2. 看速度衰减曲线：过慢 → `tensionK`↑；过冲/振荡 → `dampBand`↑；
3. 两个状态各自标定，互不影响。

---

## 5. 验收标准

- 静止时 `τ_damp ≈ 0`；
- 受扰后单调衰减、无持续振荡；
- `ff` 桶只有基础力；
- 全项目仅此处一个阻尼写手。

---

## 6. 历史教训（为什么写这份文档）

2026-10 多次出现"站立/蹲姿持续抖动收不住"，根因都是同一个错误：

```ts
kdT = kdBase + |dev| × 280;   // 位移项 → 隐式弹簧 → 与回正力双回路 → 越调越荡
```

并且该写手用 `kind:'torque'` 写进了 `ff` 桶，导致"基础力读数里混有阻尼"，排查时误判为基础力问题。

**本规范的目的：让这类错误在结构上不可能再出现。**
