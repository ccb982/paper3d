# code-merge-tool

把整个项目合并成**单个文本文件**，供 AI 网页审阅并给出**精确修改指令**。

## 解决的问题
项目源码超过 50 个文件后，AI 网页无法逐个查看。本工具把全部源码合并到一个 `.txt`，并附带：
- 每个文件段标注 **文件路径** + **行号**（每文件从 1 开始）
- 文件头有详细说明，要求 AI 输出「文件 / 行范围 → 替换内容」的精确指令
- 项目完整文件结构树，供 AI 定位参考

## 使用方法（网页版，无需安装）
直接用浏览器打开 `index.html`（**Chrome 或 Edge**）：
1. 点「📁 选择文件夹」，选中你的项目文件夹
2. （可选）调整：包含扩展名 / 忽略目录 / 单文件上限
3. 点「⚡ 扫描并合并」
4. 点「⬇️ 下载合并文件」，得到 `<项目名>_merged.txt`

注意：
- 浏览器**只读取**文件夹，不会修改项目任何文件
- 若按钮无反应，请确认浏览器为 Chrome/Edge，且页面在 `localhost` 或 `https` 环境（直接双击打开 html 文件也可用）

## 拿到修改指令后怎么应用
AI 会输出形如：
```
### 修改指令 #1
文件：src/components/Foo.tsx
替换范围：从第 12 行 到第 40 行

↓ 将此范围内的内容，全部替换为以下内容 ↓
```（新代码）```
```
用编辑器打开该文件，按「文件名 + 行号范围」手动替换即可。
（工具不自动改源码，保证安全；可放心把合并文件发给 AI）
