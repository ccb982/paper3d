## 2. 目标态（终版口径，一次性收拢 = 施工验收的"应然"）

### 2.1 双轨：命令是命令，寻路是寻路
```
命令轨（大队独占）：事态 → 大队 → 发令前【初级寻路】核验可执行 → SquadOrder{anchor, intent, coarse, ttl}
   · 命令三件套 = 目标（地点/队伍锚）+ 大致路径（coarse，初级寻路副产物）+ 战术意图
   · **命令不可变总律**：发出即冻结；后继只有【覆盖】（新令 seq++ 整体替换）与【中断】（作废/撤销）；
     原地修改一律禁止。覆盖权分层——大队命令只被大队覆盖（自主修改=覆盖新令）；
     小队无覆盖权，仅严重时申报→大队批准→**由大队覆盖**；否则等大队自主修改
   · 撤销权只在大队（损失>60% → withdraw）；小队只上报 progress/伤亡/contact，不能改派、不能撤销
寻路轨（小队自治）：寻路 = f(L1 地形语义 ⊗ L2 工事 ⊗ 事态函数)   ← 就这三个参数
   · 合成层 → L3 scoreFor → 路径代价/选点；小队在 scope 内自主拆步 + 执行，coarse 仅软参考
   · **小队级寻路命令同样不可变**：执行中调整 = 发新寻路命令**覆盖**上一个（覆盖权在小队）；
     只能被覆盖/中断，不允许原地修改
   · 执行期【时刻读】动态参照（不入合成、不触发重规划）：玩家位置 / 被保护对象位置 /
     掩体位置+LOS（防守复核"自己真的被掩体挡住"，没挡住就挪）
唯一交叉点：命令给"区块+意图+大致路径"（scope），不是逐格路径
```

### 2.2 寻路三参数 + 兵种第 4 环
- 合成层（✅ 已存在）：`score = Σ 七项特征 × weightsFor(p, posture)`（事态=权重参数）；
- **L3 `scoreFor(兵种,x,z)` = 合成字段 ⊗ 兵种特征权重 ⊗ lerp(def,atk,p)**（⏳ 本次新建）：
  盾=隘口/掩体 · 突=隐蔽接近/迎船坡 · 远程=高地+射程带+掩体 · 后勤=后区；
- 工事 = 寻路**代价项**（折扣 0.6~1，仅重规划读）：不是硬边界、不触发重规划。

### 2.3 两级寻路
| 级 | 归属 | 职责 |
|---|---|---|
| **初级（粗）** | 大队 | 发令前查"命令能不能落地"（簇级连通/走廊粗判）；不可达 → 缩近/换目标；**核验顺产【大致路径 coarse】随令附带**（走廊级参考） |
| **主（细）** | 小队 | 拆步、选格、路径锁定、替换、执行止损——主寻路+执行全在小队；**参考 coarse 但以三参数合成分为准**，可随时换走廊 |

### 2.4 事态函数的三个输出面（同源三处消费）
① 合成层权重 `weightsFor(p,posture)`；② 兵种攻防混比 `lerp(def,atk,p)`；③ **`frontP` 允许离舰半径**（`frontMinD`，S1 封顶 0.35，`SHIP_CLEAR=16m`；probe 断言越界命令=0）。

### 2.5 命令轨修复口径（P0/P1）
- **使命化 TTL**：分钟级使命（build/guard/garrison）TTL ≥ 30s + 同签名 keep-alive（`applyOrders` 在身续期不 drop）；短使命（advance/regroup）维持秒级；
- **保护配额**：同一保护对象 ≤ 2 队（`protectAssign` 拒超额）；
- **garrison 节流**：同目标同位 4m 内不重发。

### 2.6 铁律（沿用不改）
唯一执行层 `SteerPick`；禁止向量合成；命令只从大队下发；不碰地基；工兵总攻只 `setTrenchPaused(true)` 不作废战壕。

## 6. 纪律（施工期间每日自检）

1. **一 commit 一步**，commit 信息标 `[重构 Px-N]`；随时 revert 单步回退；
2. **旁路并存 → 逐点切换 → 删旧路**：新旧出口并行期 probe 打 diff，禁止一步全切；
3. **每步四关**：`npx tsc --noEmit` → `npm run guard` → 固定 seed probe → 文档标 ✅/⏳；
4. **观测先行**：先加探针断言，再写实现；
5. **不碰地基**：`ChunkManager / RasterMap / FaceBuild` 与玩家管线一律不动；
6. **两文档同步**：设计权威（《敌人管线设计.md》）+ 施工图（本文）随每期更新，处置表逐行销账；
7. **命令不可变**：任何命令（大队令/小队寻路令）发出即冻结——只允许**覆盖**（新令整体替换）与**中断**，
   写代码时禁止原地改命令字段；覆盖权按 §2.1 分层（大队令=大队覆盖，寻路令=小队覆盖）。
