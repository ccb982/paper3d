## 0. 总则（容器 / 加载 / 命名 / 兜底）

| 项 | 规则 |
|---|---|
| 两类容器 | `.ftx3.gz` 纯帧序列（可带 VAT 实体/流体元数据；图标/标记/贴片）；`.scene.zip` 特效包（帧 + 流体参数 + annotations + `hit_effects.json`；战斗实体/特效） |
| 加载器 | `Asset.load(url)`（scene.zip 优先）/ `FtxAsset.load(url)`（帧包）；中文路径一律 `encodeURI` 包裹 |
| 命名 | 直接用作者素材中文原名（如 `维什戴尔子弹.scene.zip`）；同素材两种格式**同名不同后缀** |
| 放置 | `public/characters/`、`public/fx/`、`public/fx/bullets/`、`public/ui/`、`public/textures/`、`public/models/`（预留） |
| **兜底链** | `scene.zip → ftx3.gz → 占位素材（无人机）/ 色块兜底`——任意一环缺失只降级、不报错（各代码点见 §2/§3/§4） |
| 替换素材 | **覆盖同名文件即可（零代码）**；新增素材 = 放文件 + 按各表「接入点」登记一行 |
| 素材调试 | URL：`?group=<组key>`（单组 + 单 chunk 陈列馆 + 地块名标注）、`?single=1`（仅陈列馆）、`?preset=<预设key>`（结构预设）；控制台 `setTestGroup('crystal' | null)` 运行时换组 |

### 1.2 材质接入规范（加材质 = 三步）

1. `TileMaterials.ts`：`registerTileMaterial({ fnId, label, base, detail })`（`fnId` 唯一，重复抛错）；
2. `TerrainMaterial.ts`：`MAT_FN_INDEX` 登记一行 `fnId → GLSL 索引`（数据驱动分发，容量留余量；改大时同步 GLSL 数组尺寸）；
3. `TerrainMaterial.ts` 的 `MATERIAL_GLSL` 写 `mat_<fnId>(f, w, id)` + 细化 `mat_<fnId>_hi(...)`（水/卵石是免 `_hi` 分支的例外）。
   > 同 `fnId` + 不同 `params` = 变体（地块侧 `material.params` 覆盖）；地块级底色另外可用 `visual.baseHsl` 覆盖（变体皮）。

| 采集物 key | 名称 | 图集文件（`public/textures/`） | 世界尺寸（米） | 掉落 |
|---|---|---|---|---|
| `herb_grass` | 药草丛 | `草.ftx3.gz`（4 帧） | 1.4 | `herb` |
| `flower_bloom` | 野花 | `花.ftx3.gz`（4 帧） | 1.2 | `flower` |
| `berry_bush` | 浆果丛 | `浆果丛.ftx3.gz`（4 帧） | 1.8 | `berry` |
| `young_tree` | 小树 | `树.ftx3.gz`（4 帧） | 4.8 | `wood` |

> 世界尺寸 = 基准 `params.size` × 放置 `scaleRange` × 每株随机浮动 0.8~1.2（位置 hash，确定性）；
> 着地 = 再按尺寸整体下沉 15%（`params.groundSink` 可按 key 调），抵消贴图底边留白。

- **渲染** = `render: 'plant'`（`MapEntityDecorBase`）：交叉面片 + 图集抽帧贴图（**4 帧 = 4 种独立外观**，每株放置时按确定性 hash 随机抽 1 帧**静态**显示，不轮播）；**4 帧合为一张纹理数组（`DataArrayTexture` + `sampler2DArray`），每采集物每 chunk 仅 1 个 InstancedMesh**（帧号走实例色 `instanceColor.r`——绘制调用比旧"每帧一个网格"减少约 60%）；**上部扭动 = VAT 顶点位移**（每 key 一张预烘焙偏移纹理 `getPlantVat`：uv.x=高度、uv.y=相位，RG=世界 XZ 偏移含 `v²` 梢强权重；顶点着色器单次采样位移——贴图本身不变形、边缘清晰；卡片竖直 8 分段保证弯折平滑；根部两点固定；每株相位按位置 hash 不同步；**风归零的远处（≥60m）跳过 VAT 采样**）。
- **三级 LOD**（`lod: true`，逐实例按距离，对齐全局 `LOD_RANGES=[30,60,90]`）：
  ① **<30m** 交叉面片 + 满风；② **30–60m** 风幅度渐隐归零；③ **75–105m 几何缓慢过渡（1↔2 级）**：侧面片宽度 1→0 缓慢收拢（同一网格、单份贴图——不会出现「第二份贴图突然出现再虚化」的重影；带宽 `PROP_LOD_CROSSFADE=30m`，中心 `PROP_LOD_SWITCH_MID=90m`）；④ **105–140m** 单面片形态，**120→140m 整株 alpha 渐隐**（LOD3 雾隐）；**≥140m 不绘制**（顶点级折叠到裁剪空间外，零片元；距离常量 `PROP_LOD_FADE_FAR` / `PROP_LOD_FADE_TAIL`，可调）。
  渲染 = **边缘硬裁切 + 末端渐隐**：`if (c.a<0.5) discard` 先裁掉贴图边缘的过滤像素（线性过滤/mipmap 的半透明黑边不会混合成「透明描边」，1/2 级边界干净）；仅在末 20m 才把整株 alpha 淡出（此段已很小，混合无描边观感）。
  另加 chunk 级预剔除：chunk 中心 >（140m + 半对角≈182m）→ 整组不提交 draw call（`ChunkManager.updatePropLod`）。
- 注册/掉落唯一出口 = `src/services/map/decor/CollectibleProps.ts`；无物理、JS 索引查询、接触自动入包（见《开发说明书》采集物系统）。
- 缺图集 → 该采集物自动不生成（boot 警告），不影响其它系统。
- 加采集物 = 放一包 `public/textures/xxx.ftx3.gz`（建议 4 帧 256²，根部对齐图片底边）+ `main.ts` 加载循环加一行 + `CollectibleProps.ts` 注册一条。
- 其它装饰（原石晶体/水泥台座等）仍为程序化几何（`render: 'instanced'`），无外部素材。

## 7. 素材填充 checklist（工作流）

1. 文件放进 `public/` 对应目录（替换 = 同名覆盖，零代码）；
2. 新增资源按各表「接入点」登记（材质三步 / 兵种一条 / 图标三招 / UI 一行 loader）；
3. `npx tsc --noEmit` 过门禁；
4. 游戏内验证：`?group=<组>` / `?single=1`（地块）、`?preset=<key>`（结构）、常规进图看实体/图标；
5. 性能回归：`?perf=1` + `scripts/perf/measure.mjs` / `profile.mjs`（口径见《性能评估报告.md》）；
6. 同步文档：本表 + 涉及结构时补《地形与渲染管线架构.md》。

## 8. 与其它文档的分工

- 本文件 = **素材文件清单与接入规范**（放什么、放哪、怎么接）；
- 《地形与渲染管线架构.md》= 地形生成/渲染管线原理（材质 GLSL、LOD、装饰管线细节）；
