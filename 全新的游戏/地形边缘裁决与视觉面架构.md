## 1. 核心原则（五条铁律）

1. **裁决对象是"边"，不是"地块"**。过渡是两个块的共享边界属性；
   角点是边的派生（硬顶点规则，见 §3.2）。
2. **裁决是纯函数、确定性、对称的**。输入只含两块的 def/height 与上下文常量，
   同 seed 同边恒同结果，与加载顺序无关；主线程与 Worker 跑同一份代码。
3. **视觉面语义只有一个真源**。任何"这里地面多高 / 这条边是不是断崖"的提问
   必须走 SurfaceRules；禁止消费者各自复刻 max-2×2 或自行插值。
4. **消费者全部派生，零自行决策**。渲染网格、物理 trimesh、烘焙快照、
   贴地查询、AO 断崖衰减、移动阻挡都从同一份裁决/顶点语义派生；
   物理 trimesh 与渲染网格来自同一构建产物（碰撞=所见不变式）。
5. **对外纯净、下行全消费（2026-08-29 精修层意志）**。精修层是逻辑中枢，
   内部可以是最复杂的层级，但**复杂度只许收敛在本层内部**：
   · 对外只暴露【定型产物】+ `surfaceHeightAt`/几何这一个纯净口径；
   · 装饰层、渲染层、物理、贴地、烘焙、墙**一律只读精修层产物**，
     不反向摸规则链、不复算边裁决、不感知精修意图列表——
     精修层一旦定型，下游就是纯消费；
   · **唯一判点不变式**：任何时刻某条边的过渡只有 `edgeFinal` 一个答案，
     能在它之外影响裁决的第二处代码即违例（回归抓此）。
   —— 内部随便多复杂都行，对外只有一个干净出口；这是"最复杂的层反而
   最稳"的原因：复杂度被这张边界拦住，不泄漏到下游各个系统。

## 2. 边级裁决（EdgeRuling）

### 2.0 裁决结论

```
EdgeRuling = 'weld' | 'cliff'
  weld  —— 两侧连续过渡：低侧边界顶点拉到高侧高度（= 旧 max-2×2 几何）
  cliff —— 硬突起边界：两侧各持各的平面高度，边界处生成竖直墙
```

### 2.1 规则链（有序短路，首条命中即裁决）

| 位次 | 规则 | 结论 | 状态 |
|---|---|---|---|
| 1 | TileDef 覆盖：任一侧 `physics.edgePolicy === 'hard'` | cliff | ✅ |
| 1' | TileDef 覆盖：任一侧 `edgePolicy === 'smooth'`（两侧同为 hard 时 hard 胜） | weld | ✅ |
| 1.5 | 角色对规则（α 对表首实例，2026-08-29）：**仅 ground↔ground 放行** | 其余角色对一律 weld | ✅ |
| 2 | β 微高差（仅地面↔地面到达此位）：`|Δh| ≤ EDGE_CLIFF_BAND(0.35)` | cliff | ✅ 默认 |
| 3 | 兜底 | weld | ✅ |

- **角色对规则的由来**：设计意图是"**只有地面↔地面用硬边界，其余一切用插值**"。
  实测（33750 边）曾显示 β 按高差一揽子判硬把同档高台板缝（4403）、
  水面台阶（1260）、坑缝（767）也判成了 cliff——与意图冲突，故插入本位次。
  落地后 cliff 仅剩 ground|ground 15142 条（44.9%）。
- **风格组规则是预留扩展位**：按"越具体越靠前"插在位次 1.5~2 之间，
  加规则 = 改链配置，消费端零改动。
- **默认策略的语义**：地面↔地面（含装饰皮）露出方块感台阶；
  高台板缝/水面/坑/跨类大高差全部维持插值过渡（今日天际线）。

### 2.2 ★ 带宽取值推导（为什么是 0.35 而不是 0.5）

各类型对的 |Δh| 实际分布（L4 高度公式决定）：

| 类型对 | Δh 范围 | β(0.35) 裁决 |
|---|---|---|
| 地面↔地面（含装饰皮） | < 0.16 | cliff（方块感台阶） |
| 同档高台↔同档高台 | ≤ 0.30 | cliff（板缝） |
| 异档高台↔异档高台 | ≥ 0.70 | weld（梯田坡道，今日不变） |
| 地面↔高台 | ≥ 0.93 | weld |
| 水↔高台 | ≥ 1.55 | weld |
| **水↔地面** | **0.38 ~ 0.62** | weld（< 0.35 才 weld？否——见下） |
| 坑↔任意 | ≥ 2.88 | weld |

⚠️ 水↔地面分布 (0.38, 0.62) 恰好**跨骑 0.5**——带宽取 0.5 会让水岸随逐块抖动
随机出现台阶或斜坡（不可接受）。取值必须落在 (0.30, 0.38) 或 (0.62, 0.70)：

- **0.35（定稿）**：水岸维持今日插值观感；台阶只出现在"同一平面类内部"——
  与默认策略表逐格一致的最小偏差。
- 0.65（备选）：水岸全部变台阶（更有方块感），改一个常数即可切换。

> ⚠️ 实测校正（2026-08-29）：上表按设计期分布推断，其中"坑↔任意 ≥ 2.88"
> 被实测推翻（pit|pit 存在 ≤0.35 高差对）。位次 1.5 角色对规则落地后，
> β 只对 ground|ground 生效，此类推断误差不再影响裁决结果。

### 2.3 端口连续性推论（无需端口规则）

跨 chunk 端口两侧都是 `flattenAtPorts` 平整块（高度恰为 0），Δh = 0 →
cliff 结论但落差为零 → 几何上无墙、板面同高连续——`flattenAtPorts`
的"跨块顺滑衔接"契约被 β 自动满足，**裁决链不需要端口特判**。
（块内端口衔接处 ≤ 0.12m 小台阶属于地面方块感语义，可踏过。）

## 3. 视觉面语义（SurfaceRules 唯一真源）

### 3.0 三层高度（禁止混用）

| 层 | 内容 | 消费者 |
|---|---|---|
| 逻辑高度 | L4 逐块恒定平面（`heightAt`），永不混合 | 生成、AI、摆放、Boss4D 旧路径 |
| 视觉面高度 | 裁决派生（`surfaceHeightAt`） | 渲染、物理、贴地、烘焙、影子 |
| 可遍历性 | 裁决 × 两侧 walkable × stepHeight（派生） | 移动阻挡、未来寻路 |

### 3.1 单元四角归属规则（核心公式）

网格基本单位 = **米格 cell**（1×1m，恒属于唯一 4m 块）。cell 的四个角点高度：

```
cornerHeight(块B@块坐标, 角点v):
  B 在 v 处的边界边段（与异块共享，0~2 条；同块内段不计）
    任一段裁决为 cliff → 返回 hB（自持：硬边直达角点，零插值）
    全部为 weld        → 返回 max(环绕 v 的 2×2 格高度)  ← 与旧公式逐位一致
cell 高度场 = 四角高度按三角形插值（对角线 (lx,lz+1)-(lx+1,lz)，fx+fz≤1 取 T1）
```

- **weld 边**：边界角点被 max 拉到高侧 → 低侧首列 cell 自然形成 1m 过渡坡
  ——与旧 PlaneGeometry 位移逐位等价（同顶点值、同剖分对角线）。
- **cliff 边**：两侧块的角点段皆 cliff → 各自自持，两侧 cell 各自平坦到边界，
  竖直落差由墙补（§3.3）。
- **角点**：插值许可按 §3.2 逐块判定——两边皆 weld 才吃 max，
  任一硬边介入即自持。
- 单元内全平坦（block 恒定高度）→ 板；weld 坡只存在于低侧首列。

### 3.2 角点插值许可规则（2026-08-29 定稿，取代旧"全局硬顶点"规则）

角点 v 环绕至多 4 块；块 B 在 v 处是否允许插值**只看 B 自己的边**
（"这角的插值必须两边有插值边才可以"）：

- **两边皆有插值边**（B 在 v 处的边界边段全部裁决 weld，含 0 段内角）
  → B 取环绕 2×2 max（插值）。
- **任一边段为 cliff**（一边硬一边坡，或两边皆硬）→ B 自持 hB，零插值
  ——硬边直达角点，"既然是硬边界就一点插值都不沾"。

推论与效果：

- **混合角**（如 A-B weld 与 A-C cliff 相交）：cliff 一侧自持到角，
  weld 坡以满高度到达角点——**插值只由 weld 边自己的选择产生，
  硬裁决只会 subtract**；旧版"硬裁决把坡道末格拖出对角斜坡（taper）"
  的现象随之消除。
- **weld 边端点**：周围无硬边介入时两侧同取同一 max → 恒吻合，
  weld 边全程无缝（含端点）。
- **纯 weld 世界**（β 关闭 band=-1）：一切边段皆 weld → 一切角点恒 max
  → 与旧公式逐位一致（回归 A 阶段依赖此不变式）。

⚠️ ~~已知边界情况（端点错位缝隙）~~ **已由 §3.3 通用侧壁防御闭合（2026-08-30）**：
混合角 + 对角高块 + 无墙 weld 边时，weld 侧被对角高块经 weld 边拉高、cliff
侧自持 → 该 weld 边末段曾出现 ≤1m 宽竖直错位缝。现统一判据（高顶 − 低面板
底 ≥ SEAM_EPS）使任何此类错位都补竖直墙，缝隙不再漏孔。

### 3.3 cliff 墙 + 通用侧壁防御（2026-08-30 统一判据）

- **统一判据（唯一公式，cliff/weld 两路共用）**：任一地块交界处，
  `高侧顶 − 低侧面板底 ≥ SEAM_EPS(=0.01)` 即视为悬空，该处空立即补竖直墙
  ——**底 = 低侧面板底 `baseHeightOf(低) − WALL_EPS`（深到底堵死）**。
  SEAM_EPS 0.01 量级：只要有错位就是缝。
  - cliff 因 hBase 缺省 = h → `baseHeightOf(低)=低.h` → 判据自然回落 旧 `drop>0`，
    几何不变（板 + 墙条，底边下探 WALL_EPS 防共面闪烁）。
  - weld 低侧若 hBase 更深 → 墙补到深底（= weldGap 的补墙语义，现已内联进统一判据）。
  - 取代旧 weld「还得 drop ≥ MIN_WALL_DROP(=0.5) 才发墙」的不对称门槛——正是它
    造成混合角/孤立角/对角高块的坡面侧壁漏竖直孔。
- **顶随视觉面**：墙顶不取平直高块顶，而是沿边界每米跟随 `cornerHeight`
  （取两侧块的 max）。clean 边界上 = 高块顶（与旧逐位不变）；混合角/对角
  高块把顶点经 weld 拉高时，墙顶随之抬升，自动封住 ≤1m 的坡面侧壁漏孔。
- **视觉**：并入 ChunkWalls 顶点色墙体体系（同一扫描器、同一明暗公式）。
- **物理**：墙三角形**必须**并入地面 trimesh——trimesh 无体积，低侧物体
  若无墙面会水平穿入高板体内侧坠落（单面网格下方 = 无底）。
- 大落差 weld 边（今日高台/坑壁）行为不变：墙 + 低侧隐藏坡（现状语义，
  未来按 §8 翻转）。

## 5. 移动语义（小落差可走，大落差上不去）

- 角色贴地 = WorldMode.clampCharacter（上行 7.5m/s / 下行 25m/s 限速）——
  **小台阶自动踏过由此天然成立**（0.3m 台阶 ≈ 40ms 抬升），无需新机制。
- **stepHeight ≡ EDGE_CLIFF_BAND（同一常量，注释互相绑定）**：
  β 默认产生的 cliff 全部 ≤ 0.35m → 全部可踏过 → **默认世界可达性与改造前等价**
  （坡道变可见台阶，玩法零变化，回归风险归零）。
- **大落差水平阻挡**（CharacterBase，面向未来 cliff 内容）：
  水平位移后若 `目标贴地高 − 当前脚高 > stepHeight` → 回退本次水平位移。
  β 默认下永不触发（无 > 0.35 的 cliff）；未来加"大落差断崖"规则即自动生效。
  跳跃余量：跳跃高度 ≈ 0.735m > 0.35，踏不过的断崖同样跳不上（符合"不可攀"）。
- 落水/坠坑死亡线（targetY < -1.5）不受影响（逻辑高度未动）。
