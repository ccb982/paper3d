## 结论（为什么）

1. **贪心硬门槛 `advance>0.5m` 禁止"先绕开"**：贴墙时沿墙两侧永远存在"更近"候选（±z 都满足），
   而绕墙必须先**背离**目标（advance<0）→ 永远选不到 → **贴墙振荡**。
2. **BFS 兜底永不触发**：贪心在墙沿线总能找到 advance>0.5 的候选，`feasOk` 回落分支进不去 → 没有绕障路径。
3. **山区同因放大**：崖带 + 10m LOS 候选少，振荡更明显（#85）；且防御价值把工事点拉向高地/崖边。
4. **水里**：本轮两 seed 未采到（waterFrac=0），机制预计相同（岸线/下游硬边的贴边振荡），待补采。

## 修法（待定，按"先有用路，再贪心"）

- **BFS 可走走廊作骨架**（有向、天然绕障）→ 贪心在骨架附近挑"更安全且仍可走"的点（前后段校验）；
- 或加**振荡检测**（净位移小/路径大、hop 方向反复换符号）→ 强制切 BFS 走廊；
- 保留 10m 短跳作为"沿骨架的平滑"而非唯一寻路来源。
