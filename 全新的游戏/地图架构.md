# 地图架构 —— 从生成到消费的单向流水线

> 定位：地图侧（地形）的**唯一权威架构文档**，描述当前代码的最终形态。
> 历史决策过程见文末《沿革》；《地形边缘裁决与视觉面架构》《精修层与定型快照架构》
> 《精修层过渡模型重构设计》三份旧文档已归档为指路桩，内容以本文为准。
> 状态：2026-08-31 定稿（硬边界基础 + 两插值函数 + 墙与裁决解耦）。

---

## 0. 一句话

**生成层定高度，精修层做过渡（墙=基础几何、坡=附加蒙皮），快照定型，下游纯消费。**

---

## 1. 分层总览（单向依赖，禁止反向）

```
L0–L5 生成   generateChunk → walkable / heights / blockTypes
             全方块模型：块高由 L4 assignHeights 定死，上游永不再变
L6 精修      Refinements.ts（唯一几何真源，纯函数、零 three、Worker 可加载）
             ├ 裁决：finalRuling（唯一判点）
             ├ 几何：cornerCell（唯一消费入口）→ interpEdge / interpCorner
             └ 产出：buildChunkFinal（顶面）+ buildChunkWallBuffers（墙）
快照         bakeCompute（Worker）→ per-chunk 定型快照
             （顶面缓冲 / 墙 raw / 贴图印章 / 阴影体积 / propVolumes）
消费         ChunkSurface 顶面 ┐
             ChunkWalls   墙   ├ 全部只读产物，零现算
             surfaceHeightAt 贴地┤
             ChunkAppearance 着色┘
             CharacterBase 移动（EDGE_CLIFF_BAND 台阶 + 坡面连续）
数据定义     Tiles（类型封闭 / 材质自由）· TileGroups（群系抽取）
```

两条逐位锁：**渲染 = 查询**（回归 D）、**快照 = 主线程**（回归 E）。

---

## 2. 精修层输入（只有一条路）

```
ChunkData (blockTypes + heights + groupKey)
  → makeChunkSource(readChunk)          无界块源：越界跨 chunk 读，永不 MISSING
  → refineChunkSource(src, seed, cx,cz) per-chunk 意图（planRefinements 恒空透传）
  → RasterMap.chunkSource(cx, cz)       对外唯一出口
```

- 三份 BlockSource 已合一；消费方各自建源的自算路径全部删除。
- `planRefinements` 定版恒空：地块高度 L4 已定死，精修层只做块间过渡，不灌内容。
- 块数据 `BlockInfo = { id, h, hBase? }`；缺块兜底 `MISSING_BLOCK = { id:0, h:0 }`
  （仅人工构造源可达；真实链路是无界源）。

## 3. 边裁决（weld | cliff）

### 3.1 规则（edgeRuling，纯默认引擎）

```
edgeRuling(a, b, dir):                       // dir: 0=+x 1=-x 2=+z 3=-z
  1. 任一侧 edgePolicy 'hard'                        → cliff
  2. 任一侧 edgePolicy 'smooth'                      → weld
  3. 任一侧 smoothDirs 声明该共享边（dir 或 dir^1）  → weld
  4. 兜底                                            → cliff
```

- **插值 = 显式 opt-in，默认恒硬边界立墙**。不配任何东西的世界 = 全 cliff 方块感。
- **对称性（构造保证）**：A 的 dir 边与 B 的 dir^1 边是同一条共享边，
  `edgeRuling(a,b,dir) ≡ edgeRuling(b,a,dir^1)`——两侧查询同值，永不撕裂。
- **方向性配置**（smoothDirs，per-tile 声明自己哪些方向的边参与插值）：

| 地块                | smoothDirs  | 语义              |
| ------------------- | ----------- | ----------------- |
| 高台 platform       | `[0,2]`     | +x、+z 边插值     |
| 岩台 rock_platform  | `[0,1,2]`   | +x、-x、+z 边插值 |
| 冰台 ice_platform   | `[0,3]`     | +x、-z 边插值     |
| 苔台 mossy_platform | `[0,2,3]`   | +x、+z、-z 边插值 |
| 水 water            | `[0,1,2,3]` | 全向插值          |

### 3.2 唯一判点（finalRuling）

```
finalRuling(src, bx, bz, dir):
  src.edgeFinal(bx,bz,dir) 有值 → 用之（显式钉死，回归/特判唯一入口）
  否则 → edgeRuling(本块, 邻块, dir)
```

★ 一切消费者只问 finalRuling，禁止直接调 edgeRuling。任何时刻某条边的
裁决只有这一个答案；能在它之外影响裁决的第二处代码即违例（回归抓此）。

## 4. 视觉面几何（撕裂面 + 传导场）

### 4.1 cornerCell（唯一消费入口，三层判定）

```
cornerCell(cell C ∈ 块 B, 顶点 V):
  1. V 处 B 有 cliff 边段 → B.h                          硬边界自持，压过一切
  2. V 落在 B 的 weld 斜坡带内（0 < t < w，B 为低侧）
       → interpEdge(src, B, dir, V)                      边插值，重叠带取 max
  3. 其余 → interpCorner(src, V)                         角插值（角向周围地块）
```

### 4.2 两个插值函数（插值 = 全部几何语义）

```
interpEdge(src, B, dir, V) —— 边插值
  dir 边裁决 weld 且 B 为低侧（hH > hL）
    → 剖面 s(t) = hH − (hH−hL)·t/w，t∈(0,w)，沿边 4m 不变（rampProfile 线性）
    → 否则 undefined（回落角插值）
  任意地块类型对通用：ground/platform/liquid/pit 无差别，Role 无关。

interpCorner(src, V) —— 角插值（base 无关，谁查 V 都同值 → 水密构造基础）
  候选集 = corner-open 块（在 V 处无 cliff 边段）的高度
         ∪ 触及 V 的每条 weld 边 crest(E) = max(h(a), h(b))
  触及角的插值边数自动覆盖：0 条 → 仅 open 块高；1 条 → 该 crest；
  2 条 → 两 crest 的 max（取更高，水密且无屋脊）。
  return max(候选集 ∪ {0})
```

- **斜坡是低侧块顶面的附加蒙皮**：坡带内顶面渲染 = 剖面采样；t=w 处精确落回
  hL，与块内平面对接无痕。线性剖面在 1m 网格上被三角形插值精确复现，零细分成本。
- **坡宽** `w = WELD_RAMP_CELLS = 2` 米（约束 4/w ∈ ℤ → w ∈ {1,2,4}；
  默认 2m ≈ 48°）。per-edge 覆写：`EdgeOverride.rampWidth → src.edgeRampWidth`。

### 4.3 贴地采样

```
sampleSurface(src, x, z)：查询点所在 cell 四角按【块归属】取 cornerCell 高，
  三角形插值（对角线 (lx,lz+1)-(lx+1,lz)，fx+fz≤1 取 T1）——与网格渲染逐位一致。
```

## 5. 墙（硬边界基础几何，与裁决解耦）

```
发墙判据（唯一）：两侧块逻辑高有落差（hH > hL）即发墙。裁决无关。
  cliff 墙 = 撕裂面本身（硬边界）。
  weld  墙 = 贴坡背墙——斜坡蒙皮是附加在墙前低侧块上的额外面，
             墙永远在（先硬边界，再在其上加插值坡面），任何视角看不到地形内部。
  等高块（drop=0）→ 不发（退化保护）。
墙顶 = 沿边界逐米跟随 cornerCell（weld 共享边两侧同值 = crest，构造上无撕裂）。
墙底 = min(baseHeightOf(两侧)) − WALL_EPS（深到底堵死，浅者防悬空穿透）。
去重 = 每条边界仅从高侧发一次（法线朝低处）。
```

> 演进注记：2026-08-31 上午版「weld 永不发墙」作废——坡带下方空腔在背面剔除后
> 大面积看穿地形。现行「墙与裁决解耦」是几何完整性的根，删掉坡只退化为普通断崖，
> 不会露洞。

## 6. 产出与消费（per-chunk 单产物，下游零现算）

```
buildChunkFinal(src, cx, cz, size)          → 角点高度场 + 顶面缓冲
buildChunkWallBuffers(src, cx, cz, size, ctx) → 墙 raw（顶点/法线/顶点色/索引）
mergeTerrainPhysics                          → 顶面 + 墙合并的地形 trimesh
```

| 消费者                    | 取什么                            | 禁止         |
| ------------------------- | --------------------------------- | ------------ |
| ChunkSurface              | chunkSource → cornerCell 语义     | 自算几何     |
| ChunkWalls                | buildChunkWallBuffers             | 自扫描墙     |
| RasterMap.surfaceHeightAt | chunkSource → sampleSurface       | 镜像公式     |
| bakeCompute（Worker）     | 同一份纯函数快照重算              | 第二套公式   |
| ChunkAppearance           | surfaceHeightAt + tileDefAt       | ——           |
| CharacterBase             | surfaceHeightAt + EDGE_CLIFF_BAND | 逻辑高度贴地 |

**物理分层**：精修层只产地形物理（第一次）；实体/装饰碰撞由下游管理器自产
（第二次），不经精修层。物理 trimesh 与渲染网格同源 → 碰撞 = 所见。

## 7. 移动语义

- **stepHeight ≡ EDGE_CLIFF_BAND = 0.35**（同一常量，注释互相绑定）：
  cliff 台阶 ≤ 0.35m 全部可踏过；更高落差水平阻挡（回退本次位移），跳不上。
- weld 坡面连续 → 贴地跟随 surfaceHeightAt 自然走上坡，无新机制。
- 水/坑 walkable=false；落水坠坑死亡线吃逻辑高度（L4），与视觉面无关。

---

## 8. 数据定义（Tiles / TileGroups）

- **类型/材质分离铁律**：类型 = genRole + physics（封闭集合，加类型 = 体系决策）；
  材质 = visual.material + baseHsl（自由，加皮 = 注册即生效）。变体 physics ≙ 基础类型。
- **插值配置全在数据侧**：`TilePhysics.edgePolicy`（全向）+ `smoothDirs`（方向性）
  - `edgeFinal`（per-(块,dir) 钉死）。几何层代码零改动。
- 群系 = groups 多对多归属 + TileGroups 加权抽取。

## 11. 扩展面（加配置不加代码）

| 需求                      | 改哪里                                             |
| ------------------------- | -------------------------------------------------- |
| 某群系想要更多/更少插值边 | TileDef `smoothDirs` 增删方向                      |
| 某地块全部边硬/全部边坡   | `edgePolicy: 'hard'                                | 'smooth'` |
| 某条边特判                | `edgeFinal`（per-(块,dir)，唯一判点）              |
| 坡更缓/更陡               | `WELD_RAMP_CELLS`（2→4 缓）或 per-edge `rampWidth` |
| 新地块                    | `registerTile`（id/key 唯一，physics ≙ 基础类型）  |
| 新群系                    | groups 归属 + TileGroups 权重                      |
