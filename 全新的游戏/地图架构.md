# 地图架构 —— 从生成到消费的单向流水线

> 定位：地图侧（地形）的**唯一权威架构文档**，描述当前代码的最终形态。
> 历史决策过程见文末《沿革》；《地形边缘裁决与视觉面架构》《精修层与定型快照架构》
> 《精修层过渡模型重构设计》三份旧文档已归档为指路桩，内容以本文为准。
> 状态：定稿（硬边界基础 + 两插值函数 + 墙与裁决解耦；§4 于本轮重构细化：
> 插值 = 硬边界后处理，分两阶段——先完整硬边界，再逐边/逐角最小化插值）。

---

## 0. 一句话

**生成层定高度，精修层做过渡——先完整硬边界（墙=基础几何），再在其上逐边/逐角后处理插值（坡=附加蒙皮，最小化），快照定型，下游纯消费。**

---

## 1. 分层总览（单向依赖，禁止反向）

```
L0–L5 生成   generateChunk → walkable / heights / blockTypes
             全方块模型：块高由 L4 assignHeights 定死，上游永不再变
L6 精修      Refinements.ts（唯一几何真源，纯函数、零 three、Worker 可加载）
             ├ 裁决：finalRuling（唯一判点）
             ├ 插值：interpEdge（边）/ interpCorner（角），纯函数、最小化
             ├ 控制：surfaceHeight（唯一控制/编排函数）→ cornerCell / sampleSurface
             │        / buildChunkFinal 顶点都只是它的薄包装
             └ 产出：buildChunkFinal（顶面）+ buildChunkWallBuffers（墙）
快照         bakeCompute（Worker）→ per-chunk 定型快照
             （顶面缓冲 / 墙 raw / 贴图印章 / 阴影体积 / propVolumes）
消费         ChunkSurface 顶面 ┐
             ChunkWalls   墙   ├ 全部只读产物，零现算
             surfaceHeightAt 贴地┤
             ChunkAppearance 着色┘
             CharacterBase 移动（EDGE_CLIFF_BAND 台阶 + 坡面连续）
数据定义     Tiles（类型封闭 / 材质自由）· TileGroups（群系抽取）
```

两条逐位锁：**渲染 = 查询**（回归 D）、**快照 = 主线程**（回归 E）。

## 2. 精修层输入（只有一条路）

```
ChunkData (blockTypes + heights + groupKey)
  → makeChunkSource(readChunk)          无界块源：越界跨 chunk 读，永不 MISSING
  → refineChunkSource(src, seed, cx,cz) per-chunk 意图（planRefinements 恒空透传）
  → RasterMap.chunkSource(cx, cz)       对外唯一出口
```

- 三份 BlockSource 已合一；消费方各自建源的自算路径全部删除。
- `planRefinements` 定版恒空：地块高度 L4 已定死，精修层只做块间过渡，不灌内容。
- 块数据 `BlockInfo = { id, h, hBase? }`；缺块兜底 `MISSING_BLOCK = { id:0, h:0 }`
  （仅人工构造源可达；真实链路是无界源）。

## 3. 边裁决（weld | cliff）

### 3.1 规则（edgeRuling，纯默认引擎）

```
edgeRuling(a, b, dir):                       // dir: 0=+x 1=-x 2=+z 3=-z
  1. 任一侧 edgePolicy 'hard'                        → cliff
  2. 任一侧 edgePolicy 'smooth'                      → weld
  3. 任一侧 smoothDirs 声明该共享边（dir 或 dir^1）  → weld
  4. 兜底                                            → cliff
```

- **插值 = 显式 opt-in，默认恒硬边界立墙**。不配任何东西的世界 = 全 cliff 方块感。
- **对称性（构造保证）**：A 的 dir 边与 B 的 dir^1 边是同一条共享边，
  `edgeRuling(a,b,dir) ≡ edgeRuling(b,a,dir^1)`——两侧查询同值，永不撕裂。
- **方向性配置**（smoothDirs，per-tile 声明自己哪些方向的边参与插值）：

| 地块                | smoothDirs  | 语义              |
| ------------------- | ----------- | ----------------- |
| 高台 platform       | `[0,2]`     | +x、+z 边插值     |
| 岩台 rock_platform  | `[0,1,2]`   | +x、-x、+z 边插值 |
| 冰台 ice_platform   | `[0,3]`     | +x、-z 边插值     |
| 苔台 mossy_platform | `[0,2,3]`   | +x、+z、-z 边插值 |
| 水 water            | `[0,1,2,3]` | 全向插值          |

### 3.2 唯一判点（finalRuling）

```
finalRuling(src, bx, bz, dir):
  src.edgeFinal(bx,bz,dir) 有值 → 用之（显式钉死，回归/特判唯一入口）
  否则 → edgeRuling(本块, 邻块, dir)
```

★ 一切消费者只问 finalRuling，禁止直接调 edgeRuling。任何时刻某条边的
裁决只有这一个答案；能在它之外影响裁决的第二处代码即违例（回归抓此）。

## 4. 视觉面几何（硬边界基础 + 边/角插值后处理）

> **§4 设计原则（2026-08-31 定版，本轮重构）**
> **插值 = 硬边界的后处理，分两阶段产出**：
> 1. **阶段一：先完整硬边界**。L4 定高 → 每块恒平面 `B.h`，cliff 裁决 → 相邻块
>    硬台阶。此版就是完整可用、可渲染、可碰撞的地图。
> 2. **阶段二：后处理插值**。在硬边界之上逐边、逐角做**最小化**插值：
>    - 每次操作**只动自己这一条边 / 这一个角**；不改变其他地块，也不改变自己
>      地块其他边的硬边界数据（其他边/角依旧保持硬边界平面）。
>    - **顺序：先边插值（interpEdge），后角插值（interpCorner）**；只调用这两个
>      插值函数的组合，由**唯一控制函数 surfaceHeight 编排**（§4.4，见下）。
>    - **插值有校验**（见 §4.7）：每个插值结果先过闸，不合法即回退硬边界。

### 4.1 硬边界（几何基线，先导完成）

```
基础数据（只读，永不因插值而变）：
  BlockInfo = { id, h, hBase? }
  B.h = 该块 L4 定高的恒平面高度（块内任何 (x,z) 的硬边界基面）。

硬边界语义 = 把每块当作厚度无限的水平平板：
  - 块内任意点基面高 = B.h（恒值，零插值）。
  - 相邻两块高度不同 → 交界为垂直硬台阶（高侧 B.h，低侧 B.h）。
  - 阶面无插值；cliff 边两侧各持各高，绝不相互攀爬/平滑。

「插值 = 显式 opt-in」（§3.1）：默认恒 cliff。只有显式声明（edgePolicy
'smooth' / smoothDirs / edgeFinal）的边才进入 interpEdge 坡带；否则整条边
永远是硬台阶。
```

### 4.2 边插值 interpEdge（纯函数，仅此一边，先执行）

```
interpEdge(src, B, dir, V) → number | undefined
  前置闸（任一项不满足 → undefined，该边不插值，回落硬边界）：
    a. 类型对：canInterpolateByType(tile(B), tile(邻))       // 同类型对永不插值
    b. 裁决：finalRuling(src, B, dir) === 'weld'              // cliff 一定不插值
    c. 低侧：hH > hL（B 是低侧块）                            // 只向高侧攀爬
    d. 坡带内：t ∈ [0, w]，t = V 深入块 B 的边缘距离           // 坡带外 = 硬边界
  命中 → rampProfile(w, hH, hL, t) = hH − (hH−hL)·t/w
        （沿该 4m 边等距不变，只沿深入方向线性；t=0 贴高侧顶 hH，t=w 落回 hL）
  未命中 → undefined（不产生任何高度贡献，绝不影响块的其余部分）

  ★ 最小化：interpEdge 只返回「这一条边」在 V 的坡带高度；不读、不算、不改
  其他边/角/地块。多个 weld 边对同一点的重叠带由控制函数 surfaceHeight
  取 max 合成（见 §4.4 ②）。
```

### 4.3 角插值 interpCorner（纯函数，仅此一角，后执行）

```
interpCorner(src, V) → number | undefined
  与查询块无关（谁查 V 都得到同值 → 水密构造基础）。
  候选集（取 max）：
    ∪ corner-open 块的高度：在 V 处【无任何 cliff 边段】的、触及 V 的块 B 的 B.h
    ∪ 触及 V 的每条 weld 边 crest(E) = max(h(a), h(b))（且类型对可插值）
  插值边数自动覆盖：0 条 → 仅 open 块高；1 条 → 该 crest；2 条 → 两 crest 取 max
  无任何候选 → undefined（不抬升，落回硬边界 — 勿回填 0 覆盖负高度）

  ★ 最小化：只合成「这一个角」触及边的贡献；不扩散到角外任何边/地块。
  ★ 校验（§4.7）：任一候选来自 non-weld 边 → 剔除；全候选剔除 → undefined。
```

### 4.4 surfaceHeight —— 唯一控制函数（调度核心）

```
surfaceHeight(src, x, z) → number      // 接收任意查询点（整数网格顶点 or 连续贴地点）
  B = 查询点所属块（Math.floor(x/4), Math.floor(z/4)），hB = B.h

  四级判定（先边后角；每一步都是互斥的最小化裁决）：
    ① 硬边界基面  h = hB                              // 先导完整硬边界
    ② 边插值：for dir∈{0..3}
         e = interpEdge(src, B, dir, x, z)             // 纯函数：仅此一边
         if (e !== undefined) h = max(h, e)            // 重叠带取 max；undefined 忽略
    ③ 角插值：c = interpCorner(src, x, z)              // 纯函数：仅此一角
         if (c !== undefined) h = max(h, c)            // 水密；undefined 忽略
    ④ 校验后返回 h（hB ≤ h ≤ 触及块最高 crest）

  ★ 控制职责（全部集中在 surfaceHeight，唯一一份）：
    - 定位所属块、取硬边界基面
    - 决定哪条边/哪个角进入插值（由 interpEdge/interpCorner 前置闸决定）
    - 编排【先边后角】顺序、重叠带 max 合成、undefined 忽略
    - 全面过 §4.7 校验闸
  任一插值贡献不合法（undefined/越界/类型不容）→ 该项跳过，h 落回硬边界。
```

### 4.5 薄包装 + 渲染 = 查询 一致性锁（构造级）

```
三个常驻入口全都是 surfaceHeight 的薄包装，不做任何独立编排/独立公式：

  cornerCell(src, bx, bz, V)  :=  surfaceHeight(src, V.x, V.z)    // 网格顶点
  sampleSurface(src, x, z)    :=  surfaceHeight(src, x, z)        // 贴地/碰撞
  buildChunkFinal 顶点        =  surfaceHeight(cell 角顶点)       // 渲染网格

  ★ (bx,bz) 参数仅保留为调用方视角的块坐标（墙顶等局部场景传参与
    语义无关），实际高度一律由 surfaceHeight 以 V 自身所属块为准；
    三入口不再各自实现一套判定 → 一致由构造保证，不再是靠回归对拍。

两条逐位锁（回归 D + F 强制）：
  L1【网格顶点】buildChunkFinal 每个 cell 四角 == cornerCell(cell 块, 该顶点)
       == sampleSurface(该顶点) == surfaceHeight(该顶点)。四者同值。
  L2【weld 边中段零落差】共享 weld 边低侧/高侧在整边中段
      (4, 0.5..3.5) 采样 cornerCell → 两侧同值（= crest，无撕裂）。
```

### 4.6 硬台阶语义（surfaceHeight 的直接推论）

```
  ★ 等级不变式：hB（硬边界）≤ surfaceHeight ≤ 触及块最高 crest。

  ★ 硬台阶保证（本重构的直接目标）：对 ground↔ground（cliff、同类型）边，
    interpEdge 前置闸 a/b 全不通过 → 每个查询点恒 B.h → 缝两侧各持各高，
    交界是垂直硬台阶（非连续斜坡）。这是「地面之间无过渡」的实现。

  ★ 与旧的 cell 三角形插值关系：surfaceHeight 不再做 cell 内跨块三角形
    插值（那是 ground↔ground 平滑斜坡的来源）。坡带剖面由 interpEdge
    直接给出，网格顶点由 surfaceHeight 直接给出——不再有「网格从 cell 插值、
    查询从角点插值」两套几何的对位漂移。
```

### 4.7 插值校验（合法性闸门）

```
每次 interpEdge / interpCorner 的候选在采纳前都过校验：
  V1 裁决必须 weld（cliff 一律拒绝插值候选）。
  V2 类型对必须可插值（canInterpolateByType；同类型对拒绝）。
  V3 不越界：t ∈ [0, w]（坡带外拒绝）、候选高度 ≤ 触及块最高 crest。
  V4 最小化：绝不引用/修改非本边本角的任意地块或边。
  任一校验不过 → 该项贡献 undefined → 该点落回低侧（或本块）硬边界高度。
```

- **斜坡是低侧块顶面的附加蒙皮**：坡带内顶面渲染 = interpEdge 剖面；t=w 处精确
  落回 hL，与块内平面对接无痕。剖面由 interpEdge 直接给出，零细分成本。
- **坡宽** `w = WELD_RAMP_CELLS = 2` 米（约束 4/w ∈ ℤ → w ∈ {1,2,4}；
  默认 2m ≈ 48°）。per-edge 覆写：`EdgeOverride.rampWidth → src.edgeRampWidth`。

### 4.8 验收 = Phase F 六组不变式

```
① 撕裂角自持  全 cliff 角：每块角点 = 各自 h（对角/邻块不抬）
② 无幽灵拉高  对角高台（如 (1,1)=5）不抬 (0,0) 的角
③ weld 边零落差 共享 weld 边中段低侧 == 高侧（= crest）
④ cliff 自持    cliff 边两侧各持各高，零插值
⑤ 全 weld 角水密 四块在共享角读同值 = interpCorner
⑥ 坡带剖面      rampProfile 生效；坡带外落回低侧块高
```

## 5. 墙（硬边界基础几何，与裁决解耦）

```
发墙判据（唯一）：两侧块逻辑高有落差（hH > hL）即发墙。裁决无关。
  cliff 墙 = 撕裂面本身（硬边界）。
  weld  墙 = 贴坡背墙——斜坡蒙皮是附加在墙前低侧块上的额外面，
             墙永远在（先硬边界，再在其上加插值坡面），任何视角看不到地形内部。
  等高块（drop=0）→ 不发（退化保护）。
墙顶 = 沿边界逐米跟随 cornerCell（weld 共享边两侧同值 = crest，构造上无撕裂）。
墙底 = min(baseHeightOf(两侧)) − WALL_EPS（深到底堵死，浅者防悬空穿透）。
去重 = 每条边界仅从高侧发一次（法线朝低处）。
```

> 演进注记：2026-08-31 上午版「weld 永不发墙」作废——坡带下方空腔在背面剔除后
> 大面积看穿地形。现行「墙与裁决解耦」是几何完整性的根，删掉坡只退化为普通断崖，
> 不会露洞。

## 6. 产出与消费（per-chunk 单产物，下游零现算）

```
buildChunkFinal(src, cx, cz, size)          → 角点高度场 + 顶面缓冲
buildChunkWallBuffers(src, cx, cz, size, ctx) → 墙 raw（顶点/法线/顶点色/索引）
mergeTerrainPhysics                          → 顶面 + 墙合并的地形 trimesh
```

| 消费者                    | 取什么                            | 禁止         |
| ------------------------- | --------------------------------- | ------------ |
| ChunkSurface              | chunkSource → cornerCell 语义     | 自算几何     |
| ChunkWalls                | buildChunkWallBuffers             | 自扫描墙     |
| RasterMap.surfaceHeightAt | chunkSource → sampleSurface       | 镜像公式     |
| bakeCompute（Worker）     | 同一份纯函数快照重算              | 第二套公式   |
| ChunkAppearance           | surfaceHeightAt + tileDefAt       | ——           |
| CharacterBase             | surfaceHeightAt + EDGE_CLIFF_BAND | 逻辑高度贴地 |

**物理分层**：精修层只产地形物理（第一次）；实体/装饰碰撞由下游管理器自产
（第二次），不经精修层。物理 trimesh 与渲染网格同源 → 碰撞 = 所见。

## 7. 移动语义

- **stepHeight ≡ EDGE_CLIFF_BAND = 0.35**（同一常量，注释互相绑定）：
  cliff 台阶 ≤ 0.35m 全部可踏过；更高落差水平阻挡（回退本次位移），跳不上。
- weld 坡面连续 → 贴地跟随 surfaceHeightAt 自然走上坡，无新机制。
- 水/坑 walkable=false；落水坠坑死亡线吃逻辑高度（L4），与视觉面无关。

---

## 8. 数据定义（Tiles / TileGroups）

- **类型/材质分离铁律**：类型 = genRole + physics（封闭集合，加类型 = 体系决策）；
  材质 = visual.material + baseHsl（自由，加皮 = 注册即生效）。变体 physics ≙ 基础类型。
- **插值配置全在数据侧**：`TilePhysics.edgePolicy`（全向）+ `smoothDirs`（方向性）
  - `edgeFinal`（per-(块,dir) 钉死）。几何层代码零改动。
- 群系 = groups 多对多归属 + TileGroups 加权抽取。

## 11. 扩展面（加配置不加代码）

| 需求                      | 改哪里                                             |
