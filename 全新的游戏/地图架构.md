# 地图架构 —— 从生成到消费的单向流水线

> 定位：地图侧（地形）的**唯一权威架构文档**，描述当前代码的最终形态。
> 历史决策过程见文末《沿革》；《地形边缘裁决与视觉面架构》《精修层与定型快照架构》
> 《精修层过渡模型重构设计》三份旧文档已归档为指路桩，内容以本文为准。
> 状态：定稿（硬边界基础 + 两插值函数 + 墙与裁决解耦；§4 于本轮重构细化：
> 插值 = 硬边界后处理，分两阶段——先完整硬边界，再逐边/逐角最小化插值）。

---

## 0. 一句话

**生成层定高度，精修层做过渡——先完整硬边界（墙=基础几何），再在其上逐边/逐角后处理插值（坡=附加蒙皮，最小化），快照定型，下游纯消费。**

## 1. 分层总览（单向依赖，禁止反向）

```
L0–L5 生成   generateChunk → walkable / heights / blockTypes
             全方块模型：块高由 L4 assignHeights 定死，上游永不再变
L6 精修      Refinements.ts（唯一几何真源，纯函数、零 three、Worker 可加载）
             ├ 裁决：finalRuling（唯一判点）
              ├ 插值：interpEdge（边；角=两条 weld 边 t=0 crest 汇合，无独立角函数）
              ├ 控制：surfaceHeightCore（唯一控制/编排函数）→ cornerCell（块视角）
              │        / sampleSurface = 所在米格 4 角 cornerCell + 三角形插值（= 视觉网格）
              │        / buildChunkFinal 顶点都只是 cornerCell 的薄包装
             └ 产出：buildChunkFinal（顶面）+ buildChunkWallBuffers（墙）
快照         bakeCompute（Worker）→ per-chunk 定型快照
             （顶面缓冲 / 墙 raw / 贴图印章 / 阴影体积 / propVolumes）
消费         ChunkSurface 顶面 ┐
             ChunkWalls   墙   ├ 全部只读产物，零现算
             surfaceHeightAt 贴地┤
             ChunkAppearance 着色┘
             CharacterBase 移动（EDGE_CLIFF_BAND 台阶 + 坡面连续）
数据定义     Tiles（类型封闭 / 材质自由）· TileGroups（群系抽取）
```

两条逐位锁：**渲染 = 查询**（回归 D）、**快照 = 主线程**（回归 E）。

## 2. 精修层输入（只有一条路）

```
ChunkData (blockTypes + heights + groupKey)
  → makeChunkSource(readChunk)          无界块源：越界跨 chunk 读，永不 MISSING
  → refineChunkSource(src, seed, cx,cz) per-chunk 意图（planRefinements 非空）
  → RasterMap.chunkSource(cx, cz)       对外唯一出口（per-chunk 缓存）
```

- 三份 BlockSource 已合一；消费方各自建源的自算路径全部删除。
- `planRefinements(seed, cx, cz, src)` 现**非空**：只在【默认 cliff 的
  ground/platform 边、高差 >0.5】上按 30% 确定性产坡（§3.3）。不碰任何
  地块高度——L4 assignHeights 定死，精修层只做块间过渡。
- ★ 性能稳健：`planRefinements` 每 chunk O(225×4) 只在 `RasterMap.chunkSource`
  与烘焙 `makeSnapshotSource` 各自 **per-chunk 缓存**一次（角色脚底/影子/烘焙
  逐顶点高频采样不复算计划）；`clearAll()` 清缓存。
- 块数据 `BlockInfo = { id, h, hBase? }`；缺块兜底 `MISSING_BLOCK = { id:0, h:0 }`
  （仅人工构造源可达；真实链路是无界源）。

## 3. 边裁决（weld | cliff）

### 3.1 规则（edgeRuling，纯默认引擎）

```
edgeRuling(a, b, dir):                       // dir: 0=+x 1=-x 2=+z 3=-z
  1. 任一侧 genRole 为 liquid / pit（水/坑洞）      → weld   ★一律插值，覆盖 hard
  2. 任一侧 edgePolicy 'hard'                       → cliff
  3. 任一侧 edgePolicy 'smooth'                     → weld
  4. 任一侧 smoothDirs 声明该共享边（dir 或 dir^1）  → weld
  5. 兜底                                           → cliff
```

- **插值 = 显式 opt-in，默认恒硬边界立墙**。不配任何东西的世界 = 全 cliff 方块感。
- **水/坑洞一律向周围插值（2026-08-31）**：任一侧是 liquid/pit → 无条件 weld，
  优先级最高、**覆盖 hard 硬边**（即使该地块标记了 edgePolicy:'hard'）。水已由此
  全向焊；坑默认 cliff → 此步使坑也向平地/高台缓坡入坑。同角色（water↔water / pit↔pit）
  虽也判 weld，但 interpEdge 的 canInterpolateByType 同角色闸拒绝 → 无常坡（无害）。
- **对称性（构造保证）**：A 的 dir 边与 B 的 dir^1 边是同一条共享边，
  `edgeRuling(a,b,dir) ≡ edgeRuling(b,a,dir^1)`——两侧查询同值，永不撕裂。
- **方向性配置**（smoothDirs，per-tile 声明自己哪些方向的边参与插值）。
  ★ **2026-08-31：所有 platform 类删除了 smoothDirs** —— 平地↔高台不再默认全插值，
  高台现在默认硬边界（cliff），需坡时由 30% 大落差规则（§3.3）**按需**生成：

| 地块                | smoothDirs  | 语义              |
| ------------------- | ----------- | ----------------- |
| 高台 platform       | —           | 无默认插值（cliff）|
| 岩台 rock_platform  | —           | 无默认插值（cliff）|
| 冰台 ice_platform   | —           | 无默认插值（cliff）|
| 苔台 mossy_platform | —           | 无默认插值（cliff）|
| 水 water            | `[0,1,2,3]` | 全向插值（已由规则1无条件焊）|

### 3.3 30% 大落差产坡（planRefinements，2026-08-31）

```
planRefinements(seed, cx, cz, src):
  对 chunk 内每块 × 4 边（与邻块成对）：
    例外：任一端缺块 / 角色非 {ground,platform} / 默认裁决非 cliff /
          任一侧 hard → 跳过（只在「默认 cliff 边」掷骰）
    高差闸：|hH − hL| > 0.5   （配合空格跳跃 0.6 → 可跳上）
    概率：确定性 edgeHash(seed, A, B)（无向共享边）< 0.30 → weld
    命中 → overrideEdge(本块, dir, 'weld')   // 双向对称由同一无向 hash 保证
```

- **用处**：平地↔高台、高台↔高台之间高差大时，30% 概率产生坡方便上去
  （低侧向高侧攀爬）；其余维持 cliff 硬边界。platform↔platform 同角色因此
  需要 canInterpolateByType 放行（§4.2 闸 a）。
- **确定性**：hash 只依赖 seed + 两块世界坐标（排序无向化）→ 主线程与烘焙
  Worker、以及共享边两侧块各自场景算出的决策一致，不撕裂。
- **对称**：同一条共享边，本块方案与邻块方案各自补各自方向的 override，由同一
  无向 hash 保证两侧同判 → finalRuling 唯一判点不变式不破坏（回归 B 校验对称性）。

### 3.2 唯一判点（finalRuling）

```
finalRuling(src, bx, bz, dir):
  src.edgeFinal(bx,bz,dir) 有值 → 用之（显式钉死，回归/特判唯一入口）
  否则 → edgeRuling(本块, 邻块, dir)
```

★ 一切消费者只问 finalRuling，禁止直接调 edgeRuling。任何时刻某条边的
裁决只有这一个答案；能在它之外影响裁决的第二处代码即违例（回归抓此）。

## 4. 视觉面几何（硬边界基础 + 边/角插值后处理）

> **§4 设计原则（2026-08-31 定版，本轮重构）**
> **插值 = 硬边界流水线完成后的后修正，分两阶段产出**：
> 1. **阶段一：先完整硬边界**。L4 定高 → 每块恒平面 `B.h`，cliff 裁决 → 相邻块
>    硬台阶。此版就是完整可用、可渲染、可碰撞的地图。
> 2. **阶段二：后处理插值**。在硬边界之上逐边、逐角做**最小化**插值：
>    - 每次操作**只动自己这一条边 / 这一个角**；不改变其他地块，也不改变自己
>      地块其他边的硬边界数据（其他边/角依旧保持硬边界平面）。
>    - **控制函数 surfaceHeightCore 编排一切**（§4.4）：它决定哪些边进入插值，
>      收集边插值结果 max 合成；插值函数只做最小化计算。
>    - **顺序：硬边界基面先行，边插值（interpEdge）后修正**；角不再独立抬升，
>      由两条触及 weld 边在格点角 t=0 处 crest 汇合（§4.3）。唯一控制函数
>      surfaceHeightCore 编排（§4.4，见下）。
>    - **插值有校验**（见 §4.7）：每个插值结果先过闸，不合法即回退硬边界。

### 4.1 硬边界（几何基线，先导完成）

```
基础数据（只读，永不因插值而变）：
  BlockInfo = { id, h, hBase? }
  B.h = 该块 L4 定高的恒平面高度（块内任何 (x,z) 的硬边界基面）。

硬边界语义 = 把每块当作厚度无限的水平平板：
  - 块内任意点基面高 = B.h（恒值，零插值）。
  - 相邻两块高度不同 → 交界为垂直硬台阶（高侧 B.h，低侧 B.h）。
  - 阶面无插值；cliff 边两侧各持各高，绝不相互攀爬/平滑。

「插值 = 显式 opt-in」（§3.1）：默认恒 cliff。只有显式声明（edgePolicy
'smooth' / smoothDirs / edgeFinal）的边才进入 interpEdge 坡带；否则整条边
永远是硬台阶。
```

### 4.2 边插值 interpEdge（纯函数，仅此一边，先执行）

```
interpEdge(src, B, dir, x, z) → number | undefined
  前置闸（任一项不满足 → undefined，该边不插值，回落硬边界）：
    a. 类型对：canInterpolateByType(tile(B), tile(邻))
       // 同角色对永不插值，唯一例外：platform↔platform（30% 大落差产坡需同角色）
    b. 裁决：finalRuling(src, B, dir) === 'weld'              // cliff 一定不插值
    c. 低侧：hH > hL（B 是低侧块）                            // 只向高侧攀爬
    d. 坡带内：t ∈ [0, w]                                     // 坡带外 = 硬边界

  t 值计算（V 到 B 在 dir 方向边界的米距，朝块内方向）：
    dir=0 (+x): B 右边界在 (bx+1)*4, t = (bx+1)*4 - x
    dir=1 (-x): B 左边界在 bx*4,       t = x - bx*4
    dir=2 (+z): B 上边界在 (bz+1)*4,   t = (bz+1)*4 - z
    dir=3 (-z): B 下边界在 bz*4,        t = z - bz*4
    t=0 在边界（贴高侧 crest），t=w 深入 B 内部落回 hL。

  命中 → rampProfile(w, hH, hL, t) = hH − (hH−hL)·t/w
        （沿该 4m 边等距不变，只沿深入方向线性；t=0 贴高侧顶 hH，t=w 落回 hL）
  未命中 → undefined（不产生任何高度贡献，绝不影响块的其余部分）

   ★ 最小化：interpEdge 只返回「这一条边」在 V 的坡带高度；不读、不算、不改
   其他边/角/地块。多个 weld 边对同一点的重叠带由控制函数 surfaceHeightCore
   取 max 合成（见 §4.4 ②）。
```

### 4.3 角 = 两条 weld 边的 t=0 crest 汇合（无独立角抬升）

```
★ 2026-08-31 定版：不再有独立 interpCorner / CornerCandidates /
  collectCornerCandidates / isGridCorner（全部删除，冗余）。

角点高度由触及该角格点的两条 weld 边在块边界（t=0）处的 crest 自然汇合：
  - surfaceHeightCore 对格点角 V，遍历 4 条边都调用 interpEdge：
      两条触及 weld 边在 V 处 t = 0（块边界）→ 各自返回 crest = hH；
      max 合成 → 角即得共享 crest。
  - 角到两边的区域 = 两坡平面自然相交（同一梯度 rampProfile[hH→hL t/w]，
      边角坡度完全一致，无平顶、无突变）。
  - 对向两 weld：各自占块宽 1/3 坡 + 中部 1/3 平地 → 坡+平地+坡（无 V/U 凹谷）。
  - 同类型对 / 非 weld / 等高边 → interpEdge undefined → 不贡献。

  ★ 边角融合的好处：
    - 删掉独立角模型后，「角抬多高、边抬多高」不再有两套公式对位漂移；
    - 边和角共享同一梯度，视觉过渡自然；
    - 角插值自动传导到物理（buildChunkFinal 的 cell 四角 = cornerCell，
      顶面进 mergeTerrainPhysics trimesh → 碰撞 = 所见）。
```

### 4.4 surfaceHeightCore —— 唯一控制函数（调度核心）

```
surfaceHeightCore(src, bx, bz, x, z) → number   // 核心：以块(bx,bz)为 B 视角计算
  B = blockAt(bx, bz)，hB = B.h

  两步判定（硬边界先行，边插值后修正；无独立角步骤）：
    ① 硬边界基面  h = hB                              // 先导完整硬边界

    ② 边插值：遍历 4 条边
       for dir∈{0..3}:
         e = interpEdge(src, B, dir, x, z)             // 纯函数：仅此一边
         if (e !== undefined): h = max(h, e)           // 重叠带取 max；undefined 忽略
       格点角处两条 weld 边 t=0 → 都得 crest → max 后角 = 共享 crest（见 4.3）

    ③ 返回 h（hB ≤ h ≤ 触及块最高 crest）

  ★ 块视角 (bx,bz) 是 B 的决定因素，不是语义携带：
    - 同一 (x,z) 点，从不同块 B' 视角查 surfaceHeightCore 可得不同值——
      这正是表达「撕裂角」（cliff 四块各持各高）的唯一途径。
    - cornerCell 传块视角（每个 cell 传自己所属块）；sampleSurface 取所在米格
      所属块的 4 角 cornerCell 后三角形插值（= 视觉网格形状，贴地单值，不需撕裂）。

  ★ 控制职责（全部集中在 surfaceHeightCore，唯一一份）：
    - 定位 B（由块视角 (bx,bz) 决定）、取硬边界基面
    - 决定哪条边进入插值（由 interpEdge 前置闸决定）
    - 编排重叠带 max 合成、undefined 忽略
    - 全面过 §4.7 校验闸
  任一插值贡献不合法（undefined/越界/类型不容）→ 该项跳过，h 落回硬边界。
```

### 4.5 薄包装 + 渲染 = 查询 一致性锁（构造级）

```
三个常驻入口（cornerCell = surfaceHeightCore 薄包装；sampleSurface = 网格形状采样）：

  cornerCell(src, bx, bz, x, z)  :=  surfaceHeightCore(src, bx, bz, x, z)  // 块视角
  sampleSurface(src, x, z)       := 所在米格【4 角 cornerCell(块归属)】+ 三角形插值
                                     //（2026-08-31：与 buildChunkFinal 顶面网格逐位一致；
                                     //  以视觉网格形状为准，见下 ★）
  buildChunkFinal 顶点           =  cornerCell(cell 所属块, 该顶点)（块视角）

  ★ sampleSurface 不以 surfaceHeightCore 解析面为准（2026-08-31 修正）：
    先前 sampleSurface := surfaceHeightCore(floor(x/4),floor(z/4),x,z)，与网格顶面
    （米格四角 cornerCell + 三角插值，因 max-合成 vs 三角剖分）在坡底部 / 角上部
    分叉 → 物理与视觉不统一。现改回旧式「四角 cornerCell + 三角形插值」，逐位对齐
    网格（对角剖分 c01—c10，fx+fz≤1 取 T1；不用双线性）。物理 trimesh 本就 = 顶面
    顶点，故角色/影子贴地与视觉完全一致。

  ★ 块视角 vs V-所属块（关键区别，见 §4.4 ③）：
    - cornerCell / buildChunkFinal 传调用方的【块视角 (bx,bz)】——每个 4×4 块内
      的 cell 都传自己的块。cliff 撕裂角处，不同块传不同视角 → 得不同高度 →
      网格里 V 处分裂为多个重合但高度不同的顶点（撕裂角正确表达）。
    - sampleSurface 以查询点所在米格的【所属块】为视角取 4 角高——贴地/碰撞需单值
      （无撕裂），且与网格渲染同源（同一块视角），故物理 = 视觉。
    - 同一 (x,z) 在 cornerCell(块视角) 与 sampleSurface(所属块) 可能不同值，
      但仅发生在 cliff 撕裂角处；这是语义需要，不是冲突。

两条逐位锁（回归 D + F 强制）：
  L1【网格顶点】buildChunkFinal 每个 cell 四角 == cornerCell(cell 块, 该顶点)；
        且 sampleSurface @ 面内分点 == 该米格四角 cornerCell 三角形插值（= 网格形状）
        ——回归 Phase D 逐采样校验「物理 = 视觉」。
  L2【weld 边中段零落差】共享 weld 边低侧/高侧在整边中段
      (4, 0.5..3.5) 采样 cornerCell → 两侧同值（= crest，无撕裂）。
```

### 4.6 硬台阶语义（surfaceHeightCore 的直接推论）

```
  ★ 等级不变式：hB（硬边界）≤ surfaceHeightCore ≤ 触及块最高 crest。

  ★ 硬台阶保证（本重构的直接目标）：对 ground↔ground（cliff、同类型）边，
    interpEdge 前置闸 a/b 全不通过 → 每个查询点恒 B.h → 缝两侧各持各高，
    交界是垂直硬台阶（非连续斜坡）。这是「地面之间无过渡」的实现。

  ★ 与旧的 cell 三角形插值关系：surfaceHeightCore 不再做 cell 内跨块三角形
    插值（那是 ground↔ground 平滑斜坡的来源）。坡带剖面由 interpEdge
    直接给出，网格顶点由 cornerCell（= surfaceHeightCore 块视角）直接给出——
    不再有「网格从 cell 插值、查询从角点插值」两套几何的对位漂移。
```

### 4.7 插值校验（合法性闸门）

```
插值是【硬边界流水线完成后的后修正】。每个插值结果先独立过自己的前置闸，
不合法即回退硬边界（该点保持硬边界平面，插值不产生任何副作用）：

  interpEdge 闸门（在函数内部，最小化）：
    V1 裁决必须 weld（cliff 一律拒绝插值候选）。
    V2 类型对必须可插值（canInterpolateByType；同类型对拒绝）。
    V3 不越界：t ∈ [0, w]（坡带外拒绝）。
    V4 最小化：绝不引用/修改非本边本角的任意地块或边。
    任一不过 → 返回 undefined → 该边不产生任何高度贡献。

  ★ 无 interpCorner 闸门（2026-08-31 已删）：角不再独立抬升，只由两条触及
    interpEdge 在 t=0 处 crest 汇合（见 §4.3），直接复用 V1–V4 闸门。

  后置总校验（surfaceHeightCore ③）：
    V6 最终 h 满足 hB ≤ h ≤ 触及块最高 crest（自然上界）。
```

- **斜坡是低侧块顶面的附加蒙皮**：坡带内顶面渲染 = interpEdge 剖面；t=w 处精确
  落回 hL，与块内平面对接无痕。剖面由 interpEdge 直接给出，零细分成本。
- **坡宽** `w = WELD_RAMP_CELLS = BLOCK_SIZE / 3 ≈ 1.333m`（无 4/w ∈ ℤ 约束；
  对向双坡各占块宽 1/3 → 中部留 1/3 平地 =「坡+平地+坡」）。per-edge 覆写：
  `EdgeOverride.rampWidth → src.edgeRampWidth`。

### 4.8 验收 = Phase F 六组不变式

```
① 撕裂角自持  全 cliff 角：每块角点 = 各自 h（对角/邻块不抬）
② 无幽灵拉高  对角高台（如 (1,1)=5）的触及边都是 cliff → 不抬 (0,0) 的角
              （cliff 边 interpEdge undefined → 角不受对角高台影响）
③ weld 边零落差 共享 weld 边中段低侧 == 高侧（= crest）
④ cliff 自持    cliff 边两侧各持各高，零插值
⑤ 全 weld 角水密 四块在共享角读同值 = 两触及 weld 边 t=0 crest 汇合
⑥ 坡带剖面      rampProfile 生效；坡带外落回低侧块高
```

## 5. 墙（硬边界基础几何，与裁决解耦）

```
发墙 = 块逻辑高有落差（hH > hL）【或】视觉面高有落差（坡侧裙墙）。裁决无关。
  cliff 墙 = 撕裂面本身（硬边界）。
  weld  墙 = 贴坡背墙（共享边高侧——斜坡蒙皮是附加在墙前低侧块上的额外面，
             墙永远在，任何视角看不到地形内部）
           + 坡侧裙墙（防御机制）：低块近坡的**垂直边**上，插值面高于相邻
             块顶面（视觉面高落差）→ 也发墙，堵住坡侧漏光/看穿斜草皮。
             视觉面高 = 两侧块各自块视角 blockVisualTop = cornerCell。
  等高块（drop=0 且无视觉面落差）→ 不发（退化保护）。
墙顶 = 沿边界逐米跟随 cornerCell（= surfaceHeightCore 块视角，取高侧视觉面
        = crest；weld 共享边两侧同值 = crest，构造上无撕裂）。坡面是浮在高台
        顶面上的蒙皮，坡顶与墙顶等高（= crest），不穿出、不过高。
墙底 = min(nbSide, baseHeightOf(两侧)) − WALL_EPS（深到底堵死，浅者防悬空穿透）。
去重 = 每条边界仅从「高侧（逻辑或视觉）」发一次（法线朝低处）。
```

> 演进注记：2026-08-31 上午版「weld 永不发墙」作废——坡带下方空腔在背面剔除后
> 大面积看穿地形。现行「墙与裁决解耦」是几何完整性的根，删掉坡只退化为普通断崖，
> 不会露洞。

## 7. 移动语义

- **爬阶梯 stepHeight ≡ EDGE_CLIFF_BAND = 0.35**（同一常量，注释互相绑定）：
  cliff 台阶 ≤ 0.35m 可自动踏过（clampCharacter 上行限速）；更高落差水平阻挡
  （回退本次位移）——只能跳上去。
- **空格跳跃 = 真实垂直跳高 0.6**（2026-08-31 定：爬阶梯 0.35 / 空格跳 0.6）：
  空中态 y = 起跳站立面 + 抛物线偏移（CharacterController.jumpSpeed =
  √(2·gravity·0.6) → 峰值 0.6 ≥ 0.5 高差）。空中不受 cliff 阻挡，落地落回贴地
  （WorldMode.clampCharacter 对空中跳过不钉地形）。相机 height = 站地、jump =
  偏移，二者分离不重复计。空中 y 由 CharacterBase.onUpdate 结算。
- weld 坡面连续 → 贴地跟随 surfaceHeightAt 自然走上坡，无新机制。
- 水/坑 walkable=false；落水坠坑死亡线吃逻辑高度（L4），与视觉面无关。

## 8. 数据定义（Tiles / TileGroups）

- **类型/材质分离铁律**：类型 = genRole + physics（封闭集合，加类型 = 体系决策）；
  材质 = visual.material + baseHsl（自由，加皮 = 注册即生效）。变体 physics ≙ 基础类型。
- **插值配置分两侧**：数据侧 `TilePhysics.edgePolicy`（全向）+ `smoothDirs`（方向性）
  + `edgeFinal`（per-(块,dir) 钉死）；**计划侧 planRefinements**（§3.3 30% 大落差产坡，
  per-chunk 确定性，读高度/角色）。几何层代码零改动。
- 群系 = groups 多对多归属 + TileGroups 加权抽取。
