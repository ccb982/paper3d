# 明日方舟主题肉鸽 —— 架构设计（v2）

> 背景：普瑞塞斯团灭泰拉大陆大多数角色，仅剩死魂灵形态的博士与维什戴尔抵抗。
> 玩法：每日舰船抽卡（决定进程，抽到 Boss 直接 Boss 战）→ 大世界探索/采集/战斗 → 敌人每日增益。
> 形态：**3D 大世界 RPG**，角色用 **2D 贴片（billboard）**，美术贴近明日方舟。
> 性质：**纯肉鸽，无存档**，一局一局打。

---

## 0. 核心形态决策（已拍板）

| 项 | 决策 | 说明 |
|----|------|------|
| 世界观呈现 | **3D 大世界** | three.js 全 3D 场景/地形/相机 |
| 角色 | **2D 贴片（billboard）** | 角色永远是面朝相机的 2D 立绘/小人片，类《八方旅人》纸片人 RPG 质感 |
| 战斗 | **单角色实时操控** | 只有维什戴尔可操纵，动作式实时战斗（移动/闪避/攻击/技能） |
| 地图 | **迷宫 + 块状开放结合** | 不同主题地区用不同生成风格，或同一地区混合 |
| 存档 | **无** | 肉鸽一局制，死亡/通关即结束，SessionData 只在内存 |
| 抽卡 | **后期打磨** | 先做逻辑（卡池/概率/结果），演出最后做 |
| UI | 不用 React，纯 DOM | 理由见下 |

## 1. 技术栈

| 项 | 选择 |
|----|------|
| 语言 | TypeScript |
| 渲染 | three.js |
| 物理 | rapier |
| UI | 原生 DOM 组件（或 preact，可选） |
| 特效 | 编辑器(.scene.zip) → 播放器 |
| 地图 | 程序化生成（seed 驱动） |

### 为什么不用 React
- 游戏本体 60fps 循环，实体/物理每帧更新，React 虚拟 DOM 协调是纯开销。
- UI（HUD/背包/抽卡）用原生 DOM 组件 + 事件，逻辑独立于渲染。
- 抽卡演出用 three.js 场景。

### 2D 角色方案（billboard）
```
BillboardSprite
 ├ texture      # 2D 立绘/小人贴图（方舟风格，多朝向可选）
 ├ mesh         # 始终面对相机的四边形（facing camera）
 ├ flip         # 左右翻转（移动方向）
 ├ animation    # 帧动画（走/攻/受击/死亡，纹理集）
 └ shadow       # 脚下的假阴影贴片（地面锚点）
```
- 角色挂点（头顶/手部/胸口）用于挂特效（播放器）。
- 敌人同方案。Boss 可放大贴片或半 3D。

## 2. LOD（3D 大世界重点）

### 地形 LOD
| 距离 | 方案 |
|------|------|
| 近（< 20m） | 全精度块状地形（贴图+法线+细节装饰） |
| 中（20~60m） | 简化块（合并网格，去掉法线细节） |
| 远（> 60m） | 低面数大平面 + 远景贴片（贴图蒙版） |

### 实体 LOD
| 距离 | 角色/物体 |
|------|-----------|
| 近 | 2D 贴片全细节（帧动画+阴影+特效挂点） |
| 中 | 贴片减帧（4 帧→2 帧，特效挂点停止发射） |
| 远 | 贴片换静态单帧（不播动画），无阴影 |

### 特效 LOD
- 粒子按距离降采样/停止发射。
- 爆炸/技能特效：距离 > 阈值直接不实例化（或播放简化版）。
- 子弹特效（拖尾）：只对玩家和近处敌人开全特效。

### 阴影 LOD
- 近处实体开 shadowMap，远处贴片用假阴影（地面圆形贴片）。
- 级联阴影（CSM）或简化：单张全场景阴影贴图，近处 512 近切。

### 实现：VisibilityManager
```
每 N 帧遍历实体 → 按相机距离分级（近/中/远）
 → 切换贴片细节 / 停特效 / 停动画 / 开关阴影
```

## 4. 游戏流程（一局肉鸽，无存档）

```
┌────────────────────────────────────────────┐
│ 开新局（随机 seed 初始化）                  │
├────────────────────────────────────────────┤
│  舰船(日常·固定地图·角色自由走动)          │
│  ├ 抽卡（单一卡池：外出前至少1次，可多次）   │
│  │   ├ 抽到大Boss → 直接进大Boss战          │
│  │   ├ 抽到角色 → 助战/增益                │
│  │   └ 抽到道具 → 进背包                   │
│  ├ 部署 / 商店 / 整理背包                   │
│  └ 出发 ──────────────────────────────────┤
│                                            │
│  ┌──────────────────────────────────────┐  │
│  │ 大世界探索（战斗模式·舰船被守卫）     │  │
│  │  ├ 采集 / 战斗 / 开箱 / 事件          │  │
│  │  ├ ★ 舰船是守卫目标：敌人会袭击舰船    │  │
│  │  │    需在探索与回防之间权衡          │  │
│  │  ├ 完成目标 或 撤退                    │  │
│  │  └ 返回舰船 ─────────────────────────┘  │
│  └──────────────────────────────────────┘  │
│                                            │
│  每日结束 → 敌人增益（日期推进）            │
│  死亡 / 舰船被毁 / 通关 → 局结束 → 结算     │
└────────────────────────────────────────────┘
```

**舰船（固定地图，Hub + 守卫目标）**：
- 独立固定地图，角色可自由走动（非静态 UI 界面）。
- 含：抽卡机、仓库/背包、商店、部署区、NPC、剧情触发点。
- 与其他地区共用 3D 场景/相机/角色操控（只是无战斗敌人）。
- **进入大地图后，舰船是守卫目标**（见战斗章节"舰船守卫"）。

**肉鸽一局制**：
- 无跨局存档；Session 只存当前局（seed、day、背包、卡池进度）。
- 死亡 = 局结束（可结算展示本局数据）。
- 每日增益贯穿本局，日期越往后越难，逼玩家推进。

**每日增益（数值 + 敌人种类）**
```
数值增益：enemyMultiplier = 1 + (day-1)*0.12 + floor((day-1)/7)*0.5
种类解锁：按日期阈值引入新敌人种类（可配置表）
 ├ day 1~3   ：基础兵（近战/远程）
 ├ day 4~7   ：+精英兵、袭扰兵（优先袭击舰船）
 ├ day 8~14  ：+装甲兵、自爆兵
 ├ day 15+   ：+重装精英、特殊机制敌人（召唤/冲刺/范围攻击）
 └ 每阶段在生成器布点表中加入新种类（与主题地区绑定）
```
- 数值曲线 + 种类表都做成配置，日期推进时敌人池动态扩展。
- 新种类由 `ChunkActorGenerator` 按 (day, 主题) 从激活的敌人表中采样。

## 5. 抽卡模块（逻辑先行，演出后补）

### 单一卡池（核心规则）
```
只有一个卡池：Boss / 角色 / 道具 都在里面
 ├ 每次外出前：必须至少抽 1 次
 ├ 可抽任意多次（自主决定抽多少 → 自主决定本局进程/风险）
 ├ 抽到大Boss → 直接进大Boss战（本局进程骤变）
 ├ 抽到角色 → 助战/增益
 ├ 抽到道具 → 进背包
 └ 抽的次数越多：卡池进度/保底计数前进，但风险也越大
```
- 抽卡 = 玩家对进程的"赌注"：想强 → 多抽（也更可能抽到 Boss）。
- 每日至少 1 抽的约束保证"每天都有抽卡"这个二次元仪式感。

### 明日方舟同款概率与保底（P0 核心）
```
★ 6★ 基础概率 2%，综合概率约 2.89%（方舟数值）
 ├ 抽到 6★：在【角色 / 大Boss】间按权重二选一
 │   （大Boss 是卡池里的"最稀有档"，如限定权重）
 ├ 保底：10 抽内必有 5★ 或以上
 ├ 硬保底：50 抽内必有 6★（方舟机制），且前 50 抽概率递增
 ├ 大Boss 专属：方舟同款"井"机制——如 300 抽必定出大Boss
 └ 保底计数记录在 Session（一局内有效，局结束重置——肉鸽特性）
```
- 数值细节（权重/井数/递增曲线）做成可配置表，之后调平衡。

### 后做（P1，重投入打磨）
- 写实抽卡演出（three.js 场景：星芒/立绘弹出/稀有度光效）。
- 贴合粥的呈现：档案卡、干员立绘、抽卡 BGM。

## 6. 地图系统（片状加载 + 迷宫/块状开放结合）

### 主题地区（多主题包）
| 主题 | 生成风格 | 特色 |
|------|----------|------|
| 龙门外环 | 块状开放 | 高低差平台、城墙、市场 |
| 卡西米尔竞技场 | 块状开放 | 开阔、观众席、角斗区 |
| 哥伦比亚实验室 | 迷宫 | 走廊+房间、试管/灯光、Boss房 |
| 乌萨斯废墟 | 迷宫 | 黑暗、窄道、伏击 |
| 罗德岛舰船 | 固定 | 基地（非随机，固定 chunk 集） |

### 片状加载（Chunk Streaming）
```
大世界 = 若干 Chunk（如 64m × 64m 一块）拼接
 ├ 角色进入新 chunk 边界（如距边界 < 1.5 chunk）→ 请求生成该 chunk
 ├ 生成的 chunk 由 (seed, chunkX, chunkZ, 主题) 确定性派生 → 可复现
 ├ 只加载/渲染当前视距内的 chunk（远 chunk 卸载网格，保留数据/或全卸载）
 └ 探索越多，地图自动向外扩大（无固定地图尺寸）
```
- **数据分层**：
  - `ChunkData`（纯数据：地形高度/方块类型/资源点/刷怪点）——轻量，可保留
  - `ChunkMesh`（生成的网格/贴片）——按视距加载/卸载（LOD 联动）
  - `ChunkActors`（实体的摆放：敌人/箱子/装饰）——chunk 激活时才实例化
- **生成流水线**：`chunk 请求 → 生成器(seed派生) → 网格/碰撞/布点 → 激活`，放入队列异步处理，避免卡顿。
- 舰船（固定地图）用同一套 chunk 系统，只是 chunk 数据来自预置而非生成器。

### 两种生成器（可组合）
```
MapGenerator (按主题选风格)
 ├ BlockOpenGenerator    # 块状开放：矩形块拼接、平台、路径
 └ MazeGenerator         # 迷宫：房间+走廊（BSP/回溯法）、关卡门

每 chunk 按主题风格独立生成，chunk 边界用连接点（门/坡道）衔接
地图内容 = 骨架 + 主题素材(贴图/装饰) + 资源点 + 敌人布点 + 宝箱
```
- seed 驱动全程 → 可复现，可查看本局种子。
- 大世界：主题区可以跨界连续（龙门外环 chunk 邻接哥伦比亚实验室 chunk 时风格渐变），探索自由，boss 区单独。

### 探索进度（肉鸽目标）
- 大 Boss 有专属地图生成机制（见 Boss 系统），探索到触发条件即进入 Boss 区。
- 探索越深，敌人增益与稀有度提升（与每日增益联动）。

### Boss 系统（两层级）
```
┌─────────────────────────────────────────────────┐
│ ① 常规小 Boss（地图随机刷新）                    │
│   - 随机出现在已生成 chunk 的某些节点（精英房/特殊地形）│
│   - 使用常规战斗系统 + 专属 AI/技能（无专属地图）  │
│   - 掉落稀有奖励，推动探索                        │
├─────────────────────────────────────────────────┤
│ ② 大 Boss（专属地图生成 + 专属机制 + 独立战斗模式）│
│   - 大Boss 在卡池中（方舟同款概率/保底/井）       │
│   - 抽到 → 直接传送/切换到专属 Boss 竞技场         │
│   - BossArenaGenerator：独立生成（非 chunk 流式）  │
│   - 自定义物理机制：局部重力/重力方向变化/时间缩放  │
│   - 最终 Boss 战 = 独立战斗模式（单独设计规则）     │
└─────────────────────────────────────────────────┘
```

**大 Boss 专属地图（BossArenaGenerator）**
```
独立竞技场地图（非 chunk 流式，固定规模 or 阶段变化）
 ├ 按 Boss 定制的场地布局（平台/坑/障碍/阶段破坏物）
 ├ 场地可随阶段演变化形（进入阶段2 塌陷/升平台）
 └ 与主题美术一致（实验室 Boss → 试管装置场地）
```

**自定义物理机制（大 Boss 战）**
```
rapier 扩展能力：
 ├ 局部重力场：Boss 周围区域重力方向/大小变化（反转、拉向中心）
 ├ 每实体 gravityScale：特定敌人/子弹重力倍增
 ├ 时间缩放（子弹时间）：战斗节奏控制
 └ 绑定特效：重力异常时的粒子/光线扭曲表现
```
- rapier 支持世界级重力 + 每刚体 `gravityScale` → 局部场用"区域查询 + 施加额外力"实现。

**最终 Boss 战斗模式（独立）**
```
BossRaidMode：与常规战斗模式并列的独立模式
 ├ 多阶段 Boss（血条分段，阶段切换 = 场地+AI+机制变化）
 ├ 专属机制（自定义重力/地形破坏/召唤物等，按 Boss 定制）
 ├ 专属 HUD（Boss 血条/阶段提示/机制预警）
 └ 战斗结束 → 结算 → 回舰船（本局接近终局）
```

## 7. 战斗系统（单角色实时动作）

### 操控（维什戴尔）
```
WASD 移动 / Shift 闪避 / 鼠标瞄准 / 左键攻击 / 技能(1~4) / 交互(E)
```
- 动作式：攻击连段、闪避无敌帧、技能 CD。
- 敌人：近战兵/远程兵/精英/Boss，AI 状态机（巡逻/索敌/攻击/技能/死亡）。

### 相机（第三人称越肩跟随）
```
肩后跟随（over-shoulder）：相机悬于角色右肩后方，随移动/转向平滑跟随
 ├ 基础跟随：位置 = 角色 + 右偏移(肩) + 后偏移 + 高度
 ├ 瞄准时：相机拉近到肩部齐平，准星对准鼠标射线
 ├ 闪避/受击：相机轻微震动/偏移
 └ 碰撞规避：相机与墙/地形碰撞时自动拉近（sphere cast）
```
- 舰船（日常）与战斗模式共用同一套相机系统（无战斗时只是不锁敌）。
- 鼠标控制视角旋转，角色面向与移动分离（类越肩射击/ARPG）。

### 实体阵营
```
角色：主角(维什戴尔) / 友方(助战) / 敌方
物体：可交互(箱子/机关) / 静态(墙/地形)
子弹：友方 / 敌方
```

**友军两种形态（部署型 / 跟随型）**
```
友方(助战)分两类：
 ├ ① 部署站桩型（Deployable）
 │   - 放下后固定驻守某处（如守舰船、守路口）
 │   - 自动索敌战斗（类似炮塔，但有角色形态/技能）
 │   - 玩家离开后继续战斗 → 天然契合"舰船守卫"
 │   - 可回收/换位置（或部署后固定，按设定）
 │   - 例：盾卫站桩守船、狙击干员守高台
 └ ② 跟随型（Follower）
     - 始终跟随玩家移动（保持阵型/距离）
     - 协同攻击玩家锁定的目标（或自动索敌）
     - 玩家撤退时一起撤
     - 例：维什戴尔的老搭档、召唤物

抽卡抽到的角色 → 玩家决定部署 or 跟随（或角色本身有类型）
```

**弹药机制（主角/炮塔 vs 友军不对称）**
```
├ 主角（维什戴尔）：无弹药机制（无限弹药，技能只看 CD/蓝）
├ 舰船炮塔：无弹药机制（自动无限射击）
└ 友军：有弹药机制
    ├ 弹药 = 友军使用强力技能的消耗品
    ├ 有弹药：能放强力技能（爆发伤害/范围/辅助）
    ├ 无弹药：切"扛盾"近战模式
    │   ├ 扛盾防御：高减伤/嘲讽，站桩抗线
    │   └ 近战攻击：盾击/近战挥击（持续造成近战伤害）
    └ 弹药消耗按技能强度分级（普通技 1 发 / 大招 3 发…）
```
- 不对称设计制造决策：**弹药给谁？**（友军技能 or 留作别的用途）
- 无弹药的友军依然有用（扛盾 + 近战输出），不拖累体验。

**友军辅助功能**
```
除了战斗，友军还能干杂活：
 ├ 带物资：作为移动背包（多带一件/增加携带上限）
 ├ 帮助收集：附近采集物自动拾取/加速采集
 ├ 修船支援：驻舰船时协助维修/给炮塔装弹？（待定）
 └ 提升探索效率 → 探索越深越需要友军
```

**弹药获取途径（三种）**
```
① 缴获：击杀敌人掉落（精英/Boss 掉更多）
② 搜寻：地图资源点/箱子中开出
③ 合成：用采集的物资在舰船合成台制作（配方表）
```
- 弹药进入背包（Inventory），可分配/转移给友军。
- 伤害走 rapier 碰撞回调，按阵营过滤（friend 不伤 friend）。
- 子弹 = 实体壳（rapier 刚体+伤害）+ 特效层（拖尾/粒子/命中）。
- 部署型友军 = 舰船守卫的主力（与炮塔互补）。

### 伤害公式（占位）
```
finalDamage = base * skillMult * enemyMultiplier(day) * crit(rng)
```

### 舰船守卫（探索的核心张力）
```
进入大地图后，舰船停在入口区，是"要守卫的物品"
 ├ 舰船有 HP / 装甲 / 护盾（Session 记录，可升级）
 ├ 敌人 AI 目标分级：玩家 / 舰船
 │   - 部分敌人（如"袭扰兵"）无视玩家直奔舰船
 │   - 探索越远/越久，袭击舰船的波次越频繁越强
 ├ 舰船受击警报：HUD 提示 + 小地图红点 + 音效 → 逼玩家回防
 ├ 玩家回防击杀 → 舰船恢复安全；离开后袭击继续累积
 └ 舰船被毁 = 局结束（与玩家死亡同判）
```

**舰船防御配置（可升级）**
```
炮塔系统：可在舰船甲板安置炮塔（自动索敌射击）
 ├ 炮塔位点：固定槽位（如 4 个），安置后可移除/换装
 ├ 炮塔类型：机枪塔（对空/近）/ 导弹塔（单体高伤）/ 榴弹塔（范围）
 ├ 炮塔消耗：由卡池道具/商店补给获得（与背包联动）
 └ 炮塔自动战斗，玩家不在时也能抵挡袭扰

舰船强化：消耗资源提升舰船本体
 ├ 血量上限 / 装甲减伤 / 护盾回复
 ├ 修理：探索结束后/商店可修船（消耗资源）
 └ 强化等级记录在 Session
```

**舰船科技树（简短版，不拖长流程）**
```
控制体量：单线/浅分支，一局内可点完（约 5~10 个节点）
 ├ 主线程示例：船体强化 → 装甲 → 护盾 / 炮塔解锁 → 炮塔强化
 ├ 科技点来源：探索采集 / 战斗掉落 / 卡池道具
 ├ 每个节点 1 级（或 2~3 级封顶），避免数值膨胀
 └ 科技树仅本局有效（肉鸽），重置即重来
```
- **设计张力**：探索（收益/进度）vs 回防（生存）。玩家需规划探索半径与回防时机。
- 助战角色/召唤物可留守舰船防御（与卡池抽到的角色联动）。
- 袭击波次与每日增益联动（日期越后，袭扰越猛）。

## 8. 物理 / 爆炸 / 布料 / 水

### rapier 封装
```
PhysicsWorld
 ├ step(dt)            # 固定步长
 ├ add/remove RigidBody
 ├ collisionCallbacks  # 阵营分发
 └ explosion(pos, r, force)  # 爆炸冲击
```

### 爆炸库
- 特效层（粒子/光/烟，播放器或自研）+ 物理层（explosion 冲量）分离。

### 布料（GPU verlet）
- 位置/速度纹理 + 数值积分 shader，纯视觉。
- 博士袍、披风、旗帜。

### 水（GPU）
- 顶点波 + 法线扰动 + 反射/折射近似，无碰撞体。
