
## 2. 指挥侧（引擎 → 队长）

- **唯一指挥源**：`EngineBridge`（2Hz 决策拍）。每拍给每支小队**一个状态标签 + 数据载荷**，经 `OrderWriter` 唯一发令口下发；队长核只读标签执行。
- **标签**：`march / hold / patrol / protect / assault`（march 到点→引擎换 hold；hold/patrol/protect 持续到被覆盖）。
- **五命令源（优先级）**：① 玩家令 ② 总攻 `assault` ③ §3.G 保护/支援/后撤（`tacticalPlan`）④ 工兵活源（件数据）⑤ **唯一兜底 = 行军↔巡逻交替**。
- **总攻**：目标 = `shipSidePoint`（以舰为心扫圆环取**本队可达**最近可站点）；到点转 hold（判官豁免）。
- **判官（`TimerManager`）**：只判 L3 实体；`STUCK.HOLD_S=25s / BBOX_R=4m`；豁免**只减不增**（驻守/巡逻位移/交火/被击/保护跟到）。

## 3. 执行侧（队长核）

- `SquadCore.drive`：标签 → 长/短寻路 → 路点 → 成员跟随 + 指令分发（`hooks.onDirective → WorldSpawner.applyOrderToEntity`）。
- `HoldCover`：驻守三阶段（seek/hide/retreat）；**条件允许直接进岗哨**（锚点旁 ≤10m 的件 + 移动层 ≤6m 直推、可爬）；否则旧模式（更靠舰掩体+背舰侧、`coverFrom` 校核保证被挡）。
- **位移铁律**：**所有位移出自长/短寻路**；短寻路 `localStep(force)` 为显式强制许可（穿硬边=重罚+标 climb），仅用于强制攀爬/进岗哨/掉队跟随；例外：飞行直航、判官前推离。

## 4. 导航

- `PassTable`：**可行性唯一权威**（有向边 can/drop/climb + 水 + 陡壁）；**舰心窗**（半径=罩住 舰↔落点走廊，dist+60、上限 240）；地形改动经 `PassTableKeeper` 节流重建。
- 长寻路：可行性 BFS（表中可达才发路；表外/不可达宁停不猜）。
- 短寻路：`LocalStep`（窗口 Dijkstra + 安全评分 + 段校验 `canSegment`；`force` 模式见 §3）。
- 巡逻腿 `patrolNext`：绕锚点采样 + **BFS 可达校验**；空中免校验。

## 5. 地形事实表（只给事实，不评分）

- **3 通道**：C1 高度（raw+3×3平滑）｜C2 地形结构（`kind` 平地/坡面/山顶/高原/缝道 + `slope` + `narrowW/Dir/Long`）｜C3 对舰关系（`slopeDir` 迎/背/平侧 + `occluded` 3D 遮挡，眼点=舰处地形高+1.6m）。
- **窗口**：**舰心窗**（静态；换落点/舰动重建）；出窗射线用采样器补高。
- **防区单源**：`Sectors.ts`（区数/角↔区/楔形夹取）；`SectorBuilder` 产可部署点、`BattalionManager` 产队→区部署计划。
- **动态表**：`HoleMask`（破坏掩码）+ `HoleTable`（2Hz 敌用工事表）；水可走、不挡视线。
- 细则（阈值/窄道语义/岗哨三件）见移植源《地形语义表设计.md》（已冻结，见 §11）。

## 6. 兵种管理器（决策归管理器）

- 职责：编成/补兵（`ensureSquads`）+ **选点/件数据函数**；**不产标签、不驱动运动**。
- 决策表：各管理器自带 `*_TACTICS`（系数 + 曲线 + 谓词）；**事态 p 的消费曲线各写各的**；共享数学 = `engine/UnitScoring.ts`（事实→feats + 合成 + 路由）。
- 四兵种选点：
  - 近战 `wanderPoint`（非保护=到处游荡：绕舰 8 向 36m 可达点；巡逻半径 30m）；
  - 远程 `rangedGarrisonSpot`（**有掩体岗哨的高地**；限本防区；可达优先、近位 force）；
  - 飞行 `flyerSupportSpot`（友军被打急速来援的驻位：被支援队旁 ±45°·14m）；
  - 工兵 `planFor`（件梯队：岗哨三件 → 缝道封口 → 常规；连做 2 件战术件强制转常规保战壕循环）。

## 7. 数据层

- `SwarmData`（门面：事态刻度/tick 编排/查询）＋ `CoverTables`（工事表集合）＋ `PlanData`（落点/环/施工带/防区锁）＋ `Ports`（创建/工兵端口工厂）。
- `SwarmLedger`（兵力账本，按在场补兵）、`RosterController`（编制占比/缺口）、`FortifyPlanner`（需求+建造账本+`buildBonus`）。
- 消费纪律：数据层只读查询；可行性只走 `PassTable`；**manager 只产数据**。

## 8. 装配（模式层）

- `EngineWiring.installEngineWiring(host)`：
  - 建 `EngineBridge`（LiveView 全钩子：player/ship/squads/enemies/attackables/engineer/creation/posture/assault/underAttack/clampRing/sectorLock/flyerSpot/blockedAt/canReach/coversNear/garrisonSpot/stuckR/agents/t01/ledgerTotal/setReleaseCap/exemptOf/retire/emit…）；
  - 建 `SquadRegistry`（角色/汇报/缺口/端口：ensurePath/patrolNext/leaderTarget/shipPoint/coversNear/protectNext/coverFrom/clampRing/fireAllowed/applyDirective/mobTactics）；
  - 源注入：`setLiveOrderSource` / `swarm.setFireGate` / `swarm.setSquadStateSource` / `swarm.setSquadGone` / `setTierHandover(Flux)`；
  - 战术侧 `SectorBuilder/BattalionManager`（0.5s 摊销；随机 1~3 主攻 + 优先级次序 + 可达锚点）。
- `CommanderWiring.wireCommanderPorts`：`buildCover`（正面朝舰；件面优先）/`digTrench`/`onTerrainDig→noteTerrainDig`/原子生成口（`spawnOne`，近点直放、远点外推）。
- **CoverLazy**：工事懒物化（`queueOrBuild` + 每帧 `realize`，近玩家/相机 ≤ `SWARM.L3_RADIUS` 才建实体）。
- **WorldMode**：`simT += dt; setSimNow(simT)`（玩法时钟单源）；每帧 `swarm.update → engineWire.tick`（引擎→队长核→战术）；事件（`enemy_killed/enemy_removed` 摘除、`enemy_hit` 警觉）；实体互推（H2）；`EnemyBase.climbLandedHook`。

## 9. 事态与节奏（本体口径）

- 事态函数 `PostureFn`：p = clamp(日程 + 挑衅)；驱动事态环、权重、管理器 p 曲线。
- **本体节奏（与 rts 的差异，3 处）**：
  1. **落地起算**：`hooks.dayT01=-1` → 内部节拍 `DAY_RHYTHM_S=600`（**一天 10 分钟**）；太阳钟只驱动昼夜/UI；
  2. **推进受事态门控**（`EngineBridge`）：`p<0.45` 只巡逻/游荡，不朝舰推进（防开局冲家）；
  3. **敌方登陆点**：`pickEnemyLanding`（距舰 160m 可行向）→ `planDefense(落点)`；事态环 = 走廊（落点前沿 ±80m）。
- 时间线：落地 → 布防（fortify）→ 巡逻（patrol）→ 约 7~8 分钟 p≥0.8 → 总攻（assault）。
