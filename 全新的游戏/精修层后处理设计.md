# 精修层后处理（PostProcess）设计 —— 独立双产物替换（渲染精细 · 物理粗自洽）

> 状态：设计稿（2026-09-04，v5）+ 已落地第一步。目标：精修层**定型快照之后**加一个**独立整形层**，
> 不依附精修层内部概念，能任意修改顶面 / 侧壁（墙）/ 插值 / 硬边界 / 坑洞 / 裂缝 /
> 边缘圆滑；对坑洞、裂缝这类效果**独立生成物理与渲染两套产物，再替换进原本（精修层
> 快照）该在的地方**；渲染精细、物理粗自洽。
>
> 落地现状：ppHeight + ChunkSurface 顶顶点位移已接入（开关 POST_PROCESS_ENABLED 开
> = 游戏可见坑/裂/圆滑；渲染=物理同数组自洽）。局部细分/物理粗版/替换为下一步。
>
> 版本沿革：
> - **v1**：倒角 = 真插入 45° 三角形 + bevelTape。→ 作废。
> - **v2**：倒角 = 高度场偏移；统一 heightOffset。→ 定位不准。
> - **v3**：坑/裂局部细分 + 双精度采样。→ 割裂物理/渲染。
> - **v4**：统一自洽快照整形（物理=可见逐位）。→ 物理逐位过苛。
> - **v5（本次）**：据用户「坑洞/裂缝这后处理层独立生成物理和渲染，然后替换进原本的
>   地方」定稿：**后处理独立产出物理替换件 + 渲染替换件，各自替换进原快照**；渲染精细、
>   物理粗自洽（可踩不穿不悬空）。用户另确认：能任意改侧壁/顶面/插值/硬边界且自洽。

## 0. 一句话

**精修层产出快照后，后处理层对坑洞/裂缝等效果独立生成两个替换件——渲染版（精细、多顶点、平滑）与物理版（粗、可踩不穿不悬空）——各自替换进原本精修层快照该在的位置（渲染替换顶面/墙网格、物理替换物理合并处），同时保留任意整形顶面/侧壁/裁决的能力。**

### 0.1 核心取舍（用户已确认）

| 项           | 定论                                                                 |
| ------------ | -------------------------------------------------------------------- |
| 渲染（视觉） | **一定精细**：圆滑/坑/裂多顶点、平滑曲线，非生硬大块                     |
| 物理         | **不精细但自洽**：粗网格，**可踩、不穿、不悬空**；不要求逐位=视觉边缘     |
| 生成方式     | 后处理**独立生成**物理版与渲染版两套，再**替换**进原快照对应位置           |
| 权力         | 能任意修改侧壁 / 顶面 / 插值 / 硬边界（整形后自洽）                        |
| 烘焙         | 跟渲染（细），与可见精细轮廓一致                                        |
| 物理替换件     | ★ **用户定稿（2026-09-04）**：物理用**低精度坑洞/裂缝**粗网格替换即可，可踩、不穿、不悬空   |

## 1. 定位与职责边界

### 1.1 为什么独立

精修层是块间过渡引擎。后处理是对**已定型表面**的全权整形。它不读精修层裁决语义，
只把精修层产物当数据输入，独立生成替换件。

### 1.2 职责边界

| 属于后处理层                                          | 不属于后处理层（留精修层）     |
| ----------------------------------------------------- | ------------------------------ |
| 独立生成**渲染替换件**（顶面/墙网格，精细）             | 块间过渡裁决的**初始**生成      |
| 独立生成**物理替换件**（物理网格，粗自洽）              | 插值/硬边界/斜坡的**初始**成形  |
| 任意整形顶面/侧壁/裁决（圆滑/坑/裂/改墙/改裁决）        | （精修层产物仅为输入）         |
| 把两套替换件装回原快照对应位置                          | ——                             |

### 1.3 不变式（必须保持）

1. **确定性幂等**：同 seed 同 chunk，主线程 / Worker / 重建逐位一致。
2. **渲染精细**：坑/裂/棱用局部细分多顶点画平滑曲线，非生硬凹陷。
3. **物理粗自洽**：物理版可踩、不穿、不悬空、无大洞；不要求逐位=视觉边缘。
4. **替换即生效**：两套替换件装回后，渲染用渲染版、物理用物理版，各自位置正确、不打架。
5. **全权独立**：只把精修层产物当数据；要改裁决走后处理自己的确定性规则。
6. **零 three 依赖**：纯 JS，主/Worker 同源。
7. **回归锁前置**。

## 2. 统一入口（独立双产物替换）

新增 `src/services/map/RefinementPostProcess.ts`：

```
精修层定型快照（数据输入）
  ChunkFinal · ChunkWallBuffers · BlockSource · blockTypes · seed
        │
        ▼
RefinementPostProcess.ts（纯函数 · 零 three · 确定性）
  ┌────────────────────────────────────────────┐
  │ ① 整形（任意，可选）                        │
  │    边缘圆弧过渡 / 改顶面 / 改墙 / 改裁决     │
  │ ② 独立生成渲染版（精细）                    │
  │    ppRenderTop  = 圆滑/坑/裂 + 局部细分顶点   │
  │    ppRenderWall = 与最终渲染面同步的墙        │
  │ ③ 独立生成物理版（粗自洽）                  │
  │    ppPhysTop    = 坑/裂/圆滑的粗近似（漏斗/槽粗）│
  │    ppPhysWall   = 粗自洽的墙                  │
  │ ④ 替换进原快照                              │
  │    渲染：顶面网格/墙网格 ← 渲染版             │
  │    物理：mergeTerrainPhysics ← 物理版         │
  │    烘焙高度场 = 渲染版最终面（Worker 重放）    │
  └────────────────────────────────────────────┘
        │
        ▼
  替换后的快照：渲染(细) + 物理(粗自洽) + 烘焙(细) 
```

### 消费方（替换后各自取各自的）

| 消费方          | 取什么                                   | 精度 |
| --------------- | ---------------------------------------- | ---- |
| 视觉顶面网格     | ppRenderTop（精细）                       | 细   |
| 视觉侧壁 (墙)    | ppRenderWall（与渲染面同步）              | 细   |
| 物理 trimesh     | ppPhysTop + ppPhysWall 合并（粗自洽）      | 粗   |
| 烘焙 / 贴地      | 渲染版最终面高度（Worker 重放同源）        | 细   |

## 4. 整形能力（全权，可选）

### 4.1 边缘圆弧过渡（圆滑楼缘）
```
块顶面外缘 R(0.2~0.4m) 内：视觉面 −= BEVEL_ARC·(1−cos(π·dV/R))/2   // 余弦弧平滑
判棱：高度场差分 |dh|>BEVEL_EPS 且实体地块外缘（不用精修层裁决）；水/坑非实体不圆滑
```

### 4.2 坑洞 / 裂缝（影响渲染版精致 + 物理版粗近似）
```
坑：hash 撒锚 → 渲染面用平滑对称剖面（很多顶点）；物理面用粗漏斗近似（能站）
裂：hash 折线 → 渲染面用平滑沟壁（很多顶点）；物理面用粗槽（跨过即达）
两者手工：渲染精细、物理粗自洽
```

### 4.3 改墙 / 改裁决（后处理也拥有）
```
可增/减/移墙缓冲；经自己的确定性规则写 edgeFinal 覆写裁决。
但改动必须随后处理自洽：渲染版与物理版各自重派生墙，不悬空、无裁决-墙矛盾。
```

## 5. 渲染版（精细）：局部细分

```
render top：
  coarse 区：每米格 4 顶点 / 2 三角（顶点省）
  fine 区  ：1m 递归细分至 0.125~0.25m → 多顶点，高度逐点取最终渲染面
  coarse↔fine：t-junction 修复保证水密
  （确定性 1/2 递归固定 depth → 主/Worker 同构、可重放）
顶点只加在坑缘/裂带/棱影响带 → 增长可控
```

---

## 6. 物理版（粗自洽）：粗近似 + 替换

```
物理 top/wall：用粗网格表达圆滑/坑/裂的近似
  - 坑：漏斗形粗近似（坑缘/坑底粗网格逼近能站）
  - 裂：粗槽（窄裂跨过，无需逐位）
  - 圆滑：粗化即可（效果极小，甚至保留原平面也自洽）
物理自洽底线：可踩、不穿、不悬空、无大洞（回归 E）
物理版与渲染版独立生成，不要求逐位=视觉边缘 →「物理不精细」由此表达
```

> ★ 这就是 v4 「物理=可见逐位」的修正：物理不是渲染的简化拷贝，而是后处理**独立生成**
> 的粗自洽网格；渲染精、物理粗、各自替换。烘焙跟渲染（细），与可见精细轮廓一致。

## 9. 落地顺序（建议）

1. ✅ 建 `postprocess-regression.ts` 骨架 + 总开关（默认关后已开显示），跑通空处理 ≡ 原世界。

## 10. 开放项（实现时确认）

- **BEVEL_ARC 与移动**：圆滑压低 < 0.35 不触发台阶阻挡，默认安全。
- **坑/裂是否计入移动逻辑高**：默认不改 L4 逻辑高度，仅改渲染/物理采样；坑底可站由
  物理版漏斗覆盖。
- **坑/裂与地块材质**：斜面沿用原地块材质，无新贴图；是否需专门着色。
- **改裁决权力边界**：默认只开放「坑/裂安全区域内补 wall/收边」所需极小改裁决，不通盘改。
- **物理版粗化尺度**：坑漏斗/裂槽的粗网格密度需实测调（能站且不过度占顶点）。
