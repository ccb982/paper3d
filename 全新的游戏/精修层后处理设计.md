## 0. 一句话

**精修层是块间过渡引擎（真源）。后处理层只读复用它的纯函数，在 ChunkManager 三处路由
（顶面 / 侧壁 / 贴地查询）切换为「后处理高度函数 + 重建网格」，实现圆角(bevel) / 坑(pit) /
裂缝(crack) 三种确定性整形；`POST_PROCESS_ENABLED=false` 时逐字节退化为精修层原输出。**

### 0.1 铁律（用户定稿，v6）

| 项 | 定论 |
| --- | --- |
| 精修层 | **零改动**（`Refinements.ts` / `ChunkSurface.ts` / `ChunkWalls.ts` / `RasterMap.ts` / `bakeCompute.ts` 全不碰） |
| 接入方式 | **唯一改动点 = `ChunkManager.ts` 三处路由**（顶面 / 侧壁 / 贴地查询） |
| 关闭开关 | `POST_PROCESS_ENABLED=false` → 逐字节 = 精修层原输出（A/B 等价） |
| 同源性 | 渲染网格 = 物理缓冲 = 贴地查询 = **同一份后处理高度函数**（无割裂） |
| 纯函数 | 确定性、种子可重放、零 three 装配耦合（装配只发生在路由末尾） |

## 2. 三种整形效果（确定性 · 种子可重放）

### 2.1 圆角 bevel（风化圆滑高台外露硬边）

- 只作用于「高台(platform) → 不插值地面(ground+cliff) 且邻块更低」的**外露硬边**；
- 高台↔高台 / 水 / 坑、插值(weld) 边一律棱角分明不圆滑；
- 外凸 1/4 圆弧：`drop = BEVEL_R − √(2·BEVEL_R·d − d²)`，棱处 −R、带缘 0（带宽 0.3m）；
- 判定带内按**到最近外露硬边的距离**（dMin）取弧，角点自动双弧混合；
- **插值坡豁免**：弧边左右侧向边（`dir^2` / `(dir^2)^1`）任一是 weld → 整条弧边撤销
  （侧壁补弧后 weld 坡方形顶角会突出且背面镂空；豁免后该边回精修层原生输出）。

### 2.2 坑洞 pit（块中心圆坑）

- 圆坑半径 ≤1.5m（恒在 Own 块内），平滑余弦剖面；
- **禁挖带**：任一方向邻高台(platform) 或该边是插值(weld) → 整块禁挖（不破坏敏感接缝）。

### 2.3 裂缝 crack（块锚定折线浅沟）

- 每块确定性锚点折线（种子哈希），按 5×5 邻域扫锚块 → 跨块裂缝连续；
- 同坑的禁挖带守卫。

## 3. 顶面网格（buildPostChunkTopSurface）

```
① fine 标记：效果带内 1m 格（9 点采样 ppOffset<0 判命中）
② fine 外扩 1 格（8 邻域）：fine/coarse 边界两侧偏移均为 0 → 水密无 T 结
③ 发射网格：
    coarse 格：4 顶点 + 精修层同对角剖分，y = yAt(cell 所属块视角)
    fine 格  ：2^3 细分（0.125m），中差分法线，y = yAt
顶点布局/uv 与精修层 buildChunkTopSurface 同约定 → 可无缝替换路由。
```

高度函数 yAt 的「块视角」= 精修层 cornerCell 同语义：**渲染网格 = 贴地查询 = 墙顶同源**。

## 4. 侧壁体系（buildPostSideWalls）★ 本轮核心

### 4.1 问题背景

精修层 `buildChunkWallBuffers` 产出的墙是**竖直平面 quad**，墙顶 = 视觉面高（cornerCell）。
bevel 把高台顶面边缘压成 1/4 圆弧后：
- 弧边正对墙只需墙顶跟到弧底 `H−R`（原本逻辑已可）；
- **弧带端头（沿弧边方向的左右剖面）与弧带下方的竖直空间没有面** → 侧面看穿 / 月牙缺口；
- 角点处 `cornerCell` 的混合值让墙顶与顶面边缘错位。

### 4.2 处理管线（全部在 buildPostSideWalls 内）

```
① 复用精修层墙缓冲（buildChunkWallBuffers 只读调用，产出全部原墙 quad）
② 收集「重建边集合 rebuild」：
   · 弧边左右侧壁（dir^2 / (dir^2)^1，恒成立公式）——自身是弧边（转角）跳过
       ─ 有落差(邻更低) → drop=true  全高重建
       ─ 无落差        → drop=false 只补弧带端面封片
   · 扩散 1：rebuild 中每条边的邻居若是 platform 高台 → 其「朝本块边」
     （邻居坐标 sd^1）也加入（drop=true）——背靠背同面的对侧高台墙
   · 扩散 2：弧边 dir 的对边（dir^1）方向邻居若是 platform → 其「朝本块边」
     （邻居坐标 dir）也加入——弧带缺口方向看穿的悬空
③ 遍历原墙 quad（uv 反推发射块 + quadEdgeDir 反推方向）：
   · 命中 rebuild 边 → 剔除（索引重排），材质按沿边位置记录待继承
   · 其余 → 墙顶 += ppOffset（透传原行为）
④ 重建生成（替换被剔除原墙）：
   全高墙（drop=true）：
   · 沿边采样：接弧端 0.3m 弧区对齐顶面 fine 网格（0.125m 采样）
     另一接弧端对称加密；其余 0.5m
   · 每段竖直 quad：顶 y = yAt（= 顶面边缘逐点同值 → 完全闭合无锯齿），
     底 y = min(两侧 h) − 0.5（向下延长埋地）
   端面封片（drop=false，无落差）：
   · 弧带端头曲边三角：底尖 + 沿弧边内缩方向采样，顶点高全部 yAt
     （角点混合 / 弧线完全贴合顶面）；法线沿边朝外，绕序按叉积校验翻转
⑤ 合并进同一份 buffers → 渲染 mesh 与物理 trimesh 同源更新
```

### 4.3 关键方向公式（踩坑修正记录）

| 用途 | 错误写法（曾用） | 正确写法 |
| --- | --- | --- |
| 弧边的左右侧边 | `(dir+1)/(dir+2)/(dir+3)%4`、`dir^3` | **`dir^2` 与 `(dir^2)^1`**（恒成立） |
| 弧边的对边 | — | **`dir^1`** |
| 邻居朝本块的边 | 邻居坐标 + 本块方向角点偏移 | **邻居坐标 + `WALL_DIRS[sd^1]` 角点偏移** |
| 重建墙顶点顺序 | 采样起点反转（B→A）→ 绕序反 → 面消失 | **恒定 A→B**，只把弧区加密点放接弧端 |

### 4.4 材质

- 重建墙继承被剔除原墙 quad 的颜色 / shade / uv（按沿边中点参数就近取）；
- 无原墙可继承时用默认灰（可换本块 tile 色）。

## 5. 贴地查询（postSurfaceHeightAt）

米格 4 角按【块归属】取后处理高（yAt）后三角形插值——与顶面网格 coarse 部分
逐位一致（fine 细分格内为亚米近似；物理碰撞走 trimesh，装饰 / 标签用）。
`POST_PROCESS_ENABLED=false` 时透传 `raster.surfaceHeightAt`。

## 6. 调试线框（buildBevelWallDebug）

默认**不挂载**。`ChunkManager` 仅在
`globalThis.__PP_DEBUG_LINES === true` 时把线框加进 chunk group：
- 彩色框（红/绿/蓝/黄）= 弧边记号（按方向）
- 白色框 = 弧边侧壁（墙顶含弧线轮廓）
- 橙色框 = 弧边 dir 对边方向邻居高台「朝本块边」
- 紫色框 = 弧边侧壁（左右 sd）方向邻居高台「朝本块边」（`WALL_DIRS[sd^1]` 角点偏移）

用途：对照生成逻辑排查「对边 / 邻居边」找位是否正确。

## 7. 不变式（落地保持）

1. **确定性幂等**：同 seed 同 chunk 主线程 / 重建一致。
2. **精修层零改动**：git 可证（`git diff --stat Refinements.ts` 为空）。
3. **A/B 等价**：`POST_PROCESS_ENABLED=false` → 三处路由逐字节透传。
4. **同源自洽**：渲染 = 物理 = 贴地查询同一 yAt；墙顶 ≡ 顶面边缘逐点同值。
5. **水密**：fine 外扩 1 格 → 无 T 结；弧区采样对齐 fine 网格 → 墙顶折线共点。
6. **悬空兜底**：有弧边高台的侧壁 / 对边 / 邻居高台边均向下延长埋地。

## 9. 落地沿革（本次会话关键决策）

1. ✅ 只读复用精修层 + ChunkManager 三处路由（回退旧 RefinementPostProcess 及精修层改动）。
2. ✅ bevel / pit / crack 高度偏移 + 顶面 fine 细分（coarse+外扩水密）。
3. ✅ 侧壁从「顶边 += ppOffset」逐步演进：
   剔除+重建（双弧转角排除）→ 端头封片 → 无落差曲边三角封片（yAt 贴合）→
   弧区采样对齐 fine 网格 → 采样起点恒 A→B（修绕序面消失）。
4. ✅ 对边延长：弧边对边（dir^1）硬边 → 邻居高台「朝本块边」→ 无落差也扩散。
5. ✅ weld 豁免：弧边左右侧向边有插值坡 → 整弧撤销（避免坡方角突出 / 背面镂空）。
6. ✅ 调试线框开关化（__PP_DEBUG_LINES），默认隐藏。
