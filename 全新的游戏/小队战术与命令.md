# 小队战术与命令 —— 队内执行层（2026-09-21 新建，权威）

> 本文负责**命令链与执行**：引擎 → 队长 → 个体；全局战术/态势/评分表见《蜂群引擎架构.md》，
> 载体/契约见《实体架构.md》。标记：✅ 已实现；⏳ 待实施。

---

## 1. 拓扑与职责

```
大队（引擎 SwarmCommander）
  │ SquadOrder（明确的小队命令：路径/目标/ROE/时序/信号）
  ▼
队长（Squad.leaderUid；名义指挥节点·方案 A）
  │ UnitDirective（队长分配的个体指令：残血 fallback / 开火策略 / 限速）
  ▼
个体（代理或 L3 实体）
  一层掷：决策合成（SquadOrder × UnitDirective × 角色 × 情境）→ 复杂决策
  二层掷：原子偏置（forward/back/strafeL/strafeR/hold × 开火）→ 本拍行为
```

- **收/发都只对队长**；跨队决策**上收大队**（队长不再私聊响应）✅。
- 队长只管本队微决策（残血撤、接敌推进/站庄），不跑第二套微 AI。

---

## 2. 两层命令 ✅

**SquadOrder（`TacticalOrder`）**：`kind`（advance/retreat/protect/flank/bound/focus/regroup）+
`path / target / roe(engage|holdFire|fireOnArrival|focusOnly) / formation / urgency /
startAfter / signal / subTargets(按 squadId 分派) / seq`；TTL 默认 30s，覆盖命令更短。

**UnitDirective**：`kind`（15 种：push/suppress/screen/fallback/boundBack/guardWard/block/
intercept/sneak/pin/strike/bound/cover/focusFire/regroup）+ `target / wardUid / until /
fire(free|hold|moving) / speedMul / seq`；TTL 6s（弱权限短 TTL）。

**分解矩阵** `DEFAULT_DIRECTIVE`（7 命令 × 4 桶：melee/ranged/shield/logistics）✅；
`roe` 真生效（holdFire 禁火、fireOnArrival 到位才自由）✅。

---

## 3. 执行内核（两载体同源）✅

- `runDirective`：`resolveWeights(指令×命令×角色×情境) → AtomExecutor.step`（承诺窗 ~1s）→
  移动原子 + 开火；代理（`SwarmSystem.think`）与实体（`EnemyBrain`）**同一份代码**。
- 移动原子 → 方向；`hold` = 停；进攻击距离时"前进原子不再覆盖本地走位"（攻击槽有效）。
- 开火节拍 `fireProfile`：>20m 掩护性零星散射（慢+散布 0.15）/ <20m 疯狂精准（快+0.012）；
  远程走独立冷却（不吃近战攻击令牌）。
- 角色覆写：远程保距（太近后退/适合停走/超程前进）；后勤降火降前进。

## 4. 逐兵种战术（四层解析）✅

| 层 | 位置 | 解析 |
|---|---|---|
| 通用 | `SquadDoctrine.GENERIC` / `SquadTactics.GENERIC_UNIT_DOCTRINE` | 所有小队/兵种默认（低血后撤等通用战术） |
| 小队属性 | `SQUAD_DOCTRINE` / `UNIT_DOCTRINE` | 盾 screen 死守 / 突击 flank / 远程 garrison / 后勤 regroup / 飞行 press |
| **逐兵种** | 名册 `EnemySpec.tactics.engine / .unit` | 11 兵种各自独立（standoff/chase/retreatHp/lowHp…） |
| 标签 | 施工 `canBuild` / 自爆 `suicide` | 施工强制 build；自爆强制 fight |

## 5. 队长与指挥权 ✅/⏳

- `LEADER_STRATEGY`（7 档）：突击直扑 / 防御稳推 / 远程站射程环 / 后勤缩后 / 飞行直扑 / 混编 / 自爆冲锋。
- 指挥权转移只在 Bridge（Phase 4）：队长降格/死亡 → 本队接任（最新情报 > 血量 > 靠队心）；
  代理被击 → 置顶升格并接管；单例 = 自身；⏳ 全队 dormant → 大队直管。
- 队长自主发令 1Hz（引擎命令优先不抢）。

---

## 6. 情报与共享 ✅/⏳

- 个体接触 → `lastSeenX/Z/At`、被击 `aggroFrom`；小队 4Hz 汇总（评级）；
- 小队间 `requestSupport / shareContact`（黑板中转）→ **大队裁决**（抽援/侦察）✅；
- ⏳ contactMap 大队级聚合、感知预算（小队级 LOS）、dormant 半盲规则细化。

---

## 7. 士气与豁免 ✅

- 通用低血（≤30%）→ `fallback` 撤出；**盾卫 / 自爆 / 兵种 `unit.lowHp='fight'` 豁免**；
- 代理层低血撤退同样按名册 `unit.lowHp` 豁免；
- 同伴阵亡狂暴（12m 内 +25% 速度 5s）由模式层触发。

---

## 8. SoA 同步纪律（新增列必须三处同步）✅

`AgentPool.push / copy / snapshot` 三处缺一列 = swap-remove 后静默丢值（踩过的坑）。
命令编码：`ORDER_CODES / DIRECTIVE_CODES / FIRE_*`（顺序即编码，**勿改既有值**）。
