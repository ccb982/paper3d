# 小队战术与命令 —— 命令链与队内执行（2026-09-21 整合稿）

> 全量总纲见《敌人管线设计.md》v4（表层 L1/L2/L3、指令链、路径锁定）；载体/契约见《敌人实体架构.md》。
> 本文负责**命令链与执行**：大队 → 队长 → 个体；标记：✅ 已实现；⏳ 待实施；📐 设计已定未实施。

---

## 1. 拓扑与职责

```
大队（引擎 SwarmCommander）
  │ SquadOrder { anchor, intent, TTL }          // 📐 新格式（意图见 §2）
  ▼
队长（Squad.leaderUid；名义指挥节点·方案 A）
  │ ①锚解引用已在上一层完成（队长只收位置型目标）
  │ ②多步拆解：区块内逐步选格（argmax Score）+ 锁定路径
  │ ③UnitDirective（个体指令：残血 fallback / 开火 / 限速 / 工位）
  ▼
个体（代理或 L3 实体）
  一层掷：决策合成（SquadOrder × UnitDirective × 角色 × 情境）→ 复杂决策
  二层掷：原子偏置（forward/back/strafeL/strafeR/hold × 开火）→ 本拍行为
```

- **收/发都只对队长**；跨队决策**上收大队**（队长不再私聊响应）✅；
- **队长永不查别的队**（锚解引用、支援裁决全在大队层，防帧序依赖）📐；
- 队长只管本队微决策（残血撤、接敌推进/站庄、步骤替换），不跑第二套微 AI。

## 2. 命令格式（📐 定稿；⏳ 现码未增补字段——2026-09-22 复审）

**SquadOrder（设计定稿，三件套缺一不可）**
```
{ anchor, intent, coarse, ttl }
  anchor = { kind:'区块', regionId }        // 语义区块（L1）
         | { kind:'小队', squadId }          // 大队解引用为"该小队当前区块 + 朝向"后再下发
  intent = 攻 | 守 | 守卫 | 集结 | 偷袭 | 撤退
  coarse = 走廊级大致路径（少量路点；初级寻路 P2 副产物）  // 小队软参考，可换
  // 紧急度不入令：读舰船距离圈（urgency）现算，软偏置
```
- ⚠️ **实现现状**：码中仍为 `TacticalOrder{kind, target, roe, mission, urgency, threat, seq}`（`SwarmUnit.ts`），
  **anchor/intent/coarse 三字段均未增补**；增补+锚解引用+事件重发随 **P4**（总纲 §1.1-B）；
  P2 落地时 `coarse` 随发令核验顺产。

- **锚解引用（只在大队层）**：下发到队长的永远是位置型目标；
- **事件驱动重发**（1~2Hz 或事件，非持续查）：锚跨区块/位移超 N 米；锚小队并队·换队长·阵亡·失联；
  意图完成；TTL 到期；
- 解引用附**锚精度/休眠标志**（L0~L3）→ 队长据此收放守圈（贴近守卫 ↔ 区域守卫）；
- 兼容 ✅：现有 `TacticalOrder{kind,target,roe,mission,urgency,ttl}` 增补 `anchor/intent/coarse` 字段
  （旧字段保留过渡；`roe` 语义不变）—— **⏳ 字段增补未实施，随 P4**。

**UnitDirective**（不变）✅：`kind`（15 种：push/suppress/screen/fallback/boundBack/guardWard/block/
intercept/sneak/pin/strike/bound/cover/focusFire/regroup）+ `target / wardUid / until /
fire(free|hold|moving) / speedMul / seq`；TTL 6s。

**分解矩阵** `DEFAULT_DIRECTIVE`（命令 × 桶）✅；`roe` 真生效（holdFire / fireOnArrival）✅。

### 2.1 意图 → 队长分解（"怎么守卫"由队长回答）

| 意图 | 队长干什么 | 主要载体 |
|---|---|---|
| 攻 | L3 `atk` 高分选推进格；盾前/远程后/突击侧翼；接敌与开火策略 | `UnitDirective` + `taskX/taskZ` |
| 守 | L3 `def` 高分选反斜/关口格；沿区块前沿摊开、面向威胁、控火 | 同上 |
| 守卫 | 环绕区块/锚布岗（护卫弧线、4m 间隔）、朝向/警戒/轮换 | `taskX/taskZ`（成员位置列 ✅） |
| 集结 | 区块内收敛到集结点、整队形 | 编队槽位 |
| 偷袭 | L1"隐蔽接近"格分段走；`fireOnArrival`/禁火；延迟发动 | `roe` + 分段路径 |
| 撤退 | 收拢残部沿低风险走廊后撤；伤兵先行、断后交替掩护 | `fallback/boundBack` + `taskX/taskZ` |
| 巡逻 | 绕锚（岗位/保护对象）游弋；位置随玩家与保护对象滑动；接触→反击但**截断在缰绳内**（撤退不追） | 命令 target（2 拍刷新）+ `taskX/taskZ` 扇区游弋 |

> **保护对象配置 = 蜂群引擎（大队）职责**（2026-09-21 定稿）：大队每拍下发 `protectAssign`
> （`squadId → { 锚, 来源 }`，源 = 护工 / 射手 / 工地 / 岗位）并写入 `ctx.protect`；
> **队长/个体只读位置**，不自行选保护对象。总攻时"工兵保护射手"同样是引擎配置（source='shooter'）。
> **保护语义**：锚 = 引擎下发的保护对象；
> 守在"锚→玩家"连线距锚 `guardDist` 处，横向按 `patrolR` 游弋（巡逻态）；
> 玩家踩保护对象 25m / 贴脸 `engageDist` / 8s 被击 → 反击，目标截断在锚的 `leash` 内，
> 玩家距锚 >45m 不追。**保护动作按小队分化**（`UnitTactics.PROTECT_ACTION`）：
> 盾=block / 突=intercept / 远程=ward / 后勤=rear，**工兵=build（造工事）**。

> 注：表内 `taskX/taskZ`（施工分块、守卫扇区）当前由**引擎施工指挥层**直写，队长不写成员任务；
> 工兵施工链（分块/工位/总攻掩护）以《工兵架构.md》为准。

### 2.2 多步拆解与队长自主性（📐 增强）

- 大队给**大目标（区块 + 意图）**；队长拆成**步骤序列**（每步一格/一个语义小区块），
  逐步 `argmax Score(兵种, 意图, 格)`；**推进不问大队**，只在整任务完成/失败上报 `progress(k/N)`；
- 步骤可在**同区块内替换**（地形/敌情），大目标不变 → 不触发大队重发；
- 上报口径：`progress` + 评级（血量/威胁）→ 供大队判断加派/改派/撤令。

### 2.3 回撤与任务取消（📐 两通路）

- **触发（队长侧）**：伤亡比超阈（沿用 withdraw 60% 口径）、目标不可达（坑/陡壁/被占）、
  长时间无进展、弹药/血量见底；
- 通路① **队长申报**：`requestRetreat(原因/伤亡/位置)` → 黑板 → **大队裁决**（批准/驳回/改派）；
- 通路② **大队自主**：按小队评级直接下发撤退令、取消在途任务；
- 效果：`SquadOrder` 立即失效（seq 作废）→ 转 `撤退` 或就地守；撤退途**不追打**。
- 防成环铁律：**保护队不听被保护队**；被保护队诉求走 `requestSupport/shareContact` → 大队。

## 3. 执行内核（两载体同源）✅

- `runDirective`：`resolveWeights(指令×命令×角色×情境) → AtomExecutor.step`（承诺窗 ~1s）→
  移动原子 + 开火；代理（`SwarmSystem.think`）与实体（`EnemyBrain`）**同一份代码**。
- 移动原子 → 方向；`hold` = 停；进攻击距离时"前进原子不再覆盖本地走位"（攻击槽有效）。
- 开火节拍 `fireProfile`：>20m 掩护性零星散射（慢+散布 0.15）/ <20m 疯狂精准（快+0.012）；
  远程走独立冷却（不吃近战攻击令牌）。
- 角色覆写：远程保距（太近后退/适合停走/超程前进）；后勤降火降前进。

## 4. 逐兵种战术（四层解析）✅

| 层 | 位置 | 解析 |
|---|---|---|
| 通用 | `SquadDoctrine.GENERIC` / `SquadTactics.GENERIC_UNIT_DOCTRINE` | 所有小队/兵种默认（低血后撤等） |
| 小队属性 | `SQUAD_DOCTRINE` / `UNIT_DOCTRINE` | 盾 screen 死守 / 突击 flank / 远程 garrison / 后勤 regroup / 飞行 press |
| **逐兵种** | 名册 `EnemySpec.tactics.engine / .unit` | 11 兵种各自独立（standoff/chase/retreatHp/lowHp…） |

## 5. 队长与指挥权 ✅/📐

- `LEADER_STRATEGY`（7 档）：突击直扑 / 防御稳推 / 远程站射程环 / 后勤缩后 / 飞行直扑 / 混编 / 自爆冲锋。
- 指挥权转移只在 Bridge（Phase 4）：队长降格/死亡 → 本队接任（最新情报 > 血量 > 靠队心）；
  代理被击 → 置顶升格并接管；单例 = 自身；⏳ 全队 dormant → 大队直管。
- 队长自主发令 1Hz（引擎命令优先不抢）；📐 多步步骤与回撤申报亦由队长发起（§2.2/§2.3）。

## 6. 情报与共享 ✅/📐

- 个体接触 → `lastSeenX/Z/At`、被击 `aggroFrom`；小队 4Hz 汇总（评级）；
- 小队间 `requestSupport / shareContact`（黑板中转）→ **大队裁决** ✅；
- 📐 `requestRetreat` 同黑板通道；contactMap 大队级聚合、感知预算（小队级 LOS）、dormant 半盲规则细化。

## 7. 士气与豁免 ✅

- 通用低血（≤30%）→ `fallback` 撤出；**盾卫 / 自爆 / 兵种 `unit.lowHp='fight'` 豁免**；
- 代理层低血撤退同样按名册 `unit.lowHp` 豁免；
- 同伴阵亡狂暴（12m 内 +25% 速度 5s）由模式层触发。
