## 1. 类树与组合件 ✅

```
EntityBase（物理/动画/渲染/生命周期骨架）
└─ CharacterBase（控制器/推挤/攀爬/贴地/受击染料/死亡表现）
   ├─ EnemyBase（敌人载体）
   ├─ Player / AllyBase / ShipEntity
EntityBase
└─ StructureEntity
   └─ CoverEntity（玩家墙）
      └─ EnemyCoverEntity（敌人施工掩体；独立类型/独立存档）
```

`EnemyBase` 的三块行为组合件（E5，纯搬运）：
`enemy/EnemyLocomotion`（危险地形绕行 / 结果解析）、
`enemy/EnemyPresentation`（显示帧/转身/扭曲）、
`enemy/EnemyBrain`（保底攻击/眩晕/**指令原子**）。
**AI 状态机仍保留**（巡逻/追击/攻击，配置驱动）——受引擎 steer 让位后只跑战斗决策。

## 2. 载体数据面（`entity/SwarmUnit.ts`）✅

| 字段 | 默认 | 说明 |
|---|---|---|
| `swarmUid` | 0 | 稳定身份（跨 LOD 往返不变；**禁止裸 index**） |
| `carrier` / `activation` / `isAgent` | entity / active / false | 载体与激活态（代理 = dormant） |
| `isLeader` | false | 指挥权（只挂 active；dormant 恒 false） |
| `battalionId / squadId / formSlot / corridorIdx` | -1 | 编队归属（**不随 LOD 改变**，快照全字段搬运） |
| `role / attackType / isAir / altitude` | grunt / melee / false / 0 | 兵种画像 |
| `moveTarget` / `moveSpeed` | null / 2.5 | 引擎下发移动目标（hold 语义） |
| `suicide / canBuild / noDemoteUntil` | false / false / 0 | 能力标签（与 role 解耦） |
| `order*/directive*` | none | 两层命令镜像（kind/target/fire/speedMul/seq）；📐 增补 `orderAnchorKind/orderIntent`（锚+意图，跨 LOD 快照搬运） |
| `lastSeenX/Z/At`、`aggroFrom` | 0 | 感知（逻辑单位状态，跨 LOD 保留） |

`SwarmCarrier` 契约：`controlSource`、`applySteer(intent|null)`、`hydrate/drain`、`retire(reason)`。

## 3. 移动来源三态 ✅

| controlSource | 来源 | 实体做什么 |
|---|---|---|
| `swarm` | 引擎 `applySteer`（编队槽位/射程位，10Hz 刷新） | 转向+速度积分+局部避障；**本地 moveBy 让位**（只保留战斗） |
| `local` | 本地 AI（状态机/游走） | 全量旧行为（降级兜底） |

- `SteerIntent` = "这一帧怎么走"（dir/speed/source，hold 语义，`STEER_TTL=0.5s`）；
  超时自动回落 `local`（**任何情况不停摆**）。
- `moveTarget` = "要去哪"（低频、随快照走）；`applySteerMovement` 用槽位求导 + 危险地形绕行。
- 危险探测收进 swarm（代价编码）与 `EnemyLocomotion`（~2m 局部避障）双层。

## 5. 生命周期与退役 ✅

- 状态：`active → retiring → disposed`；`retire(reason)` 幂等，业务只在 `onRetire` 发。
- 原因：`killed`（击杀统计/掉落）/ `demoted`（回池换载体）/ `recycled`（远距/无定义清理）/
  `despawned`（主动清场）/ `mode_cleanup`。
- 事件：`EnemyBase.onRetire('killed')` → `enemy_killed`（账本 +1）；其余离场 → `enemy_removed`。
- 掉坑：实体扣 50% 最大生命并放回坑沿；代理直接结算死亡（防卡坑底）。

## 6. 蜂群桥接 ✅

- `SwarmTierPort`（唯一改实体集合处）：`promote(snap)` 建实体 + `hydrate`；
  `demote(enemy)` `drain` + 回池 + `retire('demoted')`；**回收不在端口**（引擎 `noteRecall`）。
- `hydrate/drain` 覆盖全部字段（编队/命令/感知/AI 状态/移动目标/速度）；**降格不失忆、升格不重置**。
- 升格预算 ≤2/帧（倾盆而出 →6）、L3 上限 36（+15）；Boss 单例 `noDemote` 永保 active。

## 7. 能力门控与画像 ✅

- `activation`：代理 dormant（感知半盲：被击/警报/≤5m 直觉）/ 实体 active。
- `suicide`：攻击 = 范围爆炸 + 自身死亡；不撤（`lowHp='fight'`）。
- `canBuild`：施工资格（与 role 解耦；缺施工兵种时杂兵兼任兜底）。
- `airborne`：独立空中层（悬停/不贴地/不绕坑水/不吃掉坑判死）。
- 逐兵种战术：名册 `EnemySpec.tactics { engine, unit }`，四层解析（通用←属性←兵种←标签）。

### 7.1 工件（L2 表）与攀爬（📐 接线）

- 战壕/掩体/墙 = **L2 工件表**（独立存储、动态、对玩家向）：**不参与寻路代价与阻挡**；
- 敌人允许**爬墙**：`CharacterBase` 攀爬（可攀工事 `walkableTop`，顶住 `CLIMB_HOLD` → `beginClimb`）✅；
  **rts 修订**："**沿路才爬**"（期望方向朝掩体 dot>0.6 才触发）+ 翻越后 1.2s 冷却 + `SteerPick` 掩体脚印惩罚（优先绕行）；
- 工件仍照常**挡子弹**（掩体意义）；被摧毁走 `applyDamage` 既有口径；
- 实体不需要自己判断"路径是否被工事挡"——工事永不触发重规划（总纲 §5）。
