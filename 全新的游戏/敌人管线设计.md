# 敌人管线设计（总纲 · 2026-09-21 全量更新）

> 本文是**敌人 AI 的完整权威稿**：从基类 → 蜂群引擎 → 地形表 → 任务两级分派 → 唯一执行层 → 寻路 → 账本。
> 细节展开见《蜂群引擎架构.md》《实体架构.md》《小队战术与命令.md》；本文负责"一条线看全 + 最新定调"。

## 0. 总览：四层正交 × 一条执行链

```
                    ┌──────────── 地形表 TerrainScore（4m，唯一战场视图）────────────┐
                    │  生成：高度/坑水/坡墙/战壕/掩体 → 逐格分（态势权重 × 特征）      │
                    └───────────────────────────────┬───────────────────────────────┘
                                                    │ 各层"读表"（投影不同）
 态势函数 PostureFn ──p──→ 引擎 Decide（大任务，粘性） ──→ 队长/小队分解（动态细节） ──→ 唯一执行层
 schedule+provocation      UnitTactics 能力表             MISSION_EXEC + 黑板命令        SteerPick 候选选择
 账本 releaseCap 放行      岗位/施工块稳定分派             反击/换掩体/射界微调           + AtomExecutor 原子
```

**四层正交**：编队（谁） × LOD（多远） × 激活态（代理/实体） × 角色（干什么）——互不耦合。
**一条执行链**：所有战术最终都变成"执行层的候选打分"；**禁止向量合成**（§5）。

## 1. 地形表 `TerrainScore`（4m；唯一战场视图）

### 1.1 生成（落地一次 + 事件增量）
```
锚点 = 舰船落点 (plan.cx, plan.cz)；网格 4m；半径 R=144（73×73 ≈ 5.3k 格）
① 采样：h = surfaceHeightAt, role = tileDefAt().genRole
② 硬边界：role==='pit' 或 h < -1.2 → cls=3（pass=0，分=-∞，不可站）
③ 水    ：role==='liquid' → 可站（分 -0.6），寻路不挡，执行层给"上岸"权重
④ 分类（用已存高度，4 邻域）：
     dh > 3.0m  → cls=2 墙面（pass=0）
     dh > 1.5m  → cls=1 坡面（分 -0.6，路径代价 ×1.6）
     dh > 2.4m  → wallNear（贴墙可站格 +0.8：硬墙当掩体）
⑤ 战壕：显式挖掘标记格 或 低于邻域均值 ≥0.6m → +1.2（可走）
⑥ 分数：s = w.h·h + w.dist·(d船/R)·12 + w.threat·(d玩家/R)·12 + bonus·w.cover
        + (w.width·W + w.choke·K)·4 − 近舰负分 − 水惩罚 + 战壕/贴墙加成
     bonus = 扫描点位（掩体 1.2 / 制高 0.8）+ 已建成掩体 2.5
     W = 轴向连续可站格/4（0~1），K = 窄口（≤1 格宽）
     w = weightsFor(p, posture)：态势强度 p 的**连续插值**（§2）
```
### 1.2 更新
- **全量**：换落点 / 态势代次变化（触发戳 = `scoreStamp + postureEpoch×1e5`）。
- **局部** `invalidateArea(x,z,r,dug)`：脏窗 + 邻环（坡/墙/战壕依赖邻格）；用于
  **建成掩体**、**挖战壕/挖坑**（模式层任意挖改调 `commander.markTerrainDirty`）。
- **统一采样（✅ TerrainSampler）**：按世界 4m 格缓存 `h/role`，表 / HPA 簇 / SquadPath 共用；
  挖掘走 `invalidateArea` 失效。冷启动与换落点的主要采样成本已收口。
- **∇S̃（✅）**：3×3 平滑分 + `gradientInto`（单位梯度）/`isPlateau`；驻守/集结点做 ≤2m 微调。
- 实测口径：距离项必须按 R 归一化（×12），否则 180m 距离碾压一切；
  归一后 fortify 最高分在**外围 96~109m 高地**，assault 落到**舰船 6~38m 战壕**（meanTopD 108→22）。

### 1.3 读表 API（各层只准用这些）
`scoreAt` / `bestNear(x,z,r)` / `bestTrenchNear(…,minD,maxD)` / `bestCoverNear(x,z,r,敌x,敌z)`
/ `clsAt` / `blockedAt` / `costAt` / `wallNearAt` / `isWaterAt` / `isTrenchAt`
/ `widthAt` / `isChokeAt` / `smoothAt` / `gradientInto` / `isPlateau`。
**表桥**：`setSteerTable(commander)` → 实体侧 `SteerPick` 也能读表（两载体同内核、不破坏依赖方向）。

## 2. 态势与节律

```
p = clamp( schedule(t) + provocation, 0, 1 )
schedule(t)：单日节律锚点（0.45 第一波 / 0.80 总攻 / 1.0 入夜），节奏从落地起算、黄昏到 1
provocation：被击 ×0.01 + 击杀 ×0.03，指数衰减 τ=90s，上限 +0.35
态势映射：p<0.22 fortify / <0.30 patrol / <0.55 advance / <0.80 mass / ≥0.80 assault
锁定：进入 assault 后不回退（只有撤损 60% 的 withdraw 安全阀）；升级立即、降级要过 DWELL
```
- **兵力放行**：`ledger.releaseCap = ceil(total × releaseAt(t01))`（0.20→0.50→0.75→0.95→1.00）；
  `canSpawn/remaining = min(total, releaseCap)` —— 早间只放少量，第一波/总攻两个波峰放宽。
- **UI 播报**：`Director` 已退化为播报器（mass→预警 / assault→开战 / 回落→清除），**不再产兵**。
- 调试：`commander.debugDayT01` 可拨日程；`?swarmdbg` 显示 `态势 / p / 日程 / 挑衅`。

## 3. 任务两级分派（引擎定大方向 · 队长调细节）

### 3.1 战术能力表 `UnitTactics`（唯一来源）
```
TYPE_KIND     角色分类：melee / ranged / support / air / mixed
TYPE_MISSIONS 可接任务：盾[护卫,突进] 突击[护卫,突进,侧击] 远程[驻守,风筝]
              后勤[后置]（不能施工） 飞行[突进] 混编[护卫,突进]
UNIT_TACTICS  共用参数：护卫距离 / 接敌距离 / 可施工
MISSION_EXEC  任务→队内执行：build=禁火+1.05速 / guard=自由+0.9 / hold=0.85 / rear=到位才开火
engineMissionFor(type,{isBuilder,stage,posture}) → 大任务
guardPoint(site, threat, dist) → 护卫位原语
```

### 3.2 引擎（`SwarmCommander` + `Decide`）——**大任务粘性**
- `engineMissionFor` 分派后缓存 `missionAssign`；**只在落点 / 态势代次 / 施工阶段切换时重派**。
- **稳定岗位** `postAssign`：每队一次分派就近未被认领的 岗哨/高地/掩体位/战壕（杜绝每拍轮转 → 左右摆）。
- **施工块稳定分派** `buildAssign`：保持已派未建块；否则最近未认领块；各工程队**并行施工**（每队 3s/掩体、4s/战壕）。
- 读表投影（`Decide` 集中处）：进攻 `bestNear(8)`（坡面/近路）、
  防御 `bestCoverNear(14)`（硬墙后/战壕后）、目标校验（不可站 → 就近可站最高分）。
- 开局班底：**3 工程（`spawnBuilder`：名册 canBuild 优先）+ 2 盾 + 2 突击 + 1 远程**，锚点就近生成。
- 总攻时近战不受队列影响（BattleLine 只在"刚整队那一拍"发短命令，且只对非攻击队）。

### 3.3 队长 / 队内（动态调整，不改大任务）
- `decompose` 读 `order.mission` → `MISSION_EXEC` 调开火/限速；`DEFAULT_DIRECTIVE` 任务×角色桶。
- 动态反应：**被击（近 8s）或威胁贴脸（engageDist）→ 反击（TTL 4s 后回岗）**；
  接敌边界滞回（进 0.85R / 出 1.15R）；掩护位锁定（靠近不换）。
- 保护原则：**离工地远不主动进攻**；该打就打（被击/贴脸）；近战护卫施工队，工程队施工。
- **成员级任务列（✅）**：`AgentPool.taskX/taskZ` 新列（push/copy/snapshot 三处同步）——
  工程成员分到**不同施工块**（并行）、护卫成员沿**工地↔威胁弧线**分散站位（4m 间隔）；
  执行层 `move()` 里任务目标**优先作为期望方向**（压过指令原子），到位即停；
  任务随 LOD 快照往返；并队/切任务时清零。

## 4. 唯一执行层（`SteerPick` + `AtomExecutor`）

```
每决策拍：16 向 + hold 候选
① 硬否决（不是低概率）：表 blockedAt（墙/坑水）、>40° 陡坡
② 打分：W_PATH(1.6)·cos(期望) + W_TABLE(0.8)·表分 + W_TURN(0.7)·上次方向
        − W_AVOID·人群同向 − 水反向 +（禁区逃离/上岸权重）
③ softmax(温度 0.18) 抽样 → 选一个 → 承诺 0.5s；换向迟滞 1.12×
④ 已在硬边界内：不否决、优先逃离；分离只做惩罚 + 移动后物理外推（不合成方向）
原子：移动原子（forward/back/strafe/hold）× 开火（fireProfile：>20m 散射 / <20m 精准）。
两载体共用：代理 `SwarmSystem` 与实体 `EnemyBrain/EnemyLocomotion` **都用 `entity/SteerPick`**
（实体经"表桥"`setSteerTable` 读表）——"两载体同内核"已完成。
```

## 6. 敌人基类与载体（`entity/`）

- 类树：`EntityBase → CharacterBase → EnemyBase`；组合件 `EnemyBrain`（大脑+指令）、
  `EnemyLocomotion`（危险绕行：坑/陡坡，**水放行**）、`EnemyPresentation`；敌人墙 `EnemyCoverEntity`。
- 契约（`entity/SwarmUnit.ts`，systems 单向依赖 entity）：`SwarmUnit / SwarmCarrier / MobTactics /
  TacticalOrder{kind,target,roe,mission,urgency,ttl} / UnitDirective{kind,targetX/Z,fire,speedMul}`。
- 移动来源三态：`controlSource = swarm`（引擎 steer，0.5s TTL 回落 local）/ `local`（本地 AI）。
- LOD：L3 ≤45m（上限 36）/ L2 ≤120 / L1 ≤190；升降格走 `SwarmTierPort`（hydrate/drain 无损），
  Boss 单例 `noDemote`；代理 ⇄ 实体共享同一决策内核。
- 退役：`killed`（账本击杀）/ `demoted` / `recycled` / `despawned` / `mode_cleanup`；
  **唯一伤亡通道** `ledger.reportCasualty`（HUD 只管"今日击杀/上限"）。
- 存档：玩家墙 `walls` / 敌人墙 `enemyWalls` 分离；代理不存。

## 7. 账本与生成（`SwarmLedger`）

- 口径：`alive / kills / recalled / removed / spawned / total`；
  闸门 = `deployed < min(total, releaseCap)`；肃清 = `kills == total`（只作战绩）。
- 生成口唯一：`SwarmSystem.spawn`（引擎）；计划外实体（Boss，`swarmUid=0`）不入账。
- 兵力构成：基数 ≈30（±浮动）+ 精英/Boss 附加；第一波 ×1.5、总攻满编（`spawnBattalion`）。

> ★ **形态定为"重启一个新项目"**（不在本仓库里加 mode/覆盖层）；本仓库现在**只冻结设计、不实施**，
> 届时以本管线为移植源（复用的正是 `SwarmSystem`/`TerrainScore`/`LandingTerrain` 这套）。

- **形态**：**独立新项目**（重启，不在本仓库实现）；届时以本管线为移植源（同种子同模拟），
  正交俯视相机、不参与正式渲染链路。
- **复用**：同一套模拟（`SwarmSystem`/`TerrainScore`/`LandingTerrain`），只换**表现与输入**：
  - 地形层：`RasterMap` 4m 块 2D 平铺（高度色阶 + 水/坑）；
  - **表**：热力图可切换（score / cls / 战壕 / 水 / 贴墙），叠加态势权重与 p；
  - 单位层：代理=点、实体=方块、队长=空心圈；命令目标/路径/护卫位/施工块连线；

  支持暂停/单步（step 到下一个决策拍）；可选确定性种子回放（`seed + 输入日志`）。
- **收益**：一眼定位"左右摆/空转/施工停摆"；调参数（权重、节律）当天验证，不用开局打一局。
- **依赖**：先把 §9 的性能收口做完（倍速会把采样/寻路成本放大 8 倍）——本仓库这块已基本完成
  （TerrainSampler ✅ / ∇S̃ ✅），HPA Worker 可留给新项目按需做。
