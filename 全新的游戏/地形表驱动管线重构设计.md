# 地形表驱动管线重构设计 —— 表为领导，几何后置

> 状态：设计稿 v3（2026-09-04）。作者已确认的表创建与创建流程：
> **两遍建表（先单块可定 → 后邻居敏感）→ 检验 → 直接创建精修物理+渲染（无墙缓冲）**。
> 表只负责「把各个点的属性弄清楚」（领导角色）；精确几何/细分交给创建函数，
> 创建函数借鉴旧版（buildChunkFinal / buildChunkWallBuffers 思路）但主体重做。

---

## 0. 一句话

**每 chunk：Pass1 定块属性（高度/材质/边 kind）→ Pass2 定邻居敏感细节（侧壁顶沿/深度/
邻接标记/顶面插值标记）→ 检验 → 创建函数直接产出物理 + 渲染（同一份数据）。**

## 1. 动机（现管线问题，2026-09-04 诊断）

| # | 问题 | 后果 |
|---|------|------|
| 1 | 两套后处理并存（PostProcess 新 vs RefinementPostProcess 旧），服务对象不同源 | 贴地与渲染是两座山 |

| 6 | 死代码/半死代码多 | 认知负担 |

## 2. 创建流程（定案）

```
数据（无界精修 src，意图已应用；seed/cx/cz）
   │
── 全区 Pass 1：单块可定（全区所有 chunk 先跑完这一轮）──────────
   遍历 225 块，每块：
     id / role / h / hBase / topTileId（材质）
     4 向 kind：hard(硬边,默认) / weld(坡) / bevel(弧边)
     （kind 判定只需 src 查邻，无界可查 → 无需邻居表，单 chunk 独立完成）
   → 全区每块「高度 + 材质 + 边属性」确定（此时邻居信息齐备）
   │
── 全区 Pass 2：邻居敏感细节（依赖「邻居边高度查询」，全区 Pass1 完成后跑）──
   对每块每向，用邻居边查询读邻块共享边(dir^1)的高度：
     · topEdgeY  = 本块视角在该边界线的顶面视觉高（角高场/surfaceHeightCore）
     · depth     = max(本侧顶 − 低侧基准, WALL_MIN_DEPTH)
                   低侧基准 = min(邻居边顶高, 两侧 hBase)
     · hasWall   = 存在高度差 / 需壁
     · arcNeighbor / weld 邻接标记（弧顶墙、坡侧壁、顶面插值用）
     · sideTileId（材质，默认 = 顶材质）
   → 表详细属性完成（表 = 领导：属性清楚，精确几何不存）
   │
── 检验（Pass 2 内）───────────────────────────────────────────
   ① 不漏边：每个应有侧壁的边都有标注（与高度差/邻接逻辑一致）
   ② 材质对：每面材质与所属地块 tile 一致（含可改槽语义）
   ③ 弧边左右邻边非坡：bevel 的左右邻边(dir^2,(dir^2)^1)任一为 weld → 撤销弧边
      （防弧带与邻边坡面交角漏洞）
   失败 → console 明细（坐标/块/边），不放行创建
   │
── 直接创建（无墙缓冲中间物）──────────────────────────────────
   精修层创建函数（借鉴旧 buildChunkFinal/buildChunkWallBuffers，主体重做）：
     · 顶面基础网格：角高 + weld 顶部插值 + bevel 圆角（弧边=精修层形态）
     · 侧壁几何：每边按表（顶沿/深度/邻接标记）生成，弧线精确采样此处做
     · 物理 trimesh = 渲染同一份数据，一次产出
   │
── 后处理精细 pass（顶面之上）──────────────────────────────────
   pit(坑洞) / crack(裂痕)：只在顶面网格上做局部细分 + 下陷偏移
   （锚点 = seed + 块 hash；判据用表的 role/邻边 kind；不入表）
   物理不受影响（坑裂为表面细节，或随渲染同源可选并入）
```

## 3. 表数据模型（薄标注表）

```ts
interface FaceTable {
  cx: number; cz: number;
  cells: FaceCell[];            // 225
}

interface FaceCell {
  id: number;
  role: TileGenRole | "";
  h: number;                    // 逻辑高
  hBase: number;
  topTileId: number;            // 顶部材质（默认本块 tile）
  top: { materialId: number };  // 运行时单独覆写槽
  // ★ 顶面 weld 插值标记：哪些方向有坡进入顶部（Pass 2 填）
  topWeldDirs: number[];        // 朝这些方向的 weld 影响顶面形状
  sides: [FaceSide, FaceSide, FaceSide, FaceSide]; // 0=+x 1=-x 2=+z 3=-z
}

interface FaceSide {
  kind: "hard" | "weld" | "bevel";   // 边属性（默认 hard）
  ruling: "weld" | "cliff";          // 裁决溯源
  // ★ Pass 2（邻居敏感）：
  topEdgeY: number;                  // 该边顶面高度主值（边界线处）
  depth: number;                     // 侧壁深度 = max(与邻差, WALL_MIN_DEPTH)；无壁 = 0
  hasWall: boolean;                  // 该边是否有侧壁
  arcNeighbor: boolean;              // 是否 bevel 弧边的邻边（需弧顶墙）
  sideTileId: number;                // 侧壁材质（默认 = topTileId，可单独改）
}
```

**kind 语义（2026-09-04 定）**：
- `hard / weld / bevel` 三态平起平坐；**hard 是默认值**——不声明即 hard；
  也可**主动声明**（显式覆写通道：如 tile 的 edgePolicy='hard' 强制直角，
  可压过 weld/bevel 判定；预留手动覆写入口）。
- `weld`（坡面）属性特殊：不仅该边，还影响顶部插值（topWeldDirs）。
- `bevel`（弧边）属性特殊：圆角几何 + 左右邻边非坡否决 + 邻边弧顶墙标记。

**kind 判定（Pass 1）——默认 hard，特殊形态才置位**：
- 显式 hard（edgePolicy='hard'/手动覆写）→ `hard`；
- 否则 ruling=weld（edgePolicy='smooth'/意图）→ `weld`；
- 否则若（本块 platform 且邻 ground、邻 h ≤ 本 h − BEVEL_EPS、ruling=cliff、
  **弧边左右邻边（dir^2 与 (dir^2)^1）均非 weld**）→ `bevel`；
- 其余 → `hard`（默认）。

要点：
- 表 = 领导：只把**点/边的属性**弄清楚（高度、材质、类型、邻接标记）；
  精确几何（弧线采样点、细分顶点、每米分段细节）一律交给创建函数。
- 材质默认同 tile、侧壁可单独改（独立字段）。
- weld 语义：不仅边，还影响顶部插值（topWeldDirs）。
- 弧边左右邻边非坡（dir^2/(dir^2)^1 任一 weld → 撤销 bevel）。
- **分层归位（2026-09-04 定）**：
  · bevel(弧边) = **精修层形态**——kind 判定权威，圆角几何由精修层/创建统一处理；
  · **坑洞(pit) / 裂痕(crack) = 后处理精细层专属**——顶面细碎起伏（细分网格上的
    偏移），**不入表**；由后处理 pass 在创建后的顶面上施加（锚点 = seed + 块 hash，
    确定性）。

## 4. 邻居边查询函数（Pass2 与复查用）

**语义规格（方向/坐标必须写对）**：

```ts
// 输入一律「世界块坐标 + dir」；内部自行换算 chunk 局部。
interface NeighborQueries {
  neighbor(wx, wz, dir): FaceCell | null
    // 邻块 = (wx+dx, wz+dz)，永远移动一格；
    // 同表直取下标；跨界 → 邻 chunk 表（局部换算）

  neighborEdgeTop(wx, wz, dir): number | null
    // ★ Pass2 用：邻块在【共享边】（邻块的 dir^1 边）上的顶面视觉高
    //   来源：邻块角高场（其 Pass1 已就绪）或 surfaceHeightCore(src)
    //   用于本侧壁 depth = max(本侧顶 − min(邻居边顶, 两侧hBase), WALL_MIN_DEPTH)

  oppositeSide(wx, wz, dir): FaceSide | null
    // 邻块朝本块的边 = neighbor(...).sides[dir ^ 1]
    // dir^1 只翻一次：0↔1、2↔3（共享边两侧方向）

  leftRight(wx, wz, dir): [FaceSide, FaceSide] | null
    // 弧边左右邻边：dir^2 与 (dir^2)^1（XOR2 = 90° 旋转 = 垂直两向）
}
```

**正确性要点**：
1. 方向翻转与坐标移动**同步**：取邻块必须 `wx+dx`；翻转 dir 不回原地
2. `dir^1` = 共享边对侧（同轴反向）；`dir^2 / (dir^2)^1` = 左右垂直邻边——用途不同勿混
3. 跨界换算：越界块按 `邻ccx*15` 归位到邻 chunk 局部下标，勿用本 chunk 下标
4. **时机**：Pass1 不用邻居查询；Pass2 在全区 Pass1 完成后用（邻居高度齐备）；
   复查/接缝重建/校验路径同样使用
5. 初建（邻居 chunk 未建表）时：Pass1 阶段无查询需求；Pass2 前全区 Pass1 已就绪，
   跨界邻居高度由邻 chunk 角高场或 src 现算（同公式同值）

## 5. 检验规则（Pass 2 内）

1. **不漏边**：遍历每块每向，若「本块与邻居存在高度差/需壁」则该向 hasWall 必须为 true；
   若表判无壁但邻居对边有壁 → 报错（共享边两侧一致）。
2. **材质对**：每面 sideTileId/topTileId 与所属 tile 一致；可改槽默认值一致。
3. **弧边左右邻边非坡**：bevel 成立条件含否决——弧边的**左右邻边**（与弧边垂直、
   即 dir^2 与 (dir^2)^1 两个方向，例如 -x 弧边的 ±z 邻边）任一为 weld → 撤销弧边
   （弧带与邻边坡面交角会出漏洞）。表 kind 判定（Pass 1）执行；Pass 2 检验复核，
   违反 → 报错。★ 注意：此规则针对弧边**左右邻边**，与弧边同轴对边无关。
4. 邻居对边 kind 一致性：共享边两侧 kind 必须匹配（weld↔weld；hard↔hard/bevel？——
   bevel 属 hard 族，两侧一致规则 P2 定稿）。

## 6. 创建函数（精修层创建 + 后处理精细 pass）

### 6.1 精修层创建（读表，产出物理+渲染基础）
- 顶面基础：读表高度/材质 + topWeldDirs 做 weld 顶部插值；
  bevel 圆角在此统一处理（弧边是精修层形态，几何由精修层权威产出）；
  顶点/法线/uv 一次产出（参考 buildChunkFinal 布局 + 旧 coarse/fine 思路，数据全来自表）。
- 侧壁：每边按表（kind/oppKind/leftKind/rightKind/topEdgeY/calcDepth/depth/材质）生成：
  平顶墙直接生成；弧顶墙沿边采样（精确 yAt 此时算）。
  ★ 两端形态由左右邻壁决定：端点接 bevel → 弧带下弯+曲边端封；接 weld → 坡向衔接；
    接 hard → 直角收口。kind 只定类型分支——不同坡坡度/不同弧高差 → 端头曲线不同，
    创建时按端头定点取邻居块 h/topEdgeY/角高场现算（按需局部，非全量墙扫描）。
- 物理：与渲染同一份顶点/索引（合并一次），无二次合并。
- 签名：`buildChunkBase(table, cornerH, ctx{heightAt,tileDefAt,palette,seed})`。
- 不再有 buildChunkWallBuffers 墙缓冲中间物 / wallRef / UV 反推。

### 6.2 后处理精细 pass（pit/crack）
- 在顶面网格之上：坑洞/裂痕局部细分 + 下陷（锚点 = seed + 块 hash，
  判据 = 表 role / 邻边 kind；公式与常量由旧 PostProcess 平移、合并一处）。
- 不入表、不影响表字段；是否并入物理按渲染=物理不变式决定。
