# 2026-09-16

## 背包「遗物」区块改为独立滚动区（隐藏滚动条）

**问题**：`CharacterStatsPanel` 把每条遗物（图标 + 名称×件数 + 多行 description）
直接 append 进 `root`（`flex:0 0 232px` 纵向 flex 列），遗物越多左栏越高 →
撑大 `ui-panel-inner` → 撑大整个背包页面。

**改动**：
- `src/ui/shared/CharacterStatsPanel.ts`
  - 新增常量 `RELIC_SCROLL_MAX_HEIGHT_PX = 188`
  - 新增私有方法 `private scrollBox(maxHeight: number): HTMLDivElement`
    —— `max-height` + `overflow-y:auto` + `scrollbar-width:none` +
    `-ms-overflow-style:none` + 内联 `<style>` 注入 `.ui-relic-scroll::-webkit-scrollbar{display:none}` +
    `overscroll-behavior:contain` + 滚轮 `stopPropagation`（被动监听）
  - `render()` 的遗物区块：`total === 0` 时保持原样（仅「尚未拥有遗物」提示）；
    否则把「遗物」+「BOSS」两个分区**一起**塞进同一个 `scrollBox`
  - 顺手修掉既有笔误 `this.    hpFill` → `this.hpFill`
- `src/ui/shared/ui-styles.css`
  - `.ui-panel-inner` 后追加 `.ui-relic-scroll` 及其 `::-webkit-scrollbar` 兜底规则

**关键设计点**：
- 用 `max-height` 而非 `height` → 遗物少时容器自适应，不浪费空间
- 滚轮 `stopPropagation` 是必须的：外层 `gridRoot` 和弹窗 wrapper 都可纵向滚动
- 「遗物」与「BOSS」合用一个滚动区（否则两个滚动条视觉很碎）

**两处宿主自动受益**（都调 `characterStatsPanel.render`，无需改）：
- `WorldUIManager.renderInventoryPanel()`（局内背包）
- `ShipUIManager.toggleInventoryPage()` / `refreshInventoryStats()`（基地背包）

`tsc --noEmit` 通过，0 错误。

**注意**：另一处遗物入口 `ShipPanels.ts` 的 `OperatorPanel`（标题「遗物」）
未改动——那是独立的遗物管理侧边面板，不走 `CharacterStatsPanel`。
