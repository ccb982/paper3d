## BGM 系统接线（用户点题：把 music 的生命流接成基地/舰船 BGM，且只在船内响）

### 做了什么
1. 新增 `src/config/bgm.ts` —— 曲目表唯一真源（base / ship 两条路径，都指 /music/生命流.mp3）。
   中文文件名沿用工程约定：`encodeURI` 后再交给 Audio。
2. 新增 `src/services/audio/Bgm.ts` —— 模式级播放器 `playBgm(key)` / `stopBgm()`，
   一律走 `getPlatformAdapter().audio`（无适配器时静默，验收页不炸）。
3. `src/platform/WebAdapter.ts` —— playBgm 加**路径级去重**：
   同 src 在播 → 直接 return；同 src 已暂停 → 直接 `play()` 从暂停处续播（不重设 src）。
   另加自动播放被拦的补播：挂一次性 pointerdown/keydown。
4. `src/main.ts` —— `enterBaseMode` → `playBgm('base')`；`enterWorldMode` 不下发曲目。
5. `src/modes/WorldMode.ts` —— 新增 `syncShipBgm()`，在**每个 `this.phase =` 赋值后**调用：
   interior → playBgm('ship')；sail / explore → stopBgm()。
   共 5 个赋值点：enter(695 sail)、finishDock(3269 explore)、enterShipInterior(3519 interior)、
   exitShipInterior(3654 explore)、tryBoardShip(3683 sail)。

### 踩的坑（重要）
- 第一版把 `sail`（驾驶舰船航行）也算「在舰船上」→ 用户实测：点「开始行动/开始突袭」后 BGM 还在播。

  只有 **基地房间** + **舰内舱（interior）** 有 BGM，露天（航行/下机）静音。

## BGM 淡入淡出（用户追加要求）

- `src/platform/WebAdapter.ts` 新增 `fadeIn / fadeOut / fadeTo`：
  700ms 线性音量渐变，`setInterval(16ms)` 驱动（**不用 rAF** —— 切后台 rAF 停摆会卡在半途）。
  已按元素存 interval（`bgmFades: Map<HTMLAudioElement, number>`），打断淡化时先 clear。
- 三个入口都走淡入：开场播放 / 切曲（旧轨淡出 + 新轨淡入 = 交叉）/ 自动播放被拦后的手势补播。
- 停止 = 淡出到 0 再 pause（不是直接 pause）。
- 边界：淡出途中又要求播放同一首 → 识别 `volume < BGM_VOLUME` 直接拉回淡入（否则会被淡出推到 0 并暂停）。
- 音量常量：`BGM_FADE_MS = 700` / `BGM_VOLUME = 1`（都在 WebAdapter 顶部）。
