## BGM 淡入淡出（用户追加要求）

- `src/platform/WebAdapter.ts` 新增 `fadeIn / fadeOut / fadeTo`：
  700ms 线性音量渐变，`setInterval(16ms)` 驱动（**不用 rAF** —— 切后台 rAF 停摆会卡在半途）。
  已按元素存 interval（`bgmFades: Map<HTMLAudioElement, number>`），打断淡化时先 clear。
- 三个入口都走淡入：开场播放 / 切曲（旧轨淡出 + 新轨淡入 = 交叉）/ 自动播放被拦后的手势补播。
- 停止 = 淡出到 0 再 pause（不是直接 pause）。
- 边界：淡出途中又要求播放同一首 → 识别 `volume < BGM_VOLUME` 直接拉回淡入（否则会被淡出推到 0 并暂停）。
- 音量常量：`BGM_FADE_MS = 700` / `BGM_VOLUME = 1`（都在 WebAdapter 顶部）。

## BGM 体积压缩（用户嫌 3MB 太大）

- 原文件：`public/music/生命流.mp3` = 128 kbps / 44.1 kHz / stereo / 3:16 / 2.99 MB。
- 压到 **64 kbps / 44.1 kHz / stereo（joint stereo）/ 1.50 MB，-50%**，时长逐帧一致（196.05s），
  ID3 元数据保留（title/album/artist）。
- 原件备份：`全新的游戏/_audio_backup/生命流.原版128k.mp3`（**不在 public 下，不参与打包**）。
- 工具链（系统无 ffmpeg！）：`C:\Users\22641\.workbuddy\binaries\python\envs\default`
  + `pip install imageio-ffmpeg` → ffmpeg.exe 位于
  `…\envs\default\Lib\site-packages\imageio_ffmpeg\binaries\ffmpeg-win-x86_64-v7.1.exe`（自带 libmp3lame / libopus）。
  转码命令：`ffmpeg -y -i in.mp3 -c:a libmp3lame -b:a 64k -ar 44100 -joint_stereo 1 -map_metadata 0 -id3v2_version 3 out.mp3`
- 重新打包后 dist = 9.39 MB（原 10.9 MB）。**体积大头仍是主 JS 2.48MB + rapier wasm 1.44MB**（与 BGM 无关）。
