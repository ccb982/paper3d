## 2D 单相自由表面流模拟库 - 完整实现

基于新架构的完整 `FluidSimulator.ts` 实现，采用直接的 WebGLRenderTarget 替代 GPUComputationRenderer，架构更简洁。

---

### 新增功能：流体寿命系统 ⭐

流体寿命系统用于实现流体的定时消散效果，例如模拟水滴下落、烟雾消散等场景。

#### 核心设计要点

| 特性 | 实现方式 |
|------|----------|
| **水滴追踪** | 年龄平流使用反向速度追踪，让年龄跟随水流移动 |
| **真实秒计时** | 年龄更新使用真实时间增量（realDelta） |
| **新水重置** | 注入区域检测，新注入的水年龄重置为0 |
| **边界安全** | `clamp(prevPos, 0, 1)` 确保纹理采样安全 |
| **开关控制** | `maxLifetime = 0` 时完全禁用寿命系统 |
| **爆炸交互** | ⚠️ TODO: 爆炸生成的水花需额外Pass重置年龄为0 |

#### 三阶段流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        流体寿命系统三阶段流程                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  阶段1: 年龄平流                                                           │
│  ┌───────────────────────────────────────────────────────────────────────┐  │
│  │  输入: curAgeTex, curVelTex, curPhiTex                               │  │
│  │  输出: ageTexA/B (双缓冲)                                            │  │
│  │                                                                     │  │
│  │  逻辑: 反向追踪速度场，让年龄跟随水滴移动                             │  │
│  │        prevPos = uv - vel * dt / resolution                         │  │
│  │        age_new = texture2D(age, clamp(prevPos, 0, 1)).r             │  │
│  └───────────────────────────────────────────────────────────────────────┘  │
│                              │                                             │
│                              ▼                                             │
│  阶段2: 年龄更新                                                           │
│  ┌───────────────────────────────────────────────────────────────────────┐  │
│  │  输入: curAgeTex, curPhiTex                                          │  │
│  │  输出: ageTexA/B (双缓冲)                                            │  │
│  │                                                                     │  │
│  │  逻辑: 水区域年龄 += realDelta（真实时间）                            │  │
│  │        空气区域年龄 = 0                                              │  │
│  │        注入区域年龄重置为0                                           │  │
│  └───────────────────────────────────────────────────────────────────────┘  │
│                              │                                             │
│                              ▼                                             │
│  阶段3: 流体消散                                                           │
│  ┌───────────────────────────────────────────────────────────────────────┐  │
│  │  输入: curPhiTex, curAgeTex                                          │  │
│  │  输出: phiTexA/B (双缓冲)                                            │  │
│  │                                                                     │  │
│  │  逻辑: if (age >= maxLifetime) phi = 0.1  // 水变空气               │  │
│  └───────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 关键参数说明

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| `maxLifetime` | `number` | 流体最大寿命（秒），0表示禁用 | **4.0** |

#### 实现细节

1. **年龄纹理存储**：使用 RGBA 纹理的 R 通道存储年龄值（范围：0 ~ maxLifetime）

2. **双缓冲设计**：年龄纹理采用双缓冲（ageTexA/ageTexB），避免读写冲突

3. **时间增量选择**：
   - 年龄平流使用物理步长（`params.timeStep`）保持与流体模拟一致
   - 年龄更新使用真实时间增量（`realDelta`）确保按秒计时

4. **注入区域处理**：新注入的水通过距离检测重置年龄为0，实现"新鲜"水滴效果

### 扩展功能：爆炸系统 ⚡

爆炸系统采用**散度源模型**，通过向流场注入体积源而非直接修改速度，依赖压力求解器自然产生向外推进的压力梯度。

#### 核心参数

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| `cx` | `number` | 爆炸中心X坐标（UV空间，0~1） | - |
| `cy` | `number` | 爆炸中心Y坐标（UV空间，0~1） | - |
| `radius` | `number` | 爆炸半径（UV空间） | - |
| `strength` | `number` | 散度源强度（推荐25000~5000递减） | - |
| `createWater` | `boolean` | 是否生成水花（true=生成新水，false=仅注入散度） | `true` |
| `duration` | `number` | 爆炸持续时间（秒） | `0.1` |

#### 实现原理（散度源模型）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    爆炸系统流程（散度源 + 压力驱动）                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. 爆炸注册                                                                 │
│     explode() 将爆炸加入 activeExplosions 列表                              │
│     记录: cx, cy, radius, strength, createWater, startFrame, durationFrames │
│                                                                             │
│  2. 每帧构建爆炸散度 (buildExplosionDivergence)                            │
│     // 先清空爆炸散度纹理，避免上帧残留累积                                   │
│     renderFullscreen(clearShader, explosionDivTex, true)                   │
│     for each explosion in activeExplosions:                                │
│         frameElapsed = currentFrame - startFrame                          │
│         u = clamp(frameElapsed / durationFrames, 0.0, 1.0)                │
│         envelope = 4.0 * u * (1.0 - u)  // 二次抛物线包络，先升后降        │
│         S = -strength * envelope * mask(x)  // ⚠️ 负号关键！产生向外膨胀   │
│         累加渲染到 explosionDivTex（不清屏实现叠加）                        │
│                                                                             │
│  3. 散度融合（在 divergenceShader 中）                                      │
│     div = ∂vx/∂x + ∂vy/∂y + texture2D(explosionDivTex, uv).r            │
│                                                                             │
│  4. 水花生成（createWater=true时）                                          │
│     仅在空气区域（phi >= 0）生成新水，不修改已有水体                        │
│     新生水花的速度由后续压力求解驱动，而非直接注入                           │
│     同时重置新生成水花区域的年龄为0（通过 ageResetMat）                     │
│                                                                             │
│  ✅ 核心优势: 完全符合不可压缩投影框架，能量不会因压力修正而被抵消           │
│  → 散度源 S 通过压力 Poisson 方程转化为压力梯度 ∇p                        │
│  → 速度修正步骤: vel -= ∇p/ρ 自然驱动流体向外膨胀                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 参数说明

| 参数 | 详细说明 |
|------|----------|
| `strength` | 控制散度源强度，**不再对应直接的速度增量**，推荐值序列 [25000, 20000, 15000, 10000, 5000] |
| `duration` | 爆炸持续时间（秒），默认 0.1。使用二次抛物线包络，强度先升后降 |
| `createWater` | `true` 时在界面附近生成水花，但**不直接注入速度**，速度由压力驱动 |

#### 特性说明

| 特性 | 实现方式 |
|------|----------|
| **散度源注入** | 不直接修改速度，通过压力求解器自然产生向外推力 |
| **二次抛物线包络** | 爆炸强度遵循 4*u*(1-u)，先升后降的自然脉冲 |
| **活跃爆炸管理** | 使用 activeExplosions 列表跟踪所有进行中的爆炸 |
| **双重模式** | createWater 参数控制是否生成新水 |
| **独立散度纹理** | explosionDivTex 专用于累加爆炸散度贡献 |

#### 关键设计要点

1. **散度源公式**: `S = -strength * envelope(t) * mask(x)`
   - **负号关键**：注入负散度才能产生向外膨胀效果（正散度会导致收缩）
   - `envelope(t)`: 二次抛物线 `4*u*(1-u)`，u=frameElapsed/durationFrames，峰值在中间(0.5)，先升后降
   - `mask(x)`: 径向衰减掩码，`1 - smoothstep(0, radius, dist)`
   - **简化公式**: 移除了原公式中的 `/ (ρ * Δt)` 因子，避免数值爆炸问题
   - **强度推荐值**: 5000~50000序列递减，根据视觉效果调整

2. **帧计数计时机制**:
   - 使用模拟帧计数代替 `performance.now()` 墙钟时间
   - `startFrame`: 爆炸开始时的帧号
   - `durationFrames = ceil(duration / timeStep)`: 将秒转换为帧数
   - **优势**: 确保每次模拟结果一致，不受帧率波动影响

3. **压力驱动机制**:
   - 散度源累加到速度散度：`div(u*) = div(u^n) + S`
   - 压力 Poisson 方程右端项：`b = (ρ/Δt) * div(u*)`
   - 求解出的压力梯度驱动流体向外膨胀

4. **水花生成逻辑**:
   - **仅在空气区域生成**：`if (mask > 0 && phi >= 0.0)`
   - **不修改已有水体**：避免将正常水体"削平"成浅水层
   - **速度由压力驱动**：新生水花不直接注入速度，由后续压力求解驱动

5. **速度场同步修复** ⭐:
   - 在 `buildExplosionDivergence` 之后立即同步更新 `velForDiv`
   - 确保新生成水花的速度参与散度计算和压力投影
   - 修复前：`velForDiv` 保持为爆炸前的旧速度场
   - 修复后：`velForDiv = this.curVelTex.texture`（包含水花速度）

6. **重力应用修复** ⭐:
   - 在步骤3（外力计算）之后更新 `curVelTex = forcedVelTex`
   - 确保 `buildExplosionDivergence` 使用包含重力的速度场
   - 修复前：爆炸使用的速度场不含重力，导致流体不下落

7. **材质预缓存优化**:
   - `explosionDivMat`、`waterGenMat`、`waterVelInitMat`、`ageResetMat` 预创建并复用
   - 避免每帧创建/销毁 ShaderMaterial，减少 GC 和 WebGL 资源压力

8. **寿命系统交互**:
   - 新生成水花区域的年龄通过 `ageResetMat` 重置为0
   - 使用双缓冲方式更新 phi 和 age 纹理，避免原地读写冲突

9. **Jacobi边界处理**:
   - 空气区域压力直接设为0（Dirichlet条件），无需额外的Neumann边界处理

10. **解耦边界处理** ⭐（增强爆炸飞溅效果）:
    - 在压力求解的上下游（散度计算与速度修正）中，对边界环区域进行局部阻尼
    - **散度阻尼**：在边界环内降低无散约束强度，允许流体膨胀飞溅
    - **速度修正阻尼**：减弱压力梯度对速度的"硬推回"，让流体保留更多动能
    - **软过渡实现**：使用 `smoothstep` 创建渐变阻尼因子，避免硬边界带来的视觉突兀
    - 可调参数：`boundaryRingWidth`（边界环宽度）、`boundaryDivDamping`（散度阻尼）、`boundaryVelDamping`（速度阻尼）
    - 原理：模拟"流体-固体相互作用分离处理"，成本极低，无需修改核心求解器
    - 阻尼因子计算：`dampingFactor = mix(boundaryDamping, 1.0, smoothstep(0, width, minDist))`

11. **速度上限限制** ⚠️（防止 CFL 失效）:
    - 在 `velocityCorrectMat` 和 `waterVelInitMat` 中加入速度限制：
    ```glsl
    float maxVel = 200.0;
    float speed = length(vel);
    if (speed > maxVel) vel = vel * (maxVel / speed);
    ```
    - 防止爆炸产生的超高速度导致 CFL 条件失效，避免平流一步把 phi 冲成负数

12. **phi 场 clamp** ⚠️（防止负数蔓延）:
    - 在 `levelSetAdvectionMat` 输出前加入：`phi = clamp(phi, -1.0, 1.0)`
    - 防止平流后 phi 大面积变负，限制在合理的符号距离范围内

13. **水体销毁修复**:
    - `dissipationMat` 中销毁水体时使用 `phi = 1.0` 而不是 `0.05`
    - 确保被销毁的水体被正确标记为空气，便于后续处理清除

14. **爆炸随机扰动系统** ⭐（实现碎片感和不规则冲击波）:
    - 通过噪声纹理调制散度源和切向速度，模拟真实爆炸的不均匀性
    - **三个层次的扰动**:
      1. **爆源各向异性**：噪声调制散度强度，产生指状突出
      2. **切向速度分量**：噪声驱动的切线方向扰动，产生涡旋
      3. **多团块爆炸**：一次爆炸分裂成多个子团块，产生碎片效果
    - **噪声纹理设计**: 64x64 RGBA 纹理，R通道用于强度扰动，G通道用于方向扰动，双通道解耦设计
    - **关键参数**: `usePerturbation`（启用扰动）、`perturbationStrength`（扰动强度，推荐0.3~0.5）、`fragmentCount`（子团块数，推荐4）、`randomSeed`（随机种子，用于确定性重放）

    **噪声纹理生成（双通道解耦）**：
    ```typescript
    private generateNoiseTexture(size: number = 64): THREE.DataTexture {
        const data = new Float32Array(size * size * 4);
        // 基础哈希函数（用于强度扰动）
        const hash1 = (x: number, y: number) => {
            let h = x * 374761393 + y * 668265263;
            h = (h ^ (h >> 13)) * 1274126177;
            return (h ^ (h >> 16)) / 2147483648;
        };
        // 独立哈希函数（用于方向扰动，与hash1解耦）
        const hash2 = (x: number, y: number) => {
            let h = x * 131071 + y * 524287;
            h = (h ^ (h >> 15)) * 786433;
            return (h ^ (h >> 13)) / 2147483648;
        };
        for (let y = 0; y < size; y++) {
            for (let x = 0; x < size; x++) {
                const idx = (y * size + x) * 4;
                // R通道：多八度叠加的基础扰动
                let val = 0.0;
                for (let oct = 1; oct <= 4; oct++) {
                    const freq = 1 << oct;
                    val += 0.5 / oct * hash1(x * freq % size, y * freq % size);
                }
                data[idx] = val;     // R: 基础扰动（hash1）
                data[idx + 1] = hash2(x, y);  // G: 方向扰动（hash2，独立于R）
                data[idx + 2] = 0;
                data[idx + 3] = 1;
            }
        }
        const tex = new THREE.DataTexture(data, size, size, THREE.RGBAFormat, THREE.FloatType);
        tex.wrapS = THREE.RepeatWrapping;
        tex.wrapT = THREE.RepeatWrapping;
        tex.minFilter = THREE.LinearFilter;
        tex.magFilter = THREE.LinearFilter;
        tex.needsUpdate = true;
        return tex;
    }
    ```

    **散度源扰动（explosionDivMat，含随机相位偏移）**：
    ```glsl
    uniform sampler2D noiseTex;
    uniform float perturbationStrength;  // 推荐 0.3~0.5
    uniform vec2 noiseOffset;           // 每次爆炸的随机相位偏移
    
    // 在中心距离计算之后
    float perturb = texture2D(noiseTex, uv * 8.0 + noiseOffset).r;
    perturb = (perturb - 0.5) * 2.0;  // 映射到 -1..1
    float noiseMask = 1.0 + perturb * perturbationStrength;
    float mask = (1.0 - smoothstep(0.0, radius, dist)) * noiseMask;
    mask = clamp(mask, 0.0, 1.0);  // 防止负值或过冲
    ```

    **切向速度扰动（waterVelInitMat，使用未扰动速度作为基础）**：
    ```glsl
    uniform sampler2D noiseTex;
    
    // 计算径向方向和未扰动的基础速度
    vec2 dir = normalize(vec2(uv.x - center.x, uv.y - center.y));
    float baseSpeed = /* 未扰动的径向速度初始值 */;
    
    // 在未扰动速度基础上叠加切向扰动
    vec2 tangent = vec2(dir.y, -dir.x);  // 垂直于径向
    float tangentStrength = (texture2D(noiseTex, uv * 6.0).g - 0.5) * 2.0;
    vel += tangent * tangentStrength * baseSpeed * 0.3;  // 使用未扰动速度作为基础
    ```

    **确定性伪随机函数（用于可重放的随机行为）**：
    ```typescript
    // 基于种子的确定性伪随机函数
    private seededRandom(seed: number): () => number {
        let s = seed;
        return () => {
            s = Math.sin(s) * 10000;
            return s - Math.floor(s);
        };
    }
    
    // 使用示例
    const rand = this.seededRandom(seed);
    const angle = rand() * Math.PI * 2;
    ```

    **多团块爆炸方法（支持确定性种子）**：
    ```typescript
    public explodeFragmented(cx: number, cy: number, radius: number, strength: number, 
                            createWater: boolean, duration: number, 
                            fragmentCount: number = 4, seed?: number) {
        // 使用确定性随机或默认随机
        const rand = seed !== undefined 
            ? this.seededRandom(seed) 
            : Math.random.bind(Math);
        
        for (let i = 0; i < fragmentCount; i++) {
            const angle = rand() * Math.PI * 2;
            const offsetR = radius * 0.3 * rand();
            const fx = cx + Math.cos(angle) * offsetR;
            const fy = cy + Math.sin(angle) * offsetR;
            const fr = radius * (0.6 + rand() * 0.4);
            const fs = strength / fragmentCount * (0.8 + rand() * 0.4);
            // 为每个子爆炸生成独立的噪声相位偏移
            const noiseOffsetX = rand() * 10.0;
            const noiseOffsetY = rand() * 10.0;
            this.explode(fx, fy, fr, fs, createWater, duration, noiseOffsetX, noiseOffsetY);
        }
    }
    ```

    **改进说明**：
    - **噪声相位对齐**：每次爆炸传入独立的 `noiseOffset`，避免不同爆炸使用相同扰动模式
    - **切向扰动解耦**：使用未扰动的 `baseSpeed` 作为切向强度基础，避免正反馈耦合
    - **确定性重放**：支持传入 `seed` 参数，使用 `seededRandom` 实现可重复的随机行为
    - **双通道解耦**：R通道使用 `hash1`，G通道使用独立的 `hash2`，降低通道间相关性

15. **各向异性爆炸系统** ⭐（支持方向性爆炸效果）:
    - 通过方向调制函数实现不同方向的膨胀/收缩效果
    - **三种模式**:
      1. **模式0（各向同性）**: 正常均匀爆炸
      2. **模式1（四极子）**: `cos(2*angle)`，两个方向膨胀，两个方向收缩
      3. **模式2（偶极子）**: `cos(angle)`，一侧膨胀、对侧收缩
    - **相位偏移**: 支持旋转各向异性模式的方向
    - **收缩阻尼**: 收缩效果默认减弱70%（阻尼系数0.3），避免收缩过强

    ```glsl
    uniform int anisotropyMode;
    uniform float anisotropyPhase;
    uniform float anisotropyStrength;
    
    // 应用各向异性调制
    float dirMod = 1.0;
    if (anisotropyStrength > 0.001) {
        vec2 rel = uv - center;
        float angle = atan(rel.y, rel.x) + anisotropyPhase;
        
        if (anisotropyMode == 1) {
            // 四极子：cos(2*angle)
            dirMod = cos(2.0 * angle);
        } else if (anisotropyMode == 2) {
            // 偶极子：cos(angle)
            dirMod = cos(angle);
        }
        
        // 收缩阻尼：收缩效果默认减弱70%，避免视觉上收缩强于膨胀
        float shrinkDamping = 0.3;
        dirMod = dirMod > 0.0 ? dirMod : dirMod * shrinkDamping;
        
        // 混合各向异性强度
        dirMod = mix(1.0, dirMod, anisotropyStrength);
    }
    
    // 散度源: S = -strength * envelope * mask * dirMod
    float S = -strength * envelope * mask * dirMod;
    ```

    **使用示例**:
    ```typescript
    // 四极子各向异性：左右向外，上下向内（收缩已自动减弱）
    simulator.explodeAnisotropic(0.5, 0.5, 0.15, 8000, true, 0.1, 1, 0.0, 1.0);
    
    // 偶极子：右侧膨胀，左侧收缩（相位旋转90°）
    simulator.explodeAnisotropic(0.5, 0.5, 0.15, 8000, true, 0.1, 2, Math.PI/2, 1.0);
    ```

    **参数说明**:
    | 参数 | 类型 | 说明 | 默认值 |
    |------|------|------|--------|
    | `mode` | `number` | 各向异性模式：0=各向同性, 1=四极子, 2=偶极子 | 0 |
    | `phase` | `number` | 相位偏移（弧度） | 0 |
    | `anisoStrength` | `number` | 各向异性强度 (0~1) | 0.0 |

16. **多次爆炸调度改进**:
    - **位置偏移**: 后几次爆炸中心随机偏移 ±0.05，避免完美同心圆
    - **生成策略**: 第一次爆炸生成水（createWater=true），其余仅注入散度（createWater=false）
    - **强度序列**: 斐波那契式递减 [25000, 20000, 15000, 10000, 5000]

```typescript
    private externalForcesShader(): THREE.ShaderMaterial {

                sigma: { value: this.params.surfaceTension },
                density: { value: this.params.density },

                injectionFlowRate: { value: this.params.injectionFlowRate ?? 1.0 },
                injectionVel: { value: new THREE.Vector2(this.params.injectionVelX ?? 0.0, this.params.injectionVelY ?? 0.0) },
                injectionSize: { value: this.params.injectionSize ?? 0.05 }
            },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D velocity;
                uniform sampler2D levelset;
                uniform float gravity;
                uniform float sigma;
                uniform float density;
                uniform float viscosity;
                uniform vec2 resolution;
                uniform float dt;
                uniform bool injectionEnabled;
                uniform vec2 injectionPos;
                uniform float injectionFlowRate;
                uniform vec2 injectionVel;
                uniform float injectionSize;
                varying vec2 vUv;
                void main() {
                    vec2 uv = vUv;
                    float phi = texture2D(levelset, uv).r;
                    vec2 vel = texture2D(velocity, uv).rg;
                    vel.y -= gravity * dt;  // UV坐标系：y=0是底部，y=1是顶部，重力向下应减小vel.y
                    vec2 dx = vec2(1.0/resolution.x, 0.0);
                    vec2 dy = vec2(0.0, 1.0/resolution.y);
                    vec2 vel_r = texture2D(velocity, uv + dx).rg;
                    vec2 vel_l = texture2D(velocity, uv - dx).rg;
                    vec2 vel_t = texture2D(velocity, uv + dy).rg;
                    vec2 vel_b = texture2D(velocity, uv - dy).rg;
                    vec2 laplacian = (vel_r + vel_l + vel_t + vel_b - 4.0*vel) * (resolution.x * resolution.x);
                    float nu = viscosity / density;
                    vel += nu * dt * laplacian;
                    const float eps = 1.5 / resolution.x;
                    if (abs(phi) < eps) {
                        float phi_r = texture2D(levelset, uv + dx).r;
                        float phi_l = texture2D(levelset, uv - dx).r;
                        float phi_t = texture2D(levelset, uv + dy).r;
                        float phi_b = texture2D(levelset, uv - dy).r;
                        vec2 grad = vec2(phi_r - phi_l, phi_t - phi_b) / (2.0 * dx.x);
                        float len = length(grad);
                        if (len > 1e-6) {
                            vec2 n = grad / len;
                            float phi_xx = phi_r + phi_l - 2.0*phi;
                            float phi_yy = phi_t + phi_b - 2.0*phi;
                            float phi_xy = (texture2D(levelset, uv + dx + dy).r
                                          - texture2D(levelset, uv + dx - dy).r
                                          - texture2D(levelset, uv - dx + dy).r
                                          + texture2D(levelset, uv - dx - dy).r) / (4.0 * dx.x * dx.x);
                            float kappa = (phi_xx * n.y * n.y - 2.0 * phi_xy * n.x * n.y + phi_yy * n.x * n.x) / len;
                            float delta = 0.0;
                            if (abs(phi) < eps) delta = (1.0 + cos(3.1415926 * phi / eps)) / (2.0 * eps);
                            vec2 f_st = sigma * kappa * delta * n;
                            vel += (f_st / density) * dt;
                        }
                    }
                    if (injectionEnabled) {
                        float dist = length(uv - injectionPos);
                        if (dist < injectionSize) {
                            float mask = 1.0 - smoothstep(0.0, injectionSize, dist);
                            phi = min(phi, -injectionFlowRate * dt * mask);
                            vel += injectionVel * mask;
                        }
                    }
                    gl_FragColor = vec4(vel, phi, 1.0);
                }
            `
        });
    }

            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D velocity;
                uniform sampler2D solidMask;
                uniform sampler2D solidNormal;
                uniform float restitution;
                uniform float friction;
                uniform vec2 resolution;
                varying vec2 vUv;
                void main() {
                    float isSolid = texture2D(solidMask, vUv).r;
                    if (isSolid < 0.5) {
                        vec2 vel = texture2D(velocity, vUv).rg;
                        gl_FragColor = vec4(vel, 0.0, 1.0);

                    vec2 normal = texture2D(solidNormal, vUv).rg;

                    float vn = dot(vel, normal);
                    vec2 vt = vel - vn * normal;
                    float vn_new = -vn * restitution;
                    vec2 vt_new = vt * friction;
                    vec2 vel_new = vt_new + vn_new * normal;
                    gl_FragColor = vec4(vel_new, 0.0, 1.0);
                }
            `
        });
    }

    // SpMV着色器：计算 q = A * x（A是Poisson矩阵，负拉普拉斯算子）
    private spmvShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { x: { value: null }, levelset: { value: null }, resolution: { value: new THREE.Vector2(this.width, this.height) } },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D x;
                uniform sampler2D levelset;
                uniform vec2 resolution;
                varying vec2 vUv;
                void main() {
                    vec2 uv = vUv;
                    float dx = 1.0 / resolution.x;
                    vec2 dxVec = vec2(dx, 0.0);
                    vec2 dyVec = vec2(0.0, dx);

                    float phi = texture2D(levelset, uv).r;
                    // 空气区域，直接输出0（不参与系统）
                    if (phi > 0.0) { gl_FragColor = vec4(0.0); return; }

                    float xC = texture2D(x, uv).r;
                    float xL = texture2D(x, uv - dxVec).r;
                    float xR = texture2D(x, uv + dxVec).r;
                    float xD = texture2D(x, uv - dyVec).r;
                    float xU = texture2D(x, uv + dyVec).r;

                    // Neumann边界：如果邻居是空气，用当前值代替
                    float phiL = texture2D(levelset, uv - dxVec).r;
                    float phiR = texture2D(levelset, uv + dxVec).r;
                    float phiD = texture2D(levelset, uv - dyVec).r;
                    float phiU = texture2D(levelset, uv + dyVec).r;
                    if (phiL > 0.0) xL = xC;
                    if (phiR > 0.0) xR = xC;
                    if (phiD > 0.0) xD = xC;
                    if (phiU > 0.0) xU = xC;

                    // 标准负拉普拉斯: -∇²x ≈ (4*xC - xL - xR - xD - xU) / (dx*dx)
                    float Ax = (4.0 * xC - xL - xR - xD - xU) / (dx * dx);
                    gl_FragColor = vec4(Ax, 0.0, 0.0, 1.0);
                }
            `
        });
    }

        return new THREE.ShaderMaterial({
            uniforms: { x: { value: null }, y: { value: null }, a: { value: 0.0 } },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D x;
                uniform sampler2D y;
                uniform float a;
                varying vec2 vUv;
                void main() {
                    float xVal = texture2D(x, vUv).r;
                    float yVal = texture2D(y, vUv).r;
                    gl_FragColor = vec4(a * xVal + yVal, 0.0, 0.0, 1.0);
                }
            `
        });
    }

    // 向量缩放着色器：y = a * x
    private scaleShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { x: { value: null }, a: { value: 0.0 } },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D x;
                uniform float a;
                varying vec2 vUv;
                void main() {
                    float xVal = texture2D(x, vUv).r;
                    gl_FragColor = vec4(a * xVal, 0.0, 0.0, 1.0);
                }
            `
        });
    }

    // 计算右侧项着色器：b = (density / dt) * div
    private computeBShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { divergence: { value: null }, density: { value: this.params.density }, dt: { value: this.params.timeStep } },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D divergence;
                uniform float density;
                uniform float dt;
                varying vec2 vUv;
                void main() {
                    float div = texture2D(divergence, vUv).r;
                    float b = (density / dt) * div;
                    gl_FragColor = vec4(b, 0.0, 0.0, 1.0);
                }
            `
        });
    }

    // Jacobi预条件着色器：z = M⁻¹ * r = r / diag(A)，diag(A) = 4/dx²
    private jacobiPreconditionShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { r: { value: null }, resolution: { value: new THREE.Vector2(this.width, this.height) } },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D r;
                uniform vec2 resolution;
                varying vec2 vUv;
                void main() {
                    float dx = 1.0 / resolution.x;
                    float diag = 4.0 / (dx * dx);  // A的对角元
                    float rVal = texture2D(r, vUv).r;
                    float z = rVal / diag;  // z = M⁻¹r = r / diag(A)
                    gl_FragColor = vec4(z, 0.0, 0.0, 1.0);
                }
            `
        });
    }

    // 向量减法着色器：y = x - a * z
    private vecSubShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { x: { value: null }, z: { value: null }, a: { value: 0.0 } },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D x;
                uniform sampler2D z;
                uniform float a;
                varying vec2 vUv;
                void main() {
                    float xVal = texture2D(x, vUv).r;
                    float zVal = texture2D(z, vUv).r;
                    gl_FragColor = vec4(xVal - a * zVal, 0.0, 0.0, 1.0);
                }
            `
        });
    }

    // 向量相乘着色器：out = a * b（用于内积计算）
    private multiplyShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { a: { value: null }, b: { value: null } },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D a;
                uniform sampler2D b;
                varying vec2 vUv;
                void main() {
                    float aVal = texture2D(a, vUv).r;
                    float bVal = texture2D(b, vUv).r;
                    gl_FragColor = vec4(aVal * bVal, 0.0, 0.0, 1.0);
                }
            `
        });
    }

    // 归约着色器：2x2 区域求和（用于内积归约）
    private reduceShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { inputTex: { value: null }, resolution: { value: new THREE.Vector2(this.width, this.height) } },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D inputTex;
                uniform vec2 resolution;
                varying vec2 vUv;
                void main() {
                    vec2 dx = vec2(1.0 / resolution.x, 0.0);
                    vec2 dy = vec2(0.0, 1.0 / resolution.y);
                    
                    // 读取2x2区域的四个像素
                    float v00 = texture2D(inputTex, vUv).r;
                    float v01 = texture2D(inputTex, vUv + dx).r;
                    float v10 = texture2D(inputTex, vUv + dy).r;
                    float v11 = texture2D(inputTex, vUv + dx + dy).r;
                    
                    // 求和
                    float sum = v00 + v01 + v10 + v11;
                    gl_FragColor = vec4(sum, 0.0, 0.0, 1.0);
                }
            `
        });
    }

    // 计算两个向量的内积：dot(a, b) = sum(a_i * b_i)
    // 使用GPU归约：先计算逐像素乘积，然后逐级2x2归约到1x1
    private computeDot(aTex: THREE.WebGLRenderTarget, bTex: THREE.WebGLRenderTarget): number {
        // 创建临时渲染目标（尺寸与原纹理相同）
        const tempTex1 = new THREE.WebGLRenderTarget(this.width, this.height, {
            type: THREE.FloatType,
            format: THREE.RGBAFormat,
            wrapS: THREE.ClampToEdgeWrapping,
            wrapT: THREE.ClampToEdgeWrapping,
            minFilter: THREE.NearestFilter,
            magFilter: THREE.NearestFilter
        });

        // 阶段1: 计算逐像素乘积 a * b
        const multiplyMat = this.multiplyShader();
        multiplyMat.uniforms.a.value = aTex.texture;
        multiplyMat.uniforms.b.value = bTex.texture;
        this.renderFullscreen(multiplyMat, tempTex1);

        // 阶段2: 逐级归约（每次将分辨率减半）
        let currentWidth = this.width;
        let currentHeight = this.height;
        let currentTex = tempTex1;
        const reduceMat = this.reduceShader();

        while (currentWidth > 1 || currentHeight > 1) {
            // 计算下一级分辨率（向上取整）
            const nextWidth = Math.ceil(currentWidth / 2);
            const nextHeight = Math.ceil(currentHeight / 2);

            // 创建下一级渲染目标
            const nextTex = new THREE.WebGLRenderTarget(nextWidth, nextHeight, {
                type: THREE.FloatType,
                format: THREE.RGBAFormat,
                wrapS: THREE.ClampToEdgeWrapping,
                wrapT: THREE.ClampToEdgeWrapping,
                minFilter: THREE.NearestFilter,
                magFilter: THREE.NearestFilter
            });

            // 更新归约着色器的分辨率
            reduceMat.uniforms.resolution.value = new THREE.Vector2(currentWidth, currentHeight);
            reduceMat.uniforms.inputTex.value = currentTex.texture;
            this.renderFullscreen(reduceMat, nextTex);

            // 清理上一级纹理
            if (currentTex !== tempTex1) {
                currentTex.dispose();
            }

            // 移动到下一级
            currentTex = nextTex;
            currentWidth = nextWidth;
            currentHeight = nextHeight;
        }

        // 阶段3: 读取最终的1x1纹理值
        const pixelBuffer = new Float32Array(4);
        this.renderer.readRenderTargetPixels(currentTex, 0, 0, 1, 1, pixelBuffer);
        const dotProduct = pixelBuffer[0];

        // 清理临时纹理
        currentTex.dispose();
        tempTex1.dispose();

        return dotProduct;
    }

    // PCG求解器主方法
    private solvePressurePCG(): void {
        const cgIter = this.params.pressureIterations;
        
        // 1. 计算右侧项 b = (density/dt) * divergence
        const computeBMat = this.computeBShader();
        computeBMat.uniforms.divergence.value = this.divergenceTex.texture;
        this.renderFullscreen(computeBMat, this.bTex);

        // 2. 初始化：p = 0（已有）, r = b, z = M⁻¹r, d = z
        // r = b
        const copyMat = this.copyShader();
        copyMat.uniforms.texture.value = this.bTex.texture;
        this.renderFullscreen(copyMat, this.rTex);

        // z = M⁻¹r
        const precondMat = this.jacobiPreconditionShader();
        precondMat.uniforms.r.value = this.rTex.texture;
        this.renderFullscreen(precondMat, this.zTex);

        // d = z
        copyMat.uniforms.texture.value = this.zTex.texture;
        this.renderFullscreen(copyMat, this.dTex);

        // 计算初始 rz = dot(r, z)
        let rz = this.computeDot(this.rTex, this.zTex);

        const spmvMat = this.spmvShader();
        const axpyMat = this.axpyShader();
        const subMat = this.vecSubShader();

        for (let i = 0; i < cgIter; i++) {
            // 1. q = A * d
            spmvMat.uniforms.x.value = this.dTex.texture;
            spmvMat.uniforms.levelset.value = this.curPhiTex.texture;
            this.renderFullscreen(spmvMat, this.qTex);

            // 2. alpha = rz / dot(d, q)
            let dq = this.computeDot(this.dTex, this.qTex);
            let alpha = rz / dq;

            // 3. p = p + alpha * d
            axpyMat.uniforms.x.value = this.dTex.texture;
            axpyMat.uniforms.y.value = this.curPressureTex.texture;
            axpyMat.uniforms.a.value = alpha;
            this.renderFullscreen(axpyMat, this.pressureTexA);
            this.curPressureTex = this.pressureTexA;

            // 4. r = r - alpha * q
            subMat.uniforms.x.value = this.rTex.texture;
            subMat.uniforms.z.value = this.qTex.texture;
            subMat.uniforms.a.value = alpha;
            this.renderFullscreen(subMat, this.rTex);

            // 5. z_new = M⁻¹ * r
            precondMat.uniforms.r.value = this.rTex.texture;
            this.renderFullscreen(precondMat, this.zTex);

            // 6. beta = dot(r, z) / rz_old
            let rz_new = this.computeDot(this.rTex, this.zTex);
            let beta = rz_new / rz;

            // 7. d = z + beta * d
            axpyMat.uniforms.x.value = this.dTex.texture;
            axpyMat.uniforms.y.value = this.zTex.texture;
            axpyMat.uniforms.a.value = beta;
            this.renderFullscreen(axpyMat, this.dTex);

            // 8. 更新 rz
            rz = rz_new;
        }
    }

    // ==================== PCG求解器结束 ====================

    private velocityCorrectShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { velocity: { value: null }, pressure: { value: null }, dt: { value: this.params.timeStep }, density: { value: this.params.density }, resolution: { value: new THREE.Vector2(this.width, this.height) } },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D velocity;
                uniform sampler2D pressure;
                uniform float dt;
                uniform float density;
                uniform vec2 resolution;
                varying vec2 vUv;
                void main() {
                    vec2 uv = vUv;
                    vec2 dx = vec2(1.0/resolution.x, 0.0);
                    vec2 dy = vec2(0.0, 1.0/resolution.y);
                    float pL = texture2D(pressure, uv - dx).r;
                    float pR = texture2D(pressure, uv + dx).r;
                    float pD = texture2D(pressure, uv - dy).r;
                    float pU = texture2D(pressure, uv + dy).r;
                    vec2 vel = texture2D(velocity, uv).rg;
                    vel.x -= (dt / density) * (pR - pL) / (2.0*dx.x);
                    vel.y -= (dt / density) * (pU - pD) / (2.0*dy.y);
                    gl_FragColor = vec4(vel, 0.0, 1.0);
                }
            `
        });
    }

    private levelSetAdvectionShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { velocity: { value: null }, forcedVel: { value: null }, levelset: { value: null }, dt: { value: this.params.timeStep }, resolution: { value: new THREE.Vector2(this.width, this.height) }, injectionEnabled: { value: this.params.injectionEnabled ?? false } },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D velocity;
                uniform sampler2D forcedVel;
                uniform sampler2D levelset;
                uniform float dt;
                uniform vec2 resolution;
                uniform bool injectionEnabled;
                varying vec2 vUv;
                void main() {
                    vec2 uv = vUv;
                    vec2 vel = texture2D(velocity, uv).rg;
                    vec2 step = vel * dt / resolution;
                    vec2 back = uv - step;
                    float phi;
                    if (injectionEnabled) {
                        phi = texture2D(forcedVel, back).b;
                    } else {
                        phi = texture2D(levelset, back).r;
                    }
                    gl_FragColor = vec4(phi, 0.0, 0.0, 1.0);
                }
            `
        });
    }

    private levelSetReinitShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { levelset: { value: null }, dt_reinit: { value: 0.1 / Math.min(this.width, this.height) }, resolution: { value: new THREE.Vector2(this.width, this.height) } },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D levelset;
                uniform float dt_reinit;
                uniform vec2 resolution;
                varying vec2 vUv;
                void main() {
                    vec2 uv = vUv;
                    float phi0 = texture2D(levelset, uv).r;
                    float dx = 1.0 / resolution.x;
                    float eps = 0.001;

                    // 窄带限制：只重初始化界面附近（abs(phi) < 2*dx）
                    if (abs(phi0) > 2.0 * dx) {
                        gl_FragColor = vec4(phi0, 0.0, 0.0, 1.0);
                        return;
                    }

                    float phi_r = texture2D(levelset, uv + vec2(dx, 0.0)).r;
                    float phi_l = texture2D(levelset, uv - vec2(dx, 0.0)).r;
                    float phi_t = texture2D(levelset, uv + vec2(0.0, dx)).r;
                    float phi_b = texture2D(levelset, uv - vec2(0.0, dx)).r;

                    vec2 grad = vec2(phi_r - phi_l, phi_t - phi_b) / (2.0 * dx);
                    float grad_len = length(grad);

                    float sign_phi0 = phi0 > eps ? 1.0 : (phi0 < -eps ? -1.0 : 1.0);
                    float phi_new = phi0 - dt_reinit * sign_phi0 * (grad_len - 1.0);

                    // 避免符号反转
                    if (sign_phi0 > 0.0 && phi_new < 0.0) phi_new = 0.0;
                    if (sign_phi0 < 0.0 && phi_new > 0.0) phi_new = 0.0;

                    gl_FragColor = vec4(phi_new, 0.0, 0.0, 1.0);
                }
            `
        });
    }

    // ==================== 寿命系统着色器 ====================
    
    // 流体消散着色器：根据年龄将过期流体转为空气
    private dissipationShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { 
                levelset: { value: null }, 
                age: { value: null },
                maxLifetime: { value: this.params.maxLifetime ?? 10.0 }, 
                dt: { value: this.params.timeStep } 
            },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D levelset;
                uniform sampler2D age;
                uniform float maxLifetime;
                uniform float dt;
                varying vec2 vUv;
                void main() {
                    float phi = texture2D(levelset, vUv).r;
                    float currentAge = texture2D(age, vUv).r;
                    
                    // 只有当 maxLifetime > 0 且水的年龄超过最大寿命时才消散
                    if (maxLifetime > 0.0 && phi < 0.0 && currentAge >= maxLifetime) {
                        phi = 0.1; // 将水变回空气
                    }
                    
                    gl_FragColor = vec4(phi, 0.0, 0.0, 1.0);
                }
            `
        });
    }

    // 年龄更新着色器：增加水粒子年龄，注入区域重置为0
    private ageUpdateShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { 
                age: { value: null },
                levelset: { value: null },
                dt: { value: this.params.timeStep },
                injectionEnabled: { value: this.params.injectionEnabled ?? false },
                injectionPos: { value: new THREE.Vector2(this.params.injectionPosX ?? 0.5, this.params.injectionPosY ?? 0.5) },
                injectionSize: { value: this.params.injectionSize ?? 0.05 }
            },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D age;
                uniform sampler2D levelset;
                uniform float dt;
                uniform bool injectionEnabled;
                uniform vec2 injectionPos;
                uniform float injectionSize;
                varying vec2 vUv;
                void main() {
                    float currentAge = texture2D(age, vUv).r;
                    float phi = texture2D(levelset, vUv).r;
                    
                    // 如果是注入区域，重置年龄为0
                    if (injectionEnabled) {
                        float dist = length(vUv - injectionPos);
                        if (dist < injectionSize && phi < 0.0) {
                            currentAge = 0.0;
                        }
                    }
                    
                    // 水粒子年龄增加（使用真实时间增量）
                    if (phi < 0.0) {
                        currentAge += dt;
                    } else {
                        currentAge = 0.0; // 空气区域年龄为0
                    }
                    
                    gl_FragColor = vec4(currentAge, 0.0, 0.0, 1.0);
                }
            `
        });
    }

    // 年龄平流着色器：让年龄跟随水流移动（关键：追踪水滴而非像素）
    private ageAdvectionShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { 
                age: { value: null },
                velocity: { value: null },
                levelset: { value: null },
                dt: { value: this.params.timeStep },
                resolution: { value: new THREE.Vector2(this.width, this.height) }
            },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D age;
                uniform sampler2D velocity;
                uniform sampler2D levelset;
                uniform float dt;
                uniform vec2 resolution;
                varying vec2 vUv;
                void main() {
                    float phi = texture2D(levelset, vUv).r;
                    
                    // 如果是空气，年龄为0
                    if (phi >= 0.0) {
                        gl_FragColor = vec4(0.0, 0.0, 0.0, 1.0);
                        return;
                    }
                    
                    // 获取当前速度
                    vec2 vel = texture2D(velocity, vUv).rg;
                    
                    // 计算反向追踪位置（与速度平流保持一致：vel * dt / resolution）
                    vec2 step = vel * dt / resolution;
                    vec2 prevPos = vUv - step;
                    
                    // 边界检查：确保采样位置在纹理范围内
                    prevPos = clamp(prevPos, vec2(0.0), vec2(1.0));
                    
                    // 采样该位置的年龄（跟随水流移动）
                    float prevAge = texture2D(age, prevPos).r;
                    
                    gl_FragColor = vec4(prevAge, 0.0, 0.0, 1.0);
                }
            `
        });
    }

    // ==================== 寿命系统结束 ====================

    private solidBoundaryClearShader(): THREE.ShaderMaterial {
        return new THREE.ShaderMaterial({
            uniforms: { velInput: { value: null }, phiInput: { value: null }, solidMask: { value: null } },
            vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
            fragmentShader: `
                uniform sampler2D velInput;
                uniform sampler2D phiInput;
                uniform sampler2D solidMask;
                varying vec2 vUv;
                void main() {
                    float isSolid = texture2D(solidMask, vUv).r;
                    vec2 vel = texture2D(velInput, vUv).rg;
                    float phi = texture2D(phiInput, vUv).r;
                    if (isSolid > 0.5) {
                        vel = vec2(0.0);
                        phi = 1.0;  // 固体内部视为空气，彻底排除流体模拟
                    }
                    gl_FragColor = vec4(vel, phi, 1.0);
                }
            `
        });
    }

    // ==================== 更新流程 ====================
    public update(deltaTime?: number): void {
        if (!this.initialized) return;
        let dt = this.params.timeStep;
        if (deltaTime !== undefined) dt = Math.min(deltaTime, 0.033);

        const resolution = new THREE.Vector2(this.width, this.height);
        const dtReinit = 0.5 / Math.min(this.width, this.height);

        // 辅助函数：更新材质 uniform 中的 dt 和 resolution
        const updateDtRes = (mat: THREE.ShaderMaterial) => {
            if (mat.uniforms.dt) mat.uniforms.dt.value = dt;
            if (mat.uniforms.resolution) mat.uniforms.resolution.value = resolution;
            if (mat.uniforms.dt_reinit) mat.uniforms.dt_reinit.value = dtReinit;
            if (mat.uniforms.injectionEnabled) mat.uniforms.injectionEnabled.value = this.params.injectionEnabled ?? false;
            if (mat.uniforms.injectionPos) {
                mat.uniforms.injectionPos.value.set(this.params.injectionPosX ?? 0.5, this.params.injectionPosY ?? 0.5);
            }
            if (mat.uniforms.injectionFlowRate) mat.uniforms.injectionFlowRate.value = this.params.injectionFlowRate ?? 1.0;
            if (mat.uniforms.injectionVel) {
                mat.uniforms.injectionVel.value.set(this.params.injectionVelX ?? 0.0, this.params.injectionVelY ?? 0.0);
            }
            if (mat.uniforms.injectionSize) mat.uniforms.injectionSize.value = this.params.injectionSize ?? 0.05;
        };

        // 1. 固体边界清理 #1（如果需要）
        if (this.solidMaskTex) {
            const clearMat = this.solidBoundaryClearShader();
            updateDtRes(clearMat);
            this.renderFullscreen(clearMat, { velInput: this.curVelTex.texture, phiInput: this.curPhiTex.texture, solidMask: this.solidMaskTex }, this.velTexA);
            this.renderFullscreen(clearMat, { velInput: this.curVelTex.texture, phiInput: this.curPhiTex.texture, solidMask: this.solidMaskTex }, this.phiTexA);
            // 交换：更新 curVelTex 和 curPhiTex 指向清理后的
            this.curVelTex = this.velTexA;
            this.curPhiTex = this.phiTexA;
            clearMat.dispose();
        }

        // 2. 速度平流
        const advectMat = this.velocityAdvectionShader();
        updateDtRes(advectMat);
        this.renderFullscreen(advectMat, { velocity: this.curVelTex.texture }, this.velTexB);
        this.curVelTex = this.velTexB; // 交换：velTexB 成为当前速度
        advectMat.dispose();

        // 3. 外力计算
        const forceMat = this.externalForcesShader();
        updateDtRes(forceMat);
        this.renderFullscreen(forceMat, { velocity: this.curVelTex.texture, levelset: this.curPhiTex.texture }, this.forcedVelTex);
        forceMat.dispose();

        // 4. 墙碰撞处理
        let velForDiv = this.forcedVelTex.texture;
        if (this.solidMaskTex && this.solidNormalTex) {
            const collideMat = this.wallCollisionShader();
            updateDtRes(collideMat);
            this.renderFullscreen(collideMat, { velocity: this.forcedVelTex.texture, solidMask: this.solidMaskTex, solidNormal: this.solidNormalTex }, this.velAfterCollisionTex);
            velForDiv = this.velAfterCollisionTex.texture;
            collideMat.dispose();
        }

        // 5. 散度
        const divMat = this.divergenceShader();
        updateDtRes(divMat);
        this.renderFullscreen(divMat, { velocity: velForDiv }, this.divergenceTex);
        divMat.dispose();

        // 6. 压力迭代 (Jacobi, 双缓冲)
        let pressureSrc = this.pressureTexA;
        let pressureDst = this.pressureTexB;
        for (let i = 0; i < this.params.pressureIterations; i++) {
            const jacobiMat = this.pressureJacobiShader();
            updateDtRes(jacobiMat);
            this.renderFullscreen(jacobiMat, { pressure: pressureSrc.texture, divergence: this.divergenceTex.texture }, pressureDst);
            jacobiMat.dispose();
            // 交换
            [pressureSrc, pressureDst] = [pressureDst, pressureSrc];
        }
        this.curPressureTex = pressureSrc; // 最终压力

        // 7. 速度修正
        const correctMat = this.velocityCorrectShader();
        updateDtRes(correctMat);
        this.renderFullscreen(correctMat, { velocity: velForDiv, pressure: this.curPressureTex.texture }, this.velCorrectTex);
        correctMat.dispose();
        this.curVelTex = this.velCorrectTex; // 更新当前速度场为修正后的

        // 8. Level Set 平流
        const phiAdvectMat = this.levelSetAdvectionShader();
        updateDtRes(phiAdvectMat);
        this.renderFullscreen(phiAdvectMat, { velocity: this.curVelTex.texture, forcedVel: this.forcedVelTex.texture, levelset: this.curPhiTex.texture }, this.phiTexB);
        this.curPhiTex = this.phiTexB;
        phiAdvectMat.dispose();

        // 8.5. 流体寿命系统（当 maxLifetime > 0 时启用）⭐ 新增
        if (this.params.maxLifetime && this.params.maxLifetime > 0) {
            // 使用真实时间增量更新年龄（_deltaTime 可能是真实时间，也可能是默认的 timeStep）
            const realDelta = _deltaTime ?? this.params.timeStep;
            
            // ==================== 步骤1: 年龄平流 ====================
            // 关键：通过反向追踪速度场，让年龄跟随水滴移动（而非固定在像素上）
            const ageAdvectionDst = this.curAgeTex === this.ageTexA ? this.ageTexB : this.ageTexA;
            this.ageAdvectionMat.uniforms.age.value = this.curAgeTex.texture;
            this.ageAdvectionMat.uniforms.velocity.value = this.curVelTex.texture;
            this.ageAdvectionMat.uniforms.levelset.value = this.curPhiTex.texture;
            this.ageAdvectionMat.uniforms.dt.value = this.params.timeStep;  // 物理步长用于平流
            this.renderFullscreen(this.ageAdvectionMat, ageAdvectionDst);
            this.curAgeTex = ageAdvectionDst;

            // ==================== 步骤2: 年龄更新 ====================
            // 使用真实时间增量更新所有水区域的年龄，注入区域重置为0
            const ageUpdateDst = this.curAgeTex === this.ageTexA ? this.ageTexB : this.ageTexA;
            this.ageUpdateMat.uniforms.age.value = this.curAgeTex.texture;
            this.ageUpdateMat.uniforms.levelset.value = this.curPhiTex.texture;
            this.ageUpdateMat.uniforms.injectionEnabled.value = this.params.injectionEnabled ?? false;
            this.ageUpdateMat.uniforms.injectionPos.value.set(
                this.params.injectionPosX ?? 0.5,
                this.params.injectionPosY ?? 0.5
            );
            this.ageUpdateMat.uniforms.injectionSize.value = this.params.injectionSize ?? 0.05;
            this.ageUpdateMat.uniforms.dt.value = realDelta;  // 使用真实时间增量（关键！）
            this.renderFullscreen(this.ageUpdateMat, ageUpdateDst);
            this.curAgeTex = ageUpdateDst;

            // ==================== 步骤3: 流体消散 ====================
            // 年龄达到 maxLifetime 的水粒子转为空气
            // 使用双缓冲避免读写冲突
            const dissipationDst = this.curPhiTex === this.phiTexA ? this.phiTexB : this.phiTexA;
            this.dissipationMat.uniforms.levelset.value = this.curPhiTex.texture;
            this.dissipationMat.uniforms.age.value = this.curAgeTex.texture;
            this.renderFullscreen(this.dissipationMat, dissipationDst);
            this.curPhiTex = dissipationDst;
        }

        // 9. Level Set 重初始化（双缓冲交替）
        let phiSrc = this.curPhiTex;
        let phiDst = phiSrc === this.phiTexA ? this.phiTexB : this.phiTexA;
        for (let i = 0; i < this.params.reinitIterations; i++) {
            const reinitMat = this.levelSetReinitShader();
            updateDtRes(reinitMat);
            this.renderFullscreen(reinitMat, { levelset: phiSrc.texture }, phiDst);
            [phiSrc, phiDst] = [phiDst, phiSrc];  // 交换
            reinitMat.dispose();
        }
        this.curPhiTex = phiSrc;

        // 10. 固体边界清理 #2 (再次清理)
        if (this.solidMaskTex) {
            const clearMat = this.solidBoundaryClearShader();
            updateDtRes(clearMat);
            this.renderFullscreen(clearMat, { velInput: this.curVelTex.texture, phiInput: this.curPhiTex.texture, solidMask: this.solidMaskTex }, this.velTexA);
            this.renderFullscreen(clearMat, { velInput: this.curVelTex.texture, phiInput: this.curPhiTex.texture, solidMask: this.solidMaskTex }, this.phiTexA);
            this.curVelTex = this.velTexA;
            this.curPhiTex = this.phiTexA;
            clearMat.dispose();
        }

        // ========== 调试录制 ==========
        if (this.debugRecordingEnabled && this.debugCurrentFrame < this.debugFramesToRecord) {
            this.captureCurrentState();
            this.debugCurrentFrame++;
            if (this.debugCurrentFrame >= this.debugFramesToRecord) {
                this.debugRecordingEnabled = false;
                this.downloadDebugData();
            }
        }
    }

    public setSolidMaskTexture(texture: THREE.Texture | null): void {
        this.solidMaskTex = texture;
        if (texture && !this.solidNormalTex) {
            // 计算法线纹理（预计算）
            const w = this.width, h = this.height;
            const canvas = document.createElement('canvas');
            canvas.width = w;
            canvas.height = h;
            const ctx = canvas.getContext('2d')!;
            ctx.drawImage(texture.image as HTMLImageElement, 0, 0, w, h);
            const imgData = ctx.getImageData(0, 0, w, h);
            const data = new Float32Array(w * h * 4);
            const getSolid = (x: number, y: number) => {
                if (x < 0 || x >= w || y < 0 || y >= h) return 0;
                const idx = (y * w + x) * 4;
                return imgData.data[idx] > 128 ? 1 : 0;
            };
            for (let y = 0; y < h; y++) {
                for (let x = 0; x < w; x++) {
                    const solid_r = getSolid(x+1, y);
                    const solid_l = getSolid(x-1, y);
                    const solid_t = getSolid(x, y+1);
                    const solid_b = getSolid(x, y-1);
                    let nx = solid_r - solid_l;
                    let ny = solid_t - solid_b;
                    const len = Math.hypot(nx, ny);
                    if (len > 0.001) { nx /= len; ny /= len; }
                    const idx = (y * w + x) * 4;
                    data[idx] = nx; data[idx+1] = ny; data[idx+2] = 0; data[idx+3] = 1;
                }
            }
            const normalTex = new THREE.DataTexture(data, w, h, THREE.RGBAFormat, THREE.FloatType);
            normalTex.needsUpdate = true;
            this.solidNormalTex = normalTex;
        }
    }
```

### 核心改进

1. **移除 GPUComputationRenderer 依赖**
   - 直接使用 `WebGLRenderTarget` 和 `ShaderMaterial`

3. **统一的渲染流程**
   - `renderFullscreen()` 方法处理所有渲染操作
   - 自动管理渲染目标切换
   - 统一的 uniform 设置方式

4. **性能优化**
   - 场景、相机、几何体复用
   - 着色器使用后立即 dispose
   - 固体法线预计算（仅一次）

### 分层渲染架构

本库采用**分层渲染架构**将水体颜色计算拆解为多个独立层，各层使用合理的混合方式组合，最终叠加形成最终颜色。这种架构避免了传统方式中所有效果直接累加导致的颜色过曝、整体发白问题。

#### 分层架构图

```
        ┌─────────────────────────────────────┐
        │     Layer 1: 基础颜色层              │
        │     Base Color Layer                │
        │                                     │
        │  depth = clamp(-phi * 2.0, 0, 1)   │
        │  baseColor = mix(waterColor,       │
        │               deepColor, depth)     │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     Layer 2: 漫反射光照层             │
        │     Diffuse Lighting Layer          │
        │                                     │
        │  normal = normalize(∇phi)          │
        │  diff = max(0.1, dot(normal, L))   │
        │  diffuse = baseColor × diff        │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     Layer 3: 高光层                  │
        │     Specular Lighting Layer          │
        │                                     │
        │  viewDir = (0, 0, 1)               │
        │  halfDir = normalize(L + viewDir)   │
        │  spec = pow(max(dot(n,h),0), 64)   │
        │  specular = white × spec ×         │
        │             specularIntensity       │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     Layer 4: 边缘发光层              │
        │     Edge Glow / Emissive Layer      │
        │                                     │
        │  edge = 1 - smoothstep(0, edgeW,    │
        │                    abs(phi))         │
        │  glowColor = vec3(0.2, 0.6, 1.0)   │
        │  emissive = glowColor × edge ×      │
        │             edgeIntensity            │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     Layer 5: 流动扰动层              │
        │     Flow Detail Layer               │
        │                                     │
        │  flow = length(velocity) × 0.5     │
        │  flowColor = vec3(0.15, 0.25,      │
        │               0.35) × flow ×        │
        │               flowIntensity          │
        └─────────────────┬───────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐
        │     最终合成                         │
        │     Final Composition               │
        │                                     │
        │  finalColor = diffuse + specular +  │
        │               emissive + flowColor  │
        │                                     │
        │  alpha = clamp(0.6 - phi*2, 0.2,    │
        │              0.9)                    │
        └─────────────────────────────────────┘
```

#### 各层说明

| 层名称 | 内容 | 混合方式 | 说明 |
|--------|------|----------|------|
| Base Color | 水体的基础颜色 | 直接输出 | 根据深度混合浅蓝和深蓝 |
| Diffuse Lighting | 漫反射光照 | 乘以基础色 | 决定水体明暗，不添加额外颜色 |
| Specular | 高光反射 | 最后添加 | 白色高光，可独立控制强度 |
| Emissive | 边缘发光 | 最后叠加 | 仅在水面附近生效，不参与漫反射 |
| Flow Detail | 流动扰动 | 作为细节 | 不大面积改变色调 |

#### 最终合成公式

```
finalColor = diffuse + specular + emissive + flowColor
           = (baseColor × diff) + (white × spec × specInt) + 
             (glowColor × edge × edgeInt) + (flowBaseColor × flow × flowInt)

alpha = clamp(0.6 - phi × 2.0, 0.2, 0.9)
```

#### 分层渲染优势

1. **互不干扰**：漫反射、高光、发光互相独立，修改边缘光强度不会影响光照强度
2. **易于调试**：可以暂时关闭某一层来观察其它层效果
3. **可扩展**：未来增加屏幕空间反射、折射等效果，只需额外添加层，不影响已有层
4. **性能不变**：依然是一次绘制，只是计算逻辑更清晰

#### 问题分析

原始片段着色器中，所有效果直接累加到 color：

```glsl
vec3 color = baseColor * diff;      // 漫反射
color += flowColor;                  // 流动
color += edgeColor * edgeIntensity;  // 边缘光
```

这会导致颜色越来越亮，整体发白，且各层互相干扰。

#### 具体实现

**1. 修改 FluidSimulatorAdapter.ts 的 uniforms**

在构造函数中，增加两个新 uniform：

```typescript
uniforms: {
    // ... 原有
    specularIntensity: { value: 0.5 },   // 高光强度
    flowIntensity: { value: 0.3 },       // 流动扰动强度
}
```

**2. 重写片段着色器（分层合成）**

将原来的片段着色器替换为以下代码（保留 `computeNormal` 函数不变）：

```glsl
uniform sampler2D phiTex;
uniform sampler2D velTex;
uniform float time;
uniform vec2 resolution;
uniform vec3 lightDir;
uniform vec3 waterColor;
uniform vec3 deepColor;
uniform float edgeWidth;
uniform float edgeIntensity;
uniform float specularIntensity;   // 新增
uniform float flowIntensity;       // 新增

varying vec2 vUv;

vec3 computeNormal(vec2 uv, float eps) {
    // ... 保持不变
}

void main() {
    float phi = texture2D(phiTex, vUv).r;
    if (phi >= 0.0) discard;   // 空气和界面（phi = 0）完全透明

    float eps = 1.0 / resolution.x;
    vec3 normal = computeNormal(vUv, eps);
    vec3 viewDir = vec3(0.0, 0.0, 1.0);
    vec3 lightDirNorm = normalize(lightDir);

    // ========== 1. 基础颜色层 ==========
    float depth = clamp(-phi * 2.0, 0.0, 1.0);
    vec3 baseColor = mix(waterColor, deepColor, depth);

    // ========== 2. 漫反射光照层 ==========
    float diff = max(0.1, dot(normal, lightDirNorm));
    vec3 diffuse = baseColor * diff;

    // ========== 3. 高光层（独立） ==========
    vec3 halfDir = normalize(lightDirNorm + viewDir);
    float spec = pow(max(dot(normal, halfDir), 0.0), 64.0);
    vec3 specular = vec3(1.0) * spec * specularIntensity;

    // ========== 4. 边缘发光层 ==========
    float edge = 1.0 - smoothstep(0.0, edgeWidth, abs(phi));
    vec3 glowColor = vec3(0.2, 0.6, 1.0);   // 淡蓝色
    vec3 emissive = glowColor * edge * edgeIntensity;

    // ========== 5. 流动扰动层 ==========
    vec2 vel = texture2D(velTex, vUv).rg;
    float flow = length(vel) * 0.5;
    vec3 flowColor = vec3(0.15, 0.25, 0.35) * flow * flowIntensity;

    // ========== 最终合成 ==========
    vec3 color = diffuse + specular + emissive + flowColor;

    // 透明度（边缘稍透，中心不透明）
    float alpha = clamp(0.6 - phi * 2.0, 0.2, 0.9);

    gl_FragColor = vec4(color, alpha);
}
```

**3. 调整混合模式**

材质应使用 `NormalBlending`（或保持原有 `AdditiveBlending`，但建议改为 `NormalBlending` 以获得更干净的颜色）：

```typescript
blending: THREE.NormalBlending,
transparent: true,
```

#### 各层职责与优势

| 层 | 内容 | 独立控制 | 说明 |
|----|------|----------|------|
| 基础色 | 深度渐变 | 通过 waterColor/deepColor | 不受光照影响 |
| 漫反射 | 基础色 × 法线点积 | 随光照变化 | 决定明暗 |
| 高光 | 白色 × 高光强度 | specularIntensity | 独立控制镜面反射 |
| 边缘光 | 淡蓝色 × 边缘强度 | edgeIntensity | 仅界面附近 |
| 流动扰动 | 深灰色 × 流速强度 | flowIntensity | 增加细节，不冲淡主色 |

分层后：修改 `edgeIntensity` 不会影响漫反射亮度，调整 `specularIntensity` 不会让水体发白，各层互不干扰，最终颜色自然通透。

### 关键接口

#### 核心接口

| 方法 | 说明 |
|------|------|
| `getLevelSetTexture()` | 获取当前 Level Set 纹理 |
| `getVelocityTexture()` | 获取当前速度场纹理 |
| `setSolidMaskTexture()` | 设置固体掩码（自动计算法线） |
| `setLevelSetTexture()` | 设置自定义 Level Set |
| `dispose()` | 释放资源 |

#### 注入控制接口

| 方法 | 说明 |
|------|------|
| `setInjectionEnabled()` | 启用/禁用流体注入 |
| `setInjectionPosition()` | 设置注入位置 |
| `setInjectionFlowRate()` | 设置注入流量 |
| `setInjectionVelocity()` | 设置注入速度 |
| `setInjectionSize()` | 设置注入区域大小 |
| `configureInjection()` | 批量配置注入参数 |

#### 分层渲染接口

| 方法 | 说明 |
|------|------|
| `getRenderMaterial()` | 获取分层渲染材质（自动更新纹理引用） |
| `updateRenderUniforms()` | 更新渲染材质的纹理引用 |
| `setWaterColor(color)` | 设置水面颜色 |
| `setDeepColor(color)` | 设置深水颜色 |
| `setEdgeIntensity(intensity)` | 设置边缘发光强度 |
| `setSpecularIntensity(intensity)` | 设置高光强度 |
| `setFlowIntensity(intensity)` | 设置流动扰动强度 |
| `setLightDirection(dir)` | 设置光照方向 |

#### 分层渲染参数（FluidParams）

| 参数 | 类型 | 默认值 | 说明 |
